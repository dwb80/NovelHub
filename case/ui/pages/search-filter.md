# 搜索筛选测试用例

## 测试概述

**测试目标**: 验证搜索功能和筛选条件的正确性，包括关键词搜索、分类筛选、排序等
**测试范围**: 搜索框、搜索结果页、筛选条件、排序方式、搜索历史
**关联需求**: SD-SCH-001, SD-SCH-002, SD-CAT-001, SD-TAG-001, F-005

---

## 测试用例列表

### TC-UI-SF-001: 关键词搜索基础功能

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-SF-001 |
| **用例名称** | 关键词搜索基础功能 |
| **前置条件** | 1. 用户已访问搜索页面<br>2. 搜索索引已建立 |
| **优先级** | P0 |
| **所属需求** | SD-SCH-001, F-005 |

**测试步骤**:
1. 在搜索框输入关键词"科幻"
2. 点击搜索按钮
3. 验证搜索结果展示
4. 检查搜索关键词高亮
5. 验证结果相关性

**预期结果**:
- 搜索响应时间<=1秒
- 返回匹配的小说列表
- 关键词在标题、简介中高亮显示
- 显示搜索结果数量
- 无结果时显示推荐内容
