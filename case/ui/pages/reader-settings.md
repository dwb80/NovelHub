# 阅读器设置测试用例

## 测试概述

**测试目标**: 验证阅读器的各项设置功能，包括字体、主题、行高、翻页等个性化配置
**测试范围**: 阅读器设置面板、字体调节、主题切换、行高调整、翻页设置
**关联需求**: HU-PER-001, HU-PER-003, ACC-ELD-001, ACC-VIS-004

---

## 测试用例列表

### TC-UI-RS-001: 字体大小调节-7级档位

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-RS-001 |
| **用例名称** | 字体大小7级档位调节 |
| **前置条件** | 1. 用户已进入阅读器页面<br>2. 设置面板可访问 |
| **优先级** | P0 |
| **所属需求** | HU-PER-001, ACC-ELD-001 |

**测试步骤**:
1. 打开阅读器设置面板
2. 点击字体大小减小按钮（-）
3. 依次调节到12px, 14px, 16px, 18px, 20px, 22px, 24px
4. 点击字体大小增大按钮（+）
5. 验证每档字体变化

**预期结果**:
- 7级字体大小：12px, 14px, 16px, 18px, 20px, 22px, 24px
- 默认字体为16px
- 每档切换时内容实时重排
- 字体大小持久化保存
- 超出范围时按钮禁用

- 设置自动同步到云端
- 不同设备上设置保持一致
- 同步延迟不超过5秒
- 离线时本地保存，联网后同步
- 同步冲突时以最新修改为准
