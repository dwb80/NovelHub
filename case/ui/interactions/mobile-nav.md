# 移动端导航测试用例

## 测试概述

**测试目标**: 验证移动端导航交互功能，包括汉堡菜单、下拉菜单、模态框等
**测试范围**: 响应式导航、触摸交互、手势操作、移动端适配
**关联需求**: UI-MOB-001, UI-NAV-001, UI-TOU-001, UI-GES-001

---

## 测试用例列表

### TC-UI-MOB-001: 汉堡菜单展开/收起

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-MOB-001 |
| **用例名称** | 汉堡菜单展开/收起 |
| **前置条件** | 1. 使用移动设备或模拟移动视口（<768px）<br>2. 页面已加载 |
| **优先级** | P0 |
| **所属需求** | UI-MOB-001 |

**测试步骤**:
1. 在移动端视口打开网站首页
2. 点击汉堡菜单图标（三条横线）
3. 观察菜单展开动画
4. 点击菜单外部区域
5. 再次点击汉堡菜单图标

**预期结果**:
- 汉堡菜单图标正确显示在导航栏右侧
- 点击后菜单从右侧滑入，动画流畅（<300ms）
- 菜单外部区域显示半透明遮罩
- 点击遮罩或再次点击图标，菜单滑出关闭
- 菜单项可点击跳转

| **用例名称** | 下拉菜单触摸交互 |

| **优先级** | P0 |
| **所属需求** | UI-TOU-001 |

**测试步骤**:
1. 点击下拉菜单触发按钮
2. 观察下拉菜单展开
3. 点击菜单项
4. 测试快速双击
5. 测试滑动关闭

**预期结果**:
- 点击触发按钮，下拉菜单正确展开
- 菜单项文字大小适合触摸（>=44px）
- 点击菜单项执行对应操作
- 快速双击不会导致异常
- 向下滑动可关闭下拉菜单

### TC-UI-MOB-003: 模态框移动端适配

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-MOB-003 |
| **用例名称** | 模态框移动端适配 |
| **前置条件** | 1. 使用移动设备或模拟移动视口<br>2. 存在触发模态框的操作 |
| **优先级** | P0 |
| **所属需求** | UI-MOB-001 |

**测试步骤**:
1. 触发模态框显示（如登录、设置）
2. 观察模态框位置和大小
3. 测试模态框内滚动
4. 点击关闭按钮
5. 点击遮罩层关闭

**预期结果**:
- 模态框宽度适配屏幕（左右留边距16px）
- 模态框垂直居中或底部固定
- 内容超出时可独立滚动
- 关闭按钮清晰可见（>=44px）
- 点击遮罩层或关闭按钮，模态框消失

### TC-UI-MOB-005: 手势滑动导航

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-MOB-005 |
| **用例名称** | 手势滑动导航 |
| **前置条件** | 1. 使用移动设备或模拟移动视口<br>2. 支持手势操作的页面 |
| **优先级** | P1 |
| **所属需求** | UI-GES-001 |

**测试步骤**:
1. 从屏幕左侧边缘向右滑动
2. 观察侧边栏是否展开
3. 从屏幕右侧向左滑动关闭
4. 测试快速滑动和慢速滑动
5. 测试斜向滑动

**预期结果**:
- 从左侧边缘右滑展开侧边导航
- 滑动距离超过50%屏幕宽度时自动展开
- 从右向左滑动关闭侧边栏
- 滑动动画跟随手指，流畅无卡顿
- 斜向滑动不触发导航
