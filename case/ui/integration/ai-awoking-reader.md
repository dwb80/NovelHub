# AI觉醒之路阅读器集成测试用例

## 测试概述

**测试目标**: 验证AI觉醒之路专题阅读器的文件路径一致性、动态内容加载、数据一致性
**测试范围**: reader.html、index.html、chapter_01.html ~ chapter_11.html
**关联页面**: 
- `html/pages/novel/ai-awoking/index.html`
- `html/pages/novel/ai-awoking/reader.html`
- `html/pages/novel/ai-awoking/chapter_01.html` ~ `chapter_11.html`

---

## 测试用例列表

### TC-UI-AI-001: 文件路径一致性验证

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-AI-001 |
| **用例名称** | AI觉醒之路阅读器文件路径一致性验证 |
| **前置条件** | 1. 项目文件完整<br>2. 可以访问文件系统或网络 |
| **优先级** | P0 |
| **所属需求** | F-006 (阅读器功能) |

**测试步骤**:
1. 打开 `reader.html` 源代码
2. 检查 `chapters` 数组中的 `file` 属性
3. 记录所有引用的文件路径
4. 验证实际文件是否存在
5. 验证文件格式（扩展名）
6. 验证文件路径格式（相对路径）

**预期结果**:
- ✅ 文件路径应为 `chapter_XX.html` 格式
- ✅ 所有引用的文件都存在（chapter_01.html ~ chapter_11.html）
- ✅ 文件格式为 `.html` 而非 `.txt`
- ✅ 文件在同一目录下，无子目录

**验证点**:
- [ ] reader.html 中的文件路径正确
- [ ] 所有11个章节文件都存在
- [ ] 文件扩展名一致
- [ ] 无 `chapters/` 子目录引用
- [ ] 无 `.txt` 文件引用

**失败场景**:
- ❌ 引用 `chapters/chapter_01.txt` 等不存在的文件
- ❌ 文件扩展名不匹配（.txt vs .html）
- ❌ 文件路径指向错误目录

### TC-UI-AI-003: 动态内容加载格式验证

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-AI-003 |
| **用例名称** | AI觉醒之路动态内容加载格式验证 |
| **前置条件** | 1. reader.html 可访问<br>2. chapter_01.html 存在 |
| **优先级** | P0 |
| **所属需求** | F-006 (阅读器功能) |

**测试步骤**:
1. 打开 `reader.html?chapter=1`
2. 观察章节内容加载过程
3. 检查是否正确解析HTML格式
4. 检查内容样式是否保留
5. 检查段落格式是否正确
6. 检查是否有加载错误

**预期结果**:
- ✅ 成功加载 chapter_01.html 内容
- ✅ 正确解析HTML格式（非纯文本）
- ✅ 保留原有CSS样式
- ✅ 段落格式正确（首行缩进、行高等）
- ✅ 无JavaScript错误

**验证点**:
- [ ] fetch() 成功获取HTML文件
- [ ] 使用 DOMParser 解析HTML
- [ ] 提取 `.chapter-content` 或 `main` 容器内容
- [ ] 保留段落样式（class="chapter-content"）
- [ ] 内容显示正常，无乱码

**失败场景**:
- ❌ 尝试按文本文件解析HTML
- ❌ 内容样式丢失
- ❌ 段落格式错乱
- ❌ JavaScript报错

### TC-UI-AI-004: 章节导航功能验证

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-AI-004 |
| **用例名称** | AI觉醒之路章节导航功能验证 |
| **前置条件** | 1. reader.html 可访问<br>2. 所有章节文件存在 |
| **优先级** | P1 |
| **所属需求** | F-006 (阅读器功能) |

**测试步骤**:
1. 打开 `reader.html?chapter=1`
2. 点击"下一章"按钮
3. 验证是否跳转到第2章
4. 检查URL是否更新为 `?chapter=2`
5. 检查内容是否更新
6. 点击"上一章"按钮
7. 验证是否返回第1章
8. 测试边界情况（第1章点击上一章，第11章点击下一章）

**预期结果**:
- ✅ 下一章按钮正确跳转到下一章
- ✅ 上一章按钮正确返回上一章
- ✅ URL参数正确更新
- ✅ 内容正确加载
- ✅ 第1章时"上一章"按钮禁用
- ✅ 第11章时"下一章"按钮禁用

**验证点**:
- [ ] 下一章导航正常
- [ ] 上一章导航正常
- [ ] URL更新正确
- [ ] 内容更新正确
- [ ] 边界按钮禁用状态正确

**失败场景**:
- ❌ 导航按钮无响应
- ❌ 跳转到错误章节
- ❌ URL未更新
- ❌ 边界按钮未禁用

**预期结果**:
- ✅ "开始阅读"按钮链接到 `chapter_01.html`（不是 reader.html 或错误路径）
- ✅ 点击后正确跳转到 chapter_01.html
- ✅ chapter_01.html 页面无404错误
- ✅ 章节内容正确渲染

- ✅ 可以连续阅读到 chapter_02.html

- [ ] 开始阅读按钮链接地址正确（`href="chapter_01.html"`）
- [ ] 点击后URL正确（`.../ai-awoking/chapter_01.html`）
- [ ] 页面HTTP状态码200
- [ ] 章节标题正确显示
- [ ] 章节内容正确显示
- [ ] 下一章按钮存在且可点击
- [ ] 下一章跳转正确

**失败场景**:
- ❌ 开始阅读按钮链接到不存在的页面（如 reader.html）
- ❌ 链接路径错误（如 `chapters/chapter_01.html`）
- ❌ 404错误
- ❌ 页面加载后无内容
- ❌ 无法导航到下一章
