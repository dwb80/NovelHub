# 阅读流程测试用例

## 测试概述

**测试目标**: 验证用户从发现小说到完成阅读的完整流程体验
**测试范围**: 发现小说、加入书架、阅读章节、进度保存、追更通知
**关联需求**: BS-JOIN-001, BS-JOIN-002, BS-PRO-001, BS-PRO-003, NT-TYP-001

---

## 测试用例列表

### TC-UI-FLOW-001: 从首页发现小说并阅读

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-001 |
| **用例名称** | 从首页发现小说并阅读 |
| **前置条件** | 1. 用户已登录<br>2. 首页可访问 |
| **优先级** | P0 |
| **所属需求** | HU-DIS-001 |

**测试步骤**:
1. 访问首页
2. 浏览推荐小说列表
3. 点击感兴趣的小说封面
4. 查看小说详情
5. 点击"开始阅读"按钮
6. 进入阅读器阅读第一章

**预期结果**:
- 首页推荐小说正常显示
- 点击小说跳转到详情页
- 详情页显示完整信息
- 开始阅读跳转到阅读器
- 阅读器加载第一章内容

### TC-UI-FLOW-002: 加入书架流程

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-002 |
| **用例名称** | 加入书架完整流程 |
| **前置条件** | 1. 用户已登录<br>2. 在小说详情页 |
| **优先级** | P0 |
| **所属需求** | BS-JOIN-001, BS-JOIN-002 |

**测试步骤**:
1. 在小说详情页点击"加入书架"按钮
2. 验证加入成功提示
3. 检查追更状态（自动开启）
4. 进入个人书架查看
5. 验证小说在书架列表中

**预期结果**:
- 点击后显示"已加入书架"提示
- 按钮状态变为"已在书架"
- 自动开启追更功能
- 书架中显示该小说
- 显示阅读进度（未读为0%）

### TC-UI-FLOW-003: 继续阅读流程

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-003 |
| **用例名称** | 继续阅读流程 |
| **前置条件** | 1. 小说已在书架<br>2. 有阅读历史 |
| **优先级** | P0 |
| **所属需求** | BS-PRO-003 |

**测试步骤**:
1. 进入个人书架
2. 找到之前阅读过的小说
3. 点击"继续阅读"按钮
4. 验证跳转位置
5. 继续阅读内容

**预期结果**:
- 书架显示"继续阅读"按钮
- 点击后跳转到上次阅读位置
- 如果是章节中间，定位到具体段落
- 显示当前阅读进度
- 阅读进度自动保存

### TC-UI-FLOW-004: 跨章节阅读流程

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-004 |
| **用例名称** | 跨章节阅读流程 |
| **前置条件** | 1. 用户正在阅读<br>2. 存在多个章节 |
| **优先级** | P0 |
| **所属需求** | BS-PRO-001 |

**测试步骤**:
1. 阅读到当前章节末尾
2. 点击"下一章"按钮
3. 验证章节切换
4. 阅读新章节内容
5. 点击"上一章"返回

**预期结果**:
- 章节末尾显示"下一章"按钮
- 点击后平滑切换到下一章
- 新章节从开头开始显示
- 上一章功能正常返回
- 章节切换时保存阅读进度

### TC-UI-FLOW-005: 阅读进度保存与恢复

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-005 |
| **用例名称** | 阅读进度保存与恢复 |
| **前置条件** | 1. 用户正在阅读 |
| **优先级** | P0 |
| **所属需求** | BS-PRO-001, BS-PRO-003 |

**测试步骤**:
1. 阅读到章节中间位置
2. 退出阅读器（返回/关闭页面）
3. 重新进入阅读器
4. 验证是否恢复到上次位置
5. 检查进度同步

**预期结果**:
- 阅读进度自动保存（每30秒或翻页时）
- 退出后重新进入恢复位置
- 进度精确到段落级别
- 书架中显示阅读进度百分比
- 进度跨设备同步

### TC-UI-FLOW-006: 追更通知流程

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-006 |
| **用例名称** | 追更通知完整流程 |
| **前置条件** | 1. 用户已追更小说<br>2. 小说发布新章节 |
| **优先级** | P0 |
| **所属需求** | NT-TYP-001 |

**测试步骤**:
1. 用户追更小说A
2. 小说A发布新章节
3. 用户收到更新通知
4. 点击通知进入阅读器
5. 阅读新章节

**预期结果**:
- 新章节发布后发送通知
- 通知显示小说名和章节名
- 点击通知直达新章节
- 通知标记为已读后消失
- 书架显示"有更新"标识

### TC-UI-FLOW-007: 离线阅读流程

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-UI-FLOW-007 |
| **用例名称** | 离线阅读流程 |
| **前置条件** | 1. 用户已缓存章节内容<br>2. 网络断开 |
| **优先级** | P1 |
| **所属需求** | OFF-READ-001 |

**测试步骤**:
1. 在线时缓存小说章节
2. 断开网络连接
3. 进入阅读器
4. 阅读已缓存章节
5. 恢复网络后同步进度

**预期结果**:
- 已缓存章节离线可阅读
- 阅读进度本地保存
- 离线时显示离线标识
- 恢复网络后自动同步进度
- 未缓存章节提示需要联网
