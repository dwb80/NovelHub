# NovelHub CSS渲染完整性测试用例

## 测试概述

本测试用例集用于验证NovelHub项目的CSS渲染完整性，包括4种主题切换、响应式布局断点、CSS动画过渡效果、字体和图标加载等。

---

## 1. CSS文件结构测试

### TC-UI-CSS-001: 基础CSS文件存在性验证
- **测试对象**: `html/assets/css/` 目录
- **测试内容**: 验证所有基础CSS文件存在
- **验证方法**:
  1. 检查以下CSS文件存在:
     - base.css
     - components.css
     - layout.css
     - themes.css
     - accessibility.css
     - fluid-typography.css
     - page-animation.css
     - reader-progress.css
     - component-states.css
     - loading.css
     - animations.css
  2. 验证文件大小不为0
  3. 验证文件可正常加载
- **预期结果**: 所有基础CSS文件存在且可访问
- **优先级**: P0 (Critical)

### TC-UI-CSS-002: 组件CSS文件存在性验证
- **测试对象**: `html/assets/css/components/` 目录
- **测试内容**: 验证组件级CSS文件存在
- **验证方法**:
  1. 检查以下文件存在:
     - banner-carousel.css
     - comment-system.css
  2. 验证文件引用正确
- **预期结果**: 组件CSS文件存在且被正确引用
- **优先级**: P1 (High)

### TC-UI-CSS-003: CSS变量定义验证
- **测试对象**: base.css 和 themes.css
- **测试内容**: 验证CSS变量完整定义
- **验证方法**:
  1. 检查 `:root` 中定义的变量:
     - 字体变量: --font-sans, --font-serif, --font-mono
     - 颜色变量: --color-primary, --color-success, --color-error等
     - 间距变量: --space-1 到 --space-20
     - 阴影变量: --shadow-sm 到 --shadow-2xl
     - 圆角变量: --radius-sm 到 --radius-full
     - 动画变量: --duration-fast, --duration-base, --duration-slow
  2. 验证变量值格式正确
- **预期结果**: 所有CSS变量正确定义
- **优先级**: P0 (Critical)

## 12. 常见问题及修复建议

### 问题1: 主题切换闪烁
**影响**: 用户体验差
**修复**: 在head中添加主题防闪烁脚本，优先加载主题CSS

### 问题2: 移动端布局溢出
**影响**: 出现横向滚动条
**修复**: 检查元素宽度是否使用固定值，改用相对单位

### 问题3: 动画性能差
**影响**: 页面卡顿
**修复**: 使用transform和opacity代替top/left，启用GPU加速

### 问题4: 字体加载延迟
**影响**: 文字闪烁 (FOUT)
**修复**: 使用font-display: swap，添加系统字体回退

### 问题5: 对比度不足
**影响**: 无障碍访问问题
**修复**: 使用对比度检查工具，确保 >= 4.5:1
