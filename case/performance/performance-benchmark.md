# NovelHub 性能基准测试用例

**文档版本**: v1.0  
**编制日期**: 2026-04-12  
**测试类型**: 性能基准测试  
**测试工具**: Lighthouse, WebPageTest, Chrome DevTools, k6/JMeter

---

## 1. 性能测试概述

### 1.1 测试目标

- 建立系统性能基线指标
- 验证系统在各种负载下的性能表现
- 识别性能瓶颈和优化点
- 确保用户体验流畅

### 1.2 性能指标定义

| 指标类别 | 指标名称 | 目标值 | 可接受值 | 警告阈值 |
|----------|----------|--------|----------|----------|
| 加载性能 | FCP (First Contentful Paint) | < 1.0s | < 1.8s | >= 1.8s |
| 加载性能 | LCP (Largest Contentful Paint) | < 1.5s | < 2.5s | >= 2.5s |
| 加载性能 | TTI (Time to Interactive) | < 2.5s | < 3.8s | >= 3.8s |
| 加载性能 | TBT (Total Blocking Time) | < 100ms | < 200ms | >= 200ms |
| 加载性能 | CLS (Cumulative Layout Shift) | < 0.05 | < 0.1 | >= 0.1 |
| API性能 | P50响应时间 | < 50ms | < 100ms | >= 100ms |
| API性能 | P95响应时间 | < 100ms | < 200ms | >= 200ms |
| API性能 | P99响应时间 | < 200ms | < 500ms | >= 500ms |
| 并发性能 | 支持并发用户 | 1000 | 500 | < 500 |
| 资源性能 | JS文件大小 | < 150KB | < 200KB | >= 200KB |
| 资源性能 | CSS文件大小 | < 30KB | < 50KB | >= 50KB |
