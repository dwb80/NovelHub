# 性能测试用例

## 测试概述

**测试目标**: 验证系统在不同负载条件下的性能表现，包括页面加载时间、API响应时间、并发处理能力
**测试范围**: 页面加载性能、API响应性能、并发压力测试、资源消耗监控
**关联需求**: PERF-LOD-001, PERF-API-001, PERF-CON-001, PERF-RES-001

---

## 测试用例列表

### TC-PERF-001: 首页页面加载时间

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-PERF-001 |
| **用例名称** | 首页页面加载时间测试 |
| **前置条件** | 1. 测试环境部署完成<br>2. 网络环境稳定<br>3. 缓存已预热 |
| **优先级** | P0 |
| **所属需求** | PERF-LOD-001 |

**测试步骤**:
1. 使用Lighthouse进行性能测试
2. 使用Chrome DevTools Network面板
3. 测试首次加载（无缓存）
4. 测试重复加载（有缓存）
5. 测试3G/4G网络条件

**预期结果**:
- 首次内容绘制(FCP) < 1.8s
- 最大内容绘制(LCP) < 2.5s
- 可交互时间(TTI) < 3.8s
- 总阻塞时间(TBT) < 200ms
- 重复加载 < 1s
