# 输入验证边界测试用例

## 测试概述

**测试目标**: 验证系统对各种输入数据的边界处理和验证机制
**测试范围**: 字符串长度、特殊字符、SQL注入、XSS攻击、格式验证等
**关联需求**: OC-REG-002, HU-REG-001, NV-CRT-002, CM-CRT-001

---

## 测试用例列表

### TC-BDY-001: 用户名字符长度边界

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-BDY-001 |
| **用例名称** | 用户名字符长度边界测试 |
| **前置条件** | 1. 注册页面可访问 |
| **优先级** | P0 |
| **所属需求** | HU-REG-001 |

**测试步骤**:
1. 输入0字符（空字符串）
2. 输入1个字符的用户名
3. 输入50个字符的用户名（最大值）
4. 输入51个字符的用户名（超过最大值）
5. 输入包含emoji的用户名

**预期结果**:
- 0字符：提示"用户名不能为空"
- 1字符：正常通过
- 50字符：正常通过
- 51字符：提示"用户名不能超过50个字符"
- Emoji：根据策略允许或拒绝

1. 在1秒内发送10次请求（Free用户限制内）

- 10次/秒：正常响应

- 持续高频：临时封禁IP或账号
- 不同接口有各自的限制
- 频率限制按时间窗口重置
