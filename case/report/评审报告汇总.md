## 🎯 P0 级别关键问题（必须立即修复）

### 数据库设计 - 5 个 P0 问题

1. **❌ 时间字段未使用 TIMESTAMPTZ**
   - **影响**: 跨时区用户会出现时间显示错误
   - **修复建议**: 所有 DateTime 字段增加 `@db.Timestamptz`
   - **工作量**: 2 小时

2. **❌ ReadingHistory 表未分区**
   - **影响**: 6 个月后性能崩溃（预计亿级数据）
   - **修复建议**: 按 readAt 字段进行月度分区
   - **工作量**: 4 小时

3. **❌ Chapter 表未分区**
   - **影响**: 数据量超过 100 万后性能急剧下降
   - **修复建议**: 按 novel_id 哈希分区或按 published_at 范围分区
   - **工作量**: 4 小时

4. **❌ 缺少 User 表（普通读者）**
   - **影响**: 无法支持普通读者登录，书架、阅读历史归属不清晰
   - **修复建议**: 增加 User 表，与 Claw 表 1:1 可选关联
   - **工作量**: 6 小时

5. **❌ 缺少支付系统表**
   - **影响**: 无法商业化，VIP 章节功能无法实现
   - **修复建议**: 增加 PaymentOrder、Transaction 表
   - **工作量**: 8 小时

### 接口设计 - 6 个高优先级缺失

1. **❌ 搜索 API 完全缺失**
   - **影响**: 用户无法搜索小说，核心功能缺失
   - **修复建议**: 补充全文搜索 API、搜索建议 API
   - **工作量**: 4 小时

2. **❌ 评论 API 完全缺失**
   - **影响**: 用户无法互动，社区感无法建立
   - **修复建议**: 补充评论列表、发布、删除、点赞 API
   - **工作量**: 6 小时

3. **❌ 通知 API 完全缺失**
   - **影响**: 用户无法接收系统通知
   - **修复建议**: 补充通知获取、标记已读、批量操作 API
   - **工作量**: 4 小时

4. **❌ 文件上传 API 缺失**
   - **影响**: 头像、封面图片无法上传
   - **修复建议**: 补充头像、封面上传 API
   - **工作量**: 2 小时

5. **❌ 数据统计 API 缺失（管理后台）**
   - **影响**: 管理员无法查看平台运营数据
   - **修复建议**: 补充平台统计、评审队列、用户管理 API
   - **工作量**: 6 小时

6. **❌ 个人中心 API 缺失**
   - **影响**: 用户无法编辑个人信息
   - **修复建议**: 补充个人信息获取、更新 API
   - **工作量**: 3 小时

### UIUX 设计 - 3 个 P0 问题

1. **❌ VIP 付费流程缺失**
   - **影响**: 商业化闭环无法实现
   - **修复建议**: 补充 VIP 章节标识、购买弹窗、支付成功流程

## 📋 详细评审报告

### 一、数据库设计评审（software-architect）

#### ✅ 符合规范的部分

1. **命名规范**: 表名使用复数（novels、chapters），字段 snake_case ✅
2. **主键设计**: 使用 UUID，便于未来分片 ✅
3. **大文本处理**: 使用 TEXT 类型而非 VARCHAR(n) ✅
4. **Prisma ORM 选择**: 类型安全，支持 PostgreSQL 高级特性 ✅
5. **领域建模**: DDD 思想清晰，限界上下文明确 ✅

#### ⚠️ 需要调整的设计

1. **时间字段类型**: 所有 DateTime 应改为 `@db.Timestamptz`
2. **软删除不完整**: 仅 Comment 表有 is_deleted，Novel、Chapter 等表缺失
3. **索引设计不完整**: 缺少全文搜索 GIN 索引、复合索引优化
4. **缺少数据库扩展**: 未启用 pg_trgm、pg_stat_statements、pgvector

updatedAt     DateTime  @updatedAt @map("updated_at") @db.Timestamptz
publishedAt   DateTime? @map("published_at") @db.Timestamptz
```

**2. 增加 User 表（P0）**:
```prisma
model User {
  id            String    @id @default(uuid())
  userId        String    @unique @map("user_id")
  email         String    @unique
  passwordHash  String    @map("password_hash")
  avatar        String?
  
  clawId        String?   @unique @map("claw_id")
  claw          Claw?     @relation(fields: [clawId], references: [id])
  
  bookshelves   Bookshelf[]
  readingHistory ReadingHistory[]
  comments      Comment[]
  notifications Notification[]
  
  createdAt     DateTime  @default(now()) @map("created_at") @db.Timestamptz
  updatedAt     DateTime  @updatedAt @map("updated_at") @db.Timestamptz
  lastLoginAt   DateTime? @map("last_login_at") @db.Timestamptz
  
  @@map("users")
}
```

**3. 增加支付相关表（P0）**:
```prisma
model PaymentOrder {
  id            String    @id @default(uuid())
  orderId       String    @unique @map("order_id")
  
  userId        String    @map("user_id")
  user          User      @relation(fields: [userId], references: [id])
  
  amount        Decimal   @db.Decimal(10, 2)
  currency      String    @default("CNY")
  status        OrderStatus @default(PENDING)
  
  items         Json      @default("[]")
  
  paymentMethod String?   @map("payment_method")
  paidAt        DateTime? @map("paid_at") @db.Timestamptz
  
  createdAt     DateTime  @default(now()) @map("created_at") @db.Timestamptz
  updatedAt     DateTime  @updatedAt @map("updated_at") @db.Timestamptz
  
  @@map("payment_orders")
}

enum OrderStatus {
  PENDING
  PAID
  FAILED
  REFUNDED
}
```

**4. 索引设计补充（P1）**:
```sql
-- 全文搜索 GIN 索引
CREATE INDEX idx_novels_search ON novels USING GIN (to_tsvector('simple', title || ' ' || description));

-- 复合索引（最左前缀原则）
CREATE INDEX idx_chapters_novel_status ON chapters(novel_id, status);
CREATE INDEX idx_reading_history_claw_novel ON reading_history(claw_id, novel_id, read_at DESC);

-- JSONB 字段 GIN 索引
CREATE INDEX idx_writing_styles_settings ON writing_styles USING GIN (settings);

-- 模糊搜索 pg_trgm 索引
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE INDEX idx_novels_title_trgm ON novels USING GIN (title gin_trgm_ops);
```

**5. 数据库扩展建议（P1）**:

-- 性能监控

-- 模糊搜索
CREATE EXTENSION IF NOT EXISTS pg_trgm;

CREATE EXTENSION IF NOT EXISTS vector;

### X.1 全文搜索小说

| Method | GET |
| URL | `/api/v1/search/novels` |

**查询参数**:
- q: 搜索关键词（必填）

    "searchTime": 45

```

**2. 安全增强 - 防重放攻击（P0）**:
```markdown
所有认证请求应在请求头中包含：
- X-Nonce: 唯一随机数（UUID）
- X-Timestamp: 请求时间戳（ISO 8601）

服务器验证规则：
1. Timestamp 与服务器时间差不能超过 5 分钟
2. Nonce 在 5 分钟内不能重复使用（Redis 缓存）
```
