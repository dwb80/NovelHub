## 3. 优先级定义

### 3.1 P0 - 阻塞级（Critical）

**定义**: 核心功能，必须100%通过，失败将阻塞发布

**包含范围**:
- 用户注册/登录
- 小说阅读核心功能
- 支付购买流程
- 核心安全功能
- 基础性能指标

**执行要求**:
- 每次发布前必须执行
- 失败立即修复
- 自动化覆盖率100%

### 3.2 P1 - 必须级（High）

**定义**: 重要功能，失败影响用户体验，需在24小时内修复

**包含范围**:
- 书架管理
- 搜索功能
- 评论功能
- 阅读设置
- 主要边界场景

**执行要求**:
- 每日自动化执行
- 失败24小时内修复
- 自动化覆盖率>=80%

### 3.3 P2 - 重要级（Medium）

**定义**: 一般功能，失败影响较小，可在下次迭代修复

**包含范围**:
- 高级设置
- 辅助功能
- 部分边界场景
- 兼容性测试

**执行要求**:
- 每周执行
- 失败记录并安排修复
- 自动化覆盖率>=50%

### 3.4 P3 - 低优先级（Low）

**定义**: 边缘功能，失败影响极小

**包含范围**:
- 极少使用的功能
- 实验性功能
- 详细边界测试

**执行要求**:
- 按需执行
- 手动测试为主

## 5. DOM选择器规范

### 5.1 选择器优先级

1. **data-testid** (推荐)
   ```html
   <button data-testid="submit-btn">提交</button>
   ```
   ```javascript
   cy.get('[data-testid="submit-btn"]')
   ```

2. **ID选择器**
   ```html
   <input id="username-input" />
   ```
   ```javascript
   cy.get('#username-input')
   ```

3. **类名选择器**（需确保稳定）
   ```html
   <div class="modal-container active">
   ```
   ```javascript
   cy.get('.modal-container')
   ```

4. **属性选择器**
   ```javascript
   cy.get('[type="submit"]')
   ```

5. **XPath**（最后选择）
   ```javascript
   cy.xpath('//button[contains(text(),"提交")]')
   ```

### 5.2 选择器命名规范

| 元素类型 | 命名格式 | 示例 |
|----------|----------|------|
| 按钮 | `[data-testid="{action}-btn"]` | `submit-btn`, `cancel-btn` |
| 输入框 | `[data-testid="{field}-input"]` | `username-input`, `search-input` |
| 表单 | `[data-testid="{form}-form"]` | `login-form`, `register-form` |
| 弹窗 | `[data-testid="{name}-modal"]` | `confirm-modal`, `alert-modal` |
| 列表 | `[data-testid="{name}-list"]` | `novel-list`, `comment-list` |
| 卡片 | `[data-testid="{name}-card"]` | `novel-card`, `chapter-card` |
| 提示 | `[data-testid="{type}-toast"]` | `success-toast`, `error-toast` |
| 标签 | `[data-testid="{name}-tab"]` | `reading-tab`, `favorites-tab` |

## 6. 测试步骤编写规范

### 6.1 步骤粒度要求

**每个步骤应满足**:
- 单一操作原则（一个步骤只做一件事）
- 可验证性（步骤执行后应有明确结果）
- 原子性（步骤不可再拆分）

**好的示例**:
```
1. 在搜索框输入"斗破苍穹"
2. 点击搜索按钮
3. 等待搜索结果加载完成
4. 验证第一条结果的标题包含"斗破苍穹"
```

**不好的示例**:
```
1. 搜索小说并查看结果  （太粗粒度）
```

### 6.2 步骤描述规范

| 操作类型 | 描述格式 | 示例 |
|----------|----------|------|
| 点击 | 点击[元素] | 点击"搜索"按钮 |
| 输入 | 在[元素]输入[值] | 在搜索框输入"斗破苍穹" |
| 选择 | 选择[选项] | 选择"科幻"分类 |
| 等待 | 等待[条件] | 等待页面加载完成 |
| 验证 | 验证[预期] | 验证标题显示正确 |
| 滚动 | 滚动到[位置] | 滚动到评论区 |

### 6.3 预期结果规范

**必须包含**:
- 具体的UI变化
- 数据变化
- 状态变化
- 错误处理

**示例**:
```
预期结果:
- 页面URL变为 /pages/novel/detail.html?novel=1001
- 小说标题显示为"斗破苍穹"
- 作者信息显示为"天蚕土豆"
- 封面图片正确加载
- "加入书架"按钮可点击
```
