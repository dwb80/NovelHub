# 读者登录模块测试用例

**对应需求**: US-002-读者登录 / API-POST-/readers/login  
**测试范围**: 登录页面功能、表单验证、API 集成、错误处理  
**测试类型**: E2E 测试、集成测试、负例测试  
**编写日期**: 2026-04-16  
**执行环境**: 前端 http://localhost:3000, 后端 http://localhost:3001

---

## 1. 测试概述

### 1.1 功能描述
读者登录功能允许已注册的读者使用邮箱和密码登录系统，登录成功后跳转到首页并保存认证令牌。

### 1.2 涉及组件
- **前端页面**: `/login` - 登录页面
- **前端组件**: `LoginPage`, `AuthProvider`
- **后端 API**: `POST /api/v1/readers/login`
- **数据存储**: LocalStorage (accessToken, refreshToken)

### 1.3 前置条件
1. 前端服务已启动 (http://localhost:3000)
2. 后端服务已启动 (http://localhost:3001)
3. 数据库已连接且包含测试读者账户
4. 已注册测试读者: `test@example.com` / `Test1234`

## 4. API 契约测试

### 4.1 登录请求
```http
POST /api/v1/readers/login
Content-Type: application/json

{
  "account": "test@example.com",
  "password": "Test1234"
}
```

### 4.2 登录成功响应 (200)
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
  "reader": {
    "id": "uuid",
    "username": "test_reader",
    "email": "test@example.com"
  }
}
```

### 4.3 登录失败响应 (401)
```json
{
  "message": "邮箱或密码错误",
  "error": "Unauthorized",
  "statusCode": 401
}
```
