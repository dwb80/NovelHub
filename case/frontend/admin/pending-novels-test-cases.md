## 详细测试用例

### TC-PN-001: 页面加载显示待评审小说列表

**对应需求**: US-002-小说审核流程

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. 数据库中存在待评审小说

**测试步骤**:
1. 访问 http://localhost:3000/admin/pending-novels
2. 等待页面加载完成

**预期结果**:
1. 页面成功加载，显示"待评审小说"标题
2. 显示小说总数统计
3. 列表展示小说信息：标题、分类、AI智能体作家、创建时间
4. 每页显示10条记录
5. 显示分页导航

---

### TC-PN-002: 分页功能正常

**对应需求**: US-002-小说审核流程 / 分页功能设计规范

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. 待评审小说数量 > 10

**测试步骤**:
1. 访问待评审小说页面
2. 点击第2页按钮
3. 观察列表内容

**预期结果**:
1. 页面显示第2页的内容
2. URL 或状态更新为 page=2
3. 列表显示不同的小说记录
4. 分页按钮高亮当前页
5. 显示"显示 11-20 条，共 X 条"信息

---

### TC-PN-002A: 分页-每页10条验证

**对应需求**: 分页功能设计规范

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. 待评审小说数量 >= 15

**测试步骤**:
1. 访问待评审小说页面
2. 观察第一页列表数量
3. 点击下一页
4. 观察第二页列表数量

**预期结果**:
1. 第一页显示10条记录
2. 第二页显示5条记录（如果总共15条）
3. 分页信息显示正确

---

### TC-PN-002B: 分页-上一页/下一页按钮

**对应需求**: 分页功能设计规范

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. 待评审小说数量 > 10

**测试步骤**:
1. 访问待评审小说页面（第1页）
2. 观察上一页按钮状态
3. 点击下一页按钮
4. 观察上一页按钮状态
5. 点击上一页按钮

**预期结果**:
1. 第1页时，上一页按钮 disabled
2. 点击下一页后，切换到第2页
3. 第2页时，上一页按钮可用
4. 点击上一页后，返回第1页
5. 第1页时，上一页按钮再次 disabled
