## 1. 页面布局

### 1.1 整体结构

```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏 (sticky)                                         │
│  - 返回按钮 + 页面标题 + 返回仪表盘                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  筛选条件卡片                                                │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 搜索框 | 状态筛选 | AI作家输入 | 筛选按钮 | 重置    │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  任务列表卡片                                                │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 章节标题 | 所属小说 | AI作家 | 状态 | 提交时间 | 操作 │   │
│  │ ...                                                 │   │
│  │ ...                                                 │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  分页组件                                                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 显示 X-Y 条，共 Z 条    < 上一页  第 N/M 页  下一页 > │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 响应式布局

| 断点 | 布局调整 |
|------|----------|
| >= 1024px | 4列筛选条件，完整表格 |
| >= 768px | 2列筛选条件，完整表格 |
| < 768px | 1列筛选条件，表格横向滚动 |

## 2. 组件设计

### 2.1 筛选条件区

#### 搜索框
- **占位符**: "输入小说或章节标题..."
- **图标**: Search (左侧)
- **交互**: 回车触发搜索

#### 状态筛选
- **选项**: 全部状态 / 待认领 / 审核中 / 已完成
- **默认值**: 全部状态

#### AI作家输入
- **占位符**: "输入AI作家名称..."
- **交互**: 回车触发搜索

#### 按钮组
- **筛选按钮**: primary 变体，带 Filter 图标
- **重置按钮**: outline 变体，带 RefreshCw 图标

### 2.2 表格设计

#### 表头
| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 章节标题 | 280px | 左对齐 | 最小200px |
| 所属小说 | 200px | 左对齐 | 最小150px |
| AI作家 | 140px | 左对齐 | 最小100px |
| 状态 | 100px | 左对齐 | - |
| 提交时间 | 140px | 左对齐 | - |
| 操作 | 140px | 右对齐 | - |

#### 表格行
- **悬停效果**: bg-muted/30
- **斑马纹**: 无
- **边框**: 底部边框

#### 状态标签样式
| 状态 | 标签文字 | 颜色变体 |
|------|----------|----------|
| PENDING | 待认领 | secondary |
| ASSIGNED | 审核中 | default |
| COMPLETED | 已完成 | outline |

#### 操作按钮
- **查看详情**: ghost 变体，Eye 图标
- **通过**: ghost 变体，CheckCircle 图标，绿色
- **驳回**: ghost 变体，XCircle 图标，红色

### 2.3 分页组件

#### 布局
- **位置**: 表格下方，居右对齐
- **结构**: 左侧信息 + 右侧控制

#### 信息区
- **文字**: "显示 {start} - {end} 条，共 {total} 条"
- **样式**: text-sm text-muted-foreground

#### 控制区
- **上一页**: outline 按钮，size="sm"
- **页码信息**: "第 {page} / {totalPages} 页"
- **下一页**: outline 按钮，size="sm"

#### 禁用状态
- 第一页时: 上一页 disabled
- 最后一页时: 下一页 disabled

## 3. 交互设计

### 3.1 页面加载

```
页面初始化
  ↓
显示加载状态 (Loader2 旋转图标)
  ↓
调用 GET /admin/review-tasks
  ↓
渲染表格数据
  ↓
显示分页组件 (如果 totalPages > 1)
```

### 3.2 筛选流程

```
用户输入筛选条件
  ↓
点击"筛选"按钮或按回车
  ↓
重置 page = 1
  ↓
调用 API 获取数据
  ↓
更新表格和分页
```

### 3.3 分页流程

```
用户点击分页按钮
  ↓
更新 pagination.page
  ↓
调用 API 获取数据
  ↓
更新表格
  ↓
滚动到表格顶部 (可选)
```

### 3.4 审核操作流程

#### 通过审核
```
点击通过按钮
  ↓
显示确认对话框 (confirm)
  ↓
用户确认
  ↓
调用 POST /admin/chapters/{id}/approve
  ↓
刷新列表
  ↓
显示成功提示
```

#### 驳回审核
```
点击驳回按钮
  ↓
显示确认对话框 (confirm)
  ↓
用户确认
  ↓
调用 POST /admin/chapters/{id}/reject
  ↓
刷新列表
  ↓
显示成功提示
```

## 4. 数据规范

### 4.1 请求参数

```typescript
interface GetReviewTasksParams {
  page: number;        // 页码，默认 1
  limit: number;       // 每页数量，固定 10
  search?: string;     // 搜索关键词
  authorName?: string; // AI作家名称
}
```

### 4.2 响应数据

```typescript
interface ReviewTask {
  id: string;
  chapterId: string;
  chapterTitle: string;
  novelId: string;
  novelTitle: string;
  authorId: string;
  authorName: string;
  status: 'PENDING' | 'ASSIGNED' | 'COMPLETED';
  createdAt: string;
  completedAt?: string;
}

interface Pagination {
  page: number;
  limit: number;
  total: number;
  totalPages: number;
}

interface ReviewTasksResponse {
  tasks: ReviewTask[];
  pagination: Pagination;
}
```

## 5. 样式规范
