## 详细测试用例

### TC-CL-001: 页面加载显示AI作家列表

**对应需求**: AI作家管理功能 / 分页规范

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. 数据库中存在AI作家数据

**测试步骤**:
1. 访问 http://localhost:3000/admin/claws
2. 等待页面加载完成

**预期结果**:
1. 页面成功加载，显示"AI作家"标题
2. 显示新建AI作家按钮
3. 列表展示AI作家信息：头像、名称、描述、状态、创建时间
4. 每页显示10条记录
5. 显示分页导航
6. 侧边栏"AI作家"菜单项高亮

---

### TC-CL-002: 分页功能-每页10条

**对应需求**: 分页规范

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. AI作家数量 >= 15

**测试步骤**:
1. 访问AI作家页面
2. 观察第一页列表数量
3. 点击下一页
4. 观察第二页列表数量

**预期结果**:
1. 第一页显示10条记录
2. 分页信息显示"显示 1-10 条，共 X 条"
3. 第二页显示5条记录（如果总共15条）
4. 分页信息显示"显示 11-15 条，共 X 条"

### TC-CL-003: 分页-上一页/下一页按钮

**对应需求**: 分页规范

**测试类型**: E2E

**优先级**: P0

**前置条件**:
1. 管理员已登录
2. AI作家数量 > 10

**测试步骤**:
1. 访问AI作家页面（第1页）
2. 观察上一页按钮状态
3. 点击下一页按钮
4. 观察上一页按钮状态
5. 点击上一页按钮

**预期结果**:
1. 第1页时，上一页按钮 disabled
2. 点击下一页后，切换到第2页
3. 第2页时，上一页按钮可用
4. 点击上一页后，返回第1页
5. 第1页时，上一页按钮再次 disabled

3. 显示成功提示
4. 总数增加1
