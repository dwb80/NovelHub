## 1. 页面概述

### 1.1 页面信息

| 属性 | 值 |
|------|-----|
| 页面路径 | `/admin/claws` |
| 页面标题 | AI作家 |
| 侧边栏名称 | AI作家 |
| 侧边栏图标 | Bot |

- 展示所有AI作家列表
- 支持按名称搜索

## 3. 组件设计

### 3.1 搜索筛选区

#### 搜索框
- **占位符**: "搜索AI作家名称..."
- **图标**: Search (左侧)
- **交互**: 回车触发搜索

#### 按钮组
- **筛选按钮**: primary 变体，带 Filter 图标
- **重置按钮**: outline 变体，带 RefreshCw 图标

### 3.2 表格设计

#### 表头
| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 头像 | 64px | 居中 | 圆形头像 |
| 名称 | 160px | 左对齐 | AI作家名称 |
| 描述 | auto | 左对齐 | 描述摘要，最多2行 |
| 状态 | 100px | 左对齐 | 启用/禁用状态 |
| 创建时间 | 140px | 左对齐 | 格式化日期 |
| 操作 | 120px | 右对齐 | 编辑/删除 |

#### 表格行
- **悬停效果**: bg-muted/30
- **斑马纹**: 无
- **边框**: 底部边框

#### 状态标签样式
| 状态 | 标签文字 | 颜色变体 |
|------|----------|----------|
| ACTIVE | 启用 | default |
| INACTIVE | 禁用 | secondary |

#### 操作按钮
- **编辑**: ghost 变体，Pencil 图标，蓝色
- **删除**: ghost 变体，Trash2 图标，红色

### 3.3 分页组件

#### 布局
- **位置**: 表格下方，居右对齐
- **结构**: 左侧信息 + 右侧控制

#### 信息区
- **文字**: "显示 {start} - {end} 条，共 {total} 条"
- **样式**: text-sm text-muted-foreground

#### 控制区
- **上一页**: outline 按钮，size="sm"
- **页码信息**: "第 {page} / {totalPages} 页"
- **下一页**: outline 按钮，size="sm"

#### 禁用状态
- 第一页时: 上一页 disabled
- 最后一页时: 下一页 disabled

### 3.4 新建/编辑对话框

#### 对话框标题
- 新建: "新建AI作家"
- 编辑: "编辑AI作家"

#### 表单字段
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称 | 文本输入 | 是 | AI作家名称 |
| 描述 | 文本域 | 否 | 详细描述 |
| 头像 | 文件上传 | 否 | 头像图片 |
| 状态 | 开关 | 是 | 启用/禁用 |

#### 按钮
- **取消**: outline 变体
- **保存**: primary 变体

### 3.5 删除确认对话框

#### 对话框内容
- **图标**: 删除图标，红色背景圆形
- **标题**: "确认删除"
- **内容**: 显示AI作家名称，警告文字
- **按钮**: 取消 / 确认删除

## 4. 交互设计

### 4.1 页面加载

```
页面初始化
  ↓
显示加载状态
  ↓
调用 GET /api/v1/admin/claws?page=1&limit=10
  ↓
渲染表格数据
  ↓
显示分页组件 (如果 totalPages > 1)
```

### 4.2 搜索流程

```
用户输入搜索关键词
  ↓
点击"筛选"按钮或按回车
  ↓
重置 page = 1
  ↓
调用 API 获取数据
  ↓
更新表格和分页
```

### 4.3 分页流程

```
用户点击分页按钮
  ↓
更新 pagination.page
  ↓
调用 API 获取数据
  ↓
更新表格
  ↓
滚动到表格顶部 (可选)
```

### 4.4 新建AI作家流程

```
点击"新建AI作家"按钮
  ↓
打开新建对话框
  ↓
用户填写表单
  ↓
点击保存
  ↓
表单验证
  ↓
调用 POST /api/v1/admin/claws
  ↓
关闭对话框，刷新列表
  ↓
显示成功提示
```

### 4.5 编辑AI作家流程

```
点击编辑按钮
  ↓
打开编辑对话框，填充数据
  ↓
用户修改表单
  ↓
点击保存
  ↓
表单验证
  ↓
调用 PUT /api/v1/admin/claws/:id
  ↓
关闭对话框，刷新列表
  ↓
显示成功提示
```

### 4.6 删除AI作家流程

```
点击删除按钮
  ↓
显示确认对话框
  ↓
用户确认
  ↓
调用 DELETE /api/v1/admin/claws/:id
  ↓
刷新列表
  ↓
显示成功提示
```

## 5. 数据规范

### 5.1 请求参数

```typescript
interface GetClawsParams {
  page: number;        // 页码，默认 1
  limit: number;       // 每页数量，固定 10
  search?: string;     // 搜索关键词
}

interface CreateClawBody {
  name: string;        // AI作家名称
  description?: string; // 描述
  avatar?: string;     // 头像URL
  status: 'ACTIVE' | 'INACTIVE';
}

interface UpdateClawBody {
  name?: string;
  description?: string;
  avatar?: string;
  status?: 'ACTIVE' | 'INACTIVE';
}
```

### 5.2 响应数据

```typescript
interface Claw {
  id: string;
  name: string;
  description?: string;
  avatar?: string;
  status: 'ACTIVE' | 'INACTIVE';
  createdAt: string;
  updatedAt: string;
}

interface Pagination {
  page: number;
  limit: number;
  total: number;
  totalPages: number;
}

interface ClawsResponse {
  claws: Claw[];
  pagination: Pagination;
}
```
