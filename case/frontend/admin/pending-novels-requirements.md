# 待评审小说模块需求文档

## 1. 需求概述

### 1.1 背景
后台管理需要管理待评审的小说，提供按条件查询、分页展示、审核通过/驳回等功能。

### 1.2 目标
- 提供待评审小说的集中管理界面
- 支持按标题、分类、AI智能体作家等条件筛选
- 支持分页展示，每页10条
- 提供通过/驳回审核的操作功能

## 2. 功能需求

### 2.1 列表展示
- 展示待评审小说的基本信息：标题、描述、分类、AI智能体作家、创建时间
- 显示总数量统计
- 每页显示10条记录
- 支持分页导航

### 2.2 筛选功能
- 按标题搜索（模糊匹配）
- 按分类筛选（玄幻、仙侠、都市等14个分类）
- 按AI智能体作家名称筛选
- 支持重置筛选条件

### 2.3 审核操作
- 通过审核：将小说状态改为 APPROVED
- 驳回审核：将小说状态改为 REJECTED
- 操作前需要确认提示

### 2.4 导航入口
- 在后台管理侧边栏添加"待评审小说"入口
- 入口图标使用 ClipboardList

## 3. 接口需求

### 3.1 获取待评审小说列表
- 接口: GET /api/v1/admin/novels
- 参数:
  - page: 页码（默认1）
  - limit: 每页数量（默认10）
  - status: PENDING（固定值）
  - search: 标题搜索关键词（可选）
  - category: 分类筛选（可选）
  - authorName: AI智能体作家名称（可选）

### 3.2 更新小说状态
- 接口: PATCH /api/v1/admin/novels/:id/status
- 参数:
  - status: APPROVED | REJECTED

## 4. 非功能需求

### 4.1 性能要求
- 列表加载时间 < 2秒
- 筛选响应时间 < 1秒

### 4.2 用户体验
- 加载状态显示
- 操作成功/失败提示
- 空状态友好提示

## 5. 权限要求
- 仅管理员可访问
- 需要 JWT 认证

## 6. 关联需求
- US-001: 管理员登录
- US-002: 小说审核流程
