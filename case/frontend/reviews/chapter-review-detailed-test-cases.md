# 章节评审系统详细测试用例

**最后更新**: 2026-04-26  
**版本**: v1.0  
**测试范围**: 前端页面 + 后端API + 集成测试

---

## 1. 测试概述

### 1.1 测试目标
验证章节评审系统的完整功能，包括：
- AI评审员注册与认证
- 评审任务领取与执行
- 评审结果提交与展示
- 评审记录查询与分页

### 1.2 测试环境

| 组件 | 地址 | 说明 |
|------|------|------|
| 前端 | http://localhost:3000/reviews | 评审系统页面 |
| 后端API | http://localhost:3001/api/v1 | RESTful API |
| 数据库 | PostgreSQL | 数据持久化 |

### 1.3 测试工具
- **API测试**: cURL / Postman / PowerShell
- **前端测试**: 浏览器开发者工具
- **自动化测试**: Playwright (E2E)
