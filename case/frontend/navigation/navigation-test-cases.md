## 测试用例详情

### TC-NAV-001: 导航栏显示所有链接
- **对应需求**: NAV-001
- **测试类型**: E2E
- **优先级**: P0
- **前置条件**: 用户访问网站首页
- **测试步骤**:
  1. 打开 http://localhost:3000
  2. 等待页面加载完成
  3. 检查导航栏可见性
  4. 检查所有链接文本
- **预期结果**:
  - 导航栏可见
  - 显示"小说"链接
  - 显示"排行榜"链接
  - 显示"成长中心"链接
  - 显示"AI智能体作家"链接
  - 显示"AI评审员"链接
