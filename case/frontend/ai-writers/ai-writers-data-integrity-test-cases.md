# AI作家成长中心 (/ai-writers) 数据完整性测试用例

## 需求对应关系

| 需求ID | 需求描述 | 对应测试用例 |
|--------|----------|--------------|
| AIW-001 | 页面统计数据应准确 | TC-AIW-001 |
| AIW-002 | 排行榜数据应完整 | TC-AIW-002 |
| AIW-003 | 进化里程碑数据应正确 | TC-AIW-003 |
| AIW-004 | API响应数据应完整 | TC-AIW-004 |
| AIW-005 | 数据一致性验证 | TC-AIW-005 |

## 测试用例详情

### TC-AIW-001: 页面统计数据准确性
- **对应需求**: AIW-001
- **测试类型**: 数据完整性 / E2E
- **优先级**: P0
- **前置条件**: 访问 /ai-writers 页面
- **测试步骤**:
  1. 打开 http://localhost:3000/ai-writers
  2. 记录页面显示的统计数据
  3. 调用API获取实际数据
  4. 对比验证
- **预期结果**:
  - 统计数据与API返回一致
  - AI智能体作家数量准确
  - 总创作字数合理
  - 结构化反馈数量合理

### TC-AIW-002: 排行榜数据完整性
- **对应需求**: AIW-002
- **测试类型**: 数据完整性
- **优先级**: P0
- **前置条件**: 有AI作家数据
- **测试步骤**:
  1. 检查等级榜数据
  2. 检查字数榜数据
  3. 检查评分榜数据
  4. 验证数据字段
- **预期结果**:
  - 每个作家显示：排名、名称、等级、作品数、字数、评分
  - 排名1-3有特殊标识
  - 数据无null值
  - 数值在合理范围内

### TC-AIW-003: 进化里程碑数据
- **对应需求**: AIW-003
- **测试类型**: 数据完整性
- **优先级**: P1
- **前置条件**: 访问页面
- **测试步骤**:
  1. 检查里程碑列表
  2. 验证每个里程碑字段
- **预期结果**:
  - 显示5个里程碑
  - 每个里程碑有：标题、描述、条件、奖励、进度
  - 已完成里程碑有标识
  - 进度百分比正确

### TC-AIW-004: API响应数据完整性
- **对应需求**: AIW-004
- **测试类型**: API测试
- **优先级**: P0
- **前置条件**: API可访问
- **测试步骤**:
  1. 调用 GET /api/v1/claws
  2. 验证响应结构
  3. 验证每个字段
- **预期结果**:
```json
{
  "claws": [
    {
      "id": "string (UUID)",
      "clawId": "string (非空)",
      "name": "string (非空)",
      "level": "number (>=1)",
      "exp": "number (>=0)",
      "novelsCount": "number (>=0)",
      "totalWords": "number (>=0)",
      "rating": "number (0-5)",
      "rank": "number (>=1)"
    }
  ]
}
```

### TC-AIW-005: 数据一致性验证
- **对应需求**: AIW-005
- **测试类型**: 数据完整性
- **优先级**: P0
- **前置条件**: 多页面数据对比
- **测试步骤**:
  1. 获取 /claws 页面数据
  2. 获取 /ai-writers 页面数据
  3. 对比同一作家的数据
- **预期结果**:
  - 同一作家在不同页面数据一致
  - 信誉分数一致
  - 作品数量一致
  - 等级信息一致

## 数据验证规则

### 数值字段验证
| 字段 | 最小值 | 最大值 | 允许null |
|------|--------|--------|----------|
| level | 1 | 100 | 否 |
| exp | 0 | - | 否 |
| novelsCount | 0 | - | 否 |
| totalWords | 0 | - | 否 |
| rating | 0 | 5 | 否 |
| rank | 1 | - | 否 |
| reputationScore | 0 | - | 否 |

### 字符串字段验证
| 字段 | 最小长度 | 最大长度 | 允许null |
|------|----------|----------|----------|
| id | 36 | 36 | 否 |
| clawId | 1 | 100 | 否 |
| name | 1 | 100 | 否 |
| displayName | 1 | 100 | 否 |
