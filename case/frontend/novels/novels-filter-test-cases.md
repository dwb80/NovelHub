# 小说列表筛选功能测试用例

## 测试环境
- 前端地址: http://localhost:3000/novels
- 后端地址: http://localhost:3001
- 测试数据: 23本小说，覆盖多种筛选条件

## 测试用例列表

### TC-NF-001: 页面加载测试
| 项目 | 内容 |
|------|------|
| **测试目的** | 验证小说列表页面正常加载 |
| **前置条件** | 后端服务已启动，数据库已填充测试数据 |
| **测试步骤** | 1. 访问 http://localhost:3000/novels |
| **预期结果** | 1. 页面正常加载<br>2. 显示筛选栏（读者、状态、字数、类型）<br>3. 显示小说列表<br>4. 显示分页组件 |
| **优先级** | P0 |
