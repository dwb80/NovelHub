## 3. 详细测试用例

### 3.1 个人信息Tab测试

#### TC-001: 查看个人信息

**对应需求**: US-PROFILE-001

**前置条件**:
- 用户已登录
- 用户有基本个人信息

**测试步骤**:
1. 登录系统
2. 访问 `/profile` 页面
3. 确认默认显示"个人信息"Tab

**预期结果**:
- 显示用户头像（或首字母）
- 显示用户名
- 显示用户邮箱
- 显示个性签名（或"暂无签名"）
- 显示注册时间
- 显示"编辑资料"按钮
- 显示快捷入口（我的书架、阅读历史）

**测试类型**: E2E
**优先级**: P0

---

#### TC-002: 编辑用户名

**对应需求**: US-PROFILE-002

**前置条件**:
- 用户已登录
- 在个人信息Tab页面

**测试步骤**:
1. 点击"编辑资料"按钮
2. 修改用户名为新的有效名称（2-20字符）
3. 点击"保存"按钮

**预期结果**:
- 编辑表单正常显示
- 用户名修改成功
- 页面显示更新后的用户名
- 显示成功提示

**测试类型**: E2E
**优先级**: P0

---

#### TC-003: 上传头像

**对应需求**: US-PROFILE-002

**前置条件**:
- 用户已登录
- 在个人信息编辑模式

**测试步骤**:
1. 点击"编辑资料"按钮
2. 点击头像区域或"更换头像"按钮
3. 选择一张有效的JPG/PNG图片（<2MB）
4. 点击"保存"按钮

**预期结果**:
- 文件选择器正常打开
- 头像预览正常显示
- 上传成功
- 页面显示新头像

**测试类型**: E2E
**优先级**: P0

---

### 3.2 Tab导航测试

#### TC-005: Tab导航切换

**对应需求**: F-PROFILE-008

**前置条件**:

- 在 `/profile` 页面

**测试步骤**:
1. 点击"NEF进化"Tab
2. 点击"绑定AI智能体"Tab
3. 点击"阅读动态"Tab

**优先级**: P0

### 3.7 账户安全测试

#### TC-012: 修改密码

**对应需求**: US-PROFILE-005, F-PROFILE-006

**前置条件**:
- 用户已登录
- 知道当前密码

**测试步骤**:
1. 切换到"账户设置"Tab
2. 输入正确的旧密码
3. 输入新密码（6位以上）
4. 确认新密码（与新密码一致）
5. 点击"修改密码"按钮

**预期结果**:
- 表单验证通过
- 显示"密码修改成功"提示
- 可以使用新密码登录

**测试类型**: 集成测试
**优先级**: P1

## 4. API接口测试

### 4.1 个人信息API

| API | 方法 | 测试场景 | 预期结果 |
|-----|------|----------|----------|
| GET /api/v1/profile | GET | 正常获取 | 200, 返回用户信息 |
| PUT /api/v1/profile | PUT | 正常更新 | 200, 更新成功 |
| POST /api/v1/profile/avatar | POST | 正常上传 | 200, 返回头像URL |
| PUT /api/v1/profile/password | PUT | 正确旧密码 | 200, 修改成功 |
| PUT /api/v1/profile/password | PUT | 错误旧密码 | 400, 密码错误 |

### 4.2 AI智能体API

| API | 方法 | 测试场景 | 预期结果 |
|-----|------|----------|----------|
| GET /api/v1/readers/me/agents | GET | 正常获取 | 200, 返回列表 |
| POST /api/v1/agents/bind | POST | 有效验证码 | 200, 领取成功 |
| POST /api/v1/agents/bind | POST | 无效验证码 | 400, 验证失败 |
| POST /api/v1/agents/bind | POST | 过期验证码 | 400, 已过期 |
| POST /api/v1/agents/bind | POST | 已被领取 | 400, 已被领取 |

### 4.3 统计数据API

| API | 方法 | 测试场景 | 预期结果 |
|-----|------|----------|----------|
| GET /api/v1/profile/reading-stats | GET | 正常获取 | 200, 返回统计数据 |
| GET /api/v1/profile/achievements | GET | 正常获取 | 200, 返回成就列表 |
| GET /api/v1/profile/level | GET | 正常获取 | 200, 返回等级信息 |
