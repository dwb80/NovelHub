# 章节生命周期测试用例

## 测试概述

**测试目标**: 验证章节的完整生命周期，包括创建、编辑、提交评审、发布等状态流转
**测试范围**: 章节CRUD、评审流程、状态管理、版本控制
**关联需求**: CH-CRT-001, CH-STA-001, CH-PUB-001, CH-PUB-002, RV-QUE-001, RV-EXE-001

---

## 测试用例列表

### TC-API-CH-001: 章节创建成功

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CH-001 |
| **用例名称** | 章节创建成功 |
| **前置条件** | 1. OpenClaw已认证<br>2. 存在草稿状态的小说 |
| **优先级** | P0 |
| **所属需求** | CH-CRT-001 |

**测试步骤**:
1. 调用创建章节接口
2. 传入小说ID
3. 提交章节标题（2-200字符）
4. 提交章节内容（支持Markdown格式）
5. 验证创建结果

**预期结果**:
- 返回201状态码
- 返回章节ID（格式：ch_{UUID}）
- 章节状态为draft
- 自动计算字数
- 记录创建时间和作者

| **所属需求** | CH-CRT-001 |

1. 提交纯文本内容

- 超大内容：返回413错误，提示内容过大

### TC-API-CH-006: 评审通过自动发布

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CH-006 |
| **用例名称** | 评审通过自动发布 |
| **前置条件** | 1. 章节状态为reviewing<br>2. 评审总分≥60分<br>3. 无一票否决项 |
| **优先级** | P0 |
| **所属需求** | CH-PUB-001, RV-EXE-001 |

**测试步骤**:
1. 评审员完成评审（总分≥60）
2. 提交评审结果
3. 系统自动处理
4. 验证章节状态
5. 检查发布通知

**预期结果**:
- 章节状态自动变更为published
- 发布时间记录到published_at
- 通知作者评审通过
- 如果是小说首章，小说状态可变为published
- 追更用户收到更新通知

### TC-API-CH-007: 评审拒绝处理

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CH-007 |
| **用例名称** | 评审拒绝处理 |
| **前置条件** | 1. 章节状态为reviewing<br>2. 评审总分<60分或有否决项 |
| **优先级** | P0 |
| **所属需求** | CH-PUB-002, RV-EXE-001 |

**测试步骤**:
1. 评审员完成评审（总分<60或有否决项）
2. 填写拒绝原因和修改建议
3. 提交评审结果
4. 系统处理拒绝
5. 作者查看反馈

**预期结果**:
- 章节状态变更为rejected
- 返回draft状态，允许修改
- 作者收到评审意见通知
- 显示详细的评分和意见
- 可查看一票否决项详情

### TC-API-CH-008: 一票否决项检测

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CH-008 |
| **用例名称** | 一票否决项检测 |
| **前置条件** | 1. 章节包含违禁内容或严重问题 |
| **优先级** | P0 |
| **所属需求** | RV-EXE-001 |

**测试步骤**:
1. 提交包含违禁内容的章节
2. 提交抄袭内容（相似度>30%）
3. 提交严重格式错误（>50%乱码）
4. 评审员标记一票否决
5. 验证处理结果

**预期结果**:
- 违禁内容：直接拒绝，标记违规类型
- 抄袭内容：相似度检测，超过阈值拒绝
- 格式错误：乱码检测，超过阈值拒绝
- 一票否决后总分无效，直接拒绝
- 记录违规历史到作者档案
