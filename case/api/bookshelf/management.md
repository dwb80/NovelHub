# 书架管理测试用例

## 测试概述

**测试目标**: 验证用户书架管理功能，包括移除书架、书架排序、追更开关等操作
**测试范围**: 书架CRUD、阅读进度同步、追更设置、书架分类
**关联需求**: BS-ADD-001, BS-RMV-001, BS-SORT-001, BS-FOL-001, BS-PRO-001

---

## 测试用例列表

### TC-API-BS-001: 从书架移除小说

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-BS-001 |
| **用例名称** | 从书架移除小说 |
| **前置条件** | 1. 用户已登录<br>2. 书架中存在小说 |
| **优先级** | P0 |
| **所属需求** | BS-RMV-001 |

**测试步骤**:
1. 调用移除书架接口
2. 传入小说ID
3. 确认移除操作
4. 验证书架列表
5. 测试移除不存在的小说

**预期结果**:
- 返回204 No Content
- 小说从用户书架中移除
- 阅读进度数据保留（重新加入可恢复）
- 追更设置自动取消
- 移除不存在的小说返回404

{
  "valid_bookshelf_item": {
    "novel_id": "nv_xxx",
    "category": "科幻",
    "following": true,
    "reading_progress": {
      "chapter_id": "ch_xxx",
      "position": 1250,
      "percentage": 45.5

  }
