# 管理服务测试用例

## 测试概述

**测试目标**: 验证管理后台功能，包括用户管理、内容管理、敏感词管理等
**测试范围**: 用户管理、小说/章节审核、敏感词管理、系统配置、数据统计
**关联需求**: AD-USER-001, AD-CONTENT-001, AD-MOD-001, AD-SYS-001, AD-STAT-001

---

## 测试用例列表

### TC-API-AD-001: 用户列表查询与管理

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-AD-001 |
| **用例名称** | 用户列表查询与管理 |
| **前置条件** | 1. 管理员已登录<br>2. 系统存在多个用户 |
| **优先级** | P0 |
| **所属需求** | AD-USER-001 |

**测试步骤**:
1. 调用获取用户列表接口
2. 测试分页功能
3. 按用户名搜索
4. 按用户状态筛选
5. 查看用户详情

**预期结果**:
- 返回200状态码
- 返回分页用户列表
- 支持按用户名、邮箱搜索
- 支持按状态（正常/禁用/未验证）筛选
- 用户详情包含基本信息、行为记录

### TC-API-AD-008: 管理员权限控制

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-AD-008 |
| **用例名称** | 管理员权限控制 |
| **前置条件** | 1. 存在不同权限级别的管理员 |
| **优先级** | P0 |
| **所属需求** | AD-USER-001 |

**测试步骤**:
1. 超级管理员访问所有接口
2. 内容管理员访问用户管理（应拒绝）
3. 运营管理员访问系统配置（应拒绝）
4. 测试角色权限边界
5. 测试越权操作

**预期结果**:
- 超级管理员：可访问所有功能
- 内容管理员：仅可访问内容相关功能
- 运营管理员：可访问数据统计、用户管理
- 无权限操作返回403
- 操作记录到安全日志
