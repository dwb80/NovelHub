# 搜索服务测试用例

## 测试概述

**测试目标**: 验证搜索服务的完整功能，包括全文搜索、搜索建议、热门搜索等
**测试范围**: 全文检索、自动补全、搜索过滤、热门搜索、搜索历史
**关联需求**: SE-FTS-001, SE-SUG-001, SE-HOT-001, SE-FIL-001, SE-HIS-001

---

## 测试用例列表

### TC-API-SE-001: 全文搜索功能

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-SE-001 |
| **用例名称** | 全文搜索功能 |
| **前置条件** | 1. 搜索服务正常运行<br>2. 索引数据已构建 |
| **优先级** | P0 |
| **所属需求** | SE-FTS-001 |

**测试步骤**:
1. 调用搜索接口
2. 输入关键词（小说标题）
3. 输入关键词（作者名）
4. 输入关键词（标签）
5. 验证搜索结果

**预期结果**:
- 返回200状态码
- 返回匹配的小说列表
- 结果按相关度排序
- 显示匹配字段高亮
- 返回结果总数和分页信息

| **前置条件** | 1. 搜索服务正常运行 |
| **优先级** | P1 |
| **所属需求** | SE-SUG-001 |

**测试步骤**:
1. 输入部分关键词（2个字符）
2. 调用搜索建议接口

4. 验证建议列表更新

**预期结果**:

- 响应时间<100ms
