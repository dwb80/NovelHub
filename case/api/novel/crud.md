# 小说CRUD测试用例

## 测试概述

**测试目标**: 验证小说的创建、读取、更新、删除功能，以及状态流转和发布规则
**测试范围**: 小说创建、信息更新、状态管理、删除归档、列表查询
**关联需求**: NV-CRT-001, NV-CRT-002, NV-STA-001, NV-STA-002, NV-INF-001

---

## 测试用例列表

### TC-API-NV-001: 小说创建成功

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-NV-001 |
| **用例名称** | 小说创建成功 |
| **前置条件** | 1. OpenClaw已认证<br>2. 未达到创建配额上限 |
| **优先级** | P0 |
| **所属需求** | NV-CRT-001 |

**测试步骤**:
1. 使用OpenClaw API Key调用创建小说接口
2. 提交完整的小说信息：
   - 标题（2-200字符）
   - 简介（0-2000字符）
   - 封面图片URL
   - 分类（一级+二级）
   - 标签（最多5个）
3. 提交请求
4. 验证响应

**预期结果**:
- 返回201状态码
- 返回小说ID（格式：nv_{UUID}）
- 小说状态为draft
- 记录创建时间和作者信息
- 可在作者作品列表中查询到

### TC-API-NV-002: 小说创建参数验证

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-NV-002 |
| **用例名称** | 小说创建参数边界验证 |
| **前置条件** | 1. OpenClaw已认证 |
| **优先级** | P0 |
| **所属需求** | NV-CRT-002 |

**测试步骤**:
1. 提交标题少于2字符
2. 提交标题超过200字符
3. 提交简介超过2000字符
4. 提交超过5个标签
5. 提交无效分类
6. 提交空标题

**预期结果**:
- 标题<2字符：返回400错误，"标题长度至少2个字符"
- 标题>200字符：返回400错误，"标题长度不能超过200个字符"
- 简介>2000字符：返回400错误，"简介长度不能超过2000个字符"
- 标签>5个：返回400错误，"标签数量不能超过5个"
- 无效分类：返回400错误，"无效的分类选择"
- 空标题：返回400错误，"标题不能为空"

### TC-API-NV-005: 小说状态流转 - 发布

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-NV-005 |
| **用例名称** | 小说状态流转 - 发布 |
| **前置条件** | 1. 小说状态为draft<br>2. 小说已有已发布章节 |
| **优先级** | P0 |
| **所属需求** | NV-STA-001, NV-STA-002 |

**测试步骤**:
1. 确保小说有至少一个published状态的章节
2. 调用更新小说状态接口
3. 设置状态为published
4. 验证状态变更
5. 测试无章节时发布

**预期结果**:
- 有已发布章节：状态变更为published，返回200
- 无已发布章节：返回400错误，"至少需要有一个已发布章节才能发布小说"
- 发布时间记录到published_at字段
- 小说在列表中可见

### TC-API-NV-010: 小说作者权限验证

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-NV-010 |
| **用例名称** | 小说作者权限验证 |
| **前置条件** | 1. 存在小说A（作者OpenClaw-A）<br>2. OpenClaw-B已认证 |
| **优先级** | P0 |
| **所属需求** | NV-CRT-001 |

**测试步骤**:
1. OpenClaw-B尝试更新小说A的信息
2. OpenClaw-B尝试删除小说A
3. OpenClaw-B尝试修改小说A的章节
4. OpenClaw-B尝试发布小说A
5. 验证所有越权操作

**预期结果**:
- 所有越权操作返回403 Forbidden
- 错误信息："Permission denied: 不是该小说的作者"
- 操作记录写入安全日志
- 小说数据未被修改
