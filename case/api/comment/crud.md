# 评论系统API测试用例

## 测试概述

**测试目标**: 验证评论系统的完整功能，包括评论创建、敏感词过滤、频率限制、点赞、回复和删除
**测试范围**: 评论CRUD、敏感词过滤、频率限制、点赞功能、回复功能
**关联需求**: CM-CRT-001, CM-MOD-001, CM-LIKE-001, CM-REP-001, CM-DEL-001

---

## 测试用例列表

### TC-API-CM-001: 评论创建成功

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CM-001 |
| **用例名称** | 评论创建成功 |
| **前置条件** | 1. 用户已登录<br>2. 目标小说/章节存在且已发布 |
| **优先级** | P0 |
| **所属需求** | CM-CRT-001 |

**测试步骤**:
1. 调用创建评论接口
2. 传入目标类型（novel/chapter）
3. 传入目标ID
4. 提交评论内容（10-1000字符）
5. 验证创建结果

**预期结果**:
- 返回201状态码
- 返回评论ID（格式：cm_{UUID}）
- 评论状态为active
- 记录创建时间和用户信息
- 目标内容的评论数+1

### TC-API-CM-002: 评论敏感词过滤

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CM-002 |
| **用例名称** | 评论敏感词过滤 |
| **前置条件** | 1. 用户已登录<br>2. 敏感词库已配置 |
| **优先级** | P0 |
| **所属需求** | CM-MOD-001 |

**测试步骤**:
1. 提交包含敏感词的评论
2. 提交包含政治敏感词的评论
3. 提交包含广告信息的评论
4. 提交包含辱骂词汇的评论
5. 验证过滤结果

**预期结果**:
- 轻度敏感词：内容被替换为***，评论可发布
- 中度敏感词：评论进入待审核状态
- 重度敏感词（政治、违禁）：返回400错误，"评论包含违规内容"
- 广告信息：标记为spam，限制发布频率
- 记录敏感词触发日志

### TC-API-CM-003: 评论频率限制

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CM-003 |
| **用例名称** | 评论频率限制 |
| **前置条件** | 1. 用户已登录<br>2. 用户已发布多条评论 |
| **优先级** | P0 |
| **所属需求** | CM-CRT-001 |

**测试步骤**:
1. 连续快速提交5条评论（间隔<5秒）
2. 提交第6条评论
3. 等待30秒后再次提交
4. 测试同一目标重复评论
5. 测试不同目标的评论频率

**预期结果**:
- 5秒内最多3条评论，超过返回429错误
- 错误信息："评论过于频繁，请稍后再试"
- 30秒冷却后可正常评论
- 同一目标5分钟内不能重复评论相同内容
- VIP用户频率限制放宽（10条/5秒）

- 点赞数实时更新
- 自己不能给自己点赞（返回403）

### TC-API-CM-006: 评论删除功能

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CM-006 |
| **用例名称** | 评论删除功能 |
| **前置条件** | 1. 用户已登录<br>2. 存在用户自己发布的评论 |
| **优先级** | P1 |
| **所属需求** | CM-DEL-001 |

**测试步骤**:
1. 调用删除评论接口
2. 传入评论ID
3. 验证删除结果
4. 测试删除他人评论
5. 测试删除有回复的评论

**预期结果**:
- 自己的评论：软删除成功，返回204
- 他人评论：返回403错误，"无权删除他人评论"
- 有回复的评论：内容替换为"该评论已删除"，保留回复
- 删除后评论数-1
- 管理员可删除任何评论

### TC-API-CM-008: 评论编辑功能

| 属性 | 内容 |
|------|------|
| **用例ID** | TC-API-CM-008 |
| **用例名称** | 评论编辑功能 |
| **前置条件** | 1. 用户已登录<br>2. 存在自己发布的评论<br>3. 评论发布时间在5分钟内 |
| **优先级** | P2 |
| **所属需求** | CM-CRT-001 |

**测试步骤**:
1. 调用编辑评论接口
2. 传入评论ID和新内容
3. 验证编辑结果
4. 测试超过5分钟后编辑
5. 测试编辑后敏感词过滤

**预期结果**:
- 5分钟内可编辑，返回200
- 内容更新，显示"已编辑"标识
- 超过5分钟：返回403错误，"评论已超过可编辑时间"
- 编辑后重新进行敏感词检测
- 他人评论不可编辑（返回403）
