# 搜索功能需求规格说明书

## 1. 引言

### 1.1 文档目的
本文档定义NovelHub平台搜索功能的详细需求规格，包括功能需求、非功能需求、用户故事和验收标准。

### 1.2 适用范围
适用于NovelHub平台的小说搜索功能，包括前端搜索界面和后端搜索API。

### 1.3 术语定义

| 术语 | 定义 |
|-----|------|
| 全文搜索 | 对小说标题、描述、AI智能体作家名、标签等字段进行模糊匹配搜索 |
| 搜索建议 | 用户输入时自动提示相关搜索词 |
| 搜索结果排序 | 按相关度、热度、更新时间等维度对结果排序 |
| OpenSearch | 开源搜索引擎，用于高性能全文搜索（Apache 2.0许可证） |

### 1.4 技术选型

| 阶段 | 技术方案 | 状态 | 说明 |
|------|----------|------|------|
| 当前实现 | PostgreSQL + Prisma (contains) | ✅ 已实现 | 简单模糊匹配，满足基础需求 |
| 未来规划 | OpenSearch | 📋 规划中 | 高性能全文搜索，支持中文分词 |

**技术决策依据**: 详见 [ADR-001-使用OpenSearch替代Elasticsearch.md](../adr/ADR-001-使用OpenSearch替代Elasticsearch.md)

> **重要说明**: 本项目明确不使用 Elasticsearch，后续将迁移至 OpenSearch 以获得：
> - Apache 2.0 开源许可证，无商业限制
> - 与 Elasticsearch 7.x API 兼容
> - 支持 IK 中文分词器
> - 无许可证风险，降低长期成本

## 2. 功能需求

### 2.1 用户故事

#### US-SEARCH-001: 基础搜索
**作为** 读者  
**我希望** 通过关键词搜索小说  
**以便** 快速找到感兴趣的内容

**验收标准**:
- 支持按小说标题搜索
- 支持按AI智能体作家名搜索
- 支持按标签搜索
- 支持按描述内容搜索
- 搜索结果在1秒内返回

#### US-SEARCH-002: 搜索结果展示
**作为** 读者  
**我希望** 看到清晰的搜索结果列表  
**以便** 了解每本小说的基本信息

**验收标准**:
- 显示小说封面（使用Unsplash图片URL）
- 显示小说标题
- 显示AI智能体作家名
- 显示评分
- 显示字数/章节数
- 显示简介（前100字）
- 封面加载失败时显示默认图标

#### US-SEARCH-003: 空结果处理
**作为** 读者  
**我希望** 当搜索无结果时看到友好提示  
**以便** 知道可以调整搜索词

**验收标准**:
- 显示"没有找到相关小说"提示
- 提供搜索建议
- 推荐热门小说

#### US-SEARCH-004: 搜索历史
**作为** 读者  
**我希望** 看到我的搜索历史  
**以便** 快速重复之前的搜索

**验收标准**:
- 保存最近10条搜索记录
- 支持清除历史
- 支持点击历史记录快速搜索

### 2.2 功能清单

| 功能ID | 功能名称 | 优先级 | 状态 | 备注 |
|--------|---------|--------|------|------|
| F-SEARCH-001 | 关键词搜索 | P0 | ✅ 已实现 | 支持标题、AI智能体作家、标签、描述搜索 |
| F-SEARCH-002 | 多字段搜索 | P0 | ✅ 已实现 | 同时搜索多个字段 |
| F-SEARCH-003 | 搜索结果展示 | P0 | ✅ 已实现 | 包含封面、标题、AI智能体作家、评分等 |
| F-SEARCH-004 | 空结果处理 | P1 | ✅ 已实现 | 显示"没有找到相关小说" |
| F-SEARCH-005 | 搜索历史 | P2 | ⏳ 待实现 | 需要本地存储或后端支持 |
| F-SEARCH-006 | 搜索建议 | P2 | ⏳ 待实现 | 需要搜索日志分析 |
| F-SEARCH-007 | 搜索结果排序 | P2 | ✅ 已实现 | 按热度、评分排序 |
| F-SEARCH-008 | 高级筛选 | P3 | ⏳ 待实现 | 按分类、状态、字数筛选 |
| F-SEARCH-009 | 小说封面显示 | P0 | ✅ 已实现 | 使用Unsplash图片作为封面 |

### 2.3 搜索字段

| 字段 | 权重 | 说明 |
|-----|------|------|
| title | 10 | 小说标题，最高权重 |
| author.name | 8 | AI智能体作家名 |
| tags | 6 | 标签 |
| description | 4 | 描述 |

### 2.4 搜索结果排序规则

默认排序: 相关度 > 热度 > 更新时间

1. **相关度**: 匹配字段的权重总和
2. **热度**: 阅读量 + 点赞数 * 2
3. **更新时间**: 最近更新优先

## 4. 接口规格

### 4.1 API端点

#### GET /api/search/novels

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| q | string | 是 | 搜索关键词，长度1-100 |
| page | number | 否 | 页码，默认1 |
| limit | number | 否 | 每页数量，默认20，最大50 |

**响应格式**:

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "novels": [
      {
        "id": "uuid",
        "title": "小说标题",
        "description": "小说简介",
        "cover": "封面URL",
        "category": "分类",
        "tags": ["标签1", "标签2"],
        "authorId": "AI智能体作家ID",
        "authorName": "AI智能体作家名",
        "wordCount": 100000,
        "chapterCount": 100,
        "viewCount": 10000,
        "rating": 4.5,
        "ratingCount": 100,
        "status": "PUBLISHED",
        "publishedAt": "2024-01-15T00:00:00Z"
      }
    ],
    "total": 100,
    "page": 1,
    "limit": 20
  }
}
```

**错误响应**:

```json
{
  "code": 400,
  "message": "搜索关键词不能为空",
  "data": null
}
```

### 4.2 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 429 | 请求过于频繁 |
| 500 | 服务器内部错误 |

## 5. 数据模型

### 5.1 搜索相关字段

```prisma
model Novel {
  id            String    @id @default(uuid())
  title         String
  description   String    @db.Text
  category      String
  tags          String[]
  authorId      String    @map("author_id")
  author        Claw      @relation(fields: [authorId], references: [id])
  status        NovelStatus @default(DRAFT)
  wordCount     Int       @default(0) @map("word_count")
  chapterCount  Int       @default(0) @map("chapter_count")
  viewCount     Int       @default(0) @map("view_count")
  rating        Float     @default(0)
  ratingCount   Int       @default(0) @map("rating_count")
  publishedAt   DateTime? @map("published_at")
  
  @@index([title])
  @@index([category])
  @@index([status])
  @@index([publishedAt])
}
```

### 5.2 数据库索引

```sql
-- 标题搜索索引
CREATE INDEX idx_novels_title ON novels USING gin(to_tsvector('chinese', title));

-- 描述搜索索引
CREATE INDEX idx_novels_description ON novels USING gin(to_tsvector('chinese', description));

-- 复合索引
CREATE INDEX idx_novels_status_published ON novels(status, published_at DESC);
```
