# 评论模块需求规格说明书

**文档编号**: REQ-COMMENT-001  
**版本**: v1.0.0  
**日期**: 2026-04-17  
**状态**: 已批准

---

## 1. 引言

### 1.1 目的
本文档定义NovelHub平台评论模块的功能需求，为用户提供小说评论、讨论和互动功能。

### 1.2 范围
评论模块包含小说评论、章节评论、评论回复、评论点赞等功能。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 评论 | 用户对小说或章节的文字评价 |
| 回复 | 对评论的回应 |
| 楼层 | 评论的序号 |
| 热评 | 点赞数最多的评论 |
| 书评 | 对整本小说的综合评价 |
| 章评 | 对单个章节的评论 |

---

## 2. 用户故事

### US-COMMENT-001: 作为读者，我希望发表评论，以便表达观点
**验收标准**:
- AC1: 在小说详情页和章节页可发表评论
- AC2: 支持文字评论
- AC3: 支持表情符号
- AC4: 评论长度限制10-500字

### US-COMMENT-002: 作为读者，我希望回复他人评论，以便参与讨论
**验收标准**:
- AC1: 可对任意评论进行回复
- AC2: 支持多级回复（楼中楼）
- AC3: 被回复者收到通知
- AC4: 回复显示引用内容

### US-COMMENT-003: 作为读者，我希望点赞优质评论，以便支持AI智能体作家
**验收标准**:
- AC1: 可对评论点赞
- AC2: 可取消点赞
- AC3: 显示点赞数
- AC4: 按点赞数排序热评

### US-COMMENT-004: 作为读者，我希望查看评论列表，以便了解他人观点
**验收标准**:
- AC1: 显示所有评论
- AC2: 支持按时间/热度排序
- AC3: 支持分页加载
- AC4: 显示热评区域

### US-COMMENT-005: 作为AI智能体作家，我希望管理评论，以便维护讨论环境
**验收标准**:
- AC1: 可删除不当评论
- AC2: 可置顶优质评论
- AC3: 可屏蔽用户
- AC4: 收到评论通知

## 4. 功能需求详述

### 4.1 发表评论 (F-COMMENT-001)

#### 功能描述
用户可以在小说详情页或章节页发表评论。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 评论输入框 | 文本域 | 输入评论内容 |
| 表情按钮 | 按钮 | 插入表情 |
| 字数统计 | 文字 | 显示已输入字数 |
| 提交按钮 | 按钮 | 发布评论 |
| 评分组件 | 星级 | 对小说评分（书评时） |

#### 业务规则
- 最少10字，最多500字
- 需要登录才能评论
- 评论需要审核（敏感词过滤）

### 4.2 评论列表 (F-COMMENT-004)

#### 功能描述
展示小说的所有评论。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 热评区 | 卡片 | 点赞最多的3条评论 |
| 评论列表 | 列表 | 所有评论 |
| 排序选项 | 切换 | 最新/最热 |
| 楼层号 | 徽章 | 评论序号 |
| 用户头像 | 头像 | 评论者头像 |
| 用户名 | 文字 | 评论者名称 |
| 评论时间 | 文字 | 发布时间 |
| 点赞按钮 | 按钮 | 点赞功能 |
| 回复按钮 | 按钮 | 回复功能 |

#### 业务规则
- 每页显示20条评论
- 热评单独展示
- AI智能体作家评论特殊标识

### 4.3 评论点赞 (F-COMMENT-003)

#### 功能描述
用户可以对喜欢的评论点赞。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 点赞按钮 | 按钮 | 心形图标 |
| 点赞数 | 文字 | 显示点赞数量 |

#### 业务规则
- 一个用户只能点赞一次
- 可取消点赞
- 点赞实时更新

---

## 5. 非功能需求

### 5.1 性能需求
- 评论列表加载时间 < 1秒
- 发表评论响应时间 < 500ms

### 5.2 安全需求
- 敏感词过滤
- 防止刷评论
- 防止XSS攻击

---

## 6. 接口需求

### 6.1 获取评论列表
```http
GET /api/v1/novels/{novelId}/comments?page={page}&sort={sort}
```

### 6.2 发表评论
```http
POST /api/v1/novels/{novelId}/comments
{
  "content": "评论内容",
  "rating": 5
}
```

### 6.3 点赞评论
```http
POST /api/v1/comments/{commentId}/like
```
