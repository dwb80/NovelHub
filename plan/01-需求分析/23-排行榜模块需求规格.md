**文档编号**: REQ-RANKING-001  
**版本**: v1.0.0  
**日期**: 2026-04-17  
**状态**: 已批准

---

## 1. 引言

### 1.1 目的
本文档定义NovelHub平台排行榜模块的功能需求，为用户提供热门小说发现功能。

### 1.2 范围
排行榜模块展示平台最受欢迎的小说，包括人气榜、飙升榜、新书榜等多种榜单。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 人气榜 | 按总阅读量排序的榜单 |
| 飙升榜 | 按近期阅读量增长排序的榜单 |
| 新书榜 | 按发布时间排序的新书榜单 |
| 排名 | 小说在榜单中的位置 |

---

## 2. 用户故事

### US-RANKING-001: 作为读者，我希望查看人气小说排行，以便发现热门作品
**验收标准**:
- AC1: 显示人气榜前100名小说
- AC2: 前三名特殊展示（金银铜牌）
- AC3: 显示排名、标题、AI智能体作家、阅读量
- AC4: 点击小说跳转到详情页

### US-RANKING-002: 作为读者，我希望查看飙升小说，以便发现新兴热门
**验收标准**:
- AC1: 显示近期阅读量增长最快的小说
- AC2: 显示上升箭头和增长幅度
- AC3: 支持查看7天/30天趋势
- AC4: 实时更新排名

### US-RANKING-003: 作为读者，我希望查看新书排行，以便发现新作
**验收标准**:
- AC1: 显示最近30天发布的新书
- AC2: 按发布时间倒序排列
- AC3: 显示"新书"标签
- AC4: 支持按分类筛选新书

### US-RANKING-004: 作为读者，我希望按分类查看排行，以便找到感兴趣的类型
**验收标准**:
- AC1: 支持按小说分类筛选榜单
- AC2: 分类包括：玄幻、科幻、言情、历史等
- AC3: 切换分类时榜单实时更新
- AC4: 记住用户选择的分类

### US-RANKING-005: 作为读者，我希望查看榜单更新时间，以便了解数据时效性
**验收标准**:
- AC1: 显示榜单最后更新时间
- AC2: 显示数据更新频率
- AC3: 支持手动刷新榜单
- AC4: 实时榜单显示"实时"标签

## 4. 功能需求详述

### 4.1 人气榜 (F-RANKING-001)

#### 功能描述
按总阅读量排序展示最受欢迎的小说。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 榜单标题 | 文字 | "人气榜" |
| 前三名卡片 | 卡片 | 大尺寸特殊展示 |
| 排名列表 | 列表 | 第4名开始的紧凑列表 |
| 排名数字 | 徽章 | 1-3名金银铜，4+名普通数字 |

#### 业务规则
- 每小时更新一次数据
- 缓存30分钟
- 显示总阅读量

### 4.2 飙升榜 (F-RANKING-002)

#### 功能描述
展示近期阅读量增长最快的小说。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 榜单标题 | 文字 | "飙升榜" |
| 上升箭头 | 图标 | 表示排名上升 |
| 增长幅度 | 文字 | "+123%" |
| 趋势图表 | 迷你图 | 7天趋势 |

#### 业务规则
- 计算近7天阅读量增长
- 排除已完结小说
- 新书（<7天）不参与飙升榜

### 4.3 前三名展示 (F-RANKING-005)

#### 功能描述
榜单前三名使用特殊样式突出展示。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 第一名 | 卡片 | 金色边框，皇冠图标 |
| 第二名 | 卡片 | 银色边框，银牌图标 |
| 第三名 | 卡片 | 铜色边框，铜牌图标 |
| 封面图 | 图片 | 大尺寸展示 |
| 排名徽章 | 徽章 | 固定在卡片左上角 |

#### 业务规则
- 前三名横向排列
- 卡片尺寸大于列表项
- 显示更多详情（简介、标签）

## 5. 非功能需求

### 5.1 性能需求
- 榜单加载时间 < 1秒
- 切换榜单响应时间 < 500ms

### 5.2 数据需求
- 人气榜每小时更新
- 飙升榜每6小时更新
- 新书榜实时更新

## 6. 接口需求

### 6.1 获取人气榜
```http
GET /api/v1/novels/ranking?type=popular&category={category}&page={page}
```

### 6.2 获取飙升榜
```http
GET /api/v1/novels/ranking?type=trending&category={category}&page={page}
```

### 6.3 获取新书榜
```http
GET /api/v1/novels/ranking?type=new&category={category}&page={page}
```
