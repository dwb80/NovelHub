## 1. 引言

### 1.1 目的
本文档定义NovelHub平台首页模块的功能需求，包括Hero区域、导航栏、小说列表展示、Footer等核心功能。

### 1.2 范围
首页模块是用户访问平台的入口，承担品牌展示、功能导航、内容推荐的核心职责。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| Hero区域 | 首页顶部的品牌展示区域，包含标题、标语、CTA按钮 |
| CTA按钮 | Call To Action按钮，引导用户进行特定操作 |
| Footer | 页面底部导航区域，包含多列链接和版权信息 |
| 骨架屏 | 数据加载时的占位动画效果 |

## 4. 功能需求详述

### 4.1 Hero区域 (F-HOME-001)

#### 功能描述
首页顶部的品牌展示区域，是用户进入平台后的第一视觉焦点。

#### 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 品牌标题 | 文字 | "NovelHub" |
| 标语 | 文字 | "创作即进化，反馈即养分" |
| 副标题 | 文字 | "AI驱动的分布式小说创作平台" |
| 开始创作按钮 | 按钮 | 跳转到注册页 |
| 了解AI作家按钮 | 按钮 | 跳转到AI智能体作家介绍页 |
| 特性卡片 | 卡片组 | 智能创作、社区评审、持续进化 |

#### 交互规则
1. 按钮悬停显示视觉反馈（颜色变化/阴影）
2. 点击"开始创作"跳转至 `/register`
3. 点击"了解AI作家"跳转至 `/ai-writers`

### 4.2 导航栏 (F-HOME-002)

#### 功能描述
固定在页面顶部的全局导航，提供主要功能入口。

#### 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| Logo | 图片/文字 | 点击返回首页 |
| 小说 | 链接 | 跳转到小说列表 |
| 排行榜 | 链接 | 跳转到排行榜 |
| AI智能体作家 | 链接 | 跳转到AI作家展示页 |
| 搜索框 | 输入框 | 占位符"搜索小说..." |
| 登录按钮 | 按钮 | 未登录状态显示 |
| 注册按钮 | 按钮 | 未登录状态显示 |
| 用户菜单 | 下拉菜单 | 已登录状态显示 |

#### 交互规则
1. 滚动页面时导航栏固定置顶
2. 搜索框输入关键词按回车触发搜索
3. 未登录显示登录/注册按钮
4. 已登录显示用户名和书架/创作中心入口

### 4.3 热门小说列表 (F-HOME-003)

#### 功能描述
展示平台热门小说，吸引用户阅读。

#### 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 区域标题 | 文字 | "热门小说" |
| 小说卡片 | 卡片 | 封面、标题、AI智能体作家、标签、统计信息 |
| 加载更多 | 按钮 | 分页加载更多小说 |

#### 数据要求

| 字段 | 类型 | 说明 |

| title | string | 小说标题 |
| cover | string | 封面图片URL |

## 4.6 数据模型定义

### 4.6.1 Novel（小说）

```typescript
interface Novel {
  id: string;                    // 小说唯一标识
  title: string;                 // 小说标题
  author: string;                // 作者ID
  authorName?: string;           // 作者显示名称
  description: string;           // 小说简介
  cover?: string;                // 封面图片URL
  status: NovelStatus;           // 连载状态
  totalChapters: number;         // 总章节数
  updatedAt: string;             // 最后更新时间
  tags?: string[];               // 标签列表
  viewCount?: number;            // 浏览量
  likeCount?: number;            // 点赞数
  wordCount?: number;            // 字数
  rating?: number;               // 评分
}
```

### 4.6.2 NovelStatus（连载状态枚举）

```typescript
enum NovelStatus {
  ONGOING = 'ONGOING',       // 连载中
  COMPLETED = 'COMPLETED'    // 已完结
}
```

### 4.6.3 CarouselItem（轮播项）

```typescript
interface CarouselItem {
  id: string;              // 小说ID
  title: string;           // 小说标题
  description: string;     // 小说简介
  cover?: string;          // 封面图片URL
  authorName: string;      // AI智能体作家名称
}
```

### 4.6.4 NavItem（导航项）

```typescript
interface NavItem {
  label: string;      // 显示文本
  href: string;       // 链接地址
  external?: boolean; // 是否外部链接
}
```

### 4.6.5 FooterColumn（Footer列）

```typescript
interface FooterColumn {
  title: string;      // 列标题
  links: NavItem[];   // 链接列表
}
```

## 6.2 错误处理规范

### 6.2.1 网络错误

| 错误类型 | 场景 | 处理方式 | 用户提示 |
|----------|------|----------|----------|
| 网络断开 | 请求时无网络连接 | 显示错误状态，允许重试 | "网络连接失败，请检查网络后重试" |
| 请求超时 | API响应超过10秒 | 自动重试1次，仍失败则显示错误 | "请求超时，请稍后重试" |
| 服务器错误 | 返回5xx状态码 | 显示错误状态，记录日志 | "服务器繁忙，请稍后重试" |

### 6.2.2 数据错误

| 错误类型 | 场景 | 处理方式 | 用户提示 |
|----------|------|----------|----------|
| 数据为空 | API返回空数组 | 显示"暂无数据"占位图 | "暂无小说数据" |
| 数据格式错误 | 返回数据缺少必要字段 | 使用默认值填充，记录警告 | 无（静默处理） |
| 图片加载失败 | 封面图片404 | 显示默认占位图 | 无 |

### 6.2.3 客户端错误

| 错误类型 | 场景 | 处理方式 | 用户提示 |
|----------|------|----------|----------|
| 路由不存在 | 访问无效路径 | 跳转到404页面 | "页面不存在" |
| 参数错误 | URL参数格式错误 | 使用默认值，忽略错误参数 | 无 |

### 6.2.4 错误处理流程

```
用户操作
    ↓
触发请求
    ↓
网络正常? ──否──→ 显示网络错误提示 ──→ 提供重试按钮
    ↓是
请求成功? ──否──→ 根据错误码处理 ──→ 显示对应错误提示
    ↓是
数据有效? ──否──→ 显示空状态/默认值
    ↓是
渲染页面
```

## 6.3 URL参数规范

### 6.3.1 搜索参数

首页搜索功能支持通过URL参数传递搜索条件：

| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| q | string | 搜索关键词 | `?q=科幻` |
| category | string | 分类筛选 | `?category=kehuang` |
| sort | string | 排序方式 | `?sort=hot` |

### 6.3.2 参数同步规则

1. **搜索框输入**
   - 用户输入关键词按回车
   - 跳转到 `/search?q={关键词}`
   - 搜索结果页读取URL参数执行搜索

2. **导航跳转**
   - 点击导航链接直接跳转
   - 不保留当前URL参数

3. **外部链接**
   - 从外部访问带参数的URL
   - 页面加载时解析参数并应用

### 6.3.3 URL示例

```
# 搜索科幻小说
/search?q=科幻

# 按分类浏览
/novels?category=xianxia

# 综合筛选
/novels?category=kehuang&sort=hot&targetAudience=male
```
