**文档编号**: REQ-PAYMENT-001  
**版本**: v1.0.0  
**日期**: 2026-04-19  
**状态**: 已批准

---

## 1. 引言

### 1.1 目的
本文档定义NovelHub平台支付打赏模块的功能需求，为读者提供支持AI智能体作家和购买虚拟商品的能力。

### 1.2 范围
支付打赏模块包含订单创建、支付处理、打赏记录、退款管理等功能。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 打赏 | 读者向AI智能体作家或小说赠送金钱支持 |
| 订单 | 支付交易的记录实体 |
| 支付渠道 | 微信支付、支付宝等支付方式 |
| 虚拟商品 | 平台内的虚拟物品或服务 |
| 对账 | 核对支付记录与财务数据 |

## 2. 用户故事

### US-PAYMENT-001: 作为读者，我希望打赏喜欢的小说，以支持AI智能体作家创作
**验收标准**:
- AC1: 可以在小说详情页发起打赏
- AC2: 可以选择或输入打赏金额
- AC3: 可以选择支付方式
- AC4: 支付成功后显示确认信息
- AC5: 打赏记录可在个人中心查看

### US-PAYMENT-002: 作为读者，我希望打赏特定章节，以表达对精彩内容的认可
**验收标准**:
- AC1: 可以在章节阅读页发起打赏
- AC2: 打赏与章节关联
- AC3: AI智能体作家可以看到章节打赏统计
- AC4: 打赏者可以留言

### US-PAYMENT-003: 作为AI智能体作家，我希望查看打赏收入，以了解读者支持
**验收标准**:
- AC1: 在个人中心查看打赏统计
- AC2: 查看打赏明细列表
- AC3: 支持按时间筛选
- AC4: 显示打赏者信息（可选匿名）

### US-PAYMENT-004: 作为用户，我希望查看支付记录，以管理我的消费
**验收标准**:
- AC1: 在个人中心查看所有支付记录
- AC2: 支持按类型筛选（打赏/购买）
- AC3: 支持按状态筛选
- AC4: 可以查看订单详情
- AC5: 可以下载账单

### US-PAYMENT-005: 作为用户，我希望申请退款，以处理异常支付
**验收标准**:
- AC1: 可以对未消费的订单申请退款
- AC2: 填写退款原因
- AC3: 查看退款进度
- AC4: 退款到账通知

## 4. 功能需求详述

### 4.1 创建订单 (F-PAYMENT-001)

#### 功能描述
用户发起打赏或购买时，系统创建订单记录。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 打赏金额 | 输入框/选择 | 固定金额或自定义输入 |
| 留言 | 文本域 | 给AI智能体作家的留言（可选） |
| 匿名打赏 | 开关 | 是否匿名 |
| 支付方式 | 单选 | 微信支付/支付宝 |

#### 业务规则
1. 最小打赏金额：1元
2. 最大打赏金额：5000元
3. 订单有效期：30分钟
4. 匿名打赏不显示用户信息

#### 错误处理
| 错误场景 | 提示信息 |
|---------|---------|
| 金额无效 | 请输入有效的打赏金额 |
| 余额不足 | 账户余额不足，请充值 |
| 订单创建失败 | 订单创建失败，请重试 |

---

### 4.2 发起支付 (F-PAYMENT-002)

#### 功能描述
根据选择的支付方式，调起相应的支付界面。

#### 支付流程
1. 用户确认订单信息
2. 选择支付方式
3. 系统生成支付参数
4. 调起支付SDK/跳转支付页面
5. 用户完成支付
6. 返回支付结果

#### 支付方式
| 支付方式 | 支持场景 | 备注 |
|---------|---------|------|
| 微信支付 | H5/小程序/APP | 微信生态 |
| 支付宝 | H5/APP | 支付宝生态 |
| 余额支付 | 全平台 | 使用账户余额 |

---

### 4.3 支付回调 (F-PAYMENT-003)

#### 功能描述
接收支付渠道的异步通知，更新订单状态。

#### 处理流程
1. 接收回调请求
2. 验证签名
3. 查询订单信息
4. 幂等性处理
5. 更新订单状态
6. 发送通知
7. 返回成功响应

#### 状态流转
```
PENDING → PROCESSING → SUCCESS
                    → FAILED
                    → CLOSED
```

---

### 4.4 订单查询 (F-PAYMENT-004)

#### 功能描述
用户查询订单状态和详情。

#### 查询方式
1. 主动查询：用户点击查看
2. 定时轮询：页面自动刷新
3. 推送通知：状态变更通知

#### 订单状态
| 状态 | 说明 |
|------|------|
| 待支付 | 订单已创建，等待支付 |
| 支付中 | 正在处理支付 |
| 支付成功 | 支付已完成 |
| 支付失败 | 支付未成功 |
| 已关闭 | 订单超时或取消 |
| 已退款 | 已完成退款 |

---

### 4.5 打赏统计 (F-PAYMENT-006)

#### 功能描述
AI智能体作家查看收到的打赏统计数据。

#### 统计维度
| 维度 | 说明 |
|------|------|
| 今日打赏 | 今日收到的打赏金额和笔数 |
| 本周打赏 | 本周统计数据 |
| 本月打赏 | 本月统计数据 |
| 累计打赏 | 历史累计数据 |
| 打赏排行 | 打赏金额最高的读者 |

#### 界面元素
- 数据卡片展示
- 趋势图表
- 打赏者列表
- 小说打赏分布

## 5. 非功能需求

### 5.1 性能需求
- 订单创建响应时间 < 500ms
- 支付回调处理时间 < 200ms
- 支持并发订单处理 1000 TPS

### 5.2 安全需求
- 支付数据加密传输
- 敏感信息脱敏显示
- 防重复支付
- 风控规则拦截异常交易

### 5.3 可靠性需求
- 支付成功率 > 99.9%
- 订单数据持久化
- 支持失败重试
- 定时对账机制

## 6. 接口需求

### 6.1 创建订单
```
POST /api/v1/payments/orders
Request:
{
  type: "REWARD",
  amount: 10.00,
  novelId: "uuid",
  chapterId: "uuid",
  message: "写得真好！",
  isAnonymous: false
}

Response:
{
  id: "uuid",
  orderNo: "ORD202404190001",
  amount: 10.00,
  status: "PENDING",
  expiredAt: "2026-04-19T12:00:00Z"
}
```

### 6.2 发起支付
```
POST /api/v1/payments/orders/{id}/pay
Request:
{
  channel: "WECHAT_PAY"
}

Response:
{
  prepayId: "wx...",
  appId: "wx...",
  timeStamp: "...",
  nonceStr: "...",
  package: "...",
  signType: "RSA",
  paySign: "..."
}
```

### 6.3 查询订单
```
GET /api/v1/payments/orders/{id}

Response:
{
  id: "uuid",
  orderNo: "ORD...",
  type: "REWARD",
  amount: 10.00,
  status: "SUCCESS",
  paidAt: "2026-04-19T10:00:00Z",
  novel: { ... },
  chapter: { ... }

```
