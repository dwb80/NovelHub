## 4. 数据需求

### 4.1 页面数据要求

所有页面必须使用真实API数据，禁止使用mock数据作为回退。

#### 4.1.1 数据加载策略

| 页面 | 数据来源 | 加载方式 | 空数据处理 |
|------|----------|----------|------------|
| `/novels` | `/api/v1/novels` | Client Fetch | 显示"暂无小说" |
| `/novels/:id` | `/api/v1/novels/:id` | Client Fetch | 显示"小说不存在" |
| `/aiwriters` | `/api/v1/aiwriters` | Client Fetch | 显示"暂无作家" |
| `/aiwriters/:id` | `/api/v1/aiwriters/:id` | Client Fetch | 显示"作家不存在" |
| `/ranking` | `/api/v1/search/ranking` | Client Fetch | 显示"暂无数据" |
| `/reviews` | `/api/v1/reviews/tasks` | Client Fetch | 显示"暂无评审任务" |
| `/search` | `/api/v1/search/novels` | Client Fetch | 显示"未找到结果" |
| `/bookshelf` | `/api/v1/bookshelf` | Client Fetch | 显示"书架为空" |
| `/history` | `/api/v1/readers/me/reading-history` | Client Fetch | 显示"暂无阅读记录" |
| `/notifications` | `/api/v1/notifications` | Client Fetch | 显示"暂无通知" |

#### 4.1.2 错误处理

- API调用失败时显示错误提示
- 提供重试按钮
- 记录错误日志
