# 小说列表筛选功能需求文档

## 1. 功能概述

### 1.1 目的
为小说列表页面（/novels）增加多维度筛选功能，帮助读者快速找到感兴趣的小说。

### 1.2 适用范围
- 前端页面：http://localhost:3000/novels
- 后端 API：GET /api/v1/novels

## 2. 功能需求

### 2.1 读者筛选 (NOVELS-FILTER-001)
**需求描述**: 按照目标读者群体筛选小说

**筛选选项**:
| 选项 | 值 | 说明 |
|------|-----|------|
| 全部 | all | 显示所有小说 |
| 男生 | male | 男生向小说 |
| 女生 | female | 女生向小说 |

**数据模型**:
```typescript
enum TargetAudience {
  ALL    // 全部
  MALE   // 男生
  FEMALE // 女生
}
```

### 2.2 连载状态筛选 (NOVELS-FILTER-002)
**需求描述**: 按照小说连载状态筛选

**筛选选项**:
| 选项 | 值 | 说明 |
|------|-----|------|
| 全部 | all | 显示所有状态 |
| 连载中 | ongoing | 正在连载的小说 |
| 已完结 | completed | 已完结的小说 |

**数据模型**:
```typescript
enum SerialStatus {
  ONGOING   // 连载中
  COMPLETED // 已完结
}
```

### 2.3 字数筛选 (NOVELS-FILTER-003)
**需求描述**: 按照小说总字数筛选

**筛选选项**:
| 选项 | 值 | 字数范围 |
|------|-----|----------|
| 全部 | all | 不限 |
| 10万以下 | lt10w | 0 - 100,000 |
| 10-30万 | 10w30w | 100,000 - 300,000 |
| 30-50万 | 30w50w | 300,000 - 500,000 |
| 50-100万 | 50w100w | 500,000 - 1,000,000 |
| 100万以上 | gt100w | > 1,000,000 |

### 2.4 小说类型筛选 (NOVELS-FILTER-004)
**需求描述**: 按照小说分类筛选

**筛选选项**:
| 选项 | 值 | 说明 |
|------|-----|------|

| 玄幻 | XUANHUAN | 玄幻类小说 |

## 3. API 接口规范

### 3.1 获取小说列表
```
GET /api/v1/novels
```

**Query 参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | number | 否 | 页码，默认 1 |
| limit | number | 否 | 每页数量，默认 20 |
| targetAudience | string | 否 | 读者筛选: all/male/female |
| serialStatus | string | 否 | 状态筛选: all/ongoing/completed |
| wordCountRange | string | 否 | 字数筛选: all/lt10w/10w30w/30w50w/50w100w/gt100w |
| category | string | 否 | 分类筛选: all/XUANHUAN/XIANXIA/... |
| search | string | 否 | 搜索关键词 |

**响应示例**:
```json
{
  "novels": [
    {
      "id": "novel_001",
      "title": "小说标题",
      "targetAudience": "MALE",
      "serialStatus": "ONGOING",
      "wordCount": 150000,
      "category": "XUANHUAN",
      ...
    }
  ],
  "total": 100
}
```

## 4. 前端界面设计

### 4.1 筛选栏布局
- 位置：页面标题下方
- 样式：卡片式布局，包含四个下拉选择器
- 交互：选择后自动触发筛选，URL 同步更新

### 4.2 筛选器顺序
1. 读者：全部、男生、女生
2. 状态：全部、连载中、已完结
3. 字数：全部、10万以下、10-30万、30-50万、50-100万、100万以上
4. 类型：全部 + 14个分类选项

### 4.3 结果展示
- 显示符合条件的总数
- 支持清除所有筛选条件
- 分页展示结果

## 5. 数据一致性要求

### 5.1 数据库字段
- Novel 表必须包含 targetAudience 和 serialStatus 字段
- 已有数据需要设置合理的默认值

### 5.2 Seed 数据
- 测试数据应覆盖所有筛选组合
- 至少 20 本小说用于测试分页
