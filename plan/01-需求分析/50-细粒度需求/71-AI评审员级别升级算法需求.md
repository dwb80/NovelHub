## 2. 评审员级别体系

### 2.1 级别定义

| 级别 | 名称 | 声誉分数要求 | 评审权重 | 特权 |
|------|------|-------------|---------|------|
| JUNIOR | 初级评审员 | 0-99 | 1.0 | 基础评审权限 |

## 3. 声誉分数计算算法

### 3.1 声誉分数公式

```
ReputationScore = BaseScore + ReviewBonus + QualityBonus + ActivityBonus - Penalty
```

### 3.2 分数组成

#### 3.2.1 基础分数 (BaseScore)

| 来源 | 分数 | 说明 |
|------|------|------|
| 注册成功 | 0 | 初始分数为0 |
| 完成首次评审 | +10 | 激励首次参与 |

#### 3.2.2 评审奖励 (ReviewBonus)

| 评审类型 | 基础分 | 质量系数 | 最终分 |
|---------|--------|---------|--------|
| 普通评审 | +5 | 0.8-1.2 | +4 ~ +6 |
| 优先评审 | +10 | 0.8-1.2 | +8 ~ +12 |
| 紧急评审 | +15 | 0.8-1.2 | +12 ~ +18 |

#### 3.2.3 质量奖励 (QualityBonus)

| 质量指标 | 条件 | 奖励分 |
|---------|------|--------|
| 高质量评审 | 评审被采纳 | +10 |
| 一致性奖励 | 与多数评审一致 | +5 |
| 详细反馈 | 评论字数>200 | +3 |
| 及时完成 | 24小时内完成 | +2 |

#### 3.2.4 活跃度奖励 (ActivityBonus)

| 活跃指标 | 条件 | 奖励分 |
|---------|------|--------|
| 连续活跃 | 连续7天评审 | +20 |
| 月度活跃 | 月评审>20次 | +30 |
| 周期活跃 | 周评审>5次 | +10 |

#### 3.2.5 惩罚扣分 (Penalty)

| 违规类型 | 扣分 | 说明 |
|---------|------|------|
| 超时未完成 | -10 | 任务超时 |
| 低质量评审 | -5 | 评审被投诉 |
| 恶意评审 | -50 | 严重违规 |
| 长期不活跃 | -20 | 30天未评审 |

### 3.3 算法实现

```typescript
function calculateReputationScore(reviewer: ReviewerStats): number {
  let score = reviewer.reputationScore || 0;
  
  // 评审奖励
  const reviewBonus = reviewer.completedReviews * 5 * getQualityCoefficient(reviewer);
  score += reviewBonus;
  
  // 质量奖励
  const qualityBonus = calculateQualityBonus(reviewer);
  score += qualityBonus;
  
  // 活跃度奖励
  const activityBonus = calculateActivityBonus(reviewer);
  score += activityBonus;
  
  // 惩罚扣分
  const penalty = calculatePenalty(reviewer);
  score -= penalty;
  
  return Math.max(0, score);
}

function getQualityCoefficient(reviewer: ReviewerStats): number {
  // 基于评审准确率和反馈质量计算系数
  const accuracy = reviewer.accuracy || 0.8;
  const feedbackQuality = reviewer.avgFeedbackLength > 200 ? 0.1 : 0;
  return Math.min(1.2, 0.8 + accuracy * 0.3 + feedbackQuality);
}

function determineLevel(reputationScore: number): ReviewerLevel {
  if (reputationScore >= 500) return 'EXPERT';
  if (reputationScore >= 300) return 'SENIOR';
  if (reputationScore >= 100) return 'INTERMEDIATE';
  return 'JUNIOR';
}
```

## 4. 级别升级条件

### 4.1 升级条件矩阵

| 目标级别 | 声誉分数 | 最低评审数 | 准确率要求 | 活跃天数 |
|---------|---------|-----------|-----------|---------|
| INTERMEDIATE | ≥100 | ≥10 | ≥70% | ≥7 |
| SENIOR | ≥300 | ≥50 | ≥75% | ≥30 |
| EXPERT | ≥500 | ≥100 | ≥80% | ≥60 |

### 4.2 升级流程

```
1. 定时任务检查（每小时）
   ↓
2. 计算当前声誉分数
   ↓
3. 检查升级条件
   ↓
4. 满足条件 → 自动升级
   ↓
5. 发送升级通知
   ↓
6. 记录升级历史
```

## 5. 级别降级机制

### 5.1 降级条件

| 条件 | 触发 | 降级幅度 |
|------|------|---------|
| 声誉分数下降 | 低于当前级别下限 | 降一级 |
| 长期不活跃 | 60天未评审 | 降一级 |
| 恶意评审 | 被判定恶意 | 降至JUNIOR |

### 5.2 降级保护

- 降级后30天内不会再次降级
- 降级后保留50%的声誉分数
- 提供申诉渠道
