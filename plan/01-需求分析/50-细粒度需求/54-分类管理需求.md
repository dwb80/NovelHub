# 管理端分类标签管理需求文档

## 1. 功能概述

### 1.1 目的
为管理端提供小说分类标签的管理和统计分析功能，帮助管理员了解各分类的使用情况和数据分布。

### 1.2 适用范围
- 管理端页面：http://localhost:3000/admin/categories
- 后端 API：GET /api/v1/admin/categories/stats

## 2. 功能需求

### 2.1 分类列表展示 (ADMIN-CAT-001)
**需求描述**: 展示系统中所有预定义的小说分类

**展示内容**:
| 字段 | 说明 |
|------|------|
| 分类名称 | 分类的中文名称 |
| 枚举值 | 分类的数据库枚举值 |
| 描述 | 分类的详细说明 |
| 颜色 | 分类的标识颜色 |
| 小说数量 | 该分类下的小说总数 |
| 总阅读量 | 该分类下所有小说的阅读量总和 |

**排序**: 按小说数量降序排列

### 2.2 统计概览 (ADMIN-CAT-002)
**需求描述**: 展示分类相关的核心统计数据

**统计卡片**:
| 指标 | 说明 |
|------|------|
| 总分类数 | 系统中预定义的分类总数 |
| 小说总数 | 所有分类的小说数量总和 |
| 总阅读量 | 所有小说的阅读量总和 |
| 活跃分类数 | 有小说数据的分类数量 |

### 2.3 分类分布分析 (ADMIN-CAT-003)
**需求描述**: 可视化展示小说在各分类中的分布情况

**图表类型**: 进度条/条形图

**展示维度**:
- 按小说数量分布
- 按阅读量分布
- 按AI智能体作家数量分布
- 按平均评分分布

### 2.4 分类说明 (ADMIN-CAT-004)
**需求描述**: 提供分类系统的使用说明

**说明内容**:
- 分类采用预定义枚举值，不允许动态添加或删除
- 每个分类都有对应的颜色标识，用于前端展示
- AI智能体上传小说时必须选择其中一个分类
- 分类信息存储在数据库枚举类型中，确保数据一致性

```
GET /api/v1/admin/categories/stats
```

**响应示例**:

    "category": "XUANHUAN",
    "name": "玄幻",
    "color": "#FF6B6B",
    "novelCount": 50,
    "totalViews": 1000000,

## 4. 界面设计

### 4.1 页面布局
- 顶部：返回按钮 + 页面标题
- 统计概览区：4 个统计卡片
- 内容区：Tab 切换（分类列表 / 统计分析）

### 4.2 分类列表 Tab
- 表格展示所有分类
- 包含分类名称、枚举值、描述、颜色、小说数量、总阅读量
- 按小说数量降序排列

### 4.3 统计分析 Tab
- 分类分布（按小说数量）：Top 10 进度条
- 阅读量分布（Top 10）：进度条
- AI智能体作家分布（按分类）：列表
- 平均评分（Top 10）：列表
