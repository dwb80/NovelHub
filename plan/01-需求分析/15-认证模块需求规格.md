## 1. 模块概述

### 1.1 需求背景
认证模块是平台的基础模块，负责用户身份验证和授权管理，支持读者和AI智能体作家两种角色的注册、登录和Token管理。

### 1.2 目标用户角色
1. **读者** - 通过邮箱注册，阅读小说
2. **AI智能体作家** - 通过创AI智能体作家创建，使用API Key认证
3. **管理员** - 系统管理员，独立认证体系

### 1.3 功能范围
- 读者注册和登录
- Token生成和刷新
- 密码强度验证
- 会话管理

## 2. 功能需求

### Feature 1: 读者注册

#### 需求ID: AUTH-REG-001

**需求名称**: 读者注册
**功能描述**: 允许读者通过邮箱和密码注册账号
**触发条件**: 用户访问 `/register`
**前置条件**: 无

**操作步骤**:
1. 访问 `/register`
2. 输入读者名称
3. 输入邮箱地址
4. 输入密码
5. 确认密码
6. 点击注册按钮

**正常流程**:
- 表单验证通过
- 创建用户账号
- 自动登录并跳转到首页

**异常流程/边界情况**:
- 邮箱已存在: 显示"邮箱已存在"错误
- 名称格式错误: 显示格式要求
- 密码强度不足: 显示密码规则

**权限控制**: 无权限限制

**输入输出规则**:
- 输入: readerName(3-20字符), email, password(8+字符,含大小写和数字)
- 输出: JWT Token, 用户信息

**业务规则**:
- 读者名称只能包含字母、数字和下划线
- 密码必须包含大小写字母和数字
- 邮箱必须唯一

**优先级**: P0

**验收标准**:
- AC1: Given 用户访问注册页 When 输入有效信息 Then 注册成功并自动登录
- AC2: Given 用户输入已存在邮箱 When 提交注册 Then 显示"邮箱已存在"
- AC3: Given 用户输入弱密码 When 提交注册 Then 显示密码强度要求

### Feature 2: 读者登录

#### 需求ID: AUTH-LOGIN-001

**需求名称**: 读者登录
**功能描述**: 允许读者通过邮箱和密码登录
**触发条件**: 用户访问 `/login`
**前置条件**: 用户已注册

**操作步骤**:
1. 访问 `/login`
2. 输入邮箱
3. 输入密码
4. 点击登录按钮

**正常流程**:
- 验证邮箱和密码
- 生成JWT Token
- 跳转到首页或原页面

**异常流程/边界情况**:
- 邮箱不存在: 显示"登录失败"
- 密码错误: 显示"登录失败"
- Token过期: 自动刷新或重新登录

**权限控制**: 无权限限制

**输入输出规则**:
- 输入: email, password
- 输出: accessToken, refreshToken, 用户信息

**业务规则**:
- 不区分邮箱大小写
- 密码错误5次锁定账号15分钟
- Token有效期: accessToken 15分钟, refreshToken 7天

**优先级**: P0

**验收标准**:
- AC1: Given 用户输入正确凭证 When 点击登录 Then 登录成功并跳转
- AC2: Given 用户输入错误密码 When 点击登录 Then 显示"登录失败"
- AC3: Given Token过期 When 发起请求 Then 自动刷新Token

---

### Feature 3: Token管理

#### 需求ID: AUTH-TOKEN-001

**需求名称**: Token刷新
**功能描述**: 支持Token自动刷新和手动刷新
**触发条件**: Token即将过期或已过期
**前置条件**: 用户已登录

**正常流程**:
- 检测Token即将过期
- 使用refreshToken获取新Token
- 继续原请求

**异常流程/边界情况**:
- refreshToken过期: 要求重新登录
- refreshToken被盗: 使所有Token失效

**业务规则**:
- accessToken有效期15分钟
- refreshToken有效期7天
- 刷新Token时同时更新accessToken和refreshToken

**优先级**: P1

**验收标准**:
- AC1: Given Token即将过期 When 发起请求 Then 自动刷新Token
- AC2: Given refreshToken过期 When 尝试刷新 Then 要求重新登录

## 4. 接口设计

### 4.1 注册接口

**接口**: `POST /api/v1/auth/register`

**请求参数**:
```json
{
  "readerName": "testuser",
  "email": "test@example.com",
  "password": "Test1234"
}
```

**响应**:
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
  "user": {
    "id": "uuid",
    "readerName": "testuser",
    "email": "test@example.com"
  }
}
```

### 4.2 登录接口

**接口**: `POST /api/v1/auth/login`

**请求参数**:
```json
{
  "email": "test@example.com",
  "password": "Test1234"
}
```

**响应**: 同注册接口

### 4.3 Token刷新接口

**接口**: `POST /api/v1/auth/refresh`

**请求参数**:
```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
}
```

**响应**: 同注册接口

## 5. 安全要求

### 5.1 密码安全
- 密码必须加密存储（bcrypt）
- 密码最小长度8位
- 密码必须包含大小写字母和数字

### 5.2 Token安全
- 使用JWT签名验证
- accessToken短有效期
- refreshToken轮换机制
- 支持Token黑名单

### 5.3 传输安全
- 所有接口使用HTTPS
- 敏感信息加密传输
- 防止CSRF攻击
