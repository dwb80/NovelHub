## 1. 引言

### 1.1 目的
本文档定义NovelHub平台书架模块的功能需求，为用户提供小说收藏、阅读历史管理和阅读进度追踪功能。

### 1.2 范围
书架模块是用户的个人阅读空间，包含收藏的小说、阅读历史、阅读进度同步等功能。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 书架 | 用户收藏的小说集合 |
| 阅读历史 | 用户阅读过的小说记录 |
| 阅读进度 | 用户在每本小说中的阅读位置 |
| 最近阅读 | 按最后阅读时间排序的小说列表 |

---

## 2. 用户故事

### US-BOOKSHELF-001: 作为读者，我希望收藏喜欢的小说，以便日后阅读
**验收标准**:
- AC1: 在小说详情页可以添加/取消收藏
- AC2: 收藏成功后显示提示信息
- AC3: 收藏的小说出现在书架页面
- AC4: 取消收藏后从书架移除

### US-BOOKSHELF-002: 作为读者，我希望查看阅读历史，以便继续阅读
**验收标准**:
- AC1: 书架页面显示阅读历史列表
- AC2: 按最后阅读时间倒序排列
- AC3: 显示每本小说的阅读进度
- AC4: 点击小说跳转到阅读位置

### US-BOOKSHELF-003: 作为读者，我希望同步阅读进度，以便跨设备阅读
**验收标准**:
- AC1: 阅读时自动保存进度
- AC2: 换设备登录后进度自动同步
- AC3: 显示上次阅读时间和位置
- AC4: 支持手动刷新进度

### US-BOOKSHELF-004: 作为读者，我希望对书架进行分类管理，以便整理小说
**验收标准**:
- AC1: 支持创建自定义分类
- AC2: 支持将小说移动到分类
- AC3: 支持按分类筛选
- AC4: 支持删除分类（不删除小说）

### US-BOOKSHELF-005: 作为读者，我希望查看小说更新提醒，以便追更
**验收标准**:
- AC1: 书架显示有更新的小说标记
- AC2: 显示未读章节数量
- AC3: 一键跳转到最新章节
- AC4: 支持开启/关闭更新提醒

## 4. 功能需求详述

### 4.1 添加收藏 (F-BOOKSHELF-001)

#### 功能描述
用户可以在小说详情页将小说添加到书架。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 收藏按钮 | 按钮 | 心形图标，未收藏为空心，已收藏为实心 |
| 收藏数 | 文字 | 显示该小说的总收藏数 |

#### 业务规则
- 未登录用户点击收藏按钮，跳转到登录页
- 已收藏的小说再次点击取消收藏
- 收藏成功后显示Toast提示

### 4.2 书架列表展示 (F-BOOKSHELF-003)

#### 功能描述
书架页面以网格或列表形式展示用户收藏的小说。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 视图切换 | 切换按钮 | 网格视图/列表视图 |
| 排序选项 | 下拉菜单 | 最近阅读/最近添加/书名/AI智能体作家 |
| 筛选选项 | 标签 | 全部/在读/已读完/未开始 |
| 小说卡片 | 卡片 | 封面、标题、AI智能体作家、阅读进度 |

#### 业务规则
- 默认按最近阅读时间倒序排列
- 支持按阅读状态筛选
- 空书架显示引导提示

### 4.3 阅读进度同步 (F-BOOKSHELF-005)

#### 功能描述
自动保存和同步用户的阅读进度。

#### 界面元素
| 元素 | 类型 | 说明 |
|------|------|------|
| 进度条 | 进度条 | 显示当前阅读进度百分比 |
| 阅读位置 | 文字 | 显示"第X章 X%" |
| 上次阅读 | 文字 | 显示"2小时前阅读" |

#### 业务规则
- 每30秒自动保存一次进度
- 章节切换时立即保存
- 支持离线阅读，联网后同步

## 5. 非功能需求

### 5.1 性能需求
- 书架列表加载时间 < 1秒
- 阅读进度保存延迟 < 100ms

### 5.2 安全需求
- 只能查看自己的书架
- 阅读进度数据加密存储

### 5.3 兼容性需求
- 支持桌面端、平板端、移动端

## 6. 接口需求

### 6.1 获取书架列表
```http
GET /api/v1/bookshelf
```

### 6.2 添加收藏
```http
POST /api/v1/bookshelf
{
  "novelId": "uuid"
}
```

### 6.3 取消收藏
```http
DELETE /api/v1/bookshelf/{novelId}
```

### 6.4 更新阅读进度
```http
PUT /api/v1/bookshelf/progress
{
  "novelId": "uuid",
  "chapterId": "uuid",
  "progress": 65.5
}
```
