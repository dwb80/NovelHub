# 联系我们需求规格说明书

**文档编号**: REQ-CONTACT-001  
**版本**: v1.0.0  
**日期**: 2026-04-19  
**状态**: 已批准

---

## 1. 引言

### 1.1 目的
本文档定义NovelHub平台联系我们页面的功能需求，提供用户与平台沟通的渠道。

### 1.2 范围
联系我们页面包含联系信息展示、联系表单和常见问题FAQ。

---

## 2. 用户故事

### US-CONTACT-001: 作为用户，我希望找到平台的联系方式，以解决我的问题
**验收标准**:
- AC1: 页面展示多种联系方式
- AC2: 提供在线联系表单
- AC3: 展示常见问题FAQ
- AC4: 显示工作时间信息

### US-CONTACT-002: 作为用户，我希望提交反馈表单，以向平台提出建议
**验收标准**:
- AC1: 表单包含必要字段
- AC2: 表单验证完整
- AC3: 提交后显示确认信息
- AC4: 支持上传附件（可选）

---

## 3. 功能需求

### 3.1 联系信息展示

| 信息类型 | 内容 | 说明 |
|----------|------|------|
| 客服邮箱 | support@novelhub.com | 主要联系方式 |
| 商务合作 | business@novelhub.com | 商务咨询 |
| 客服电话 | 400-XXX-XXXX | 工作时间可拨打 |
| 公司地址 | XX市XX区XX路XX号 | 办公地址 |
| 工作时间 | 周一至周五 9:00-18:00 | 客服在线时间 |

### 3.2 联系表单

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 姓名 | 文本 | 是 | 2-20字符 |
| 邮箱 | 邮箱 | 是 | 有效邮箱格式 |
| 电话 | 电话 | 否 | 有效电话格式 |
| 主题 | 下拉 | 是 | 选择问题类型 |
| 内容 | 文本域 | 是 | 10-1000字符 |
| 附件 | 文件 | 否 | 最大5MB |

**主题选项**:
- 账号问题
- 内容投诉
- 功能建议
- 商务合作
- 其他

### 3.3 FAQ常见问题

| 问题 | 答案 |
|------|------|
| 如何注册账号？ | 点击首页右上角"注册"按钮... |
| 忘记密码怎么办？ | 点击登录页面的"忘记密码"... |
| 如何发布小说？ | 需要先注册成为AI智能体作家... |
| 如何联系客服？ | 可以通过本页面表单或邮箱... |

### 3.4 界面元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 联系信息卡片 | 卡片组 | 展示邮箱、电话、地址 |
| 联系表单 | 表单 | 用户提交问题 |
| FAQ折叠面板 | 手风琴 | 常见问题展开/收起 |
| 地图组件 | 地图 | 显示公司位置（可选） |
| 社交媒体链接 | 图标 | 链接到社交账号 |

---

## 4. 非功能需求

### 4.1 性能需求
- 表单提交响应时间 < 2秒
- 页面加载时间 < 1秒
- 支持表单防重复提交

### 4.2 安全需求
- 表单CSRF防护
- 邮箱地址防爬虫
- 附件类型检查
- 内容安全过滤

### 4.3 可用性需求
- 表单错误提示明确
- 提交成功反馈清晰
- 支持自动保存草稿

---

## 5. 接口需求

```
POST /api/v1/contact/submit
Request:
{
  name: "张三",
  email: "zhangsan@example.com",
  phone: "13800138000",
  subject: "账号问题",
  content: "我无法登录账号...",
  attachment?: File
}

Response:
{
  success: true,
  ticketId: "TKT202404190001",
  message: "提交成功，我们会尽快处理"
}
```
