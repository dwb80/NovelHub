# NTF-001 通知系统需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 通知系统 (Notifications)  
**需求等级**: P1 - 必须实现

---

## 1. 需求概述

### 1.1 功能目标
为用户提供系统通知功能，包括小说更新、评论回复、系统公告等。

### 1.2 通知类型
- 小说更新通知
- 评论回复通知
- 系统公告
- 活动通知
- 私信通知

---

## 2. 功能需求

### 2.1 通知列表 (NTF-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | NTF-001-001 |
| **功能描述** | 展示用户所有通知 |
| **分类筛选** | 全部、更新、互动、系统 |
| **排序方式** | 时间倒序 |
| **分页加载** | 每页20条 |
| **已读/未读** | 视觉区分（红点、高亮） |

### 2.2 推送通知 (NTF-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | NTF-001-002 |
| **功能描述** | 浏览器/移动端推送 |
| **推送条件** | 用户开启推送权限 |
| **推送内容** | 小说更新、评论回复 |
| **免打扰** | 支持设置免打扰时段 |

### 2.3 通知设置 (NTF-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | NTF-001-003 |
| **功能描述** | 用户自定义通知偏好 |
| **设置项** | 更新通知、评论通知、系统通知、推送开关 |
| **粒度控制** | 按小说设置是否接收更新通知 |
