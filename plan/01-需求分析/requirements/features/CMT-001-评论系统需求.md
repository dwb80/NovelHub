# CMT-001 评论系统需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 评论系统 (Comments)  
**需求等级**: P1 - 必须实现

---

## 1. 需求概述

### 1.1 功能目标
为小说、章节提供评论功能，支持用户发表观点、互动交流，增强社区氛围。

### 1.2 用户场景
- 用户阅读完章节后发表评论
- 用户查看其他读者的评论和观点
- 用户对评论进行点赞、回复
- 作者查看读者反馈

---

## 2. 功能需求

### 2.1 发表评论 (CMT-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-001 |
| **功能描述** | 用户发表对小说或章节的评论 |
| **评论对象** | 小说整体、单个章节 |
| **内容限制** | 最少5字，最多500字 |
| **敏感词过滤** | 自动检测并拦截敏感内容 |
| **频率限制** | 同一章节30秒内只能评论一次 |
| **API端点** | `POST /api/comments` |

### 2.2 评论列表展示 (CMT-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-002 |
| **功能描述** | 展示评论列表 |
| **排序方式** | 最新、最热（点赞数）、最早 |
| **分页加载** | 每页10条，支持无限滚动 |
| **展示内容** | 用户头像、昵称、评论内容、时间、点赞数、回复数 |
| **楼层显示** | 显示楼层号（#1, #2...） |

### 2.3 评论回复 (CMT-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-003 |
| **功能描述** | 对评论进行回复 |
| **回复层级** | 支持二级回复（评论的评论） |
| **@功能** | 支持@其他用户 |
| **回复展示** | 楼中楼形式或展开显示 |
| **通知** | 被回复用户收到通知 |

### 2.4 点赞功能 (CMT-001-004)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-004 |
| **功能描述** | 对评论点赞 |
| **点赞状态** | 已点赞/未点赞 |
| **取消点赞** | 支持取消 |
| **防刷机制** | 同一评论短时间内不能重复点赞 |
| **API端点** | `POST /api/comments/:id/like` |

### 2.5 删除评论 (CMT-001-005)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-005 |
| **功能描述** | 删除自己发表的评论 |
| **权限控制** | 仅评论作者可删除 |
| **软删除** | 标记删除，保留数据 |
| **级联删除** | 删除评论时同时删除其回复 |

### 2.6 举报功能 (CMT-001-006)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-006 |
| **功能描述** | 举报违规评论 |
| **举报类型** | 垃圾广告、人身攻击、色情低俗、政治敏感 |
| **举报流程** | 选择类型 → 填写说明 → 提交 |
| **处理机制** | 进入审核队列，人工处理 |

### 2.7 评论审核 (CMT-001-007)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | CMT-001-007 |
| **功能描述** | 评论发布前审核 |
| **审核策略** | 先发后审/先审后发（可配置） |
| **自动审核** | 敏感词过滤、AI内容检测 |
| **人工审核** | 后台审核队列 |

## 3. API接口

### 3.1 发表评论
```
POST /api/comments
```

**请求体**:
```json
{
  "novelId": "uuid",
  "chapterId": "uuid",
  "content": "评论内容",
  "parentId": null
}
```

### 3.2 获取评论列表
```
GET /api/comments
```

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| novelId | string | 条件 | 小说ID |
| chapterId | string | 条件 | 章节ID |
| sortBy | string | 否 | 排序方式：newest/hottest/oldest |
| page | number | 否 | 页码 |
| limit | number | 否 | 每页数量 |

**响应示例**:
```json
{
  "data": [
    {
      "id": "uuid",
      "user": {
        "id": "uuid",
        "nickname": "用户名",
        "avatar": "头像URL"
      },
      "content": "评论内容",
      "floor": 1,
      "likeCount": 10,
      "replyCount": 3,
      "createdAt": "2026-04-27T10:00:00Z",
      "isLiked": false,
      "replies": [
        {
          "id": "uuid",
          "user": {...},
          "content": "回复内容",
          "toUser": {...},
          "createdAt": "2026-04-27T10:05:00Z"
        }
      ]
    }
  ],
  "total": 100
}
```

## 4. 页面级需求

### 4.1 章节评论页
- **位置**: 章节阅读页底部
- **功能**: 展示评论列表、发表评论、点赞、回复
- **快捷入口**: 阅读器工具栏显示评论数

### 4.2 小说评论页
- **页面URL**: `/novels/:id/comments`
- **功能**: 展示小说整体评论
- **筛选**: 按星级、时间筛选
