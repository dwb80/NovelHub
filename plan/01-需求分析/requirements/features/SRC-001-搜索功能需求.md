# SRC-001 搜索功能需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 搜索系统 (Search)  
**需求等级**: P0 - 阻塞级

---

## 1. 需求概述

### 1.1 功能目标
提供全文搜索功能，支持小说、作者的多维度搜索。

### 1.2 搜索场景
- 用户通过关键词搜索小说
- 用户通过作者名搜索
- 用户通过分类、标签筛选

---

## 2. 功能需求

### 2.1 关键词搜索 (SRC-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | SRC-001-001 |
| **功能描述** | 通过关键词搜索小说 |
| **搜索范围** | 小说标题、作者名、简介、标签 |
| **搜索建议** | 输入时实时显示搜索建议 |
| **搜索历史** | 保存最近10条搜索记录 |
| **热门搜索** | 展示热门搜索词 |

### 2.2 高级筛选 (SRC-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | SRC-001-002 |
| **功能描述** | 多维度筛选搜索结果 |
| **筛选条件** | 分类、状态、字数、评分、更新时间 |
| **排序方式** | 相关度、热度、更新时间、评分 |

### 2.3 搜索结果展示 (SRC-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | SRC-001-003 |
| **功能描述** | 展示搜索结果 |
| **展示内容** | 封面、标题、作者、简介、标签、评分、字数 |
| **结果数量** | 显示"找到约 X 个结果" |
| **高亮显示** | 关键词高亮 |
| **分页** | 每页20条 |

### 2.4 搜索联想 (SRC-001-004)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | SRC-001-004 |
| **功能描述** | 输入时联想提示 |
| **联想来源** | 热门小说、作者、标签 |
| **联想数量** | 最多8条 |
| **快捷操作** | 点击联想词直接搜索 |

---

## 3. API接口

### 3.1 搜索
```
GET /api/search
```

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| q | string | 是 | 搜索关键词 |
| category | string | 否 | 分类筛选 |
| status | string | 否 | 状态筛选 |
| sortBy | string | 否 | 排序方式 |
| page | number | 否 | 页码 |
