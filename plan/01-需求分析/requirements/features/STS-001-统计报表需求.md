# STS-001 统计报表需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 统计报表 (Statistics)  
**需求等级**: P2 - 重要

---

## 1. 需求概述

### 1.1 功能目标
为管理员和作者提供数据统计和报表功能，支持业务决策。

### 1.2 统计对象
- 平台整体数据
- 小说数据
- 用户数据
- 作者数据

---

## 2. 功能需求

### 2.1 平台概览 (STS-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | STS-001-001 |
| **功能描述** | 展示平台核心指标 |
| **指标内容** | 总用户数、日活跃用户、总小说数、总章节数、日阅读量 |
| **时间维度** | 今日、昨日、近7天、近30天 |
| **趋势图表** | 折线图展示趋势 |

### 2.2 小说统计 (STS-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | STS-001-002 |
| **功能描述** | 统计小说相关数据 |
| **统计内容** | 阅读量、收藏量、评论量、评分分布 |
| **排行榜** | 阅读榜、收藏榜、评分榜 |
| **分类分布** | 各分类小说数量、阅读量分布 |

### 2.3 用户统计 (STS-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | STS-001-003 |
| **功能描述** | 统计用户相关数据 |
| **统计内容** | 新增用户、活跃用户、留存率、阅读时长 |
| **用户画像** | 性别分布、年龄分布、阅读偏好 |

### 2.4 作者统计 (STS-001-004)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | STS-001-004 |
| **功能描述** | 为作者提供作品统计 |
| **统计内容** | 作品阅读量、收藏量、评论量、收入统计 |
| **粉丝数据** | 粉丝增长、粉丝活跃度 |

### 2.5 报表导出 (STS-001-005)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | STS-001-005 |
| **功能描述** | 导出统计报表 |
| **导出格式** | Excel、CSV、PDF |
| **导出范围** | 自定义时间范围 |
| **定时报表** | 支持设置定时发送报表邮件 |
