# PAY-001 支付系统需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 支付系统 (Payments)  
**需求等级**: P2 - 重要

---

## 1. 需求概述

### 1.1 功能目标
支持用户充值、购买付费章节、打赏作者等支付功能。

### 1.2 支付场景
- 账户充值
- 购买付费章节
- 打赏作者
- 购买会员

---

## 2. 功能需求

### 2.1 账户充值 (PAY-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | PAY-001-001 |
| **功能描述** | 用户充值账户余额 |
| **支付方式** | 支付宝、微信支付 |
| **充值金额** | 预设档位 + 自定义金额 |
| **到账时间** | 实时到账 |

### 2.2 余额管理 (PAY-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | PAY-001-002 |
| **功能描述** | 查看余额和交易记录 |
| **展示内容** | 当前余额、冻结金额、总收入 |
| **交易记录** | 充值、消费、打赏记录 |
| **记录筛选** | 按类型、时间筛选 |

### 2.3 付费章节购买 (PAY-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | PAY-001-003 |
| **功能描述** | 购买付费章节 |
| **定价方式** | 按字数定价、统一价格 |
| **购买方式** | 单章购买、批量购买 |
| **自动订阅** | 支持自动购买下一章 |

### 2.4 打赏功能 (PAY-001-004)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | PAY-001-004 |
| **功能描述** | 打赏作者 |
| **打赏金额** | 预设档位（100、500、1000币） |
| **自定义** | 支持自定义金额 |
| **打赏留言** | 可选填写留言 |
