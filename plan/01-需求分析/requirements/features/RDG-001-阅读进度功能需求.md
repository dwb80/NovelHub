# RDG-001 阅读进度功能需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 阅读进度 (Reading Progress)  
**需求等级**: P0 - 阻塞级

---

## 1. 需求概述

### 1.1 功能目标
记录和管理用户的阅读进度，支持跨设备同步，提供阅读统计和阅读历史。

### 1.2 用户场景
- 用户阅读到某章节中途退出，下次继续阅读
- 用户在手机阅读后，在电脑上继续
- 用户查看自己的阅读历史和统计数据

---

## 2. 功能需求

### 2.1 阅读位置记录 (RDG-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | RDG-001-001 |
| **功能描述** | 自动记录用户阅读位置 |
| **记录粒度** | 章节级别 + 页内位置（像素/百分比） |
| **保存频率** | 每30秒自动保存，退出时保存 |
| **存储内容** | 小说ID、章节ID、阅读位置、阅读百分比 |

### 2.2 阅读进度同步 (RDG-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | RDG-001-002 |
| **功能描述** | 跨设备同步阅读进度 |
| **同步时机** | 打开阅读器时拉取，阅读时推送 |
| **冲突处理** | 取最新时间戳的进度 |
| **离线支持** | 本地缓存，联网后同步 |

### 2.3 继续阅读 (RDG-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | RDG-001-003 |
| **功能描述** | 一键继续上次阅读位置 |
| **入口位置** | 书架页、小说详情页 |
| **显示信息** | "上次读到：第X章 X%" |
| **快捷操作** | 点击直接跳转到阅读位置 |

### 2.4 阅读历史 (RDG-001-004)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | RDG-001-004 |
| **功能描述** | 展示阅读历史记录 |
| **记录内容** | 阅读时间、阅读时长、阅读章节 |
| **时间分组** | 今天、昨天、本周、更早 |
| **清除历史** | 支持删除单条或清空 |

### 2.5 阅读统计 (RDG-001-005)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | RDG-001-005 |
| **功能描述** | 统计用户阅读数据 |
| **统计维度** | 总阅读时长、总阅读字数、连续阅读天数 |
| **可视化** | 图表展示阅读趋势 |
| **成就系统** | 阅读里程碑徽章 |

## 3. API接口

### 3.1 保存阅读进度
```
POST /api/reading-progress
```

**请求体**:
```json
{
  "novelId": "uuid",
  "chapterId": "uuid",
  "position": 1250,
  "percentage": 45.5,
  "totalChars": 3000
}
```

### 3.2 获取阅读进度
```
GET /api/reading-progress/:novelId
```

**响应示例**:
```json
{
  "novelId": "uuid",
  "chapterId": "uuid",
  "chapterTitle": "第10章 标题",
  "position": 1250,
  "percentage": 45.5,
  "updatedAt": "2026-04-27T10:00:00Z"
}
```
