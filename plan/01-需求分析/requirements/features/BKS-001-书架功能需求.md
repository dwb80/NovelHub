# BKS-001 书架功能需求

**文档版本**: 1.0.0  
**最后更新**: 2026-04-27  
**对应模块**: 书架管理 (Bookshelf)  
**需求等级**: P1 - 必须实现

---

## 1. 需求概述

### 1.1 功能目标
为用户提供个人书架管理功能，支持小说的添加、删除、分类、排序和阅读进度追踪。

### 1.2 用户场景
- 用户发现感兴趣的小说，添加到书架以便后续阅读
- 用户管理已添加的小说，按阅读状态分类查看
- 用户追踪阅读进度，快速继续阅读
- 用户接收小说更新提醒

---

## 2. 功能需求

### 2.1 书架列表展示 (BKS-001-001)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-001 |
| **功能描述** | 展示用户书架中的所有小说 |
| **展示内容** | 小说封面、标题、作者、最新阅读章节、阅读进度百分比、更新时间 |
| **排序方式** | 最近阅读时间、添加时间、更新时间、书名排序 |
| **视图模式** | 卡片视图、列表视图 |
| **分页** | 每页20条，支持无限滚动或分页 |

### 2.2 添加小说到书架 (BKS-001-002)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-002 |
| **功能描述** | 将小说添加到用户书架 |
| **入口位置** | 小说详情页、搜索结果页、推荐列表 |
| **按钮状态** | 未添加时显示"加入书架"，已添加显示"已在书架" |
| **业务规则** | 同一小说只能添加一次 |
| **API端点** | `POST /api/bookshelf/novels/:novelId` |

### 2.3 从书架移除 (BKS-001-003)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-003 |
| **功能描述** | 从书架中移除小说 |
| **操作方式** | 长按/右键菜单、批量选择后删除 |
| **确认机制** | 二次确认弹窗 |
| **数据保留** | 阅读进度数据保留30天，可恢复 |
| **API端点** | `DELETE /api/bookshelf/novels/:novelId` |

### 2.4 阅读状态分类 (BKS-001-004)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-004 |
| **功能描述** | 按阅读状态筛选小说 |
| **状态分类** | 全部、正在阅读、已读完、未开始、已弃书 |
| **默认选中** | "全部" |
| **统计数字** | 每个状态显示对应数量 |

### 2.5 书架分类标签 (BKS-001-005)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-005 |
| **功能描述** | 用户自定义书架分类标签 |
| **默认标签** | 默认书架、追更中、已完结、待阅读 |
| **自定义** | 支持创建、编辑、删除自定义标签 |
| **多标签** | 一本小说可属于多个标签 |
| **标签管理** | 拖拽排序、颜色标记 |

### 2.6 更新提醒 (BKS-001-006)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-006 |
| **功能描述** | 书架小说更新时提醒用户 |
| **提醒方式** | 应用内红点、推送通知（可选） |
| **提醒内容** | "《xxx》更新了第xx章" |
| **已读标记** | 点击后标记为已读，红点消失 |
| **批量操作** | 一键标记所有更新为已读 |

### 2.7 最近阅读 (BKS-001-007)

| 需求项 | 描述 |
|--------|------|
| **需求ID** | BKS-001-007 |
| **功能描述** | 快速访问最近阅读的小说 |
| **展示数量** | 最近3-5本 |
| **展示位置** | 书架顶部或独立模块 |
| **快捷操作** | 一键继续阅读 |

## 3. API接口

### 3.1 获取书架列表
```
GET /api/bookshelf/novels
```

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | string | 否 | 阅读状态筛选 |
| tagId | string | 否 | 标签筛选 |
| sortBy | string | 否 | 排序方式 |
| page | number | 否 | 页码 |
| limit | number | 否 | 每页数量 |

**响应示例**:
```json
{
  "data": [
    {
      "id": "uuid",
      "novelId": "uuid",
      "title": "小说标题",
      "author": "作者名",
      "cover": "封面URL",
      "lastReadChapter": "第10章",
      "progress": 45.5,
      "totalChapters": 100,
      "updatedAt": "2026-04-27T10:00:00Z",
      "hasUpdate": true,
      "newChapterCount": 3
    }
  ],
  "total": 50,
  "page": 1,
  "limit": 20
}
```

### 3.2 添加小说到书架
```
POST /api/bookshelf/novels/:novelId
```

**响应示例**:
```json
{
  "success": true,
  "message": "已添加到书架",
  "data": {
    "bookshelfItemId": "uuid",
    "addedAt": "2026-04-27T10:00:00Z"
  }
}
```

### 3.3 更新阅读进度
```
PATCH /api/bookshelf/novels/:novelId/progress
```

**请求体**:
```json
{
  "chapterId": "uuid",
  "chapterNumber": 10,
  "progress": 45.5,
  "lastReadPosition": 1250
}
```

## 4. 页面级需求

### 4.1 我的书架页
- **页面URL**: `/bookshelf`
- **页面标题**: 我的书架
- **主要功能**: 展示书架列表、分类筛选、排序、搜索
- **空状态**: 引导用户去发现页添加小说

### 4.2 书架管理页
- **页面URL**: `/bookshelf/manage`
- **页面标题**: 书架管理
- **主要功能**: 批量选择、移动标签、删除、排序
