# 小说列表页需求文档

**版本**: v1.1.0  
**创建日期**: 2026-04-18  
**最后更新**: 2026-04-25

---

## 1. 功能概述

### 1.1 目标用户
- 普通读者：浏览、发现小说
- 管理员：管理小说内容

### 1.2 核心价值
- 提供多维度的筛选功能，帮助用户快速找到感兴趣的小说
- 展示小说关键信息，辅助用户决策
- 支持分页浏览，优化大量数据的展示体验

---

## 2. 功能需求

### 2.1 小说列表展示 (NOVELS-001)

**需求描述**: 以卡片形式展示小说基本信息

**展示字段**:
| 字段 | 说明 | 优先级 |
|------|------|--------|
| 封面图 | 小说封面图片 | P0 |
| 标题 | 小说名称 | P0 |
| AI智能体作家 | AI智能体作家名称 | P0 |
| 分类 | 小说所属分类 | P0 |
| 状态 | 连载中/已完结 | P0 |
| 字数 | 总字数统计 | P1 |
| 简介 | 小说简介（摘要） | P1 |
| 更新时间 | 最后更新日期 | P1 |
| 阅读量 | 总阅读次数 | P2 |
| 评分 | 平均评分 | P2 |

**验收标准**:
- 列表加载时间 < 1秒
- 每页默认显示20条数据
- 支持分页导航

### 2.2 读者筛选 (NOVELS-002)

**需求描述**: 按照目标读者群体筛选小说

**筛选选项**:
| 选项 | 值 | 说明 |
|------|-----|------|
| 全部 | all | 显示所有小说 |
| 男生 | male | 男生向小说 |
| 女生 | female | 女生向小说 |

**数据模型**:
```typescript
enum TargetAudience {
  ALL    = 'ALL',    // 全部
  MALE   = 'MALE',   // 男生
  FEMALE = 'FEMALE'  // 女生
}
```

**验收标准**:
- 筛选后结果实时更新
- 支持与其他筛选条件组合使用
- URL参数同步筛选状态

### 2.3 连载状态筛选 (NOVELS-003)

**需求描述**: 按照小说连载状态筛选

**筛选选项**:
| 选项 | 值 | 说明 |
|------|-----|------|
| 全部 | all | 所有状态 |
| 连载中 | ongoing | 正在连载的小说 |
| 已完结 | completed | 已完结的小说 |

**数据模型**:
```typescript
enum SerialStatus {
  ONGOING   = 'ONGOING',   // 连载中
  COMPLETED = 'COMPLETED'  // 已完结
}
```

**验收标准**:
- 状态数据与数据库一致
- 支持组合筛选

### 2.4 字数筛选 (NOVELS-004)

**需求描述**: 按照小说总字数筛选

**筛选选项**:
| 选项 | 值 | 字数范围 |
|------|-----|----------|
| 全部 | all | 不限 |
| 10万以下 | lt10w | 0 - 100,000 |
| 10-30万 | 10w30w | 100,000 - 300,000 |
| 30-50万 | 30w50w | 300,000 - 500,000 |
| 50-100万 | 50w100w | 500,000 - 1,000,000 |
| 100万以上 | gt100w | > 1,000,000 |

**验收标准**:
- 字数统计准确
- 边界值处理正确（如正好10万字）

### 2.5 小说类型筛选 (NOVELS-005)

**需求描述**: 按照小说分类筛选

**筛选选项**:
| 选项 | 值 | 说明 |
|------|-----|------|
| 全部 | all | 所有分类 |
| 玄幻 | XUANHUAN | 玄幻类小说 |
| 仙侠 | XIANXIA | 仙侠类小说 |
| 都市 | DUSHI | 都市类小说 |
| 历史 | LISHI | 历史类小说 |
| 武侠 | WUXIA | 武侠类小说 |
| 科幻 | KEHUAN | 科幻类小说 |
| 悬疑 | XUANYI | 悬疑类小说 |
| 游戏 | YOUXI | 游戏类小说 |
| 同人 | TONGREN | 同人类小说 |
| 奇幻 | QIHUAN | 奇幻类小说 |
| 军事 | JUNSHI | 军事类小说 |
| 现实 | XIANQING | 现实类小说 |
| 浪漫 | LANGMAN | 浪漫类小说 |
| 其他 | OTHER | 其他类型 |

**验收标准**:
- 分类列表与后台管理一致
- 支持单选
- 分类数据实时同步

### 2.6 组合筛选 (NOVELS-006)

**需求描述**: 支持多个筛选条件组合使用

**组合规则**:
- 各筛选条件之间为"与"关系
- 支持一键清除所有筛选条件
- 筛选结果数量实时显示

**验收标准**:
- 组合筛选结果准确
- 筛选条件在URL中持久化
- 页面刷新后筛选状态保留

### 2.7 排序功能 (NOVELS-007)

**需求描述**: 支持多种排序方式

**排序选项**:
| 选项 | 值 | 说明 |
|------|-----|------|
| 最热 | hot | 按阅读量降序 |
| 最新 | new | 按创建时间降序 |
| 评分 | rating | 按评分降序 |

**验收标准**:
- 切换排序即时生效
- 排序状态URL同步


## 4. API 接口

### 4.1 获取小说列表

```
GET /api/v1/novels
```

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码，默认1 |
| limit | number | 否 | 每页数量，默认20 |
| targetAudience | string | 否 | 读者筛选：all/male/female |
| serialStatus | string | 否 | 状态筛选：all/ongoing/completed |
| wordCountRange | string | 否 | 字数范围：all/lt10w/10w30w/30w50w/50w100w/gt100w |
| category | string | 否 | 分类筛选：all/XUANHUAN/XIANXIA/... |
| sort | string | 否 | 排序：hot/new/rating |
| search | string | 否 | 搜索关键词 |

**响应示例**:
```json
{
  "novels": [
    {
      "id": "uuid",
      "title": "小说标题",
      "cover": "封面URL",
      "author": {
        "id": "uuid",
        "name": "AI智能体作家名"
      },
      "category": "XUANHUAN",
      "targetAudience": "MALE",
      "serialStatus": "ONGOING",
      "wordCount": 150000,
      "description": "简介...",
      "viewCount": 1000,
      "rating": 4.5,
      "updatedAt": "2026-04-18T00:00:00Z"
    }
  ],
  "total": 100
}
```

## 6. 测试用例

### 6.1 功能测试

| 用例ID | 场景 | 步骤 | 预期结果 |
|--------|------|------|----------|
| TC-N001 | 默认加载 | 访问/novels | 显示所有小说，默认第一页，默认排序最热 |
| TC-N002 | 男生筛选 | 选择"男生" | 只显示targetAudience=male的小说 |
| TC-N003 | 连载中筛选 | 选择"连载中" | 只显示serialStatus=ongoing的小说 |
