## 2. 功能模块细粒度需求

### 2.1 筛选栏 (CMT-FLT-001)

**需求ID**: CMT-FLT-001  
**需求名称**: 评论筛选栏  
**功能描述**: 提供搜索、状态筛选、时间筛选功能  
**触发条件**: 用户输入或选择筛选条件  

**正常流程**:
1. 搜索框输入时防抖300ms后触发搜索
2. 状态筛选选项：全部、正常、已屏蔽、已删除
3. 时间筛选：全部、今天、最近7天、最近30天
4. 筛选条件变化时自动刷新表格数据

**输入输出规则**:
- 输入：
  - keyword | string | 搜索关键词
  - status | enum | 状态筛选 | normal/hidden/deleted
  - timeRange | enum | 时间范围 | all/today/week/month

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 搜索框支持实时搜索
- [ ] AC2: 状态、时间筛选器正常工作
- [ ] AC3: 筛选条件变化时自动刷新表格

**来源**: [admin/comments.html L134-L147](../../html/pages/admin/comments.html#L134-L147)

### 2.2 评论数据表格 (CMT-TBL-001)

**需求ID**: CMT-TBL-001  
**需求名称**: 评论数据表格  
**功能描述**: 展示评论列表，支持查看、屏蔽、删除操作  
**触发条件**: 页面加载或筛选条件变化  
**前置条件**: 用户已登录且具有管理员权限  

**操作步骤**:
1. 查看评论列表
2. 点击"查看"按钮查看评论详情
3. 点击"屏蔽"按钮屏蔽评论
4. 点击"删除"按钮删除评论

**正常流程**:
1. 表格显示字段：评论内容（截断）、用户（头像+名称）、作品、评论时间、状态、操作
2. 状态显示为标签：正常（绿色）、已屏蔽（黄色）、已删除（红色）
3. 点击"查看"：打开评论详情弹窗
4. 点击"屏蔽"：弹出确认框，确认后评论状态变为"已屏蔽"
5. 点击"删除"：弹出确认框，确认后评论状态变为"已删除"

**异常流程/边界情况**:
- 评论内容过长：显示前50字+"..."
- 操作失败：显示错误提示

**输入输出规则**:
- 输出：
  - content | string | 评论内容
  - user_name | string | 用户名称
  - user_avatar | string | 用户头像
  - novel_name | string | 作品名称
  - created_at | string | 评论时间
  - status | enum | 状态

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 表格正确显示评论数据
- [ ] AC2: 状态标签颜色正确
- [ ] AC3: 查看/屏蔽/删除按钮正常工作
- [ ] AC4: 操作后显示toast提示

**来源**: [admin/comments.html L149-L168](../../html/pages/admin/comments.html#L149-L168)
