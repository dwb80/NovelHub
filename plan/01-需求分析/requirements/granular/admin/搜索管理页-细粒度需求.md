## 2. 搜索区域

### 2.1 搜索输入框

#### 需求ID: ADMIN-SEARCH-INPUT-001

**需求名称**: 全局搜索

**功能描述**: 搜索小说、作者、用户等

**输入规则**:
| 属性 | 规则 |
|------|------|
| 类型 | text |
| 占位符 | "搜索小说、作者、用户..." |
| 最大长度 | 100字符 |

**组件结构**:
| 元素 | 说明 |
|------|------|
| 输入框 | 搜索关键词输入 |
| 搜索按钮 | 图标按钮，执行搜索 |

**样式规则**:
- 输入框: 大尺寸，圆角，边框
- 聚焦: 边框变primary色，外发光
- 搜索按钮: 绝对定位在右侧，primary色背景

**交互**:
- 输入关键词，点击搜索或按回车执行搜索
- 实时显示搜索建议（可选）

**优先级**: P0

---

### 2.2 搜索建议

#### 需求ID: ADMIN-SEARCH-SUGGEST-001

**需求名称**: 搜索建议

**功能描述**: 显示热门搜索和搜索历史

**建议类型**:
| 类型 | 说明 |
|------|------|
| 热门搜索 | 平台热门搜索词 |
| 搜索历史 | 当前用户搜索历史 |
| 智能提示 | 根据输入实时提示 |

**样式规则**:
- 背景: elevated色
- 圆角: var(--radius-lg)
- 标签: 圆角标签，可点击

**交互**: 点击建议标签直接搜索

**优先级**: P1

## 3. 筛选条件

### 需求ID: ADMIN-SEARCH-FILTER-001

**需求名称**: 搜索结果筛选

**功能描述**: 按类型筛选搜索结果

**筛选选项**:
| 选项 | 说明 |
|------|------|
| 全部 | 显示所有类型结果 |
| 小说 | 仅显示小说 |
| 作者 | 仅显示作者 |
| 用户 | 仅显示用户 |
| 章节 | 仅显示章节 |
| 评论 | 仅显示评论 |

**组件**: 筛选标签组（chip样式）

**样式规则**:
- 标签: 圆角，边框
- 选中: primary色背景，白色文字
- 悬停: 边框变primary色

**交互**: 点击切换筛选条件，重新过滤结果

**优先级**: P0

## 4. 搜索结果列表

### 4.1 结果项

#### 需求ID: ADMIN-SEARCH-RESULT-001

**需求名称**: 搜索结果项

**功能描述**: 展示单个搜索结果

**结果类型及结构**:

**小说结果**:
| 元素 | 说明 |
|------|------|
| 封面 | 小说封面 |
| 标题 | 小说名称（高亮关键词） |
| 作者 | 作者名 |
| 简介 | 简介摘要（高亮关键词） |
| 标签 | 分类标签 |
| 数据 | 阅读量、评分 |

**作者结果**:
| 元素 | 说明 |
|------|------|
| 头像 | 作者头像 |
| 昵称 | 作者昵称（高亮关键词） |
| 简介 | 作者简介 |
| 作品数 | 作品数量 |
| 粉丝数 | 粉丝数量 |

**用户结果**:
| 元素 | 说明 |
|------|------|
| 头像 | 用户头像 |
| 昵称 | 用户昵称（高亮关键词） |
| 等级 | 用户等级 |
| 注册时间 | 注册日期 |

**样式规则**:
- 布局: 横向flex，封面/头像在左
- 背景: elevated色
- 边框: 1px solid var(--color-border)
- 圆角: var(--radius-xl)
- 悬停: 边框变primary色，阴影

**高亮规则**:
- 匹配的关键词用primary色背景高亮

**交互**:
- 点击结果项: 跳转到详情页
- 悬停: 显示悬停效果

**优先级**: P0

## 7. 交互说明

### 7.1 搜索流程

| 步骤 | 行为 |
|------|------|
| 1 | 输入关键词 |
| 2 | 显示搜索建议（可选） |
| 3 | 执行搜索 |
| 4 | 显示结果列表 |
| 5 | 可进一步筛选 |

### 7.2 结果操作

| 操作 | 行为 |
|------|------|
| 点击结果 | 跳转到详情页 |
| 切换筛选 | 重新过滤结果 |
| 翻页 | 加载更多结果 |

## 8. 数据需求汇总

### 8.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/admin/search | GET | 执行搜索 |
| /api/admin/search/suggestions | GET | 获取搜索建议 |
| /api/admin/search/logs | GET | 获取搜索日志 |
| /api/admin/search/hot | GET/POST/PUT/DELETE | 热门搜索词管理 |

### 8.2 请求参数

```typescript
interface SearchParams {
  keyword: string;
  type?: 'all' | 'novel' | 'author' | 'user' | 'chapter' | 'comment';
  page?: number;
  pageSize?: number;
}

interface SearchResult {
  type: 'novel' | 'author' | 'user' | 'chapter' | 'comment';
  data: any;
  highlights: string[]; // 高亮的关键词位置
}
```
