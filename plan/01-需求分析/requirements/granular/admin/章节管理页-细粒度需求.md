## 2. 功能模块细粒度需求

### 2.1 标签页切换 (CHP-TAB-001)

**需求ID**: CHP-TAB-001  
**需求名称**: 章节状态标签页  
**功能描述**: 按章节审核状态筛选显示：待审核、已通过、已拒绝  
**触发条件**: 用户点击标签页  
**前置条件**: 页面已加载  

**操作步骤**:
1. 点击"待审核"标签
2. 点击"已通过"标签
3. 点击"已拒绝"标签

**正常流程**:
1. 点击标签页，标签高亮显示
2. 表格数据按对应状态筛选
3. 待审核标签显示数量角标

**输入输出规则**:
- 输入：tab | enum | pending/approved/rejected | pending

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 显示3个标签页
- [ ] AC2: 待审核标签显示数量角标
- [ ] AC3: 切换标签时表格数据刷新
- [ ] AC4: 当前标签高亮显示

**来源**: [admin/chapters.html L463-L470](../../html/pages/admin/chapters.html#L463-L470)

### 2.2 批量操作栏 (CHP-BAT-001)

**需求ID**: CHP-BAT-001  
**需求名称**: 批量操作栏  
**功能描述**: 支持全选和批量通过/拒绝操作  
**触发条件**: 用户选择章节后点击批量操作按钮  
**前置条件**: 至少选中一个章节  

**操作步骤**:
1. 点击全选复选框
2. 选择单个章节复选框
3. 点击"批量通过"按钮
4. 点击"批量拒绝"按钮

**正常流程**:
1. 点击全选：选中当前页所有章节
2. 点击批量通过：弹出确认框，确认后批量通过选中章节
3. 点击批量拒绝：弹出确认框，确认后批量拒绝选中章节
4. 操作成功后显示toast提示，刷新表格

**异常流程/边界情况**:
- 未选择章节：按钮禁用或提示"请先选择"
- 操作失败：
