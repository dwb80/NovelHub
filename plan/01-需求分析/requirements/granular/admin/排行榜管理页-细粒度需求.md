## 3. 榜单类型标签

### 需求ID: ADMIN-RANK-TABS-001

**需求名称**: 榜单类型切换

**功能描述**: 切换不同类型的排行榜

**榜单类型**:
| 类型 | 说明 |
|------|------|
| 阅读榜 | 按阅读量排序 |
| 收藏榜 | 按收藏量排序 |
| 评分榜 | 按评分排序 |
| 新书榜 | 按新书热度排序 |
| 完结榜 | 按完本热度排序 |
| 飙升榜 | 按增长趋势排序 |

**组件**: 横向标签页

**样式规则**:
- 底部边框: 2px solid var(--color-border)
- 标签: padding 0.75rem 1.5rem
- 选中: primary色背景，primary色文字
- 悬停: 背景色变化

**交互**: 点击切换榜单类型，重新加载榜单数据

**优先级**: P0

## 5. 榜单列表

### 5.1 榜单项

#### 需求ID: ADMIN-RANK-LIST-001

**需求名称**: 榜单排名项

**功能描述**: 展示单个小说的排名信息

**榜单项结构**:
| 元素 | 说明 |
|------|------|
| 排名 | 排名序号，前3名特殊样式 |
| 趋势 | 排名变化趋势（上升/下降/持平） |
| 封面 | 小说封面缩略图 |
| 标题 | 小说名称 |
| 作者 | 作者名 |
| 分类 | 小说分类 |
| 数据 | 阅读量/收藏量/评分等 |
| 操作 | 查看详情、编辑、下架 |

**排名样式**:
| 排名 | 样式 |
|------|------|
| 第1名 | 金色渐变背景，白色文字 |
| 第2名 | 银色渐变背景，白色文字 |
| 第3名 | 铜色渐变背景，白色文字 |
| 其他 | 灰色背景，灰色文字 |

**趋势图标**:
| 趋势 | 图标 | 颜色 |
|------|------|------|
| 上升 | ↑ | 绿色 |
| 下降 | ↓ | 红色 |
| 持平 | - | 灰色 |

**样式规则**:
- 布局: 横向flex，两端对齐
- 背景: 白色/elevated色
- 边框: 1px solid var(--color-border)
- 圆角: var(--radius-lg)
- 悬停: 边框变primary色，阴影

**交互**:
- 点击行: 查看小说详情
- 点击操作按钮: 执行对应操作

**优先级**: P0

#### 需求ID: ADMIN-RANK-ACTION-003

## 8. 数据需求汇总

### 8.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/admin/rankings | GET | 获取榜单数据 |
| /api/admin/rankings/refresh | POST | 刷新榜单 |
| /api/admin/rankings/adjust | POST | 手动调整排名 |

### 8.2 请求参数

```typescript
interface GetRankingsParams {
  type: 'read' | 'favorite' | 'rating' | 'new' | 'completed' | 'rising';
  period: 'day' | 'week' | 'month' | 'all';
  page?: number;
  pageSize?: number;
}

interface RankingItem {
  rank: number;
  previousRank: number;
  novel: {
    id: string;
    title: string;
    cover: string;
    author: string;
    category: string;
  };
  value: number; // 阅读量/收藏量/评分等
  trend: 'up' | 'down' | 'same';
}
```
