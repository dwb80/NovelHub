# Token 过期提示功能 - 细粒度需求文档

**最后更新**: 2026-04-19
**功能版本**: v1.0
**相关模块**: Admin 管理后台

---

## 1. 功能概述

### 1.1 背景
管理后台使用 JWT Token 进行身份认证，Token 有效期为 30 分钟。由于 Admin 角色没有 Refresh Token 机制，Token 过期后用户会被强制跳转至登录页面，可能导致未保存的工作丢失。

### 1.2 目标
- 在 Token 即将过期前提醒用户
- 给用户足够时间保存工作
- 提供便捷的操作选项（延长会话或退出登录）

### 1.3 适用范围
- 所有管理后台页面 (`/admin/*`)
- 仅对 Admin 角色生效

## 2. 需求详情

### 2.1 Token 监控与预警 (ADM-TOKEN-001)

**需求ID**: ADM-TOKEN-001  
**需求名称**: Token 过期监控与预警  
**功能描述**: 实时监控 Admin Token 的过期时间，在过期前 5 分钟发出警告提示  
**触发条件**: 
- 用户登录管理后台后
- Token 剩余有效期 ≤ 5 分钟

**前置条件**: 
- 用户已登录管理后台
- Token 有效且未过期

**操作步骤**:
1. 用户登录管理后台
2. 系统自动启动 Token 监控
3. Token 即将过期时显示警告提示
4. 用户选择"我已保存，继续工作"或"立即退出登录"

**正常流程**:
1. 用户成功登录，系统解析 JWT Token 获取过期时间
2. 启动定时器每 30 秒检查一次 Token 状态
3. 当 Token 剩余时间 ≤ 5 分钟时：
   - 触发 `auth:token-expiring` 事件
   - 在页面顶部显示警告提示框
   - 显示剩余时间倒计时
4. 用户点击"我已保存，继续工作"：
   - 调用 `/admin/statistics` API 验证 Token
   - 重置警告状态
   - 继续监控
5. 用户点击"立即退出登录"：
   - 清除登录状态
   - 跳转到登录页面

**异常流程/边界情况**:
- Token 已过期：立即跳转登录页
- 用户无操作直到过期：自动跳转登录页
- 网络异常无法验证：提示网络错误

**输入输出规则**:
- 输入：JWT Token (从 localStorage 读取)
- 输出：
  - 警告提示信息 | string | 包含剩余时间
  - 倒计时更新 | number | 毫秒

**业务规则**:
- 预警阈值：5 分钟 (300,000 毫秒)
- 检查间隔：30 秒
- 时间格式："X分X秒" (如 "4分30秒")
- 提示级别：警告 (destructive alert)

**权限控制**: 仅 Admin 角色  
**优先级**: P1

**验收标准**:
- [ ] AC1: Token 监控在登录后自动启动
- [ ] AC2: 剩余时间 ≤ 5 分钟时显示警告提示
- [ ] AC3: 倒计时实时更新（每 30 秒）
- [ ] AC4: 提示框固定在页面顶部，不随滚动消失
- [ ] AC5: 提示信息包含具体剩余时间
- [ ] AC6: 提供两个操作按钮："我已保存，继续工作"和"立即退出登录"

**来源**: 功能优化需求

### 2.2 警告提示 UI (ADM-TOKEN-002)

**需求ID**: ADM-TOKEN-002  
**需求名称**: Token 过期警告提示 UI  
**功能描述**: 在页面顶部显示醒目的警告提示框，提醒用户 Token 即将过期  
**触发条件**: Token 即将过期事件触发  
**前置条件**: 用户处于管理后台页面

**操作步骤**:
1. 查看警告提示框
2. 阅读提示信息
3. 根据需要选择操作按钮

**正常流程**:
1. 警告框从页面顶部滑入显示
2. 显示图标、标题、描述信息
3. 显示剩余时间倒计时
4. 显示两个操作按钮
5. 用户操作后或 Token 过期后警告框消失

**异常流程/边界情况**:
- 用户切换页面：警告框保持显示
- 用户刷新页面：重新检查 Token 状态

**UI 规范**:
```
┌─────────────────────────────────────────────────────────┐
│  ⚠️ 登录即将过期                                         │
│  ⏱️ 登录即将在 4分30秒后过期，请保存您的工作              │
│  请尽快保存您的工作，然后重新登录以继续操作。              │
│  ┌─────────────────┐  ┌───────────────┐                  │
│  │ 我已保存，继续工作 │  │ 立即退出登录   │                  │
│  └─────────────────┘  └───────────────┘                  │
└─────────────────────────────────────────────────────────┘
```

- 位置：页面顶部固定 (fixed top)
- 宽度：最大 2xl (672px)，居中显示
- 层级：z-50
- 样式：Alert variant="destructive"，带阴影和边框
- 图标：AlertTriangle + Clock (动画)

**权限控制**: 仅 Admin 角色  
**优先级**: P1

**验收标准**:
- [ ] AC1: 警告框固定在页面顶部，不随页面滚动
- [ ] AC2: 使用 Alert 组件，variant 为 destructive
- [ ] AC3: 显示警告图标和时钟图标（带脉冲动画）
- [ ] AC4: 标题为"登录即将过期"
- [ ] AC5: 描述信息包含具体剩余时间
- [ ] AC6: 两个按钮样式正确，主按钮为实心，次按钮为 outline

### 2.3 延长会话操作 (ADM-TOKEN-003)

**需求ID**: ADM-TOKEN-003  
**需求名称**: 延长会话操作  
**功能描述**: 用户点击"我已保存，继续工作"按钮后，延长当前会话  
**触发条件**: 用户点击"我已保存，继续工作"按钮  
**前置条件**: Token 即将过期警告已显示

**操作步骤**:
1. 用户完成工作保存
2. 点击"我已保存，继续工作"按钮
3. 系统验证 Token 有效性
4. 警告框关闭，继续监控

**正常流程**:
1. 用户点击按钮
2. 调用 `/admin/statistics` API
3. API 返回成功：
   - 重置 TokenMonitor 警告状态
   - 关闭警告提示框
   - 继续监控 Token 状态
4. 如果 Token 已过期：
   - API 返回 401
   - 跳转至登录页面

**异常流程/边界情况**:
- Token 在点击时已过期：跳转登录页
- 网络异常：提示网络错误，保持警告框显示

**业务规则**:
- 延长会话实际上是重新验证当前 Token
- 如果 Token 未过期，验证成功后会继续使用原 Token
- 用户需要在 Token 过期前点击按钮才有效

**权限控制**: 仅 Admin 角色  
**优先级**: P1

**验收标准**:
- [ ] AC1: 点击按钮后调用 `/admin/statistics` API
- [ ] AC2: 验证成功后关闭警告框
- [ ] AC3: 重置监控状态，继续检查 Token
- [ ] AC4: Token 已过期时跳转登录页

## 3. 技术实现

### 3.1 前端组件

| 组件 | 路径 | 说明 |
|------|------|------|
| TokenMonitor | `src/lib/token-monitor.ts` | Token 监控工具类 |
| AdminLayout | `src/app/admin/layout.tsx` | 集成警告提示 UI |
| EventBus | `src/lib/event-bus.ts` | 事件通信 |

### 3.2 事件定义

```typescript
// 事件类型
type AppEventType = 
  | 'auth:token-expiring'        // Token 即将过期
  | 'auth:token-expiring-update' // 更新剩余时间
  | 'auth:token-expired'         // Token 已过期
  | 'auth:session-expired';      // 会话已过期

// auth:token-expiring 事件数据
interface TokenExpiringEvent {
  message: string;        // 提示信息
  timeRemaining: number;  // 剩余毫秒数
  expiresAt: Date;        // 过期时间
}

// auth:token-expiring-update 事件数据
interface TokenExpiringUpdateEvent {
  timeRemaining: number;  // 剩余毫秒数
  formattedTime: string;  // 格式化后的时间
}
```

### 3.3 配置参数

```typescript
// Token 过期警告阈值（5分钟）
const TOKEN_EXPIRY_WARNING_THRESHOLD = 5 * 60 * 1000;

// 检查间隔（30秒）
const CHECK_INTERVAL = 30 * 1000;
```
