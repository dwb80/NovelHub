## 2. 功能模块细粒度需求

### 2.1 站点信息设置 (SET-SITE-001)

**需求ID**: SET-SITE-001  
**需求名称**: 站点信息设置  
**功能描述**: 配置网站基本信息：站点名称、站点描述、联系邮箱  
**触发条件**: 用户修改输入框内容  

**输入输出规则**:
- 输入：
  - site_name | string | 站点名称 | 2-50字符
  - site_description | string | 站点描述 | 0-200字符
  - contact_email | email | 联系邮箱 | 有效邮箱格式

**业务规则**:
- 站点名称必填
- 邮箱格式需合法

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 输入框正确显示当前设置
- [ ] AC2: 输入验证正常工作
- [ ] AC3: 保存后设置生效

**来源**: [admin/settings.html L89-L94](../../html/pages/admin/settings.html#L89-L94)

---

### 2.2 功能开关 (SET-TOG-001)

**需求ID**: SET-TOG-001  
**需求名称**: 功能开关  
**功能描述**: 启用或禁用系统功能：用户注册、评论功能、AI智能体创作、维护模式  
**触发条件**: 用户点击开关  

**正常流程**:
1. 点击开关切换状态
2. 开关滑动动画效果
3. 保存后功能立即生效

**输入输出规则**:
- 输入：
  - enable_registration | boolean | 用户注册
  - enable_comments | boolean | 评论功能
  - enable_AI智能体 | boolean | AI智能体创作
  - maintenance_mode | boolean | 维护模式

**业务规则**:
- 维护模式开启后，普通用户无法访问站点
- 关闭用户注册后，新用户无法注册

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 4个功能开关正常显示
- [ ] AC2: 点击开关状态切换
- [ ] AC3: 开关动画效果正常
- [ ] AC4: 保存后功能状态生效

**来源**: [admin/settings.html L97-L114](../../html/pages/admin/settings.html#L97-L114)

---

### 2.3 内容审核设置 (SET-REV-001)

**需求ID**: SET-REV-001  
**需求名称**: 内容审核设置  
**功能描述**: 配置内容审核规则  
**触发条件**: 用户选择下拉选项  

**输入输出规则**:
- 输入：
  - chapter_review | enum | 章节审核 | all/new/none
  - comment_review | enum | 评论审核 | all/sensitive/none
  - sensitive_level | enum | 敏感词过滤级别 | strict/normal/loose

**业务规则**:
- 章节审核：全部需要审核/仅新作者需要/无需审核
- 评论审核：全部需要审核/仅含敏感词需审核/无需审核
- 敏感词级别：严格/正常/宽松

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 3个下拉选项正常显示
- [ ] AC2: 选项值正确
- [ ] AC3: 保存后设置生效

**来源**: [admin/settings.html L117-L130](../../html/pages/admin/settings.html#L117-L130)

---

### 2.4 安全设置 (SET-SEC-001)

**需求ID**: SET-SEC-001  
**需求名称**: 安全设置  
**功能描述**: 配置安全相关选项  
**触发条件**: 用户修改输入或点击开关  

**输入输出规则**:
- 输入：
  - login_attempts | number | 登录失败锁定次数 | 3-10
  - session_timeout | number | 登录会话有效期（小时） | 1-72
  - enable_2fa | boolean | 双重验证

**业务规则**:
- 登录失败超过设定次数后锁定账号
- 会话过期后需重新登录
- 双重验证开启后管理员登录需额外验证

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 输入框和开关正常显示
- [ ] AC2: 数值输入验证正常
- [ ] AC3: 保存后设置生效

**来源**: [admin/settings.html L133-L140](../../html/pages/admin/settings.html#L133-L140)

---

### 2.5 保存/重置按钮 (SET-SAVE-001)

**需求ID**: SET-SAVE-001  
**需求名称**: 保存/重置按钮  
**功能描述**: 保存设置或重置为默认值  
**触发条件**: 用户点击按钮  

**正常流程**:
1. 点击保存：验证所有输入，通过后保存设置
2. 点击重置：弹出确认框，确认后恢复默认设置

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 保存按钮正常工作
- [ ] AC2: 重置按钮弹出确认框
- [ ] AC3: 操作后显示toast提示

**来源**: [admin/settings.html L143-L147](../../html/pages/admin/settings.html#L143-L147)

## 3. 表单验证规则汇总

| 字段 | 类型 | 必填 | 校验规则 | 错误提示 |
|------|------|------|----------|----------|
| 站点名称 | string | 是 | 2-50字符 | 站点名称2-50字符 |
| 站点描述 | string | 否 | 0-200字符 | 描述不能超过200字符 |
| 联系邮箱 | email | 是 | 有效邮箱格式 | 请输入有效邮箱 |
| 登录失败锁定次数 | number | 是 | 3-10 | 次数范围3-10 |
| 会话有效期 | number | 是 | 1-72 | 有效期范围1-72小时 |
