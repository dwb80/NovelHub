# 审核历史页 - 细粒度需求

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面名称** | 审核历史 |
| **页面路径** | /admin/review/history |
| **优先级** | P2 |
| **页面目标** | 展示所有已完成的审核记录，支持查询和统计 |
| **所属模块** | 管理后台 - 内容审核 |
| **访问权限** | 审核员、管理员 |

## 3. 组件详细说明

### 3.1 页面标题区

**位置**: 主内容区顶部
**样式**:
- 标题: 24px, font-weight: 600
- 副标题: 显示当前筛选条件下的记录数

**内容**:
- 主标题: "审核历史记录"
- 副标题: "共 XXX 条审核记录"

### 3.2 统计概览卡片

**位置**: 标题区下方
**样式**:
- 4列卡片布局
- 每个卡片显示一个统计指标
- 图标 + 数值 + 标签

**统计指标**:

| 指标 | 说明 |
|------|------|
| 今日审核 | 当天完成的审核数量 |
| 通过数量 | 筛选条件下通过的数量 |
| 拒绝数量 | 筛选条件下拒绝的数量 |
| 平均审核时长 | 从提交到完成的平均时间 |

**数据需求**:
```typescript
interface ReviewStats {
  todayCount: number;
  approvedCount: number;
  rejectedCount: number;
  avgReviewTime: number;  // 分钟
}
```

### 3.3 筛选条件区

**位置**: 统计卡片下方
**样式**:
- 横向排列的筛选器
- 日期范围选择器
- 下拉选择器
- 搜索输入框

**筛选条件**:

| 条件 | 类型 | 说明 |
|------|------|------|
| 时间范围 | 日期范围 | 审核完成时间范围 |
| 审核员 | 下拉多选 | 按审核员筛选 |
| 审核结果 | 下拉单选 | 全部/通过/拒绝 |
| 搜索 | 输入框 | 搜索章节标题/作者 |

**交互**:
- 筛选条件变更自动刷新列表
- 支持重置筛选条件
- 筛选条件保存在URL参数中

### 3.4 审核历史表格

**位置**: 筛选条件区下方
**样式**:
- 标准表格布局
- 表头固定
- 行悬停高亮
- 分页显示

**表格列定义**:

| 列名 | 宽度 | 说明 |
|------|------|------|
| 章节标题 | 25% | 章节标题，点击可查看详情 |
| 所属小说 | 15% | 小说名称 |
| 作者 | 12% | 作者用户名 |
| 审核员 | 12% | 审核员用户名 |
| 审核结果 | 10% | 通过/拒绝标签 |
| 审核时间 | 15% | 完成审核的时间 |
| 操作 | 11% | 查看详情按钮 |

**数据需求**:
```typescript
interface ReviewHistoryItem {
  id: string;
  chapterId: string;
  chapterTitle: string;
  novelId: string;
  novelTitle: string;
  authorId: string;
  authorName: string;
  reviewerId: string;
  reviewerName: string;
  result: 'approved' | 'rejected';
  reason?: string;        // 拒绝原因
  reviewedAt: Date;
  reviewDuration: number; // 审核耗时（分钟）
}

type ReviewHistoryList = ReviewHistoryItem[];
```

**交互**:
- 点击章节标题查看章节详情
- 点击"查看详情"查看完整审核记录
- 表格支持排序（点击表头）

### 3.5 分页控制

**位置**: 表格下方
**样式**:
- 居中对齐
- 页码 + 上一页/下一页
- 每页显示数量选择器

**配置**:
- 默认每页: 20条
- 可选: 20/50/100条

## 4. 交互说明

### 4.1 页面加载

| 触发条件 | 交互行为 |
|----------|----------|
| 页面初始化 | 加载统计数据和历史列表 |
| 筛选变更 | 重新加载列表，重置到第1页 |
| 分页切换 | 加载对应页数据 |
| 排序变更 | 按新排序重新加载 |

### 4.2 详情查看

| 操作 | 行为 |
|------|------|
| 点击章节标题 | 打开章节详情弹窗/页面 |
| 点击查看详情 | 打开审核记录详情弹窗 |
| 点击作者名 | 跳转到作者详情页 |
| 点击审核员名 | 筛选该审核员的记录 |

### 4.3 审核记录详情弹窗

**内容**:
- 章节基本信息（标题、小说、作者）
- 提交信息（提交时间、内容快照）
- 自动审核结果
- 人工审核结果（审核员、决定、原因、备注）
- 审核时间线

## 5. 数据需求汇总

### 5.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/admin/review/history | GET | 获取审核历史列表 |
| /api/admin/review/stats | GET | 获取审核统计数据 |
| /api/admin/review/:id | GET | 获取单条审核记录详情 |

### 5.2 请求参数

```typescript
interface GetReviewHistoryParams {
  startDate?: string;     // 开始日期 YYYY-MM-DD
  endDate?: string;       // 结束日期 YYYY-MM-DD
  reviewerIds?: string[]; // 审核员ID数组
  result?: 'approved' | 'rejected';
  keyword?: string;       // 搜索关键词
  sortBy?: string;        // 排序字段
  sortOrder?: 'asc' | 'desc';
  page?: number;
  pageSize?: number;
}
```

### 5.3 响应结构

```typescript
interface ReviewHistoryResponse {
  list: ReviewHistoryItem[];
  pagination: {
    current: number;
    pageSize: number;
    total: number;
    totalPages: number;
  };
  stats: ReviewStats;
}
```

## 6. 性能要求

- 页面加载时间 < 2s
- 列表查询响应 < 500ms
- 支持大数据量分页
- 统计数据缓存5分钟

## 7. 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 列表加载失败 | 显示错误提示，保留筛选条件 |
| 统计加载失败 | 显示"--"占位，不影响列表 |
| 无权限访问 | 重定向到403页面 |

## 8. 导出功能（可选）

- 支持导出当前筛选结果
- 格式: Excel/CSV
- 包含所有字段
