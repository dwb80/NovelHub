## 2. 功能模块细粒度需求

### 2.1 统计卡片区域 (NVL-STAT-001)

**需求ID**: NVL-STAT-001  
**需求名称**: 小说统计卡片  
**功能描述**: 展示小说相关统计数据：总小说数、已发布、草稿、已完结  
**触发条件**: 页面加载完成  
**前置条件**: 用户已登录且具有管理员权限  

**操作步骤**:
1. 页面加载时自动获取小说统计数据
2. 查看各统计卡片的数值

**正常流程**:
1. 页面加载时发起API请求获取统计数据
2. 显示4个统计卡片：总小说数、已发布、草稿、已完结
3. 数值格式化显示（如2,847）

**输入输出规则**:
- 输出：
  - total_novels | number | 总小说数
  - published_count | number | 已发布数量
  - draft_count | number | 草稿数量
  - completed_count | number | 已完结数量

**权限控制**: 仅管理员可见  
**优先级**: P2

**验收标准**:
- [ ] AC1: 显示4个统计卡片
- [ ] AC2: 数值正确格式化显示
- [ ] AC3: 小于1024px时显示为2列

**来源**: [admin/novels.html L481-L498](../../html/pages/admin/novels.html#L481-L498)

### 2.2 筛选栏 (NVL-FLT-001)

**需求ID**: NVL-FLT-001  
**需求名称**: 小说筛选栏  
**功能描述**: 提供搜索、状态筛选、分类筛选、排序功能  
**触发条件**: 用户输入或选择筛选条件  
**前置条件**: 页面已加载  

**操作步骤**:
1. 在搜索框输入关键词
2. 选择状态筛选条件
3. 选择分类筛选条件
4. 选择排序方式

**正常流程**:
1. 搜索框输入时防抖300ms后触发搜索
2. 状态筛选选项：全部、已发布、草稿、已下架
3. 分类筛选选项：全部、玄幻、武侠、科幻、言情、悬疑
4. 排序选项：最新发布、最早发布、阅读量、点赞数
5. 筛选条件变化时自动刷新表格数据

**输入输出规则**:
- 输入：
  - keyword | string | 搜索关键词 | 1-100字符
  - status | enum | 状态筛选 | published/draft/suspended
  - category | enum | 分类筛选 | fantasy/wuxia/scifi/romance/mystery
  - sort | enum | 排序方式 | newest/oldest/views/likes

**业务规则**:
- 搜索范围：小说名称、作者名称
- 多条件筛选为AND关系
- 筛选条件变化时重置到第1页

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 搜索框支持实时搜索（防抖300ms）
- [ ] AC2: 状态、分类、排序筛选器正常工作
- [ ] AC3: 筛选条件变化时自动刷新表格
- [ ] AC4: 多条件筛选同时生效

**来源**: [admin/novels.html L500-L538](../../html/pages/admin/novels.html#L500-L538)

### 2.3 小说数据表格 (NVL-TBL-001)

**需求ID**: NVL-TBL-001  
**需求名称**: 小说数据表格  
**功能描述**: 展示小说列表，支持查看、编辑、删除操作  
**触发条件**: 页面加载或筛选条件变化  
**前置条件**: 用户已登录且具有管理员权限  

**操作步骤**:
1. 查看小说列表数据
2. 点击编辑按钮编辑小说
3. 点击查看按钮查看小说详情
4. 点击删除按钮删除小说

**正常流程**:
1. 表格显示字段：小说信息（封面+标题+作者）、分类、章节数、阅读量、状态、更新时间、操作
2. 状态显示为标签：已发布（绿色）、草稿（黄色）、已下架（红色）
3. 点击编辑：跳转到小说编辑页
4. 点击查看：在新窗口打开小说详情页
5. 点击删除：弹出确认框，确认后删除小说

**异常流程/边界情况**:
- 无数据：显示"暂无数据"空状态
- 删除失败：显示错误提示
- 网络错误：显示重试按钮

**输入输出规则**:
- 输出：
  - cover | string | 封面URL
  - title | string | 小说标题
  - author | string | 作者名称
  - category | string | 分类
  - chapter_count | number | 章节数
  - view_count | number | 阅读量
  - status | enum | 状态
  - updated_at | datetime | 更新时间

**业务规则**:
- 阅读量>=10000时显示为"x.xw"
- 阅读量>=1000时显示为"x.xk"
- 默认每页10条

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 表格正确显示小说数据
- [ ] AC2: 状态标签颜色正确
- [ ] AC3: 编辑、查看、删除按钮正常工作
- [ ] AC4: 删除操作需二次确认
- [ ] AC5: 阅读量格式化显示

**来源**: [admin/novels.html L540-L574](../../html/pages/admin/novels.html#L540-L574)

### 2.4 分页控件 (NVL-PAG-001)

**需求ID**: NVL-PAG-001  
**需求名称**: 分页控件  
**功能描述**: 提供分页导航功能  
**触发条件**: 用户点击分页按钮  
**前置条件**: 数据总量>每页条数  

**操作步骤**:
1. 点击页码跳转到对应页
2. 点击上一页/下一页翻页

**正常流程**:
1. 显示当前页码和总页数
2. 点击页码：跳转到对应页，刷新表格数据
3. 点击上一页/下一页：翻页并刷新数据
4. 当前页码高亮显示

**异常流程/边界情况**:
- 第一页时"上一页"禁用
- 最后一页时"下一页"禁用

**输入输出规则**:
- 输入：page | number | 页码 | >=1
- 输出：当前页数据列表

**业务规则**:
- 默认每页10条
- 页码过多时显示省略号

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 分页控件正确显示
- [ ] AC2: 点击页码正确跳转
- [ ] AC3: 上一页/下一页按钮正常工作
- [ ] AC4: 边界情况下按钮禁用状态正确

**来源**: [admin/novels.html L559-L573](../../html/pages/admin/novels.html#L559-L573)
