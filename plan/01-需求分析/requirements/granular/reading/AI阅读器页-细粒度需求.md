**最后更新**: 2026-04-13

## 1. 页面整体结构

### 1.1 页面元数据

| 属性 | 值 |
|------|-----|
| 页面标题 | 第{X}章：{章节名} - {小说名} - 小说阅读平台 |
| 页面路径 | /novel/{novel_id}/reader/{chapter_id} |
| 登录要求 | 无需登录(阅读)，需登录(记录进度) |
| 角色权限 | 公开访问 |

### 1.2 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│  阅读器头部 (固定顶部，滚动时隐藏/显示)                           │
│  [返回] 第{X}章：{章节名}                    [目录] [设置] [夜间] │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                         阅读内容区                               │
│                                                                 │
│                      第{X}章：{章节名}                           │
│                                                                 │
│                        章节正文...                               │
│                                                                 │
│                     (羊皮纸背景色)                               │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  章节导航                                                       │
│  [← 上一章]              [返回目录]              [下一章 →]      │
├─────────────────────────────────────────────────────────────────┤
│  阅读器底部 (固定底部，滚动时隐藏/显示)                           │
│  [上一章] [目录] [进度 45%] [夜间] [设置] [下一章]               │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 响应式断点

| 断点 | 布局变化 |
|------|----------|
| ≥768px | 内容区最大宽度800px，居中显示 |
| <768px | 内容区全宽，减小边距 |

## 2. 功能模块细粒度需求

### 2.1 阅读器头部

#### 需求ID: RD-001

**需求名称**: 头部信息展示

**功能描述**: 显示章节标题和快捷操作

**触发条件**: 页面加载

**前置条件**: 章节数据加载完成

**操作步骤**:
  1. 加载章节数据
  2. 渲染头部

**正常流程**:
  1. 显示"返回"按钮
  2. 显示章节标题
  3. 显示"目录"、"设置"、"夜间模式"按钮

**异常流程/边界情况**:
  - 章节不存在: 显示404

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 章节数据
  - 输出: 头部UI

**业务规则**:
  - 头部滚动时自动隐藏
  - 向上滚动时显示

**优先级**: P1

**验收标准**:
  - [ ] AC1: 头部正确显示
  - [ ] AC2: 滚动时隐藏/显示正常

**来源**: reader.html L1-L50, chapter_01.html L1-L50

### 2.3 阅读进度

#### 需求ID: RD-011

**需求名称**: 阅读进度保存

**功能描述**: 自动保存阅读进度

**触发条件**: 用户阅读时

**前置条件**: 用户已登录

**操作步骤**:
  1. 监听滚动事件(防抖)
  2. 计算阅读进度
  3. 保存进度

**正常流程**:
  1. 用户滚动页面
  2. 计算当前阅读百分比
  3. 保存至服务端(登录用户)
  4. 保存至localStorage(所有用户)

**异常流程/边界情况**:
  - 未登录: 仅保存至localStorage

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 滚动位置
  - 输出: 进度保存

**业务规则**:
  - 防抖时间: 2秒
  - 进度精确到段落

**优先级**: P1

**验收标准**:
  - [ ] AC1: 进度自动保存
  - [ ] AC2: 重新进入时恢复进度

**来源**: reader.html L361-L400
