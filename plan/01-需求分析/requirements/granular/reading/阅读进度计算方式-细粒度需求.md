## 2. 阅读进度定义

### 2.1 进度类型

| 进度类型 | 定义 | 用途 |
|----------|------|------|
| 章节进度 | 当前阅读章节编号 | 定位阅读位置 |
| 页面进度 | 当前章节内滚动位置（像素） | 精确定位 |
| 百分比进度 | 整本书阅读百分比 | 展示阅读进度 |
| 字数进度 | 已阅读字数 | 统计阅读时长 |

### 2.2 进度数据结构

```typescript
interface ReadingProgress {
  novelId: string;           // 小说ID
  chapterId: string;         // 当前章节ID
  chapterNumber: number;     // 章节序号
  scrollPosition: number;    // 章节内滚动位置（像素）
  totalWords: number;        // 本书总字数
  readWords: number;         // 已阅读字数
  percentage: number;        // 阅读百分比 0-100
  lastReadAt: Date;          // 最后阅读时间
  deviceId: string;          // 设备标识
}
```

## 3. 进度计算规则

### 3.1 章节进度计算

#### 需求ID: RD-PROG-001

**需求名称**: 章节进度计算  
**功能描述**: 计算用户当前阅读章节及章节内位置  
**触发条件**: 用户滚动阅读内容  

**计算规则**:
```
当前章节 = 视口中心所在的章节元素
章节内进度 = 已滚动高度 / 章节总高度 × 100%
```

**更新频率**:
- 本地存储: 每5秒或滚动停止时
- 服务器同步: 每30秒或切换章节时

**优先级**: P1

**验收标准**:
- [ ] AC1: 章节切换时正确记录
- [ ] AC2: 章节内滚动位置准确
- [ ] AC3: 页面刷新后恢复位置

---

### 3.2 百分比进度计算

#### 需求ID: RD-PROG-002

**需求名称**: 整书百分比进度  
**功能描述**: 计算整本书的阅读百分比  

**计算方式**:

```typescript
// 方式1: 基于章节数（简单）
percentage = (currentChapterNumber / totalChapters) × 100%

// 方式2: 基于字数（精确）
percentage = (readWords / totalWords) × 100%

// 方式3: 混合计算（推荐）
completedChaptersWords = sum(已完成章节字数)
currentChapterWords = currentChapter字数 × currentChapter阅读比例
readWords = completedChaptersWords + currentChapterWords
percentage = (readWords / totalWords) × 100%
```

**显示规则**:
| 百分比范围 | 显示方式 |
|------------|----------|
| 0% | "未开始" |
| 1-99% | 保留1位小数，如"35.2%" |
| 100% | "已读完" |

**优先级**: P1

---

### 3.3 字数统计

#### 需求ID: RD-PROG-003

**需求名称**: 阅读字数统计  
**功能描述**: 统计用户实际阅读的字数  

**统计规则**:
- 已完成章节: 按章节实际字数统计
- 当前章节: 按阅读比例估算
- 排除: 标点符号、空格（可选）

```typescript
// 章节字数计算
chapterWordCount = 章节内容文本长度（不含HTML标签）

// 已读字数计算
readWords = sum(已完成章节字数) + currentChapter字数 × 阅读比例
```

**优先级**: P2

## 4. 数据同步机制

### 4.1 本地存储

**存储位置**: localStorage + IndexedDB

**存储内容**:
```typescript
// localStorage: 轻量进度数据
localStorage.setItem('reading_progress', JSON.stringify({
  novelId: 'xxx',
  chapterId: 'xxx',
  scrollPosition: 1234,
  lastReadAt: '2024-01-15T10:30:00Z'
}));

// IndexedDB: 详细阅读历史
// 存储最近50本书的详细进度
```

**存储策略**:
| 事件 | 操作 |
|------|------|
| 滚动停止 | 更新localStorage |
| 切换章节 | 更新localStorage + IndexedDB |
| 关闭页面 | 同步到服务器 |
| 每30秒 | 同步到服务器 |

---

### 4.2 服务器同步

#### 需求ID: RD-SYNC-001

**需求名称**: 阅读进度同步  
**功能描述**: 将阅读进度同步到服务器，支持多设备同步  

**同步时机**:
1. 每30秒自动同步
2. 切换章节时同步
3. 关闭页面前同步
4. 手动点击"同步"按钮

**冲突解决**:
```
当本地进度与服务器进度冲突时:
1. 比较lastReadAt时间戳
2. 保留时间戳较新的进度
3. 如果相同，保留百分比更高的进度
```

**离线处理**:
- 离线时保存到本地队列
- 恢复在线后批量同步
- 显示同步状态提示

**优先级**: P1

**验收标准**:
- [ ] AC1: 进度正确同步到服务器
- [ ] AC2: 多设备进度正确合并
- [ ] AC3: 离线时本地保存正常
- [ ] AC4: 恢复在线后自动同步

## 5. 多设备同步

### 5.1 同步规则

| 场景 | 处理方式 |
|------|----------|
| 设备A阅读到第10章 | 设备B打开显示"继续阅读第10章" |
| 多设备同时阅读 | 以最后阅读时间为准 |
| 设备A读完 | 设备B标记为已读完 |

### 5.2 同步提示

当从其他设备继续阅读时:
- 显示提示: "您在其他设备阅读到第X章"
- 提供按钮: "继续阅读" / "从头开始"

## 6. 阅读时长统计

### 6.1 时长计算

```typescript
interface ReadingSession {
  startTime: Date;
  endTime: Date;
  duration: number;        // 实际阅读时长（秒）
  novelId: string;
  chapterId: string;
}

// 有效阅读判定
有效阅读 = 页面可见 + 有滚动操作 + 每5分钟内有交互

// 排除情况
无效阅读 = 页面后台运行 + 无操作超过5分钟
```
