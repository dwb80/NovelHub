## 2. 筛选标签

### 2.1 通知类型筛选

#### 需求ID: NOTIF-FILTER-001

**需求名称**: 通知类型筛选标签

**功能描述**: 按通知类型筛选显示

**标签列表**:
| 标签 | 说明 |
|------|------|
| 全部 | 显示所有通知 |
| 系统 | 系统公告、维护通知 |
| 互动 | 评论回复、点赞 |
| 关注 | 新粉丝、关注更新 |
| 作品 | 审核结果、数据更新 |

**样式规则**:
- 当前标签: 主色背景+边框+文字
- 默认标签: 灰色背景+灰色文字
- 未读数量角标: 红色圆点/数字

**交互**:
- 点击标签切换筛选
- URL参数同步筛选状态
