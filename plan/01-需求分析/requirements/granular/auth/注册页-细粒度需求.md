### 3.2 用户名输入框

#### 需求ID: REG-INPUT-001

**需求名称**: 用户名输入

**功能描述**: 用户输入用户名进行注册

**触发条件**: 
- 页面加载完成
- 用户输入
- 失去焦点时验证

**前置条件**: 无

**操作步骤**:
1. 用户输入用户名
2. 实时清除错误状态
3. 失去焦点时验证格式
4. 验证失败显示错误提示

**输入规则**:
| 属性 | 规则 |
|------|------|
| 类型 | text |
| 必填 | 是 |
| 占位符 | "请输入用户名（2-20个字符）" |
| 自动完成 | username |
| 最小长度 | 2字符 |
| 最大长度 | 20字符 |

**验证规则**:
| 场景 | 错误提示 |
|------|----------|
| 为空 | "请输入用户名" |
| 长度不足 | "用户名至少2个字符" |
| 长度超限 | "用户名最多20个字符" |
| 格式错误 | "用户名只能包含中文、字母、数字和下划线" |

**正则表达式**: `/^[\u4e00-\u9fa5a-zA-Z0-9_]+$/`

**样式状态**:
| 状态 | 边框颜色 | 阴影 |
|------|----------|------|
| 默认 | var(--color-border) | 无 |
| 聚焦 | var(--color-primary) | 0 0 0 3px var(--color-primary-light) |
| 错误 | var(--color-error) | 0 0 0 3px var(--color-error-light) |

**无障碍支持**:
- aria-describedby="nameError"
- required属性

**优先级**: P0

**验收标准**:
- [ ] AC1: 输入框正确显示
- [ ] AC2: 用户名格式验证正常
- [ ] AC3: 错误提示正确显示
- [ ] AC4: 聚焦样式正常

### 3.4 密码输入框

#### 需求ID: REG-INPUT-003

**需求名称**: 密码输入

**功能描述**: 用户输入密码，支持显示/隐藏切换，实时显示密码强度

**触发条件**: 
- 用户输入
- 点击显示/隐藏按钮

**前置条件**: 无

**操作步骤**:
1. 用户输入密码（默认隐藏）
2. 实时检测密码强度
3. 点击眼睛图标切换显示/隐藏
4. 失去焦点时验证

**输入规则**:
| 属性 | 规则 |
|------|------|
| 类型 | password / text |
| 必填 | 是 |
| 占位符 | "至少8位，包含字母和数字" |
| 自动完成 | new-password |
| 最小长度 | 8字符 |

**验证规则**:
| 场景 | 错误提示 |
|------|----------|
| 为空 | "请输入密码" |
| 长度不足 | "密码长度至少8位" |
| 无字母 | "密码必须包含字母" |
| 无数字 | "密码必须包含数字" |

**密码强度检测**:
| 强度等级 | 条件 | 颜色 |
|----------|------|------|
| 弱 | 仅满足长度 | 红色 |
| 一般 | 长度+字母+数字 | 黄色 |
| 良好 | 上述+特殊字符 | 蓝色 |
| 强 | 上述+长度≥12 | 绿色 |

**密码要求列表**:
- 至少8个字符
- 包含字母
- 包含数字
- 包含特殊字符（可选，增强强度）

**显示/隐藏切换**:
| 状态 | 图标 | 按钮aria-label |
|------|------|----------------|
| 隐藏 | 睁眼图标 | "显示密码" |
| 显示 | 闭眼图标 | "隐藏密码" |

**样式**:
- 切换按钮: 绝对定位，右侧1rem
- 图标尺寸: 1.25rem

**优先级**: P0

**验收标准**:
- [ ] AC1: 密码输入正常
- [ ] AC2: 显示/隐藏切换正常
- [ ] AC3: 密码强度检测正常
- [ ] AC4: 验证规则正常工作
