## 3. 学习路径区

### 3.1 路径卡片

#### 需求ID: GROWTH-PATH-001

**需求名称**: 学习路径展示

**功能描述**: 展示不同阶段的写作学习路径

**路径列表**:
| 路径 | 图标 | 标题 | 描述 |
|------|------|------|------|
| 新手入门 | 🌱 | 新手入门 | 写作基础，从零开始学写作 |
| 进阶提升 | 🚀 | 进阶提升 | 技巧进阶，提升写作水平 |
| 专业深化 | 💎 | 专业深化 | 深度修炼，打造个人风格 |
| 大师之路 | 👑 | 大师之路 | 巅峰突破，成为顶尖作家 |

**路径卡片结构**:
| 元素 | 说明 |
|------|------|
| 图标 | 路径图标，渐变背景 |
| 标题 | 路径名称 |
| 描述 | 路径简介 |
| 统计 | 课程数、学习人数 |
| 进度 | 当前用户学习进度（如已登录） |

**样式规则**:
- 布局: 4列网格
- 卡片: 白色背景，圆角，边框
- 图标: 80x80px，渐变背景，圆角
- 悬停: 上移4px，阴影加深，边框变primary色
- 激活: 边框高亮，浅紫背景

**交互**:
- 点击卡片: 展开/收起该路径下的课程列表
- 悬停: 显示悬停效果

**优先级**: P0

## 10. 数据需求汇总

### 10.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/learning/paths | GET | 获取学习路径列表 |
| /api/learning/courses | GET | 获取课程列表 |
| /api/learning/progress | GET | 获取学习进度 |
| /api/learning/resources | GET | 获取资源列表 |

### 10.2 数据结构

```typescript
interface LearningPath {
  id: string;
  icon: string;
  title: string;
  description: string;
  courseCount: number;
  studentCount: number;
  difficulty: 'beginner' | 'intermediate' | 'advanced' | 'master';
}

interface Course {
  id: string;
  cover: string;
  title: string;
  description: string;
  pathId: string;
  difficulty: string;
  duration: number;
  instructor: {
    name: string;
    avatar: string;
  };
  studentCount: number;
  rating: number;
}

interface LearningProgress {
  totalCourses: number;
  completedCourses: number;
  totalTime: number; // 分钟
  certificates: number;
  recentCourses: Course[];
}
```
