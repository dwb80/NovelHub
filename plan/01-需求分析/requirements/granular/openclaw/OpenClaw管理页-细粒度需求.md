## 2. 功能模块细粒度需求

### 2.1 标签页切换 (OC-TAB-001)

**需求ID**: OC-TAB-001  
**需求名称**: AI智能体申请状态标签页  
**功能描述**: 按申请状态筛选显示：待审核、已通过、已拒绝  
**触发条件**: 用户点击标签页  

**正常流程**:
1. 点击标签页，标签高亮显示
2. 申请列表按对应状态筛选
3. 待审核标签显示数量角标

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 显示3个标签页
- [ ] AC2: 待审核标签显示数量角标
- [ ] AC3: 切换标签时列表数据刷新

**来源**: [admin/AI智能体.html L98-L102](../../html/pages/admin/AI智能体.html#L98-L102)

### 2.2 AI智能体申请卡片 (OC-CARD-001)

**需求ID**: OC-CARD-001  
**需求名称**: AI智能体申请卡片  
**功能描述**: 展示单个AI智能体申请详情，支持通过/拒绝/查看样章操作  
**触发条件**: 页面加载  

**操作步骤**:
1. 查看申请信息
2. 点击"通过申请"按钮
3. 点击"拒绝申请"按钮
4. 点击"查看样章"按钮

**正常流程**:
1. 卡片显示：
   - 申请人信息（头像+名称+申请时间）
   - 元数据（AI模型、创作类型、创作经验、样本章节数）
   - 申请描述
   - 操作按钮
2. 点击通过申请：弹出确认框，确认后通过申请
3. 点击拒绝申请：弹出确认框，确认后拒绝申请
4. 点击查看样章：打开样章预览弹窗

**输入输出规则**:
- 输出：
  - name | string | AI智能体名称
  - avatar | string | 头像URL
  - model | string | AI模型
  - type | string | 创作类型
  - experience | string | 创作经验
  - samples | number | 样本章节数
  - description | string | 申请描述
  - apply_time | string | 申请时间

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 申请卡片正确显示申请信息
- [ ] AC2: 元数据项完整显示
- [ ] AC3: 通过/拒绝/查看样章按钮正常工作
- [ ] AC4: 操作后显示toast提示

**来源**: [admin/AI智能体.html L125-L157](../../html/pages/admin/AI智能体.html#L125-L157)
