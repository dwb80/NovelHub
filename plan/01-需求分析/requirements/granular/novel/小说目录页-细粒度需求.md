# 小说目录页细粒度需求文档

**最后更新**: 2026-04-15

---

## 1. 页面整体结构

### 1.1 页面布局

| 需求ID | 需求名称 | 功能描述 | 优先级 |
|--------|----------|----------|--------|
| CATALOG-LAYOUT-001 | 单栏布局 | 头部信息 + 工具栏 + 目录列表 + 分页 | P0 |
| CATALOG-LAYOUT-002 | 响应式适配 | 移动端优化，工具栏堆叠显示 | P0 |
| CATALOG-LAYOUT-003 | 标准导航 | 包含顶部导航栏和页脚 | P0 |

### 1.2 页面元数据

| 需求ID | 需求名称 | 功能描述 | 优先级 |
|--------|----------|----------|--------|
| CATALOG-META-001 | 页面标题 | "{小说名} - 目录 - NovelHub" | P0 |
| CATALOG-META-002 | Meta描述 | "{小说名}章节目录，共X章，最新章节{章节名}" | P1 |

---

## 2. 页面头部

### 2.1 小说信息区

#### 需求ID: CATALOG-HEADER-001

**需求名称**: 小说基本信息

**功能描述**: 展示小说封面、标题、作者等基本信息

**区域结构**:
| 元素 | 说明 |
|------|------|
| 封面 | 小说封面，左侧 |
| 标题 | 小说名称 |
| 作者 | 作者名，可点击 |
| 状态 | 连载中/已完结 |
| 总章节 | 共X章 |
| 更新时间 | 最后更新时间 |

**样式规则**:
- 封面: 120px宽度，圆角
- 标题: 1.5rem, font-weight 600
- 作者: primary色，可点击

**优先级**: P0

---

## 3. 工具栏

### 3.1 目录信息

#### 需求ID: CATALOG-TOOLBAR-001

**需求名称**: 目录统计信息

**功能描述**: 显示章节总数和阅读进度

**内容**:
- 总章节: "共 X 章"
- 阅读进度: "已读 X 章" 或 "阅读进度 X%"

**样式规则**:
- 字号: 0.875rem
- 颜色: 灰色

**优先级**: P1

---

### 3.2 筛选功能

#### 需求ID: CATALOG-TOOLBAR-002

**需求名称**: 章节筛选

**功能描述**: 按状态筛选章节

**筛选选项**:
| 选项 | 说明 |
|------|------|
| 全部章节 | 显示所有章节 |
| 已发布 | 仅显示已发布章节 |
| VIP章节 | 仅显示VIP章节 |

**组件**: 下拉选择框

**优先级**: P1

---

### 3.3 跳转功能

#### 需求ID: CATALOG-TOOLBAR-003

**需求名称**: 章节跳转

**功能描述**: 快速跳转到指定章节

**组件结构**:
| 元素 | 说明 |
|------|------|
| 输入框 | 输入章节号 |
| 跳转按钮 | 确认跳转 |

**输入规则**:
| 属性 | 规则 |
|------|------|
| 类型 | number |
| 最小值 | 1 |
| 最大值 | 总章节数 |
| 占位符 | "章号" |

**交互**:
1. 输入章节号
2. 点击跳转按钮
3. 滚动到对应章节位置
4. 章节高亮显示

**优先级**: P1

---

### 3.4 排序控制

#### 需求ID: CATALOG-TOOLBAR-004

**需求名称**: 章节排序

**功能描述**: 切换章节正序/倒序显示

**排序选项**:
| 选项 | 图标 | 说明 |
|------|------|------|
| 正序 | 向下箭头 | 第1章到最后一章 |
| 倒序 | 向上箭头 | 最后一章到第1章 |

**组件**: 图标按钮组

**交互**:
- 点击切换排序方式
- 当前排序按钮高亮

**优先级**: P1

---

## 4. 章节目录列表

### 4.1 章节项

#### 需求ID: CATALOG-LIST-001

**需求名称**: 章节列表项

**功能描述**: 展示单个章节信息

**章节项结构**:
| 元素 | 说明 |
|------|------|
| 序号 | 章节序号 |
| 标题 | 章节标题 |
| 标记 | VIP/免费/最新 标记 |
| 时间 | 发布时间 |
| 字数 | 章节字数 |

**状态标记**:
| 标记 | 说明 | 样式 |
|------|------|------|
| VIP | VIP章节 | 金色标签 |
| 免费 | 免费章节 | 绿色标签 |
| 最新 | 最新章节 | 红色标签 |
| 已读 | 已读章节 | 灰色文字 |

**样式规则**:
- 布局: 横向排列，两端对齐
- 间距: 1rem垂直间距
- 分隔线: 底部边框
- 悬停: 背景色变化

**交互**:
- 点击章节: 跳转到阅读器对应章节
- 悬停: 显示悬停效果

**优先级**: P0

---

### 4.2 卷/篇分组

#### 需求ID: CATALOG-LIST-002

**需求名称**: 卷/篇分组

**功能描述**: 按卷或篇分组显示章节

**分组标题样式**:
- 背景: 浅灰色
- 字重: 600
- 内边距: 0.75rem 1rem

**优先级**: P2

---

## 5. 分页导航

### 需求ID: CATALOG-PAGE-001

**需求名称**: 分页控制

**功能描述**: 分页显示章节列表

**分页组件**:
| 元素 | 说明 |
|------|------|
| 上一页 | 上一页按钮 |
| 页码 | 页码按钮组 |
| 下一页 | 下一页按钮 |
| 跳转 | 快速跳转输入框 |

**分页规则**:
- 每页显示: 50-100章
- 页码显示: 当前页前后各2页 + 首尾页
- 省略: 中间用"..."表示

**样式规则**:
- 按钮: 圆角，灰色背景
- 当前页: primary色背景
- 禁用: 灰色，不可点击

**优先级**: P1

---

## 6. 交互说明

### 6.1 页面加载

| 触发条件 | 交互行为 |
|----------|----------|
| 页面初始化 | 显示加载器，获取小说和章节数据 |
| 数据加载完成 | 渲染页面，隐藏加载器 |
| 数据加载失败 | 显示错误提示 |

### 6.2 用户操作

| 操作 | 行为 |
|------|------|
| 点击章节 | 跳转到阅读器对应章节 |
| 切换筛选 | 重新过滤章节列表 |
| 切换排序 | 重新排序章节列表 |
| 输入页码跳转 | 跳转到指定章节位置 |
| 点击分页 | 加载对应页章节 |

## 7. 数据需求汇总

### 7.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/novels/:id | GET | 获取小说详情 |
| /api/novels/:id/chapters | GET | 获取章节目录 |
| /api/user/reading-progress/:novelId | GET | 获取阅读进度 |

### 7.2 请求参数

```typescript
interface GetChaptersParams {
  novelId: string;
  page?: number;
  pageSize?: number;
  sort?: 'asc' | 'desc';
  filter?: 'all' | 'published' | 'vip';
}

interface Chapter {
  id: string;
  novelId: string;
  chapterNumber: number;
  title: string;
  isVip: boolean;
  isPublished: boolean;
  wordCount: number;
  publishedAt: Date;
  isRead?: boolean;
}
```

## 8. 性能要求

- 章节列表首屏渲染 < 1s
- 分页切换 < 500ms
- 筛选排序 < 300ms

---

## 9. 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 小说不存在 | 显示404页面 |
| 章节加载失败 | 显示错误提示，提供重试 |
| 跳转章节不存在 | 提示"章节不存在" |
