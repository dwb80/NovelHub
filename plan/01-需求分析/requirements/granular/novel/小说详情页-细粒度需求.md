## 2. 页面加载器

### 需求ID: DETAIL-LOADER-001

**需求名称**: 页面加载动画

**功能描述**: 页面初始化时显示全屏加载动画，数据加载完成后淡出隐藏

**触发条件**: 页面DOM加载完成时自动触发

**正常流程**:
1. 显示加载器（白色背景 + 旋转动画 + 文字"正在加载..."）
2. 等待小说数据加载完成
3. 执行渲染函数
4. 淡出隐藏加载器

**样式规则**:
- 背景: rgba(255,255,255,0.95)
- 旋转动画: 圆形spinner，primary色
- 文字: "正在加载..."

**优先级**: P1

## 4. 小说信息区 (Hero)

### 4.1 小说基本信息

#### 需求ID: DETAIL-HERO-001

**需求名称**: 小说信息展示区

**功能描述**: 展示小说封面、标题、作者、分类、标签、评分、阅读量等核心信息

**区域结构**:
| 元素 | 说明 |
|------|------|
| 封面图 | 小说封面，左侧显示，3:4比例 |
| 标题 | 小说名称，大字号 |
| 作者 | 作者名，可点击跳转作者页 |
| 分类 | 小说分类标签 |
| 标签 | 小说标签列表 |
| 评分 | 评分星级 + 分数 |
| 阅读量 | 阅读次数 |
| 字数 | 总字数 |
| 状态 | 连载中/已完结 |
| 更新时间 | 最后更新时间 |

**样式规则**:
- 封面: 左侧，宽度240px，圆角
- 标题: 2rem, font-weight 700
- 作者: 可点击，primary色
- 标签: 小标签样式，圆角

**数据需求**:
```typescript
interface NovelDetail {
  id: string;
  title: string;
  cover: string;
  author: {
    id: string;
    name: string;
  };
  category: string;
  tags: string[];
  rating: number;
  ratingCount: number;
  viewCount: number;
  wordCount: number;
  status: 'ongoing' | 'completed';
  updatedAt: Date;
  description: string;
}
```

**优先级**: P0

**来源**: [detail.html L85-120](file:///d:/trae/novelhub/html/pages/novel/detail.html#L85-L120)

### 4.2 操作按钮区

#### 需求ID: DETAIL-ACTION-001

**需求名称**: 小说操作按钮

**功能描述**: 提供开始阅读、加入书架、分享等操作

**按钮列表**:
| 按钮 | 说明 | 状态 |
|------|------|------|
| 开始阅读 | 跳转到阅读器，从第一章或上次阅读位置开始 | P0 |
| 加入书架 | 将小说加入用户书架 | P0 |
| 分享 | 分享小说到社交媒体 | P1 |
| 打赏 | 打赏作者（可选） | P2 |

**样式规则**:
- 开始阅读: primary按钮，大尺寸
- 加入书架: secondary按钮
- 分享: icon按钮

**交互**:
- 点击"开始阅读": 跳转到阅读器
- 点击"加入书架": 显示成功提示，按钮变为"已在书架"
- 点击"分享": 弹出分享选项

**优先级**: P0

## 5. 简介区

### 需求ID: DETAIL-DESC-001

**需求名称**: 小说简介

**功能描述**: 展示小说详细简介，支持展开/收起

## 7. 情绪反馈区

### 需求ID: DETAIL-EMOTION-001

**需求名称**: 读者情绪反馈

**功能描述**: 展示读者情绪统计，支持用户反馈情绪

**情绪类型**:
| 情绪 | 图标 | 说明 |
|------|------|------|
| 感动 | 😭 | 被情节感动 |
| 震惊 | 😱 | 情节出乎意料 |
| 笑出声 | 😂 | 幽默搞笑 |
| 燃爆了 | 🔥 | 热血激动 |

**区域结构**:
- 情绪统计: 各情绪点击数
- 情绪进度条: 可视化展示比例
- 情绪按钮: 用户可点击反馈

**样式规则**:
- 情绪项: 横向排列，图标+名称+数量
- 进度条: 彩色分段，显示比例

**优先级**: P2

### 8.2 发表评论

#### 需求ID: DETAIL-COMMENT-002

**需求名称**: 发表评论

**功能描述**: 用户发表评论

**输入规则**:
| 属性 | 规则 |
|------|------|
| 类型 | textarea |
| 占位符 | "发表你的看法..." |
| 最小长度 | 1字符 |
| 最大长度 | 2000字符 |

**操作步骤**:
1. 用户输入评论内容
2. 点击"发表评论"按钮
3. 验证内容（非空、长度、敏感词）
4. 提交评论
5. 显示成功提示，刷新评论列表

**优先级**: P1

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/novels/:id | GET | 获取小说详情 |
