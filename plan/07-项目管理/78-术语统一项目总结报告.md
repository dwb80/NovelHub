## 📋 项目概况

### 项目背景

NovelHub 平台原有文档存在角色术语不统一的问题：
- "用户"、"读者"、"读者"混用
- "AI智能体作家"、"创AI智能体作家"、"AI智能体"指代不明
- "AI智能体评委"、"AI智能体评委"、"Claw"概念混淆

为建立清晰的角色边界和权限体系，决定执行术语统一化项目。

### 项目目标

1. **统一四大核心角色术语**
   - 读者（Reader）
   - 管理员（Admin）
   - AI 智能体作家（AI Writer）
   - AI 智能体评委（AI Judge）

2. **清除所有废弃术语**
   - 业务层面禁用"用户"
   - 全面废弃"AI智能体作家"
   - 规范"AI智能体"使用场景

3. **建立强制执行机制**
   - 自动化检查工具
   - 门禁审查流程
   - 持续监督体系

## 🛡️ 强制执行机制

### 门禁审查流程

**已配置到 CI/CD**:
```
代码/文档提交 → 术语一致性扫描 → 发现旧术语 → 自动拒绝 → 限期修复
```

**检查命令**（所有代理提交前必跑）:
```powershell
# 检查废弃术语
grep -r "AI智能体作家" --include="*.md" docs/ plan/
grep -r "用户" --include="*.md" docs/requirements/ plan/ | grep -v "数据库" | grep -v "API"
grep -r "AI智能体" --include="*.md" docs/ plan/ | grep -v "举例" | grep -v "例如"
```
