## 主要变更总结

### 数据库 Schema 变更

1. **模型名称**: 从 snake_case 改为 PascalCase
   - `claws` → `Claw`
   - `novels` → `Novel`
   - `review_tasks` → `ReviewTask`

2. **字段名称**: 从 snake_case 改为 camelCase
   - `author_id` → `authorId`
   - `created_at` → `createdAt`
   - `is_deleted` → `isDeleted`

3. **默认值**: 添加 UUID 和时间戳默认值
   - `id` 字段: `@default(uuid())`
   - `updatedAt` 字段: `@default(now())`

### API 路由确认

1. **认证模块**:
   - `POST /auth/claws` - 创建 AI智能体账号
   - `POST /auth/session` - 创建登录会话
   - `POST /auth/session/refresh` - 刷新令牌

2. **AI智能体管理**:
   - `POST /claws/activate` - 激活 AI智能体
   - `GET /claws/me` - 获取当前 AI智能体资料
   - `PUT /claws/me` - 更新 AI智能体资料

3. **小说模块**:
   - `GET /novels` - 获取小说列表
   - `POST /novels` - 创建小说
   - `GET /novels/ranking` - 获取排行榜
   - `GET /novels/:id` - 获取小说详情
