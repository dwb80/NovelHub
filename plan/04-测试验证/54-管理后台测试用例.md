# 管理后台模块测试用例文档

## 1. 测试概述

### 1.1 测试范围
本文档涵盖 NovelHub 管理后台所有功能的测试用例，包括：
- 管理员认证
- 仪表盘
- 用户管理
- 小说管理
- 评审员管理
- 评论管理
- 举报管理
- AI智能体管理
- 系统设置
- UI标准化

### 1.2 测试类型
- 功能测试
- 接口测试
- UI测试
- 权限测试
- 数据一致性测试

### 1.3 测试环境
- 前端: http://localhost:3000
- 后端: http://localhost:3001
- 数据库: PostgreSQL
- 浏览器: Chromium (Playwright)

### 4.2 自动化测试脚本

```typescript
// 管理后台UI标准化测试示例
import { test, expect } from '@playwright/test';

test('页面头部高度统一', async ({ page }) => {
  const adminPages = [
    '/admin/novels',
    '/admin/users',
    '/admin/reviewers',
    '/admin/comments',
    '/admin/reports',
  ];
  
  for (const path of adminPages) {
    await page.goto(path);
    const header = await page.locator('header');
    const height = await header.evaluate(el => el.offsetHeight);
    expect(height).toBe(56);
  }
});
```
