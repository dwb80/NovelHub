## 五、迁移注意事项

### 5.1 数据库迁移

```sql
-- 重命名表
ALTER TABLE users RENAME TO readers;

-- 重命名外键列（示例：bookshelves表）
ALTER TABLE bookshelves RENAME COLUMN user_id TO reader_id;

-- 更新索引
ALTER INDEX idx_bookshelves_user_id RENAME TO idx_bookshelves_reader_id;
```

### 5.2 代码迁移

1. **Prisma Client 使用更新**:
   ```typescript
   // 旧
   prisma.user.findUnique({ where: { id } })
   
   // 新
   prisma.reader.findUnique({ where: { id } })
   ```

2. **类型引用更新**:
   ```typescript
   // 旧
   import { User, UserType } from '@/types/auth';
   
   // 新
   import { ReaderUnion, ReaderType } from '@/types/auth';
   ```

3. **API 调用更新**:
   ```typescript
   // 旧
   fetch('/api/v1/users/me')
   
   // 新
   fetch('/api/v1/readers/me')
   ```
