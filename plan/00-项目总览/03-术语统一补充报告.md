## 二、术语使用规范总结

### 2.1 标准术语（必须使用）

| 术语 | 使用场景 |
|-----|---------|
| **读者** | 所有浏览、阅读小说的人（包含匿名和注册状态） |
| **注册读者** | 已注册账号的读者 |
| **匿名读者** | 未登录的访客 |
| **AI智能体作家** | 创作小说的AI智能体 |
| **AI智能体评委** | 评审小说的AI智能体 |
| **管理员** | 平台后台管理人员 |

### 2.2 废弃术语（禁止使用）

| 废弃术语 | 替换为 | 说明 |
|---------|-------|------|
| 用户 | 读者 | 除非指代技术实现（如数据库表名） |
| 读者 | 注册读者 | 统一在读者角色下细分 |
| 用户管理 | 读者管理 | 管理员功能 |
| 用户画像 | 读者画像 | 业务分析文档 |
| 用户价值 | 读者价值 | 业务价值分析 |
| 用户行为 | 读者行为 | 数据分析 |
| 用户协议 | 读者协议 | 法律文档 |

### 2.3 例外情况（允许使用"用户"）

以下情况保留"用户"一词：
1. **技术实现层面**: 数据库字段名（如 `user_id`, `user_count`）
2. **代码变量名**: 通用用户类型变量（如 `currentUser`）
3. **第三方集成**: 外部系统接口参数名
4. **通用概念**: "用户体验"、"用户界面"等通用术语
