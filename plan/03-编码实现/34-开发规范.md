## 1. 命名规范

### 1.1 数据库命名规范 (Prisma Schema)

#### 模型命名
- **规范**: 使用 PascalCase
- **示例**: `Claw`, `Novel`, `ReviewTask`, `CreationArchive`
- **数据库表名**: 使用 snake_case，通过 `@@map` 映射
- **示例**:
  ```prisma
  model ReviewTask {
    // ... fields
    @@map("review_tasks")
  }
  ```

#### 字段命名
- **规范**: 使用 camelCase
- **数据库列名**: 使用 snake_case，通过 `@map` 映射
- **示例**:
  ```prisma
  model Novel {
    id          String   @id @default(uuid())
    authorId    String   @map("author_id")
    wordCount   Int      @map("word_count")
    isDeleted   Boolean  @default(false) @map("is_deleted")
    createdAt   DateTime @default(now()) @map("created_at")
    updatedAt   DateTime @default(now()) @map("updated_at")
  }
  ```

#### 关系字段命名
- **规范**: 使用 camelCase，清晰表达关系
- **示例**:
  ```prisma
  model Claw {
    novels          Novel[]
    reviewTasks     ReviewTask[]
    creationArchive CreationArchive?
  }
  ```

#### 枚举命名
- **枚举名**: PascalCase
- **枚举值**: UPPER_SNAKE_CASE
- **示例**:
  ```prisma
  enum NovelStatus {
    DRAFT
    PENDING
    PUBLISHED
    REJECTED
    COMPLETED
  }
  ```

### 1.2 TypeScript/JavaScript 命名规范

#### 类名
- **规范**: PascalCase
- **示例**: `NovelsService`, `AuthController`, `JwtAuthGuard`

#### 接口/类型名
- **规范**: PascalCase，使用描述性后缀
- **示例**:
  ```typescript
  interface NovelResponseDto { }
  interface CreateNovelDto { }
  type NovelStatus = 'DRAFT' | 'PUBLISHED';
  ```

#### 变量/函数名
- **规范**: camelCase
- **示例**:
  ```typescript
  const novelId = '123';
  const isPublished = true;
  function createNovel(dto: CreateNovelDto) { }
  async function findNovelById(id: string) { }
  ```

#### 常量名
- **规范**: UPPER_SNAKE_CASE
- **示例**:
  ```typescript
  const MAX_PAGE_SIZE = 100;
  const DEFAULT_TIMEOUT = 5000;
  ```

#### 私有成员
- **规范**: 使用下划线前缀
- **示例**:
  ```typescript
  class NovelsService {
    private readonly _prisma: PrismaService;
    private _cache: Map<string, any>;
  }
  ```

### 1.3 API 路由命名规范

#### 控制器路由
- **规范**: 使用名词复数，小写
- **示例**:
  ```typescript
  @Controller('novels')      // ✓ 正确
  @Controller('novel')       // ✗ 错误
  @Controller('Novels')      // ✗ 错误
  ```

#### 端点命名
- **规范**: 使用动词或动作描述
- **示例**:
  ```typescript
  @Get()                     // 获取列表
  @Get(':id')               // 获取单个
  @Post()                   // 创建
  @Put(':id')               // 完整更新
  @Patch(':id')             // 部分更新
  @Delete(':id')            // 删除
  @Get('ranking')           // 自定义端点
  @Get('scope/mine')        // 作用域端点
  ```

### 1.4 文件命名规范

#### 源代码文件
- **规范**: kebab-case，描述性名称
- **示例**:
  ```
  novels.service.ts
  auth.controller.ts
  jwt-auth.guard.ts
  create-novel.dto.ts
  novel-response.dto.ts
  ```

#### 测试文件
- **规范**: 与被测试文件同名，添加 `.spec.ts` 或 `.test.ts` 后缀
- **示例**:
  ```
  novels.service.spec.ts
  auth.controller.spec.ts
  ```

#### 目录命名
- **规范**: kebab-case，复数形式
- **示例**:
  ```
  src/novels/
  src/auth/
  src/common/filters/
  src/common/interceptors/
  ```

```typescript
/**
 * 创建新小说
 * @param authorId - 作者ID
 * @param dto - 创建小说数据传输对象

  // 验证作者是否存在
  const author = await this._prisma.claw.findUnique({ where: { id: authorId } });
  if (!author) {
    throw new NotFoundException('Author not found');
  }
  
  // TODO: 添加更多验证逻辑
  
  return this._prisma.novel.create({ data: { ...dto, authorId } });
}
```

```typescript
  @ApiProperty({ description: '小说标题', example: '星际穿越' })
```

## 4. 数据库操作规范

### 4.1 Prisma 查询规范

```typescript
// 使用类型安全的查询
const novel = await this._prisma.novel.findUnique({
  where: { id: novelId },
  include: {
    author: true,
    chapters: {
      where: { isDeleted: false },
      orderBy: { orderIndex: 'asc' },
    },
  },
});

// 使用事务
const [novel, chapter] = await this._prisma.$transaction([
  this._prisma.novel.create({ data: novelData }),
  this._prisma.chapter.create({ data: chapterData }),
]);
```

### 4.2 软删除规范

```typescript
// 软删除查询
const novels = await this._prisma.novel.findMany({
  where: { isDeleted: false },
});

// 软删除操作
await this._prisma.novel.update({
  where: { id: novelId },
  data: { isDeleted: true, updatedAt: new Date() },
});
```
