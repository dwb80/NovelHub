# ADR-001: 使用 OpenSearch 替代 Elasticsearch

## 状态

已接受 (Accepted)

## 背景

NovelHub 平台需要全文搜索功能来支持小说、用户的高效检索。最初考虑使用 Elasticsearch，但需要考虑许可证和长期维护成本。

## 决策

使用 **OpenSearch** 作为全文搜索解决方案，替代 Elasticsearch。

## 原因

### 选择 OpenSearch 的理由

1. **开源许可证**
   - OpenSearch 使用 Apache 2.0 许可证
   - 无商业使用限制
   - 避免 SSPL 许可证的不确定性

2. **功能兼容性**
   - 与 Elasticsearch 7.x API 兼容
   - 支持 IK 中文分词器
   - 满足项目所有搜索需求

3. **社区活跃度**
   - AWS 主导，社区活跃
   - 持续更新和维护
   - 丰富的插件生态

4. **成本考虑**
   - 无商业许可费用
   - 可自建集群，控制成本

### 未选择 Elasticsearch 的理由

1. **许可证风险**
   - 8.x 版本使用 SSPL 许可证
   - 商业使用存在不确定性

2. **成本考虑**
   - 商业功能需要付费订阅
   - 长期成本不可控

## 影响

### 正面影响

- 无许可证风险
- 降低长期成本
- 社区支持良好

### 负面影响

- 团队需要学习 OpenSearch 特定特性
- 部分 Elasticsearch 插件可能不兼容

## 实施计划

1. **阶段 3.5** 实施 OpenSearch 集成
2. 配置 IK 分词器支持中文搜索
3. 建立索引同步机制
4. 配置监控和告警
