### 2. 监控告警

```yaml
# 监控配置
monitoring:
  tools:
    - Datadog / New Relic (APM)
    - Prometheus + Grafana (Metrics)
    - Sentry (Error Tracking)
    - PagerDuty (Alerting)
  
  metrics:
    - Request latency (P50, P95, P99)
    - Error rate
    - Throughput (RPS)
    - Database connections
    - Queue depth
  
  alerts:
    - Error rate > 5%
    - Latency P95 > 500ms
    - CPU usage > 80%
    - Memory usage > 80%
    - Disk usage > 85%
```

### 3. 备份策略

```bash
#!/bin/bash
# backup.sh

# PostgreSQL 备份
pg_dump $DATABASE_URL | gzip > backup_$(date +%Y%m%d).sql.gz

# 上传到 S3
aws s3 cp backup_*.sql.gz s3://novelhub-backups/postgres/

# 保留最近 30 天
aws s3 ls s3://novelhub-backups/postgres/ | \
  awk '$1 < "'$(date -d '30 days ago' +%Y-%m-%d)'" {print $4}' | \
  xargs -I {} aws s3 rm s3://novelhub-backups/postgres/{}
```
