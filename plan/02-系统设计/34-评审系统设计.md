## 1. 概述

### 1.1 设计目标
设计一个公平、高效的社区评审系统，通过众包评审提升作品质量，同时激励用户参与。

### 1.2 设计原则
- 公平公正：随机分配评审任务
- 质量优先：多维度评审标准
- 激励驱动：积分和等级体系
- 透明公开：评审流程可追溯

## 6. 数据库设计

### 6.1 评审任务表

```sql
CREATE TABLE review_tasks (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  novel_id UUID NOT NULL REFERENCES novels(id),
  reviewer_id UUID NOT NULL REFERENCES readers(id),
  status VARCHAR(20) NOT NULL DEFAULT 'pending',
  priority VARCHAR(10) NOT NULL DEFAULT 'medium',
  deadline TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  completed_at TIMESTAMP
);
```

### 6.2 评审结果表

```sql
CREATE TABLE review_results (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  task_id UUID NOT NULL REFERENCES review_tasks(id),
  plot_score INTEGER NOT NULL CHECK (plot_score BETWEEN 1 AND 10),
  character_score INTEGER NOT NULL CHECK (character_score BETWEEN 1 AND 10),
  writing_score INTEGER NOT NULL CHECK (writing_score BETWEEN 1 AND 10),
  innovation_score INTEGER NOT NULL CHECK (innovation_score BETWEEN 1 AND 10),
  overall_score INTEGER NOT NULL CHECK (overall_score BETWEEN 1 AND 10),
  strengths TEXT,
  suggestions TEXT,
  comment TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 6.3 评审员统计表

```sql
CREATE TABLE reviewer_stats (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  reader_id UUID NOT NULL REFERENCES readers(id) UNIQUE,
  total_reviews INTEGER NOT NULL DEFAULT 0,
  accuracy DECIMAL(5,2) NOT NULL DEFAULT 0,
  total_points INTEGER NOT NULL DEFAULT 0,
  current_level VARCHAR(20) NOT NULL DEFAULT 'bronze',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 8. 安全设计

### 8.1 防刷机制
- 同一用户不能评审自己的作品
- 评审间隔时间限制（5分钟）
- 异常评审行为检测

### 8.2 质量控制
- 评审内容自动审核
- 低质量评审过滤
- 评审员信誉系统
