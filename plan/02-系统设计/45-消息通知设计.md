## 1. 设计概述

### 1.1 设计目标
- 提供多渠道、实时、可靠的消息通知服务
- 支持站内通知、邮件、短信、推送等多种通知方式
- 支持通知模板管理和动态配置
- 提供通知发送状态追踪和失败重试机制

### 1.2 设计原则
- **可靠性**: 消息不丢失，至少送达一次
- **实时性**: 关键通知秒级送达
- **可扩展性**: 支持多种通知渠道灵活扩展
- **可观测性**: 完整的发送日志和监控

```prisma
model NotificationTemplate {
```

## 4. 通知渠道设计

### 4.1 站内通知 (In-App)

```typescript
class InAppDispatcher implements NotificationDispatcher {
  async dispatch(notification: Notification): Promise<DispatchResult> {
    // 1. 保存到数据库
    await this.prisma.notification.create({
      data: {
        readerId: notification.recipientId,
        type: notification.type,
        title: notification.title,
        content: notification.content,
        data: notification.data,
        isRead: false,
        createdAt: new Date()
      }
    });
    
    // 2. 发送WebSocket实时通知
    await this.webSocketService.emit(
      `user:${notification.recipientId}`,
      'notification:new',
      notification
    );
    
    // 3. 更新未读计数
    await this.updateUnreadCount(notification.recipientId);
    
    return { success: true, channel: 'IN_APP' };
  }
}
```

### 4.2 邮件通知 (Email)

```typescript
class EmailDispatcher implements NotificationDispatcher {
  async dispatch(notification: Notification): Promise<DispatchResult> {
    const user = await this.getUser(notification.recipientId);
    
    if (!user.email) {
      return { success: false, error: '用户未绑定邮箱' };
    }
    
    // 渲染邮件模板
    const html = await this.templateEngine.render('email', {
      title: notification.title,
      content: notification.content,
      actionUrl: notification.data?.actionUrl,
      unsubscribeUrl: this.generateUnsubscribeUrl(user.id)
    });
    
    // 发送邮件
    await this.emailService.send({
      to: user.email,
      subject: notification.title,
      html,
      from: 'noreply@novelhub.com'
    });
    
    return { success: true, channel: 'EMAIL' };
  }
}
```

### 4.3 短信通知 (SMS)

```typescript
class SmsDispatcher implements NotificationDispatcher {
  async dispatch(notification: Notification): Promise<DispatchResult> {
    const user = await this.getUser(notification.recipientId);
    
    if (!user.phone) {
      return { success: false, error: '用户未绑定手机号' };
    }
    
    // 检查短信频率限制
    if (await this.isRateLimited(user.phone)) {
      return { success: false, error: '短信发送频率超限' };
    }
    
    // 发送短信
    await this.smsService.send({
      phone: user.phone,
      templateCode: notification.templateCode,
      params: notification.data
    });
    
    return { success: true, channel: 'SMS' };
  }
}
```

### 4.4 推送通知 (Push)

```typescript
class PushDispatcher implements NotificationDispatcher {
  async dispatch(notification: Notification): Promise<DispatchResult> {
    // 获取用户设备令牌
    const devices = await this.getUserDevices(notification.recipientId);
    
    if (devices.length === 0) {
      return { success: false, error: '用户未订阅推送' };
    }
    
    // 批量发送推送
    const results = await Promise.all(
      devices.map(device => 
        this.pushService.send({
          token: device.token,
          platform: device.platform,
          title: notification.title,
          body: notification.content,
          data: notification.data,
          badge: await this.getUnreadCount(notification.recipientId)
        })
      )
    );
    
    const success = results.some(r => r.success);
    return { success, channel: 'PUSH' };
  }
}
```

## 6. 重试机制

### 6.1 重试策略

```typescript
interface RetryPolicy {
  maxRetries: number;        // 最大重试次数
  backoffMultiplier: number; // 退避倍数
  initialDelay: number;      // 初始延迟(ms)
  maxDelay: number;          // 最大延迟(ms)
}

const defaultRetryPolicy: RetryPolicy = {
  maxRetries: 3,
  backoffMultiplier: 2,
  initialDelay: 1000,
  maxDelay: 60000
};

// 计算下次重试时间
function calculateNextRetryTime(
  attempt: number,
  policy: RetryPolicy
): number {
  const delay = Math.min(
    policy.initialDelay * Math.pow(policy.backoffMultiplier, attempt),
    policy.maxDelay
  );
  return Date.now() + delay;
}
```

### 6.2 重试队列

```typescript
// BullMQ 重试队列配置
const retryQueue = new Queue('notification-retry', {
  defaultJobOptions: {
    attempts: 3,
    backoff: {
      type: 'exponential',
      delay: 1000
    },
    removeOnComplete: 100,
    removeOnFail: 50
  }
});

// 重试处理器
retryQueue.process(async (job) => {
  const { notificationId, attempt } = job.data;
  
  const notification = await getNotification(notificationId);
  
  try {
    await dispatchNotification(notification);
    await updateNotificationStatus(notificationId, 'SENT');
  } catch (error) {
    if (attempt >= 3) {
      await updateNotificationStatus(notificationId, 'FAILED', error.message);
      await alertAdmin(notification);
    } else {
      throw error; // 触发重试
    }
  }
});
```

## 7. 监控与告警

### 7.1 监控指标

| 指标 | 说明 | 告警阈值 |
|------|------|---------|
| 发送成功率 | 成功发送/总发送 | < 95% |
| 平均发送延迟 | 从接收到发送的时间 | > 5s |
| 队列堆积数 | 待处理消息数量 | > 10000 |
| 重试率 | 需要重试的比例 | > 10% |
| 失败率 | 最终失败的比例 | > 5% |

### 7.2 告警规则

```yaml
alerts:
  - name: 发送成功率下降
    condition: success_rate < 0.95
    duration: 5m
    severity: warning
    
  - name: 队列堆积
    condition: queue_depth > 10000
    duration: 2m
    severity: critical
    
  - name: 大量发送失败
    condition: failure_rate > 0.05
    duration: 5m
    severity: critical
```

## 8. 性能优化

### 8.1 批量发送

```typescript
async function sendBatchNotifications(
  notifications: Notification[],
  batchSize: number = 100
): Promise<void> {
  // 分批处理
  const batches = chunk(notifications, batchSize);
  
  for (const batch of batches) {
    // 并行发送
    await Promise.all(
      batch.map(notification => 
        notificationQueue.add('send', notification)
      )
    );
    
    // 控制速率
    await sleep(100);
  }
}
```

### 8.2 缓存优化

```typescript
// 模板缓存
const templateCache = new Map<string, NotificationTemplate>();

async function getTemplate(code: string): Promise<NotificationTemplate> {
  // 先查缓存
  if (templateCache.has(code)) {
    return templateCache.get(code)!;
  }
  
  // 查数据库
  const template = await prisma.notificationTemplate.findUnique({
    where: { code }
  });
  
  // 写入缓存
  if (template) {
    templateCache.set(code, template);
  }
  
  return template;
}
```
