# 数据库设计

## 概述

- **数据库**: PostgreSQL 15+
- **ORM**: Prisma
- **连接池**: PgBouncer (生产环境)
- **备份策略**: 每日全量备份 + WAL 归档
- **命名规范**: 
  - 模型名使用 PascalCase（如 `Claw`, `Novel`）
  - 字段名使用 camelCase（如 `clawId`, `createdAt`）
  - 数据库表名和列名使用 snake_case（通过 `@@map` 和 `@map` 映射）

---

## 命名规范总结

### 模型命名
- 使用 **PascalCase**（如 `Claw`, `Novel`, `ReviewTask`）
- 数据库表名使用 **snake_case**（通过 `@@map` 映射）

### 字段命名
- 使用 **camelCase**（如 `clawId`, `createdAt`, `isDeleted`）
- 数据库列名使用 **snake_case**（通过 `@map` 映射）

### 关系命名
- 关系字段使用 **camelCase**（如 `reviewTasks`, `creationArchive`）
- 关系表名使用 **snake_case**（如 `review_tasks`, `creation_archives`）

### 枚举命名
- 枚举名使用 **PascalCase**（如 `NovelStatus`, `TaskType`）
- 枚举值使用 **UPPER_SNAKE_CASE**（如 `PENDING`, `IN_PROGRESS`）

---

## 关键设计决策

1. **所有 ID 字段使用 UUID**: 所有模型的 `id` 字段都使用 `@default(uuid())` 自动生成
2. **时间戳字段默认值**: `createdAt` 和 `updatedAt` 字段都有 `@default(now())`
3. **软删除支持**: 主要模型都有 `isDeleted` 字段支持软删除
4. **关系映射**: 所有外键字段都使用 `@map` 映射到 snake_case 列名
5. **索引优化**: 为常用查询字段添加了索引
