# 静态页面模块设计文档

**文档编号**: DES-STATIC-001  
**版本**: v1.0.0  
**日期**: 2026-04-17

---

## 1. 概述

### 1.1 设计目标
设计一套统一、专业的静态页面，提供平台基础信息展示和用户沟通渠道。

### 1.2 设计原则
- 简洁专业：内容清晰，布局简洁
- 品牌一致：保持平台视觉风格
- SEO友好：优化搜索引擎收录
- 响应式：适配各种设备

## 2. 页面设计

### 2.1 通用布局

```
┌─────────────────────────────────────────────────────────────┐
│                         Header                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                      Main Content                           │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                         Footer                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 使用条款页面

**页面结构**
```typescript
TermsPage
├── Header
├── Main Content
│   ├── Page Title (使用条款)
│   ├── Last Updated (最后更新日期)
│   └── Content Sections
│       ├── 1. 接受条款
│       ├── 2. 账号注册
│       ├── 3. 用户行为准则
│       ├── 4. 内容发布规范
│       ├── 5. 知识产权
│       ├── 6. 免责声明
│       ├── 7. 协议变更
│       └── 8. 联系我们
└── Footer
```

**样式规范**
- 标题：text-4xl font-bold
- 章节标题：text-2xl font-semibold
- 正文：text-muted-foreground leading-relaxed
- 容器：max-w-4xl mx-auto

### 2.4 联系我们页面

**页面结构**
```typescript
ContactPage
├── Header
├── Main Content
│   ├── Page Title (联系我们)
│   ├── Contact Info Cards
│   │   ├── Email Card
│   │   ├── Phone Card
│   │   └── Address Card
│   ├── Contact Form
│   └── FAQ Section
└── Footer
```

**联系表单字段**
| 字段 | 类型 | 必填 | 验证 |
|------|------|------|------|
| 姓名 | text | 是 | 2-50字符 |
| 邮箱 | email | 是 | 邮箱格式 |
| 主题 | text | 是 | 5-100字符 |
| 内容 | textarea | 是 | 20-1000字符 |

### 2.5 反馈建议页面

**页面结构**
```typescript
FeedbackPage
├── Header
├── Main Content
│   ├── Page Title (反馈建议)
│   ├── Feedback Types
│   └── Feedback Form
└── Footer
```

**反馈类型**
| 类型 | 图标 | 描述 |
|------|------|------|
| 功能建议 | Lightbulb | 提出新功能建议 |
| Bug报告 | Bug | 报告系统问题 |
| 体验反馈 | Sparkles | 分享使用体验 |
| 其他 | MessageSquare | 其他反馈 |

**表单字段**
| 字段 | 类型 | 必填 | 验证 |
|------|------|------|------|
| 反馈类型 | select | 是 | 四选一 |
| 标题 | text | 是 | 5-100字符 |
| 详细描述 | textarea | 是 | 20-2000字符 |
| 联系邮箱 | email | 否 | 邮箱格式 |

### 2.6 关于我们页面

**页面结构**

AboutPage
