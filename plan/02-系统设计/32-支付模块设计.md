## 1. 设计概述

### 1.1 设计目标
- 支持读者打赏小说和AI智能体作家
- 支持平台虚拟商品购买
- 提供安全可靠的支付流程
- 完整的订单管理和对账功能

### 1.2 设计原则
- **安全性**: 支付数据加密传输和存储
- **可靠性**: 订单状态幂等性保证
- **可扩展性**: 支持多种支付渠道接入
- **可追溯性**: 完整的支付日志和审计

## 2. 架构设计

### 2.1 模块架构

```
PaymentModule
├── PaymentController
│   ├── POST /payments/orders          # 创建订单
│   ├── GET  /payments/orders          # 查询订单列表
```

## 3. 数据库设计

### 3.1 订单表 (PaymentOrder)

```prisma
model PaymentOrder {
  id            String        @id @default(uuid())
  orderNo       String        @unique @map("order_no")
  readerId      String        @map("reader_id")
  type          OrderType     // REWARD-打赏, PURCHASE-购买
  amount        Decimal       @db.Decimal(10, 2)
  currency      String        @default("CNY")
  status        OrderStatus   @default(PENDING)
  subject       String        // 订单标题
  body          String?       // 订单描述
  novelId       String?       @map("novel_id") // 打赏的小说
  chapterId     String?       @map("chapter_id") // 打赏的章节
  recipientId   String?       @map("recipient_id") // 接收者(AI智能体作家)
  
  // 支付渠道信息
  channel       PaymentChannel? @map("payment_channel")
  channelOrderNo String?      @map("channel_order_no")
  paidAt        DateTime?     @map("paid_at")
  
  // 退款信息
  refundAmount  Decimal?      @default(0) @map("refund_amount") @db.Decimal(10, 2)
  refundReason  String?       @map("refund_reason")
  refundedAt    DateTime?     @map("refunded_at")
  
  // 时间戳
  expiredAt     DateTime      @map("expired_at")
  createdAt     DateTime      @default(now()) @map("created_at")
  updatedAt     DateTime      @updatedAt @map("updated_at")
  
  reader        Reader        @relation(fields: [readerId], references: [id])
  
  @@index([readerId])
  @@index([orderNo])
  @@index([status])
  @@index([createdAt])
  @@map("payment_orders")
}
```

### 3.2 枚举定义

```prisma
enum OrderType {
  REWARD      // 打赏
  PURCHASE    // 购买
  VIP         // VIP会员
}

enum OrderStatus {
  PENDING     // 待支付
  PROCESSING  // 支付中
  SUCCESS     // 支付成功
  FAILED      // 支付失败
  CLOSED      // 已关闭
  REFUNDED    // 已退款
  PARTIAL_REFUNDED // 部分退款
}

enum PaymentChannel {
  WECHAT_PAY  // 微信支付
  ALIPAY      // 支付宝
  MOCK        // 测试支付
}
```

## 4. API设计

### 4.1 创建订单

**端点**: `POST /api/v1/payments/orders`

**请求体**:
```typescript
{
  type: "REWARD",           // 订单类型
  amount: 10.00,            // 金额(元)
  novelId?: "uuid",         // 打赏小说ID
  chapterId?: "uuid",       // 打赏章节ID
  recipientId?: "uuid",     // 接收者ID
  subject: "打赏《星际穿越者》", // 订单标题
  body?: "感谢AI智能体作家",         // 订单描述
}
```

**响应**:
```typescript
{
  id: "uuid",
  orderNo: "ORD202404190001",
  type: "REWARD",
  amount: "10.00",
  status: "PENDING",
  subject: "打赏《星际穿越者》",
  expiredAt: "2026-04-19T12:00:00Z",
  createdAt: "2026-04-19T11:30:00Z"
}
```

### 4.2 发起支付

**端点**: `POST /api/v1/payments/orders/:id/pay`

**请求体**:
```typescript
{
  channel: "WECHAT_PAY",    // 支付渠道
  returnUrl?: "https://..." // 支付完成回调地址
}
```

**响应**:
```typescript
{
  orderId: "uuid",
  orderNo: "ORD202404190001",
  channel: "WECHAT_PAY",
  // 微信支付参数
  prepayId: "wx201410272009395522657a690399285100",
  appId: "wx8888888888888888",
  timeStamp: "1414411784",
  nonceStr: "5K8264ILTKCH16CQ2502SI8ZNMTM67VS",
  package: "prepay_id=wx201410272009395522657a690399285100",
  signType: "RSA",
  paySign: "C380BEC2BFD727A4B6845133519F3AD6"
}
```

### 4.3 支付回调

**端点**: `POST /api/v1/payments/callback/:channel`

**处理逻辑**:
1. 验证签名
2. 查询订单状态
3. 幂等性处理
4. 更新订单状态
5. 发送通知

### 4.4 查询订单列表

**端点**: `GET /api/v1/payments/orders`

**查询参数**:
- `type`: 订单类型筛选
- `status`: 订单状态筛选
- `startDate`: 开始日期
- `endDate`: 结束日期
- `page`: 页码
- `limit`: 每页数量

**响应**:
```typescript
{
  items: [...],
  total: 100,
  page: 1,
  limit: 20,
  totalPages: 5
}
```

## 5. 支付流程

### 5.1 打赏流程

```
┌─────────┐    1.创建订单    ┌─────────┐    2.返回订单    ┌─────────┐
│  Reader │ ───────────────→│ Backend │ ───────────────→│  Reader │
└─────────┘                 └─────────┘                 └─────────┘
     │                           │                           │
     │    3.选择支付方式          │    4.发起支付              │
     │ ─────────────────────────→│ ─────────────────────────→│
     │                           │                           │
     │                           │    5.调起支付SDK           │
     │                           │ ←─────────────────────────│
     │                           │                           │
     │    6.支付完成              │    7.支付结果              │
     │ ─────────────────────────→│ ─────────────────────────→│
     │                           │                           │
     │                           │    8.异步通知              │
     │                           │ ←─────────────────────────│
     │                           │                           │
     │    9.查询结果              │    10.返回状态             │
     │ ─────────────────────────→│ ─────────────────────────→│
```

### 5.2 状态机

```
                    ┌─────────┐
         ┌─────────→│ PENDING │←────────┐
         │          │ (待支付) │         │
         │          └────┬────┘         │
    创建订单              │              │
         │          发起支付            │
         │               │              │
         │               ▼              │
         │          ┌─────────┐         │
         │    ┌────→│PROCESSING│        │
         │    │     │(支付中)  │        │
         │    │     └────┬────┘        │
         │    │          │             │
         │    │    支付成功/失败        │
         │    │          │             │
         │    │    ┌─────┴─────┐       │
         │    └───→│           │       │
         │      ┌──┴──┐     ┌──┴──┐    │
         │      │SUCCESS│    │FAILED│    │

         │    申请退款      关闭订单    │

         └──────────────────────────────┘
```

## 6. 安全设计

### 6.1 数据安全

- 敏感字段加密存储（AES-256）
- 支付密码单独加密
- 数据库字段级加密

### 6.2 传输安全

- 强制HTTPS
- 请求签名验证
- 防重放攻击（timestamp + nonce）

### 6.3 业务安全

- 订单金额校验
- 支付频率限制
- 异常订单监控
- 风控规则引擎

---

## 7. 异常处理

| 异常场景 | 处理策略 |
|---------|---------|
| 支付超时 | 主动查询订单状态，超时关闭订单 |
| 重复支付 | 幂等性校验，返回已支付结果 |
| 回调失败 | 定时任务补偿，最多重试5次 |
| 金额不一致 | 记录异常日志，人工介入处理 |
| 网络异常 | 重试机制，降级处理 |
