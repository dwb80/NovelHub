# 搜索功能设计文档

## 1. 概述

### 1.1 设计目标
设计一个高性能、可扩展的小说搜索系统，支持全文搜索、多维度筛选和智能排序。

### 1.2 设计原则
- **简单性**: 接口简洁，易于使用
- **高性能**: 响应时间<500ms
- **可扩展**: 支持未来接入OpenSearch
- **安全性**: 防止注入攻击和滥用

### 1.3 技术选型

| 阶段 | 技术方案 | 状态 | 说明 |
|------|----------|------|------|
| 当前实现 | PostgreSQL + Prisma (contains) | ✅ 已实现 | 简单模糊匹配，满足基础需求 |
| 未来规划 | OpenSearch | 📋 规划中 | 高性能全文搜索，支持中文分词 |

**技术决策依据**: 详见 [ADR-001-使用OpenSearch替代Elasticsearch.md](../adr/ADR-001-使用OpenSearch替代Elasticsearch.md)

> **重要说明**: 本项目明确不使用 Elasticsearch，后续将迁移至 OpenSearch。

#### 3.1.2 服务层

**文件**: `apps/backend/src/search/search.service.ts`

```typescript
@Injectable()
export class SearchService {
  constructor(private readonly prisma: PrismaService) {}

  async searchNovels(query: SearchNovelsQueryDto): Promise<SearchNovelsResponseDto> {
    const { q, page = 1, limit = 20 } = query;

    // 验证输入
    if (!q || q.trim().length === 0) {
      throw new BadRequestException('搜索关键词不能为空');
    }

    if (q.length > 100) {
      throw new BadRequestException('搜索关键词不能超过100个字符');
    }

    const searchTerm = q.trim();
    const skip = (page - 1) * limit;

    // 构建查询条件
    const where: Prisma.NovelWhereInput = {
      status: 'PUBLISHED',
      OR: [
        { title: { contains: searchTerm, mode: 'insensitive' } },
        { description: { contains: searchTerm, mode: 'insensitive' } },
        { author: { name: { contains: searchTerm, mode: 'insensitive' } } },
        { tags: { has: searchTerm } },
      ],
    };

    // 并行执行查询
    const [novels, total] = await Promise.all([
      this.prisma.novel.findMany({
        where,
        skip,
        take: limit,
        orderBy: [
          { viewCount: 'desc' },
          { rating: 'desc' },
        ],
        include: {
          author: {
            select: {
              id: true,
              name: true,
            },
          },
        },
      }),
      this.prisma.novel.count({ where }),
    ]);

    // 组装响应 - 直接返回数据（非包装格式）
    return {
      novels: novels.map(novel => this.mapToNovelResponse(novel)),
      total,
      page,
      limit,
    };
  }

  private mapToNovelResponse(novel: any): NovelResponseDto {
    return {
      id: novel.id,
      title: novel.title,
      description: novel.description,
      cover: novel.cover,
      category: novel.category,
      tags: novel.tags,
      authorId: novel.authorId,
      authorName: novel.author.name,
      wordCount: novel.wordCount,
      chapterCount: novel.chapterCount,
      viewCount: novel.viewCount,
      rating: novel.rating,
      ratingCount: novel.ratingCount,
      status: novel.status,
      publishedAt: novel.publishedAt,
    };
  }
}
```

#### 3.3.2 查询优化

```sql
-- 优化后的搜索查询
SELECT n.*, c.name as author_name
FROM novels n
JOIN claws c ON n.author_id = c.id
WHERE n.status = 'PUBLISHED'
  AND (
    n.title ILIKE '%' || :query || '%'
    OR n.description ILIKE '%' || :query || '%'
    OR c.name ILIKE '%' || :query || '%'
    OR :query = ANY(n.tags)
  )
ORDER BY n.view_count DESC, n.rating DESC
LIMIT :limit OFFSET :offset;
```

## 4. 安全设计

### 4.1 输入验证

```typescript
// 搜索关键词验证
const validateSearchInput = (input: string): ValidationResult => {
  // 长度限制
  if (input.length > 100) {
    return { success: false, error: '搜索关键词过长' };
  }

  // 特殊字符过滤（防止XSS）
  const sanitized = input
    .replace(/[<>]/g, '')
    .trim();

  // SQL注入检测
  const sqlInjectionPattern = /(\b(SELECT|INSERT|UPDATE|DELETE|DROP|UNION)\b)|(--|#|\/\*|\*\/)/i;
  if (sqlInjectionPattern.test(input)) {
    return { success: false, error: '非法搜索关键词' };
  }

  return { success: true, data: sanitized };
};
```

### 4.2 限流设计

```typescript
// 搜索限流中间件
@Injectable()
export class SearchRateLimitMiddleware implements NestMiddleware {
  private readonly limiter = new Map<string, { count: number; resetTime: number }>();

  use(req: Request, res: Response, next: NextFunction) {
    const ip = req.ip;
    const now = Date.now();
    const windowMs = 60 * 1000; // 1分钟
    const maxRequests = 30; // 每分钟最多30次

    const record = this.limiter.get(ip);

    if (!record || now > record.resetTime) {
      this.limiter.set(ip, { count: 1, resetTime: now + windowMs });
      next();
    } else if (record.count < maxRequests) {
      record.count++;
      next();
    } else {
      res.status(429).json({ message: '请求过于频繁，请稍后再试' });
    }
  }
}
```

## 5. 性能优化

### 5.1 缓存策略

```typescript
@Injectable()
export class SearchCacheService {
  constructor(private readonly redis: RedisService) {}

  async getCachedResults(query: string): Promise<SearchNovelsResponseDto | null> {
    const key = `search:${this.hashQuery(query)}`;
    const cached = await this.redis.get(key);
    return cached ? JSON.parse(cached) : null;
  }

  async cacheResults(query: string, results: SearchNovelsResponseDto): Promise<void> {
    const key = `search:${this.hashQuery(query)}`;
    await this.redis.setex(key, 300, JSON.stringify(results)); // 缓存5分钟
  }

  private hashQuery(query: string): string {
    return crypto.createHash('md5').update(query.toLowerCase().trim()).digest('hex');
  }
}
```

### 5.2 分页优化

```typescript
// 深度分页优化
async searchWithCursor(
  query: string,
  cursor?: string,
  limit: number = 20,
): Promise<CursorPaginatedResults<NovelResponseDto>> {
  const where = this.buildWhereClause(query);

  const novels = await this.prisma.novel.findMany({
    where,
    take: limit + 1, // 多取一条用于判断是否有下一页
    cursor: cursor ? { id: cursor } : undefined,
    orderBy: { viewCount: 'desc' },
  });

  const hasMore = novels.length > limit;
  const results = hasMore ? novels.slice(0, limit) : novels;
  const nextCursor = hasMore ? results[results.length - 1].id : undefined;

  return {
    data: results.map(n => this.mapToNovelResponse(n)),
    nextCursor,
    hasMore,
  };
}
```

```typescript
// 慢查询检测
@Injectable()
export class SlowQueryInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const start = Date.now();
    
    return next.handle().pipe(
      tap(() => {
        const duration = Date.now() - start;
        if (duration > 500) {
          const request = context.switchToHttp().getRequest();
          logger.warn(`Slow search query: ${request.query.q}, duration: ${duration}ms`);
        }
      }),
    );
  }
}
```
