## 1. 设计原则

### 1.1 核心设计理念

| 原则        | 说明                   |
| --------- | -------------------- |
| **沉浸式阅读** | 阅读页面极致简洁，减少干扰元素      |
| **性能优先**  | 首屏渲染 < 1.5s，LCP < 2s |
| **渐进式披露** | 高级功能只在需要时显示          |
| **一致性**   | 全站交互模式统一             |
| **无障碍**   | WCAG 2.1 AA 级标准      |
| **精致文学** | 克制优雅，让技术隐于文字之后      |

> **设计哲学**: "让技术隐于文字之后，让阅读回归纯粹"
>
> - **克制**: 少即是多，每个元素都有明确功能目的
> - **优雅**: 精致不张扬，细节打磨不过度设计
> - **沉浸**: 内容优先，界面服务于阅读
> - **温度**: 人文气息，避免冷冰冰的科技感

### 1.2 目标设备覆盖

| 设备分类 | 断点范围            | 适配策略             |
| ---- | --------------- | ---------------- |
| 移动端  | 320px - 767px   | 单列布局，汉堡菜单，触摸友好   |
| 平板   | 768px - 1023px  | 双列布局，侧边栏可折叠      |
| 桌面   | 1024px - 1439px | 三列布局，完整导航        |
| 大屏桌面 | ≥ 1440px        | 内容居中，最大宽度 1400px |

### 2.4 圆角与阴影（精致文学风）

#### 精细化圆角系统

| 元素 | 圆角值 | Tailwind类 | 使用场景 | 设计理由 |
|------|--------|-----------|----------|----------|
| **微型按钮** | 4px | `rounded` | 图标按钮、小操作 | 精致紧凑 |
| **标准按钮** | 6px | `rounded-sm` | 主要操作按钮 | 柔和但不失利落 |
| **大按钮** | 8px | `rounded-md` | CTA按钮、悬浮按钮 | 突出重要操作 |
| **输入框** | 4px | `rounded` | 表单输入 | 与按钮区分，更稳重 |
| **搜索框** | 9999px | `rounded-full` | 搜索输入 | 特殊识别性，行业惯例 |
| **小卡片** | 8px | `rounded-md` | 小说卡片、列表项 | 温和友好 |
| **大卡片** | 12px | `rounded-lg` | 模块容器、内容块 | 明显容器感 |
| **弹窗** | 16px | `rounded-xl` | 模态框、抽屉 | 层级提升，聚焦注意力 |
| **图片** | 4px | `rounded` | 封面图 | 轻微柔和，不抢内容 |
| **头像** | 9999px | `rounded-full` | 人物头像 | 完全圆形，识别性强 |

**核心规则**:
- 操作元素（按钮/输入）≤ 6px，精致紧凑
- 内容容器（卡片）8-12px，温和友好
- 浮层/弹窗 16px，明显层级
- 圆形元素（头像/标签）full，识别性强

## 5. 主题系统与无障碍

### 5.1 深色模式实现

```css
/* CSS 变量方案 */
:root {
  --color-bg-primary: #ffffff;
  --color-text-primary: #111827;
  --color-border: #e5e7eb;
}

[data-theme="dark"] {
  --color-bg-primary: #111827;
  --color-text-primary: #f9fafb;
  --color-border: #374151;
}
```

**切换逻辑**:

1. 首次访问根据系统 `prefers-color-scheme` 自动选择
2. 读者手动选择后存储到 `localStorage`
3. SSR 阶段读取 cookie 渲染正确主题（避免闪烁）

***

### 5.2 无障碍规范 (WCAG 2.1 AA)

| 检查项   | 要求                          | 实现方案               |
| ----- | --------------------------- | ------------------ |
| 颜色对比度 | ≥ 4.5:1 普通文本≥ 3:1 大文本       | Design Token 强制校验  |
| 键盘导航  | 所有交互元素可 Tab 访问焦点环清晰可见       | `focus-visible` 样式 |
| 屏幕阅读器 | 所有图片有 alt按钮/链接语义正确          | ARIA label + role  |
| 缩放支持  | 150% 缩放无横向滚动200% 缩放功能完整     | REM 相对单位           |
| 动画    | `prefers-reduced-motion` 检测 | 运动障碍读者关闭动画         |

## 6. 动画与微交互

### 6.1 动画曲线标准

| 曲线   | 用途     | 值                              |
| ---- | ------ | ------------------------------ |
| 标准缓动 | 入场、离场  | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 减速缓动 | 元素进入屏幕 | `cubic-bezier(0, 0, 0.2, 1)`   |
| 加速缓动 | 元素离开屏幕 | `cubic-bezier(0.4, 0, 1, 1)`   |

### 6.2 时长标准

| 类型   | 时长            | 示例        |
| ---- | ------------- | --------- |
| 微交互  | 100ms - 200ms | 按钮悬停、开关切换 |
| 转场动画 | 200ms - 350ms | 页面路由、模态框  |
| 大型动画 | 350ms - 500ms | 侧边栏展开、引导  |

### 6.3 骨架屏标准

- 脉冲动画: `opacity 0 1 0` 1.5s 无限循环
- 与真实组件形状一一对应
- 浅色遮罩，避免视觉干扰
