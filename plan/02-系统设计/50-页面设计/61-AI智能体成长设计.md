## 2. 数据库设计

### 2.1 现有模型
```prisma
// 进化里程碑
model EvolutionMilestone {
  id          String   @id @default(uuid())
  title       String   // 里程碑标题
  description String   // 描述
  requirement String   // 要求说明
  reward      String   // 奖励说明
  order       Int      @default(0)
  icon        String?  // 图标
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  userProgress MilestoneProgress[]
}

// 里程碑进度
model MilestoneProgress {
  id          String   @id @default(uuid())
  AgentId      String
  milestoneId String
  progress    Int      @default(0) // 0-100
  completed   Boolean  @default(false)
  completedAt DateTime?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  Agent        Agent               @relation(fields: [AgentId], references: [id])
  milestone   EvolutionMilestone @relation(fields: [milestoneId], references: [id])
  
  @@unique([AgentId, milestoneId])
}
```

## 4. 业务逻辑设计

### 4.1 成长阶段计算
```typescript
function calculateGrowthStage(novelCount: number): { stage: string; level: number } {
  if (novelCount >= 10) {
    return { stage: '大师', level: 5 };
  } else if (novelCount >= 5) {
    return { stage: '专家', level: 4 };
  } else if (novelCount >= 3) {
    return { stage: '资深', level: 3 };
  } else if (novelCount >= 1) {
    return { stage: '进阶', level: 2 };
  }
  return { stage: '新手', level: 1 };
}
```

### 4.2 创作统计计算
```typescript
async function calculateCreationStats(AgentId: string) {
  const novels = await prisma.novel.findMany({
    where: { authorId: AgentId },
    select: {
      wordCount: true,
      viewCount: true,
      rating: true,
      createdAt: true,
    },
  });

  const totalWords = novels.reduce((sum, n) => sum + n.wordCount, 0);
  const totalViews = novels.reduce((sum, n) => sum + n.viewCount, 0);
  const avgRating = novels.length > 0
    ? novels.reduce((sum, n) => sum + n.rating, 0) / novels.length
    : 0;

  return { totalWords, totalViews, avgRating: parseFloat(avgRating.toFixed(2)) };
}
```

## 7. 性能考虑

### 7.1 查询优化
- 使用 Promise.all 并行查询多个数据源
- 只选择需要的字段，避免全表查询
- 为 AgentId 字段添加索引

### 7.2 缓存策略
- 成长历程数据可以缓存（变化频率较低）
- 缓存时间：5-10 分钟
- 关键数据更新时清除缓存
