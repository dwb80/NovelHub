# 数据流与编码处理设计文档

## 1. 概述

### 1.1 设计目标
确保 NovelHub 平台所有文本数据（特别是中文）在以下环节中保持编码一致性：
- 客户端 → API 服务器
- API 服务器 → 数据库
- 数据库 → API 服务器
- API 服务器 → 客户端

### 1.2 编码标准
- **统一使用 UTF-8 编码**
- 所有接口必须声明 `charset=utf-8`
- 数据库使用 UTF-8 字符集

## 2. 数据流架构

```
┌─────────────┐     HTTP/JSON      ┌─────────────┐     SQL/UTF-8     ┌─────────────┐
│   前端页面   │ ─────────────────→ │  API 服务器  │ ────────────────→ │  PostgreSQL  │
│  (UTF-8)   │   Content-Type:    │  (UTF-8)    │   Connection:     │  (UTF-8)    │
│            │   application/json │             │   charset=utf-8   │             │
│            │   charset=utf-8    │             │                   │             │
└─────────────┘                    └─────────────┘                   └─────────────┘
       ↑                                                                    │
       │                              读取流程                               │
       └────────────────────────────────────────────────────────────────────┘
```

## 3. 各层编码处理

### 3.1 前端层

#### 3.1.1 HTML 编码声明
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <!-- 确保浏览器使用 UTF-8 解析 -->

```

#### 3.1.2 API 请求配置
```typescript
// api.ts
const api = axios.create({
  baseURL: '/api/v1',
  headers: {
    'Content-Type': 'application/json; charset=utf-8',
  },
  // 确保请求体使用 UTF-8
});

// 请求拦截器 - 确保数据编码正确
api.interceptors.request.use((config) => {
  if (config.data) {
    // 验证数据可以正确 JSON 序列化
    JSON.stringify(config.data);
  }
  return config;
});
```

### 3.2 API 服务器层 (NestJS)

#### 3.2.1 全局编码配置
```typescript
// main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  
  // 确保使用 UTF-8
  app.use((req, res, next) => {
    res.setHeader('Content-Type', 'application/json; charset=utf-8');
    next();
  });
  
  await app.listen(3001);
}
```

### 3.3 数据库层

#### 3.3.1 PostgreSQL 编码配置
```sql
-- 创建数据库时指定编码
CREATE DATABASE novelhub_dev
  WITH ENCODING = 'UTF8'
  LC_COLLATE = 'zh_CN.UTF-8'
  LC_CTYPE = 'zh_CN.UTF-8';

-- 验证编码
SHOW SERVER_ENCODING;  -- UTF8
SHOW CLIENT_ENCODING;  -- UTF8
```

#### 3.3.2 表字段设计
```prisma
model Novel {
  id          String   @id @default(uuid())
  title       String   // 使用 String 类型，自动支持 UTF-8
  description String?
  category    String
  tags        String[] // 数组也支持 UTF-8
  
  @@map("novels")
}
```

## 4. 编码验证机制

### 4.1 API 层验证
```typescript
// 创建数据的验证
@Post()
async create(@Body() dto: CreateNovelDto) {
  // 1. 创建数据
  const novel = await this.novelsService.create(dto);
  
  // 2. 立即读取验证（关键！）
  const verified = await this.novelsService.findById(novel.id);
  
  // 3. 验证编码正确性
  if (verified.title !== dto.title) {
    throw new Error('数据编码异常：标题不匹配');
  }
  
  return verified;
}
```

### 4.2 测试层验证
```typescript
// E2E 测试中的验证
async function verifyEncoding(request, novelId, expectedTitle) {
  // 1. 通过 API 读取
  const response = await request.get(`/api/v1/novels/${novelId}`);
  const data = await response.json();
  
  // 2. 验证内容一致
  expect(data.title).toBe(expectedTitle);
  
  // 3. 验证字符编码（无乱码标记）
  expect(data.title).not.toContain('?');
  expect(data.title).not.toContain('�');
}
```

## 5. 常见编码问题及解决方案

### 5.1 PowerShell 编码问题
**问题**: Windows PowerShell 默认使用 GBK 编码，导致中文乱码

**解决方案**:
```powershell
# 方案1: 设置 PowerShell 编码
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 方案2: 使用 Node.js 脚本代替 PowerShell
# scripts/api-call.js
const http = require('http');
// Node.js 默认使用 UTF-8

# 方案3: 使用 curl（Windows 10+）
curl -X POST http://localhost:3001/api/v1/novels \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{"title":"中文标题"}'
```

### 5.2 终端编码问题
**问题**: 终端显示乱码，但数据实际正确

**验证方法**:
```javascript
// 使用 Node.js 验证，避免终端编码干扰
const data = await response.json();
console.log('Title bytes:', Buffer.from(data.title).toString('hex'));
// 中文 UTF-8 编码以 E4 B8 等开头
```

### 5.3 数据库连接编码
**问题**: 数据库连接字符集不匹配

**解决方案**:
```typescript
// 连接字符串添加编码参数
DATABASE_URL="postgresql://user:pass@localhost:5432/novelhub_dev?charset=utf8"

// 或 Prisma 配置
const prisma = new PrismaClient({
  datasources: {
    db: {
      url: process.env.DATABASE_URL + '?charset=utf8',
    },
  },
});
```

## 7. 监控与告警

### 7.1 编码监控指标
```typescript
// 监控中间件
@Injectable()
export class EncodingMonitor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler) {
    return next.handle().pipe(
      tap((data) => {
        // 检查响应中是否有乱码特征
        const json = JSON.stringify(data);
        if (json.includes('\ufffd') || json.includes('???')) {
          // 记录告警
          this.logger.warn('检测到可能的编码问题', data);
        }
      }),
    );
  }
}
```

### 7.2 告警规则
- 响应中包含 `�` 字符
- 响应中包含连续 `???`
- 数据库查询返回非 UTF-8 字符
