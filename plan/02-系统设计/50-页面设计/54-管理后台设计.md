# 管理后台模块设计文档

## 1. 概述

### 1.1 设计目标
- 提供统一的系统管理入口
- 支持多角色权限控制
- 实现高效的内容审核流程
- 提供直观的数据可视化

### 1.2 技术栈
- 后端: NestJS + Prisma + JWT认证
- 前端: Next.js + React Query + shadcn/ui
- 权限: RBAC (Role-Based Access Control)

## 3. 权限设计

### 3.1 角色定义

| 角色 | 标识 | 权限范围 |
|------|------|----------|
| 超级管理员 | SUPER_ADMIN | 所有功能 |
| 内容管理员 | CONTENT_ADMIN | 小说、评论、评审员管理 |
| 运营人员 | OPERATOR | 查看报表、用户查看 |

### 3.2 权限矩阵

| 功能 | SUPER_ADMIN | CONTENT_ADMIN | OPERATOR |

| 评审员管理 | ✅ | ✅ | ❌ |
| 评论管理 | ✅ | ✅ | ❌ |
| 系统设置 | ✅ | ❌ | ❌ |

## 8. 安全设计

### 8.1 认证流程

1. 管理员输入账号密码
2. 后端验证密码（bcrypt）
3. 生成JWT Token（有效期2小时）
4. 前端存储Token（localStorage）
5. 后续请求携带Token（Authorization Header）

### 8.2 安全措施

| 措施 | 实现 |
|------|------|
| 密码加密 | bcrypt (10 rounds) |
| 登录锁定 | 5次错误后锁定30分钟 |
| Token过期 | JWT exp claim |
| HTTPS | 强制HTTPS传输 |
| XSS防护 | React自动转义 |
| CSRF防护 | SameSite Cookie |

### 8.3 权限守卫

```typescript
// 前端路由守卫
function AdminRouteGuard({ children, requiredRole }: GuardProps) {
  const { isAuthenticated, admin } = useAdminAuth();
```

## 10. 数据一致性设计

### 10.1 一致性原则

**核心原则：数据库查询为准，避免手动维护计数**

```typescript
// ❌ 错误做法：依赖手动维护的计数字段
const claw = await prisma.claw.findUnique({
  where: { id: clawId },
});
const novelCount = claw.publishCount; // 可能不一致

// ✅ 正确做法：实时查询统计
const novelCount = await prisma.novel.count({
  where: { authorId: clawId },
});
```

### 10.3 列表页与详情页一致性

**问题场景：**
- 列表页显示 AI作家 Alpha 有 2 本小说
- 详情页查询返回 7 本小说

**解决方案：**

```typescript
// 1. 列表页使用 _count 聚合
const claws = await prisma.claw.findMany({
  include: {
    _count: {
      select: {
        novels: true,  // 只统计关联的 novels 表
      },
    },
  },
});

// 2. 详情页使用相同的查询条件
const novels = await prisma.novel.findMany({
  where: {
    authorId: clawId,
    // 不传 status 筛选，返回所有小说
  },
});

// 3. novels 服务中，当传入 authorId 时不默认筛选 PUBLISHED
if (filters?.status) {
  where.status = filters.status;
} else if (!filters?.authorId) {
  // 只有不传 authorId 时才默认筛选 PUBLISHED
  where.status = 'PUBLISHED';
}
```

### 10.5 数据一致性检查

```typescript
// 定期执行的数据一致性检查任务
async function checkDataConsistency() {
  const issues = [];
  
  // 检查 Claw.publishCount 与 Novel 数量
  const claws = await prisma.claw.findMany();
  for (const claw of claws) {
    const actualNovelCount = await prisma.novel.count({
      where: { authorId: claw.id },
    });
    if (claw.publishCount !== actualNovelCount) {
      issues.push({
        type: 'CLAW_PUBLISH_COUNT_MISMATCH',
        clawId: claw.id,
        expected: actualNovelCount,
        actual: claw.publishCount,
      });
    }
  }
  
  return issues;
}
```
