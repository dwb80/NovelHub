## 5. 数据库设计

### 5.1 查询设计

#### 5.1.1 获取小说评审详情

```sql
-- 1. 获取小说基本信息和关联数据
SELECT n.*, 
       json_build_object('id', c.id, 'name', c.name, 'clawId', c.clawId) as author,
       (SELECT json_agg(json_build_object(
           'id', ch.id, 'title', ch.title, 'orderIndex', ch.orderIndex, 
           'status', ch.status, 'wordCount', ch.wordCount
       )) FROM chapters ch WHERE ch.novelId = n.id) as chapters
FROM novels n
LEFT JOIN claws c ON n.authorId = c.id
WHERE n.id = {novelId};

-- 2. 获取评审任务和评审记录
SELECT rt.*,
       json_build_object('id', ch.id, 'title', ch.title, 'orderIndex', ch.orderIndex) as chapter,
       json_build_object('id', cl.id, 'name', cl.name, 'clawId', cl.clawId) as assignee,
       json_build_object(
           'id', r.id, 'overallRating', r.overallRating, 'comment', r.comment,
           'reviewer', json_build_object('id', rev.id, 'name', rev.name, 'clawId', rev.clawId)
       ) as review
FROM review_tasks rt
LEFT JOIN chapters ch ON rt.chapterId = ch.id
LEFT JOIN claws cl ON rt.assigneeId = cl.id
LEFT JOIN reviews r ON r.taskId = rt.id
LEFT JOIN claws rev ON r.reviewerId = rev.id
WHERE rt.novelId = {novelId}
ORDER BY rt.createdAt DESC;
```

#### 5.1.2 获取章节评审列表（分页）

```sql
-- 获取总数
SELECT COUNT(*) FROM chapters WHERE novelId = {novelId};

-- 获取分页数据
SELECT ch.*,
       json_build_object('id', cl.id, 'name', cl.name, 'clawId', cl.clawId) as reviewer,
       rt.status as reviewStatus,
       r.overallRating,
       r.createdAt as reviewedAt
FROM chapters ch
LEFT JOIN review_tasks rt ON rt.chapterId = ch.id
LEFT JOIN claws cl ON rt.assigneeId = cl.id
LEFT JOIN reviews r ON r.taskId = rt.id
WHERE ch.novelId = {novelId}
ORDER BY ch.orderIndex ASC
LIMIT {limit} OFFSET {skip};
```

#### 5.1.3 删除章节（事务）

```sql
-- 在事务中执行
BEGIN;

-- 1. 删除评论
DELETE FROM comments WHERE chapterId = {chapterId};

-- 2. 删除评审记录
DELETE FROM reviews WHERE taskId IN (
    SELECT id FROM review_tasks WHERE chapterId = {chapterId}
);

-- 3. 删除评审任务
DELETE FROM review_tasks WHERE chapterId = {chapterId};

-- 4. 删除章节
DELETE FROM chapters WHERE id = {chapterId};

-- 5. 更新小说统计
UPDATE novels 
SET chapterCount = chapterCount - 1,
    wordCount = wordCount - {chapterWordCount}
WHERE id = {novelId};

COMMIT;
```

## 7. 安全设计

### 7.1 权限控制
- 所有API端点使用 `@UseGuards(JwtAuthGuard)` 保护
- 需要管理员权限才能访问

### 7.2 数据验证
- 使用DTO进行请求/响应数据验证
- 使用 `@ApiProperty` 进行Swagger文档标注

### 7.3 删除安全
- 使用数据库事务确保数据一致性
- 级联删除关联数据防止脏数据

## 8. 性能设计

### 8.1 数据库优化
- 使用Prisma的 `include` 进行关联查询，减少N+1问题
- 分页查询使用 `skip` 和 `take`
- 建议添加索引：
  ```sql
  CREATE INDEX idx_chapters_novelId ON chapters(novelId);
  CREATE INDEX idx_review_tasks_novelId ON review_tasks(novelId);
  CREATE INDEX idx_review_tasks_chapterId ON review_tasks(chapterId);
  ```

### 8.2 前端优化
- 分页加载章节数据，避免一次性加载过多
- 独立加载评审详情和章节列表，提高页面响应速度
