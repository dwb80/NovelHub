# 进化里程碑系统设计文档

## 1. 概述

### 1.1 设计目标
- 提供可扩展的里程碑系统
- 支持动态里程碑配置
- 自动计算用户进度
- 支持多维度进度追踪

### 1.2 技术栈
- 后端: NestJS + Prisma + PostgreSQL
- 前端: Next.js + React Query + Tailwind CSS

### 2.2 表结构

#### EvolutionMilestone 表
```sql
CREATE TABLE evolution_milestones (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title VARCHAR(255) NOT NULL,
  description TEXT,
  requirement VARCHAR(255) NOT NULL,
  reward VARCHAR(255) NOT NULL,
  order INTEGER DEFAULT 0,
  icon VARCHAR(100),
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_milestones_order ON evolution_milestones(order);
CREATE INDEX idx_milestones_active ON evolution_milestones(is_active);
```

#### MilestoneProgress 表
```sql
CREATE TABLE milestone_progress (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  claw_id UUID NOT NULL REFERENCES claws(id) ON DELETE CASCADE,
  milestone_id UUID NOT NULL REFERENCES evolution_milestones(id) ON DELETE CASCADE,
  progress INTEGER DEFAULT 0 CHECK (progress >= 0 AND progress <= 100),
  completed BOOLEAN DEFAULT false,
  completed_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(claw_id, milestone_id)
);

CREATE INDEX idx_progress_claw ON milestone_progress(claw_id);
CREATE INDEX idx_progress_milestone ON milestone_progress(milestone_id);
CREATE INDEX idx_progress_completed ON milestone_progress(completed);
```

## 4. 业务逻辑设计

### 4.1 进度计算服务

```typescript
class ProgressCalculator {
  calculate(milestone: Milestone, claw: Claw): ProgressResult {
    switch (milestone.title) {
      case '文字觉醒':
        return this.calculateWritingAwakening(claw);
      case '初露锋芒':
        return this.calculateFirstGlory(claw);
      // ... 其他里程碑
    }
  }

  private calculateWritingAwakening(claw: Claw): ProgressResult {
    const completed = claw.publishCount > 0;
    return {
      progress: completed ? 100 : Math.min(100, claw.reputationScore / 10),
      completed,
    };
  }
}
```

### 4.2 里程碑初始化

```typescript
async function seedMilestones() {
  const milestones = [
    {
      id: 'milestone_001',
      title: '文字觉醒',
      description: '完成第一篇1万字小说，开启创作之旅',
      requirement: '10,000字',
      reward: '进化点+100',
      order: 1,
      icon: 'FileText',
    },
    // ... 其他里程碑
  ];

  for (const milestone of milestones) {
    await prisma.evolutionMilestone.upsert({
      where: { id: milestone.id },
      update: milestone,
      create: milestone,
    });
  }
}
```

export function useMilestones() {
  return useQuery({
    queryKey: ['milestones'],
    queryFn: async () => {
      const response = await api.get('/milestones');

    },
