**最后更新**: 2026-04-19  
**状态**: 已实现  
**对应页面**: http://localhost:3000/admin/settings

---

## 1. 设计目标

为管理员提供一个统一的系统配置界面，支持：
- 网站基础信息配置（名称、描述、功能开关）
- 通知偏好设置
- 安全策略配置

## 4. 状态管理设计

### 4.1 数据流架构

```
┌─────────────────────────────────────────────────────────────┐
│                      Server State                           │
│                   (React Query Cache)                       │
│                      admin-settings                         │
└─────────────────────┬───────────────────────────────────────┘
                      │ useQuery
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                   Component State                           │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │ siteSettings│  │notification │  │  security   │         │
│  │             │  │  Settings   │  │  Settings   │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└─────────────────────────────────────────────────────────────┘
                      │
                      │ useMutation
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                      API Layer                              │
│              GET /admin/settings                            │
│              PATCH /admin/settings                          │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 状态同步策略

```typescript
// 1. 页面加载时获取服务器数据
const { data: settingsData } = useQuery({
  queryKey: ['admin-settings'],
  queryFn: fetchSettings,
});

// 2. 使用 useEffect 同步到本地状态
useEffect(() => {
  if (settingsData?.settings) {
    setSiteSettings({
      siteName: settingsData.settings.siteName,
      // ...
    });
  }
}, [settingsData]);

// 3. 用户修改时只更新本地状态
const handleChange = (value: string) => {
  setSiteSettings(prev => ({ ...prev, siteName: value }));
};

// 4. 保存时提交到服务器
const mutation = useMutation({
  mutationFn: updateSettings,
  onSuccess: () => {
    // 刷新缓存
    queryClient.invalidateQueries(['admin-settings']);
  },
});
```

## 9. 性能优化

### 9.1 缓存策略

```typescript
// React Query 配置
const queryConfig = {
  queryKey: ['admin-settings'],
  queryFn: fetchSettings,
  staleTime: 5 * 60 * 1000, // 5分钟内数据视为新鲜
  cacheTime: 10 * 60 * 1000, // 缓存保留10分钟
};
```

### 9.2 乐观更新

```typescript
const mutation = useMutation({
  mutationFn: updateSettings,
  onMutate: async (newSettings) => {
    // 取消正在进行的重新获取
    await queryClient.cancelQueries(['admin-settings']);
    
    // 保存之前的值用于回滚
    const previousSettings = queryClient.getQueryData(['admin-settings']);
    
    // 乐观更新
    queryClient.setQueryData(['admin-settings'], newSettings);
    
    return { previousSettings };
  },
  onError: (err, newSettings, context) => {
    // 出错时回滚
    queryClient.setQueryData(['admin-settings'], context?.previousSettings);
  },
  onSettled: () => {
    // 无论成功与否都重新获取
    queryClient.invalidateQueries(['admin-settings']);
  },
});
```
