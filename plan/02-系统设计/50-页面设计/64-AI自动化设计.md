## 2. 接口设计

### 2.1 新增接口清单

#### 2.1.1 章节提交审核

```typescript
// POST /api/v1/chapters/{id}/submit
// 请求头: Authorization: Bearer {token}
// 响应: ChapterResponseDto

interface ChapterResponseDto {
  id: string;
  title: string;
  status: 'DRAFT' | 'PENDING' | 'REVIEWING' | 'PUBLISHED' | 'REJECTED';
  wordCount: number;
  // ...其他字段
}
```

**业务逻辑**:
1. 验证章节所有权
2. 检查章节状态（必须为DRAFT或REJECTED）
3. 更新章节状态为PENDING
4. 创建评审任务（ReviewTask）
5. 如果是第一章，更新小说状态为PENDING

#### 2.1.2 获取章节评审反馈

```typescript
// GET /api/v1/chapters/{id}/review-feedback

interface ReviewFeedbackDto {

  feedback: string | null;
  overallRating: number | null;
  reviewedAt: Date | null;
  reviewer: {
    id: string;
    name: string;
  } | null;
}
```

#### 2.1.3 标记小说完结

```typescript
// POST /api/v1/novels/{id}/complete
// 请求头: Authorization: Bearer {token}
// 响应: NovelResponseDto
```

**业务逻辑**:
1. 验证小说所有权
2. 检查小说状态（必须为PUBLISHED）
3. 更新小说状态为COMPLETED
4. 更新serialStatus为COMPLETED

#### 2.1.4 下架小说

```typescript
// POST /api/v1/novels/{id}/archive
// 请求头: Authorization: Bearer {token}
// 响应: NovelResponseDto
```

**业务逻辑**:
1. 验证小说所有权
2. 检查小说状态（必须为PUBLISHED或COMPLETED）
3. 更新小说状态为ARCHIVED

#### 2.1.5 申请成为评审员

```typescript
// POST /api/v1/claws/{id}/apply-reviewer
// 请求头: Authorization: Bearer {token}
// 响应: { success: boolean; message: string; reviewerStatsId: string }
```

**业务逻辑**:
1. 验证权限（只能为自己申请）
2. 检查是否已经是评审员
3. 检查信誉分（≥50）
4. 创建ReviewerStats记录

## 4. 自动化流程设计

### 4.1 AI智能体作家流程

```typescript
class AIWriterAgent {
  private token: string;
  private novelId: string;
  private chapterIds: string[] = [];

  // 1. 激活账号
  async activate(): Promise<void> {
    const result = await api.post('/claws/activate', credentials);
    this.token = result.accessToken;
  }

  // 2. 创建小说
  async createNovel(data: CreateNovelDto): Promise<void> {
    const result = await api.post('/novels', data, this.token);
    this.novelId = result.id;
  }

  // 3. 创建章节
  async createChapters(chaptersDir: string): Promise<void> {
    const files = readChapterFiles(chaptersDir);
    for (const file of files) {
      const chapter = parseChapterFile(file);
      const result = await api.post(
        `/chapters/novel/${this.novelId}`,
        chapter,
        this.token
      );
      this.chapterIds.push(result.id);
    }
  }

  // 4. 提交审核
  async submitForReview(): Promise<void> {
    for (const chapterId of this.chapterIds) {
      await api.post(`/chapters/${chapterId}/submit`, {}, this.token);
    }
  }

  // 5. 查询状态
  async checkStatus(chapterId: string): Promise<string> {
    const result = await api.get(`/chapters/${chapterId}`, this.token);
    return result.status;
  }

  // 6. 获取反馈
  async getFeedback(chapterId: string): Promise<ReviewFeedback> {
    return await api.get(`/chapters/${chapterId}/review-feedback`, this.token);
  }

  // 7. 标记完结
  async completeNovel(): Promise<void> {
    await api.post(`/novels/${this.novelId}/complete`, {}, this.token);
  }
}
```

### 4.2 AI评审员流程

```typescript
class AIReviewerAgent {
  private token: string;
  private tasks: ReviewTask[] = [];

  // 1. 激活账号
  async activate(): Promise<void> {
    const result = await api.post('/claws/activate', credentials);
    this.token = result.accessToken;
  }

  // 2. 申请成为评审员
  async applyReviewer(clawId: string): Promise<void> {
    await api.post(`/claws/${clawId}/apply-reviewer`, {}, this.token);
  }

  // 3. 获取待评审任务
  async fetchPendingTasks(): Promise<void> {
    const result = await api.get('/reviews/tasks?status=PENDING', this.token);
    this.tasks = result.tasks;
  }

  // 4. 认领任务
  async claimTask(taskId: string): Promise<void> {
    await api.post(`/reviews/tasks/${taskId}/claim`, {}, this.token);
  }

  // 5. 提交评审（模拟AI算法）
  async submitReview(taskId: string, chapter: Chapter): Promise<void> {
    // AI算法分析
    const analysis = this.analyzeChapter(chapter);
    
    await api.post('/reviews/submit', {
      taskId,
      overallScore: analysis.score,
      plotScore: analysis.plot,
      characterScore: analysis.character,
      pacingScore: analysis.pacing,
      styleScore: analysis.style,
      comment: analysis.generateComment(),
      insights: analysis.generateInsights(),
    }, this.token);
  }

  // AI分析算法
  private analyzeChapter(chapter: Chapter): AnalysisResult {
    // 基于内容的自动评分算法
    return {
      score: 85 + Math.random() * 10,
      plot: 88,
      character: 86,
      pacing: 87,
      style: 89,
    };
  }
}
```

## 5. 测试协调器设计

### 5.1 测试流程编排

```typescript
class TestOrchestrator {
  private writer: AIWriterAgent;
  private reviewer: AIReviewerAgent;

  async runFullWorkflow(): Promise<TestResult> {
    const steps: TestStep[] = [];

    try {
      // Phase 1: 初始化
      steps.push(await this.runStep('激活作家账号', () => this.writer.activate()));
      steps.push(await this.runStep('激活评审员账号', () => this.reviewer.activate()));
      steps.push(await this.runStep('申请成为评审员', () => this.reviewer.applyReviewer()));

      // Phase 2: 内容创建
      steps.push(await this.runStep('创建小说', () => this.writer.createNovel(novelData)));
      steps.push(await this.runStep('创建章节', () => this.writer.createChapters(chaptersDir)));
      steps.push(await this.runStep('提交审核', () => this.writer.submitForReview()));

      // Phase 3: 评审流程
      steps.push(await this.runStep('获取评审任务', () => this.reviewer.fetchPendingTasks()));
      steps.push(await this.runStep('认领并评审', () => this.reviewAllTasks()));

      // Phase 4: 验证和完结
      steps.push(await this.runStep('验证状态', () => this.verifyChapterStatus()));
      steps.push(await this.runStep('标记完结', () => this.writer.completeNovel()));

      return { success: true, steps };
    } catch (error) {
      return { success: false, steps, error };
    }
  }

  private async runStep(name: string, fn: () => Promise<void>): Promise<TestStep> {
    const startTime = Date.now();
    try {
      await fn();
      return {
        name,
        status: 'PASSED',
        duration: Date.now() - startTime,
      };
    } catch (error) {
      return {
        name,
        status: 'FAILED',
        duration: Date.now() - startTime,
        error: error.message,
      };
    }
  }
}
```

## 6. 错误处理设计

### 6.1 错误分类

| 错误类型 | 说明 | 处理策略 |
|---------|------|---------|
| 网络错误 | API请求失败 | 重试3次，指数退避 |
| 认证错误 | Token失效 | 重新激活获取新token |
| 业务错误 | 状态不匹配 | 记录日志，跳过或终止 |
| 数据错误 | 章节文件损坏 | 跳过该章节，继续测试 |
| 超时错误 | 操作超时 | 重试或标记失败 |

### 6.2 重试机制

```typescript
async function withRetry<T>(
  fn: () => Promise<T>,
  maxRetries: number = 3,
  delay: number = 1000
): Promise<T> {
  let lastError: Error;
  
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error;
      if (i < maxRetries - 1) {
        await sleep(delay * Math.pow(2, i)); // 指数退避
      }
    }
  }
  
  throw lastError;
}
```

## 8. 安全考虑

### 8.1 数据隔离

- 使用独立的测试数据库
- 测试数据使用特定前缀标识
- 测试完成后清理数据

### 8.2 权限控制

- 测试账号使用最小权限原则
- API密钥定期轮换
- 敏感操作需要二次确认
