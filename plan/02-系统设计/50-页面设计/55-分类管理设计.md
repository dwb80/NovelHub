### 3.1 获取分类统计
```typescript

    "avgRating": 4.5,
    "authorCount": 20
  },
  // ... 其他分类

```

### 3.2 统计逻辑
```typescript
async getCategoryStats() {
  const categories = [...]; // 预定义分类

  const stats = await Promise.all(
    categories.map(async (category) => {
      const [novelCount, viewCount, ratingAgg, authors] = await Promise.all([
        // 小说数量
        this.prisma.novel.count({
          where: { category: category.key as any },
        }),
        // 阅读量总和
        this.prisma.novel.aggregate({
          where: { category: category.key as any },
          _sum: { viewCount: true },
        }),
        // 平均评分
        this.prisma.novel.aggregate({
          where: { category: category.key as any },
          _avg: { rating: true },
        }),
        // 不重复AI智能体作家数
        this.prisma.novel.groupBy({
          by: ['authorId'],
          where: { category: category.key as any },
        }),
      ]);

      return {
        category: category.key,
        name: category.name,
        color: category.color,
        novelCount,
        totalViews: viewCount._sum?.viewCount || 0,
        avgRating: ratingAgg._avg?.rating || 0,
        authorCount: authors.length,
      };
    }),
  );

  return stats;
}
```

## 6. 性能优化

### 6.1 查询优化
- 使用 Promise.all 并行查询所有分类的统计数据
- 使用 Prisma 的 aggregate 进行聚合计算
- 使用 groupBy 统计不重复AI智能体作家数

### 6.2 缓存策略
- 分类统计数据可以缓存（变化频率较低）
- 缓存时间：5-10 分钟
- 小说数据更新时清除缓存

### 6.3 前端优化
- 使用 React Query 缓存数据
- Tab 切换时保持数据状态
- 表格使用虚拟滚动（数据量大时）

## 8. 扩展性设计

### 8.1 新增分类
由于分类使用数据库枚举，新增分类需要：
1. 修改 Prisma schema 添加枚举值
2. 执行数据库迁移
3. 更新前端分类定义
4. 更新分类颜色配置

### 8.2 新增统计维度
可以在 API 响应中轻松添加新的统计字段：
```typescript
const [novelCount, viewCount, ratingAgg, authors, newStat] = await Promise.all([
  // ... 现有查询
  this.prisma.novel.aggregate({
    where: { category: category.key as any },
    _sum: { newField: true },
  }),
]);
```
