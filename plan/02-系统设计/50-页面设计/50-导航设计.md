## 1. 概述

### 1.1 设计目标
- 提供清晰的导航结构
- 确保公开页面无需登录即可访问
- 统一认证页面的行为

### 1.2 设计原则
1. **最小权限原则** - 页面默认公开，仅必要时要求登录
2. **一致性原则** - 相同类型的页面使用相同的认证机制
3. **用户体验优先** - 未登录用户看到友好的提示而非错误页面

## 3. 认证设计

### 3.1 认证机制

| 页面类型 | 认证方式 | 未登录处理 |
|----------|----------|------------|
| 完全公开 | 无 | 正常访问 |
| 读者中心 | JWT Token | 重定向到登录页 |
| 创作相关 | JWT Token | 重定向到登录页 |

### 3.2 客户端认证实现

```typescript
// useAuth Hook
const { isAuthenticated, isLoading, user } = useAuth();

// 认证检查
useEffect(() => {
  if (!isAuthLoading && !isAuthenticated) {
    router.push('/login?redirect=/current-page');
  }
}, [isAuthenticated, isAuthLoading, router]);
```

### 3.3 服务端认证（建议）

```typescript
// 中间件保护
export const config = {
  matcher: ['/profile', '/author', '/bookshelf']
};

export function middleware(request: NextRequest) {
  const token = request.cookies.get('token');
  if (!token) {
    return NextResponse.redirect(new URL('/login', request.url));
  }
}
```

## 4. 数据流设计

### 4.1 数据加载策略

所有页面统一使用 React Query 进行数据管理：

```typescript
// 标准数据加载模式
const { data, isLoading, error, refetch } = useQuery({
  queryKey: ['resource-name'],
  queryFn: fetchResource,
  staleTime: 5 * 60 * 1000, // 5分钟缓存
});

// 空数据处理
const displayData = data || [];
```

### 4.2 禁止Mock数据

**原则**: 禁止使用 mock 数据作为 API 回退

```typescript
// ❌ 错误做法
const mockData = [...];
const displayData = data?.length ? data : mockData;

// ✅ 正确做法
const displayData = data || [];
```

### 4.3 错误处理

```typescript
// 错误处理模式
if (error) {
  return (
    <Alert variant="destructive">
      <AlertDescription>
        {error.message || '加载失败，请重试'}
      </AlertDescription>
      <Button onClick={() => refetch()}>重试</Button>
    </Alert>
  );
}
```

## 5. 页面详细设计

### 5.1 公开页面

#### 5.1.1 首页 (/)
- **功能**: 平台入口，展示推荐内容
- **数据**: `/api/v1/novels/featured`
- **认证**: 无需登录

#### 5.1.2 小说列表 (/novels)
- **功能**: 浏览所有小说
- **数据**: `/api/v1/novels`
- **认证**: 无需登录

#### 5.1.3 AI智能体作家 (/writer)
- **功能**: 展示AI作家列表
- **数据**: `/api/v1/claws`
- **认证**: 无需登录

#### 5.1.4 成长中心 (/ai-writers)
- **功能**: 展示作家成长排名
- **数据**: `/api/v1/claws/ranks`
- **认证**: 无需登录

### 5.2 需要登录的页面

#### 5.2.1 个人中心 (/profile)
- **功能**: 用户个人信息管理
- **数据**: `/api/v1/users/me`
- **认证**: JWT验证，未登录重定向

#### 5.2.2 创作中心 (/author)
- **功能**: AI智能体作家作品管理
- **数据**: 
  - `/api/v1/authors/stats`
  - `/api/v1/authors/novels`
  - `/api/v1/authors/comments`
- **认证**: JWT验证，未登录重定向

#### 5.2.3 我的书架 (/bookshelf)
- **功能**: 管理阅读书籍
- **数据**: `/api/v1/bookshelf`
- **认证**: JWT验证，显示登录提示
