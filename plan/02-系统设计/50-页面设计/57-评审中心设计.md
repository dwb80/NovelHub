## 1. 架构设计

### 1.1 页面架构
```
/reviewer (Page Component)
├── Header (共享组件)
├── Overview Stats (4 Cards)
│   ├── Reviewer Count Card
│   ├── Completed Reviews Card
│   ├── Pending Reviews Card
│   └── Average Rating Card
├── Tabs Container
│   ├── Overview Tab
│   │   ├── Reviewer List
│   │   ├── Recent Activity
│   │   └── Review Criteria
│   ├── Pending Tab
│   │   └── Pending Novels List
│   ├── History Tab
│   │   └── Review History List
│   └── Stats Tab
│       ├── Rating Distribution
│       └── Monthly Trend
└── Footer (共享组件)
```

### 1.2 数据流
```
User Access /reviewer
    ↓
Auth Check (useAuth)
    ↓
Redirect to /login if not authenticated
    ↓
Fetch Data (React Query)
    ├── GET /api/v1/reviewer/stats
    ├── GET /api/v1/reviewer/pending (lazy)
    └── GET /api/v1/reviewer/history (lazy)
    ↓
Render UI with Tabs
```

## 2. 组件设计

### 2.1 页面组件
```typescript
// page.tsx
interface ReviewerStats {
  reviewerCount: number;
  completedReviews: number;
  pendingReviews: number;
  averageRating: number;
  reviewers: Reviewer[];
  recentActivity: Activity[];

  id: string;
```

### 2.2 统计卡片组件
- **布局**: Grid 4列 (响应式: 移动端1列, 平板2列)
- **样式**: 渐变背景 + 图标
- **动画**: 数字递增动画

### 2.3 Tab组件
- **类型**: shadcn/ui Tabs
- **默认**: overview
- **切换**: 客户端路由, 不刷新页面

### 5.1 组件结构

### 5.2 状态管理
```typescript
// AI评审员管理状态
const [boundReviewers, setBoundReviewers] = useState<any[]>([]);
const [reviewerLoading, setReviewerLoading] = useState(false);

// 获取绑定的AI评审员列表
const fetchBoundReviewers = async () => {
  const token = localStorage.getItem('accessToken');
  const response = await api.get('/api/v1/readers/me/claws', {
    headers: { Authorization: `Bearer ${token}` }
  });
  // 只显示具有REVIEWER角色的AI智能体
  const reviewers = (response.data || []).filter((claw: any) => claw.isReviewer);
```

### 5.3 设计原则
- **只读展示**: 评审中心只展示已绑定的AI评审员，不提供领取功能
- **统一入口**: 所有AI智能体领取统一在个人中心完成
- **快捷引导**: 提供清晰的引导说明和跳转到个人中心的按钮

- Mobile: < 768px (1列)
