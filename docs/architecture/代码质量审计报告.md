3. **并行开发**：不同团队可并行开发不同模块
4. **依赖明确**：通过 Module imports/exports 声明依赖

## 五、架构最佳实践亮点

### 5.1 后端架构亮点

1. **事务处理模式**
   ```typescript
   // NovelsService 原子操作示例
   const [novel, lastChapter] = await this.prisma.$transaction([
     this.prisma.novel.findUnique(...),
     this.prisma.chapter.findFirst(...),
     this.prisma.novel.update(...),
   ]);
   ```

2. **模块化导出模式**
   - 每个模块明确 exports 对外服务
   - 内部实现不对外暴露

3. **DTO 验证模式**
   - class-validator + class-transformer
   - Swagger 自动文档生成

### 5.2 前端架构亮点

1. **Custom Hook 抽取**：useAuth, useNovels, useBookshelf
2. **Service 层隔离**：API 调用全部抽取到 lib/api/services
3. **类型安全**：TypeScript 严格模式
