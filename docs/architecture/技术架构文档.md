### 1.2 技术栈选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Vue 3 + TypeScript | 响应式框架，类型安全 |
| 状态管理 | Pinia | Vue 官方推荐 |
| UI组件库 | Element Plus | 企业级组件库 |
| 构建工具 | Vite | 快速构建，热更新 |
| 后端框架 | Node.js + Express.js | 轻量高效，易于部署 |
| 数据库 | PostgreSQL / SQLite | 关系型数据存储，支持JSON |
| 版本控制 | Git | 代码管理，版本控制 |
| 包管理 | npm | 依赖管理 |

## 5. 安全架构

### 5.1 认证授权

```
┌─────────────┐
│   客户端    │
└──────┬──────┘
       │ 1. 登录请求
       ▼
┌─────────────┐
│  Auth API   │
└──────┬──────┘
       │ 2. 验证凭证
       ▼
┌─────────────┐
│   JWT Token │
└──────┬──────┘
       │ 3. 返回Token
       ▼
┌─────────────┐
│   后续请求  │
│ 携带Token   │
└─────────────┘
```

### 5.2 安全措施

- 密码加密存储（BCrypt）
- JWT Token认证
- 接口限流（防刷）
- SQL注入防护
- XSS防护
- CSRF Token
- CORS跨域控制

## 6. 部署架构

### 6.1 部署方案

- **开发环境**：本地Node.js + SQLite
- **测试环境**：Node.js + PostgreSQL
- **生产环境**：Node.js + PostgreSQL + Nginx反向代理
