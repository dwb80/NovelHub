# NovelHub 组件规范文档

## 概述

本文档定义了 NovelHub 前端项目的组件开发规范，包括设计系统、组件命名、结构、样式和文档要求。

---

## 1. 设计系统

### 1.1 设计原则

#### 一致性原则
- 所有页面使用统一的组件样式
- 保持视觉语言的一致性
- 交互行为统一

#### 可访问性原则
- 符合 WCAG 2.1 AA 标准
- 支持键盘导航
- 支持屏幕阅读器

#### 响应式原则
- 移动端优先设计
- 支持多种屏幕尺寸
- 适配不同设备

## 2. 组件开发规范

### 2.1 组件命名规范

#### 文件命名
- 使用 PascalCase（大驼峰命名法）
- 组件名应该具有描述性
- 示例：`NovelCard.vue`, `ReaderToolbar.vue`

#### 组件名前缀
| 前缀 | 用途 | 示例 |
|------|------|------|
| Base | 基础组件 | `BaseButton.vue`, `BaseInput.vue` |
| App | 应用级组件 | `AppHeader.vue`, `AppFooter.vue` |
| 无 | 业务组件 | `NovelCard.vue`, `ChapterList.vue` |

### 2.2 组件结构规范

#### 单文件组件结构

```vue
<template>
  <!-- 模板代码 -->
</template>

<script setup lang="ts">
// 脚本代码
</script>

<style scoped lang="scss">
/* 样式代码 */
</style>
```

#### 组件顺序

1. **template**: 模板部分
2. **script**: 脚本部分
3. **style**: 样式部分

#### Props 定义规范

```typescript
interface Props {
  // 基础类型
  title: string
  count?: number
  
  // 带默认值
  size?: 'small' | 'medium' | 'large'
  disabled?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  size: 'medium',
  disabled: false
})
```

#### Emits 定义规范

```typescript
const emit = defineEmits<{
  click: [event: MouseEvent]
  change: [value: string]
  'update:modelValue': [value: string]
}>()
```

### 2.3 组件文档规范

#### 组件注释

```vue
<script setup lang="ts">
/**
 * NovelCard 组件
 * 
 * 用于展示小说基本信息的卡片组件
 * 
 * @example
 * <NovelCard
 *   :title="'小说标题'"
 *   :author="'作者名'"
 *   :cover="'封面URL'"
 *   @click="handleClick"
 * />
 */

interface Props {
  /** 小说标题 */
  title: string
  /** 作者名称 */
  author: string
  /** 封面图片URL */
  cover?: string
  /** 评分 */
  rating?: number
}

defineProps<Props>()
</script>
```

### 2.4 组件示例

#### 基础按钮组件

```vue
<template>
  <button
    :class="buttonClasses"
    :disabled="disabled"
    @click="handleClick"
  >
    <slot />
  </button>
</template>

<script setup lang="ts">
import { computed } from 'vue'

interface Props {
  variant?: 'primary' | 'secondary' | 'ghost'
  size?: 'small' | 'medium' | 'large'
  disabled?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  variant: 'primary',
  size: 'medium',
  disabled: false
})

const emit = defineEmits<{
  click: [event: MouseEvent]
}>()

const buttonClasses = computed(() => [
  'btn',
  `btn--${props.variant}`,
  `btn--${props.size}`,
  { 'btn--disabled': props.disabled }
])

function handleClick(event: MouseEvent) {
  if (!props.disabled) {
    emit('click', event)
  }
}
</script>

<style scoped lang="scss">
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  border: none;
  border-radius: var(--radius-md);
  cursor: pointer;
  transition: all 200ms ease-out;
  
  &--primary {
    background: var(--color-primary);
    color: white;
    
    &:hover:not(&--disabled) {
      background: var(--color-primary-hover);
    }
  }
  
  &--medium {
    padding: var(--space-2) var(--space-4);
    font-size: var(--text-body);
  }
  
  &--disabled {
    opacity: 0.5;
    cursor: not-allowed;
  }
}
</style>
```

## 4. 组件测试规范

### 4.1 测试文件命名
- 与组件同名，后缀为 `.spec.ts` 或 `.test.ts`
- 示例：`BaseButton.spec.ts`

### 4.2 测试示例

```typescript
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import BaseButton from './BaseButton.vue'

describe('BaseButton', () => {
  it('renders correctly', () => {
    const wrapper = mount(BaseButton, {
      slots: {
        default: 'Click me'
      }
    })
    expect(wrapper.text()).toBe('Click me')
  })
  
  it('emits click event', async () => {
    const wrapper = mount(BaseButton)
    await wrapper.trigger('click')
    expect(wrapper.emitted('click')).toBeTruthy()
  })
  
  it('is disabled when disabled prop is true', () => {
    const wrapper = mount(BaseButton, {
      props: { disabled: true }
    })
    expect(wrapper.find('button').attributes('disabled')).toBeDefined()
  })
})
```
