## 快速开始

### 注册账号

1. 打开 NovelHub 网站
2. 点击右上角"注册"按钮
3. 选择注册方式：
   - 邮箱注册：输入邮箱地址、设置密码
   - 手机号注册：输入手机号、获取验证码
4. 阅读并同意用户协议
5. 点击"注册"完成账号创建

### 登录账号

1. 点击右上角"登录"按钮
2. 输入账号（邮箱/手机号）和密码
3. 点击"登录"

> 提示：勾选"记住我"可在下次访问时自动登录

## 账号管理

### 修改个人信息

1. 点击右上角头像进入"个人中心"
2. 选择"账号设置"
3. 修改以下信息：
   - 昵称
   - 头像
   - 性别
   - 生日
   - 个性签名
4. 点击"保存"

### 修改密码

1. 进入"个人中心" → "账号设置"
2. 点击"修改密码"
3. 输入原密码和新密码
4. 点击"确认修改"

### 绑定第三方账号

1. 进入"个人中心" → "账号安全"
2. 选择要绑定的平台（微信/QQ/微博）
3. 按提示完成授权

## 发现小说

### 浏览分类

1. 点击导航栏"分类"
2. 选择感兴趣的分类（玄幻、都市、言情等）
3. 使用筛选条件缩小范围：
   - 状态：连载/完结
   - 字数范围
   - 更新时间
   - 评分

### 使用搜索

1. 点击顶部搜索框
2. 输入关键词（书名/作者）
3. 查看搜索建议或按回车搜索
4. 在结果页可使用高级筛选

### 查看排行榜

1. 点击导航栏"排行"
2. 选择榜单类型：
   - 点击榜
   - 收藏榜
   - 推荐榜
   - 新书榜
   - 完结榜
3. 切换时间维度：日榜/周榜/月榜/总榜

## 阅读小说

### 开始阅读

1. 在小说详情页点击"开始阅读"或选择具体章节
2. 阅读器界面说明：
   - 点击屏幕中央：显示/隐藏工具栏
   - 左右滑动：翻页
   - 点击左侧：上一页
   - 点击右侧：下一页

### 阅读设置

点击工具栏"设置"按钮：

**字体设置**
- 字体大小：12px - 24px（6档）
- 行间距：紧凑/适中/宽松

**主题设置**
- 日间模式：白底黑字
- 夜间模式：黑底灰字
- 护眼模式：米黄底
- 纸质模式：仿真纸纹

**翻页模式**
- 滚动模式：上下滑动
- 翻页模式：左右翻页

### 使用目录

1. 点击工具栏"目录"按钮
2. 查看完整章节列表
3. 点击章节标题跳转
4. 支持正序/倒序切换

### 添加书签

1. 点击工具栏"书签"按钮
2. 点击"添加书签"
3. 输入书签备注（可选）
4. 在目录面板可查看所有书签

## 书架管理

### 添加书籍到书架

**方式一**：在小说详情页点击"加入书架"

**方式二**：阅读时自动提示添加

### 管理书架

1. 点击导航栏"书架"
2. 查看已添加的书籍
3. 支持以下操作：
   - 点击书籍继续阅读
   - 长按/右键删除书籍
   - 拖拽排序
   - 批量管理

### 分类管理

1. 在书架页面点击"分类管理"
2. 创建新分类
3. 将书籍移动到分类
4. 支持分类重命名和删除

### 更新提醒

- 书架中的书籍有更新时，会显示"更新"标签
- 可在设置中开启推送通知

## 个人中心

### 阅读历史

1. 进入"个人中心"
2. 查看"阅读历史"
3. 可清空历史记录

### 我的评论

1. 进入"个人中心"
2. 查看"我的评论"
3. 管理已发表的评论

### 消息通知

1. 点击顶部消息图标
2. 查看系统通知、评论回复等
3. 可设置免打扰模式

## 常见问题

### Q: 如何找回密码？

A: 在登录页面点击"忘记密码"，按提示通过邮箱或手机号重置密码。

### Q: 阅读记录会同步吗？

A: 是的，登录状态下阅读记录会自动同步到云端，换设备登录后可继续阅读。

### Q: 如何下载小说离线阅读？

A: 目前暂不支持下载功能，请在线阅读。

### Q: 书架有容量限制吗？

A: 书架最多可添加500本书籍。

### Q: 如何联系客服？

A: 进入"个人中心" → "帮助与反馈" → "联系客服"
