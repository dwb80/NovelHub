## 3. 组件详细说明

### 3.1 搜索栏

**需求ID**: SEARCH-BAR-001

**功能描述**: 搜索输入和提交功能

**结构**:
```
┌─────────────────────────────────────────────────────────────┐
│ 🔍  ┌────────────────────────────────────────┐  [×] [搜索]  │
│     │ 搜索小说、作者、标签...                 │             │
│     └────────────────────────────────────────┘             │
└─────────────────────────────────────────────────────────────┘
```

**样式**:
- 高度: 56px（桌面）/ 48px（移动）
- 背景: var(--color-bg-elevated)
- 边框: 2px solid var(--color-border)
- 圆角: var(--radius-xl)（28px）
- 聚焦边框: var(--color-primary)
- 阴影: 0 0 0 4px var(--color-primary-light)（聚焦时）

**搜索图标**:
- 位置: 左侧内边距16px
- 大小: 20px
- 颜色: var(--color-text-muted)

**清除按钮**:
- 显示条件: 输入框有内容时
- 图标: ×
- 点击: 清空输入框，聚焦输入框

**搜索按钮**:
- 文字: "搜索"
- 样式: 主色背景，白色文字
- 圆角: var(--radius-lg)
- 点击: 执行搜索，跳转到结果页

**输入框**:
- Placeholder: "搜索小说、作者、标签..."
- 最大长度: 50字符
- 自动完成: off
- 自动聚焦: 页面加载后自动聚焦

**交互**:
| 操作 | 响应 |
|------|------|
| 输入内容 | 显示搜索建议下拉 |
| 按Enter | 执行搜索 |
| 按Esc | 关闭建议下拉，清空输入 |
| 点击清除 | 清空输入，保持聚焦 |
| 点击搜索 | 执行搜索 |

**优先级**: P0

**验收标准**:
- AC1: 输入时实时显示搜索建议
- AC2: 按Enter正确执行搜索
- AC3: 清除按钮正确清空输入
- AC4: 搜索按钮正确跳转

**需求ID**: SEARCH-HISTORY-001

**功能描述**: 显示和管理搜索历史

**显示条件**: 输入框为空且聚焦，或页面加载完成

**存储规则**:
- 存储位置: localStorage
- 键名: `novelhub_search_history`

## 4. 搜索逻辑

### 4.1 搜索执行流程

```
用户触发搜索
  ↓
校验关键词
  ├─ 为空 → 提示"请输入搜索关键词"
  ├─ 超长 → 截断至50字符
  ↓
保存搜索历史
  ↓
跳转搜索结果页
  ↓
URL: /search/results?q={关键词}
```

### 4.2 关键词处理

**预处理规则**:
| 处理项 | 规则 |
|--------|------|
| 去除首尾空格 | `trim()` |
| 合并连续空格 | 替换为单个空格 |
| 去除特殊字符 | 只保留中文、英文、数字、空格 |
| 长度限制 | 最多50字符 |

**敏感词过滤**:
- 检查关键词是否包含敏感词
- 包含敏感词时提示"搜索词包含敏感内容"
- 记录敏感词搜索日志

## 5. 数据需求

### 5.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/search/suggest | GET | 获取搜索建议 |
| /api/search/hot | GET | 获取热门搜索 |

### 5.2 请求参数

```typescript
// 搜索建议
interface SearchSuggestParams {
  keyword: string;
  limit?: number;  // 默认10
}

// 热门搜索
interface HotSearchParams {
  limit?: number;  // 默认10
  days?: number;   // 统计天数，默认7
}
```

### 5.3 响应结构

```typescript
// 搜索建议响应
interface SearchSuggestResponse {
  history: string[];      // 历史搜索
  suggestions: {          // 智能补全
    type: 'novel' | 'author' | 'tag';
    text: string;
    highlight: string;    // 高亮部分
  }[];
  hot: string[];          // 热门搜索
}

// 热门搜索响应
interface HotSearchResponse {
  list: {
    keyword: string;
    rank: number;
    heat: number;         // 热度值
  }[];
}
```
