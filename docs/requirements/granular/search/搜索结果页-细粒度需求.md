## 3. 搜索区域

### 3.1 搜索框

#### 需求ID: RES-SEARCH-001

**需求名称**: 搜索结果页搜索框

**功能描述**: 提供搜索输入和搜索按钮

**搜索框结构**:
| 元素 | 说明 |
|------|------|
| 搜索图标 | 左侧搜索图标 |
| 输入框 | 搜索关键词输入 |
| 清除按钮 | 清除输入内容 |
| 搜索按钮 | 执行搜索 |

**输入规则**:
| 属性 | 规则 |
|------|------|
| 占位符 | "搜索书名、作者或关键词" |
| 自动完成 | off |
| 最大长度 | 100字符 |

**搜索建议**:
- 输入时显示下拉建议列表
- 建议项包括: 书名、作者、标签

**样式**:
- 最大宽度: 720px
- 背景: var(--color-bg-elevated)
- 边框: 2px solid var(--color-border)
- 聚焦: 主色边框+阴影

**优先级**: P0

**验收标准**:
- [ ] AC1: 搜索框正确显示
- [ ] AC2: 清除按钮正常
- [ ] AC3: 搜索建议正常显示
- [ ] AC4: 搜索功能正常

**来源**: [search.html L28-100](file:///d:/trae/xiaoshuo/html/pages/discover/search.html#L28-L100)

## 4. 搜索结果区

### 4.1 结果头部

#### 需求ID: RES-HEADER-001

**需求名称**: 搜索结果头部

**功能描述**: 显示搜索结果统计和筛选

**头部内容**:
| 元素 | 说明 |
|------|------|
| 结果统计 | "找到 128 个结果" |
| 搜索关键词 | "搜索：'玄幻'" |
| 排序选项 | 相关度/热度/更新时间/评分 |
| 视图切换 | 网格/列表视图 |

**排序选项**:
| 选项 | 说明 |
|------|------|
| 综合排序 | 默认排序 |
| 热度优先 | 按阅读量排序 |
| 更新时间 | 按更新时间排序 |
| 评分最高 | 按评分排序 |

**优先级**: P0

---

### 4.2 搜索结果卡片

#### 需求ID: RES-CARD-001

**需求名称**: 搜索结果卡片

**功能描述**: 展示搜索结果小说

**卡片结构**:
| 元素 | 说明 |
|------|------|
| 封面 | 小说封面图 |
| 标题 | 小说名称（关键词高亮） |
| 作者 | 作者名称（关键词高亮） |
| 简介 | 简介摘要（关键词高亮） |
| 标签 | 分类标签 |
| 数据 | 阅读量/评分/字数/章节数 |
| 操作 | 加入书架/立即阅读 |

**关键词高亮**:
- 匹配的关键词用主色背景高亮
- 支持多关键词匹配

**样式**:
- 网格视图: 5列（桌面）、4列（平板）、2列（手机）
- 列表视图: 单行显示，封面在左

**优先级**: P0

**验收标准**:
- [ ] AC1: 结果卡片正确显示
- [ ] AC2: 关键词高亮正常
- [ ] AC3: 网格/列表视图切换正常
- [ ] AC4: 操作按钮正常

### 4.3 无结果状态

#### 需求ID: RES-EMPTY-001

**需求名称**: 无搜索结果

**功能描述**: 当搜索无结果时显示提示

- 标题: "未找到相关结果"
- 描述: "换个关键词试试，或浏览热门小说"

**样式**:
- 图标: 4rem, opacity 0.3
- 文字居中

**优先级**: P1
