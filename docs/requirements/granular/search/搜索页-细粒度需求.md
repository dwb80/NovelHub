## 2. 搜索栏

### 2.1 搜索输入框

#### 需求ID: SEARCH-INPUT-001

**需求名称**: 搜索输入框

**功能描述**: 用户输入搜索关键词

**输入规则**:
| 属性 | 规则 |
|------|------|
| 类型 | text |
| 必填 | 是 |
| 最小长度 | 1字符 |
| 最大长度 | 50字符 |
| 占位符 | "搜索小说、作者、标签..." |
| 自动完成 | off |

**输入行为**:
| 行为 | 响应 |
|------|------|
| 输入中 | 显示搜索建议下拉 |
| 按Enter | 执行搜索 |
| 清空按钮 | 清空输入框 |
| 粘贴内容 | 自动触发搜索建议 |

**样式**:
- 高度: 48px
- 圆角: var(--radius-full)
- 背景: var(--color-bg-secondary)
- 聚焦: 边框变primary色

**优先级**: P0

**来源**: [search.html L24-32](file:///d:/trae/xiaoshuo/html/pages/discover/search.html#L24-L32)

### 2.2 搜索按钮

#### 需求ID: SEARCH-BTN-001

**需求名称**: 搜索提交按钮

**功能描述**: 点击执行搜索

### 2.3 搜索建议下拉

#### 需求ID: SEARCH-SUGGEST-001

**需求名称**: 搜索建议

**功能描述**: 根据输入显示搜索建议

**建议来源**:
| 类型 | 来源 |
|------|------|
| 历史搜索 | localStorage存储的搜索历史 |
| 热门搜索 | 系统热门搜索词 |
| 智能补全 | 匹配的小说名、作者名 |

**建议项结构**:
| 元素 | 说明 |
|------|------|
| 图标 | 时钟（历史）/ 火焰（热门）/ 搜索（补全） |
| 文本 | 建议词 |
| 删除按钮 | 历史项可删除 |

**交互**:
- 点击建议项: 执行搜索
- 删除历史: 从localStorage移除
- 清空历史: 清空所有历史记录
- 键盘导航: 上下键选择，Enter确认

**最大显示**: 10条建议

**优先级**: P1

## 3. 搜索历史

### 需求ID: SEARCH-HISTORY-001

**需求名称**: 搜索历史展示

**功能描述**: 显示用户最近的搜索记录

**存储规则**:
- 存储位置: localStorage
- 键名: novelhub_search_history
- 最大数量: 10条
- 去重: 相同搜索词只保留最新

**历史项结构**:
| 元素 | 说明 |
|------|------|
| 搜索词 | 历史搜索关键词 |
| 时间 | 相对时间（如"2小时前"） |
| 删除按钮 | 删除单条记录 |

**清空历史**:
- 显示"清空历史"按钮
- 点击后确认对话框
- 确认后清空所有历史

**优先级**: P1

**来源**: [search.html L35-39](file:///d:/trae/xiaoshuo/html/pages/discover/search.html#L35-L39)

## 7. 搜索逻辑

### 7.1 搜索匹配规则

#### 需求ID: SEARCH-LOGIC-001

**需求名称**: 搜索匹配算法

**功能描述**: 定义搜索匹配逻辑

**匹配字段**（按优先级排序）:
| 优先级 | 字段 | 权重 |
|--------|------|------|
| 1 | 小说名 | 10 |
| 2 | 作者名 | 8 |
| 3 | 标签 | 5 |
| 4 | 简介 | 3 |

**匹配规则**:
- 完全匹配 > 前缀匹配 > 包含匹配
- 多关键词支持（空格分隔）
- 忽略大小写
- 支持拼音搜索（可选）

**排序规则**:
| 排序方式 | 规则 |
|----------|------|
| 相关度 | 按匹配权重降序 |
| 最新 | 按发布时间降序 |
| 最热 | 按阅读量降序 |
| 评分 | 按评分降序 |

**优先级**: P0

## 8. URL参数

### 需求ID: SEARCH-URL-001

**需求名称**: 搜索URL参数

**功能描述**: 支持URL参数传递搜索条件

**参数定义**:
| 参数 | 说明 | 示例 |
|------|------|------|
| q | 搜索关键词 | ?q=玄幻 |
| sort | 排序方式 | ?sort=hot |
| status | 状态筛选 | ?status=completed |
| category | 分类筛选 | ?category=玄幻 |
| page | 页码 | ?page=2 |

**优先级**: P1

## 9. 性能优化

### 需求ID: SEARCH-PERF-001

**需求名称**: 搜索性能优化

**功能描述**: 优化搜索响应速度

**优化措施**:
| 措施 | 说明 |
|------|------|
| 防抖 | 输入停止300ms后触发搜索建议 |
| 节流 | 滚动加载节流100ms |
| 缓存 | 搜索结果缓存5分钟 |
| 预加载 | 预加载下一页结果 |

**优先级**: P1
