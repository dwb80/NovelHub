## 2. 功能模块细粒度需求

### 2.1 统计卡片 (SEN-STAT-001)

**需求ID**: SEN-STAT-001  
**需求名称**: 敏感词统计卡片  
**功能描述**: 展示敏感词相关统计数据  
**触发条件**: 页面加载完成  

**正常流程**:
1. 页面加载时获取统计数据
2. 显示3个统计项：敏感词总数、今日拦截、待审核

**输入输出规则**:
- 输出：
  - total_count | number | 敏感词总数
  - today_blocked | number | 今日拦截数
  - pending_review | number | 待审核数

**权限控制**: 仅管理员可见  
**优先级**: P2

**验收标准**:
- [ ] AC1: 显示3个统计卡片
- [ ] AC2: 数值正确显示

**来源**: [admin/sensitive.html L87-L91](../../html/pages/admin/sensitive.html#L87-L91)

### 2.2 批量添加敏感词 (SEN-ADD-001)

**需求ID**: SEN-ADD-001  
**需求名称**: 批量添加敏感词  
**功能描述**: 支持批量添加敏感词，每行一个  
**触发条件**: 用户输入敏感词并点击添加按钮  

**操作步骤**:
1. 在文本域输入敏感词（每行一个）
2. 点击"添加敏感词"按钮
3. 或点击"清空"按钮清空输入

**正常流程**:
1. 在文本域输入敏感词，每行一个
2. 点击"添加敏感词"按钮
3. 系统解析每行内容，去除空行
4. 添加到敏感词库
5. 显示成功提示，刷新敏感词列表

**异常流程/边界情况**:
- 输入为空：提示"请输入敏感词"
- 重复添加：自动去重

**输入输出规则**:
- 输入：words | string | 敏感词列表 | 每行一个

**业务规则**:
- 每行一个敏感词
- 自动去除首尾空格
- 空行自动忽略

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 文本域支持多行输入
- [ ] AC2: 添加按钮正常工作
- [ ] AC3: 清空按钮正常工作
- [ ] AC4: 添加后显示成功提示

**来源**: [admin/sensitive.html L94-L108](../../html/pages/admin/sensitive.html#L94-L108)

### 2.3 敏感词标签列表 (SEN-LIST-001)

**需求ID**: SEN-LIST-001  
**需求名称**: 敏感词标签列表  
**功能描述**: 展示当前敏感词列表，支持删除和导出  
**触发条件**: 页面加载或添加敏感词后  

**操作步骤**:
1. 查看敏感词列表
2. 点击标签上的删除按钮删除单个敏感词
3. 点击"导出"按钮导出全部敏感词

**正常流程**:
1. 敏感词以标签形式展示
2. 点击删除按钮：立即删除该敏感词
3. 点击导出按钮：生成txt文件下载

**异常流程/边界情况**:
- 删除失败：显示错误提示

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 敏感词以标签形式展示
- [ ] AC2: 删除按钮正常工作
- [ ] AC3: 导出按钮生成txt文件

**来源**: [admin/sensitive.html L110-L121](../../html/pages/admin/sensitive.html#L110-L121)
