## 2. 功能模块细粒度需求

### 2.1 筛选栏 (USR-FLT-001)

**需求ID**: USR-FLT-001  
**需求名称**: 用户筛选栏  
**功能描述**: 提供搜索、角色筛选、状态筛选功能  
**触发条件**: 用户输入或选择筛选条件  

**正常流程**:
1. 搜索框输入时防抖300ms后触发搜索
2. 角色筛选选项：全部、普通用户、作者、管理员
3. 状态筛选选项：全部、正常、已封禁
4. 筛选条件变化时自动刷新表格数据

**输入输出规则**:
- 输入：
  - keyword | string | 搜索关键词
  - role | enum | 角色筛选 | user/author/admin
  - status | enum | 状态筛选 | active/banned

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 搜索框支持实时搜索
- [ ] AC2: 角色、状态筛选器正常工作
- [ ] AC3: 筛选条件变化时自动刷新表格

**来源**: [admin/users.html L134-L147](../../html/pages/admin/users.html#L134-L147)

### 2.2 用户数据表格 (USR-TBL-001)

**需求ID**: USR-TBL-001  
**需求名称**: 用户数据表格  
**功能描述**: 展示用户列表，支持编辑、封禁操作  
**触发条件**: 页面加载或筛选条件变化  

**正常流程**:
1. 表格显示字段：用户信息（头像+名称+邮箱）、角色、注册时间、最后登录、状态、操作
2. 角色显示为标签：管理员（红色）、作者（绿色）、普通用户（蓝色）
3. 状态显示为标签：正常（绿色）、已封禁（红色）
4. 点击编辑：打开用户编辑弹窗
5. 点击封禁：弹出确认框，确认后封禁用户

**输入输出规则**:
- 输出：
  - avatar | string | 头像URL
  - username | string | 用户名
  - email | string | 邮箱
  - role | enum | 角色
  - created_at | datetime | 注册时间
  - last_login | datetime | 最后登录时间
  - status | enum | 状态

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 表格正确显示用户数据
- [ ] AC2: 角色和状态标签颜色正确
- [ ] AC3: 编辑、封禁按钮正常工作
- [ ] AC4: 封禁操作需二次确认

**来源**: [admin/users.html L149-L168](../../html/pages/admin/users.html#L149-L168)
