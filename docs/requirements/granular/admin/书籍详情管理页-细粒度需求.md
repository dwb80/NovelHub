## 9. 数据需求汇总

### 9.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/admin/novels/:id | GET/PUT | 获取/更新书籍信息 |
| /api/admin/novels/:id/chapters | GET | 获取章节列表 |
| /api/admin/novels/:id/comments | GET | 获取评论列表 |
| /api/admin/novels/:id/stats | GET | 获取统计数据 |
| /api/admin/novels/:id/logs | GET | 获取操作日志 |

### 9.2 请求参数

```typescript
interface UpdateNovelBody {
  title?: string;
  description?: string;
  category?: string;
  tags?: string[];
  status?: 'ongoing' | 'completed' | 'paused';
  cover?: string;
}

interface NovelDetail {
  id: string;
  title: string;
  cover: string;
  author: {
    id: string;
    name: string;
  };
  category: string;
  tags: string[];
  status: string;
  description: string;
  stats: {
    wordCount: number;
    viewCount: number;
    favoriteCount: number;
    rating: number;
    commentCount: number;
    chapterCount: number;
  };
  updatedAt: Date;
}
```
