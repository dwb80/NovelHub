## 2. 功能模块细粒度需求

### 2.1 队列统计区域 (REV-STAT-001)

**需求ID**: REV-STAT-001  
**需求名称**: 评审队列统计  
**功能描述**: 展示评审队列统计信息：待评审数、已评审数、通过率  
**触发条件**: 页面加载完成  
**前置条件**: 用户已登录且具有评审员权限  

**正常流程**:
1. 页面加载时获取队列统计数据
2. 显示待评审数、已评审数、通过率
3. 数据实时更新

**输入输出规则**:
- 输出：
  - pending_count | number | 待评审数
  - reviewed_count | number | 已评审数
  - pass_rate | string | 通过率（百分比）

**权限控制**: 仅评审员可见  
**优先级**: P2

**验收标准**:
- [ ] AC1: 显示3个统计项
- [ ] AC2: 数值正确显示
- [ ] AC3: 通过率格式正确

**来源**: [review/pending.html L63-L69](../../html/pages/review/pending.html#L63-L69)

### 2.2 进度条 (REV-PROG-001)

**需求ID**: REV-PROG-001  
**需求名称**: 评审进度条  
**功能描述**: 可视化展示评审进度  
**触发条件**: 页面加载或评审状态变化  

**正常流程**:
1. 根据已评审数和总数计算进度
2. 进度条动画填充

**业务规则**:
- 进度 = 已评审数 / (已评审数 + 待评审数) * 100%

**权限控制**: 仅评审员可见  
**优先级**: P2

**验收标准**:
- [ ] AC1: 进度条正确显示进度
- [ ] AC2: 进度变化时有动画效果

**来源**: [review/pending.html L71](../../html/pages/review/pending.html#L71)

### 2.5 评审列表 (REV-LIST-001)

**需求ID**: REV-LIST-001  
**需求名称**: 待评审章节列表  
**功能描述**: 展示待评审章节，支持通过/拒绝/预览操作  
**触发条件**: 页面加载  

**操作步骤**:
1. 查看待评审章节列表
2. 点击"预览"按钮预览章节
3. 点击"通过"按钮通过章节
4. 点击"拒绝"按钮拒绝章节

**正常流程**:
1. 列表显示：序号、章节信息（小说名+章节标题+作者+提交时间+字数+优先级）、操作按钮
2. 高优先级章节显示"优先"标签
3. 点击预览：打开章节预览
4. 点击通过：章节从列表移除，统计更新
5. 点击拒绝：章节从列表移除，统计更新

**异常流程/边界情况**:
- 无待评审内容：显示空状态

**输入输出规则**:
- 输出：
  - novel_name | string | 小说名称
  - chapter_title | string | 章节标题
  - author | string | 作者
  - submit_time | string | 提交时间
  - word_count | number | 字数
  - priority | enum | 优先级（normal/high）

**权限控制**: 仅评审员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 列表正确显示章节信息
- [ ] AC2: 高优先级显示标签
- [ ] AC3: 通过/拒绝/预览按钮正常工作
- [ ] AC4: 操作后列表和统计更新

**来源**: [review/pending.html L87-L92](../../html/pages/review/pending.html#L87-L92)
