## 2. 功能模块细粒度需求

### 2.1 侧边栏导航 (ADM-NAV-001)

**需求ID**: ADM-NAV-001  
**需求名称**: 侧边栏导航菜单  
**功能描述**: 提供管理后台各功能模块的快速导航入口，当前页面高亮显示  
**触发条件**: 管理员访问管理后台任意页面  
**前置条件**: 用户已登录且具有管理员权限  

**操作步骤**:
1. 管理员查看侧边栏导航
2. 点击导航项跳转到对应页面
3. 当前页面导航项高亮显示

**正常流程**:
1. 系统加载侧边栏导航结构
2. 根据当前页面URL匹配对应导航项
3. 匹配项添加active样式（背景色变化、文字颜色变化）
4. 点击导航项后页面跳转，新页面导航项高亮

**异常流程/边界情况**:
- 页面URL不匹配任何导航项：无高亮项
- 网络延迟：导航项可点击，跳转时显示loading

**权限控制**: 仅管理员角色可见全部导航项  
**优先级**: P2

**验收标准**:
- [ ] AC1: 侧边栏包含4个导航分组（概览、内容管理、用户管理、系统）
- [ ] AC2: 当前页面导航项显示高亮样式
- [ ] AC3: 点击导航项正确跳转到对应页面
- [ ] AC4: 小于1024px时侧边栏自动隐藏

**来源**: [admin/dashboard.html L371-L462](../../html/pages/admin/dashboard.html#L371-L462)

### 2.2 页面头部区域 (ADM-HEAD-001)

**需求ID**: ADM-HEAD-001  
**需求名称**: 页面头部区域  
**功能描述**: 显示当前页面标题、全局搜索框、主题切换按钮、退出登录按钮  
**触发条件**: 页面加载完成  
**前置条件**: 用户已登录  

**操作步骤**:
1. 查看页面标题"数据看板"
2. 使用搜索框进行全局搜索
3. 点击主题切换按钮切换明暗主题
4. 点击退出登录按钮退出系统

**正常流程**:
1. 页面加载时显示标题"数据看板"
2. 搜索框输入关键词，实时显示搜索结果（防抖300ms）
3. 点击主题切换按钮，切换页面主题并保存到localStorage
4. 点击退出登录，弹出确认框，确认后清除登录状态并跳转到登录页

**异常流程/边界情况**:
- 搜索关键词为空：显示默认提示"搜索..."
- 搜索结果为空：显示"无搜索结果"
- 退出登录取消：保持在当前页面

**输入输出规则**:
- 输入：搜索关键词 | string | 1-100字符 | 空
- 输出：搜索结果列表 | array | 包含小说、用户、章节等

**权限控制**: 仅管理员可访问  
**优先级**: P2

**验收标准**:
- [ ] AC1: 页面标题正确显示"数据看板"
- [ ] AC2: 搜索框支持输入并实时搜索
- [ ] AC3: 主题切换按钮可切换明暗主题
- [ ] AC4: 退出登录按钮弹出确认框

**来源**: [admin/dashboard.html L465-L487](../../html/pages/admin/dashboard.html#L465-L487)

### 2.3 统计卡片区域 (ADM-STAT-001)

**需求ID**: ADM-STAT-001  
**需求名称**: 数据统计卡片  
**功能描述**: 展示平台核心数据指标，包括总小说数、活跃用户、待审核章节、待处理举报  
**触发条件**: 页面加载完成  
**前置条件**: 用户已登录且具有管理员权限  

**操作步骤**:
1. 页面加载时自动获取统计数据
2. 查看各统计卡片的数值和变化趋势
3. 点击卡片可跳转到对应详情页

**正常流程**:
1. 页面加载时发起API请求获取统计数据
2. 显示4个统计卡片，每个卡片包含：图标、数值、标签、变化趋势
3. 数值格式化显示（如2,847、15.2k）
4. 变化趋势显示为"↑ 12% 较上月"或"↑ 23 待处理"
5. 正数显示绿色，负数/警告显示红色

**异常流程/边界情况**:
- API请求失败：显示"--"占位符，提供刷新按钮
- 数据为0：显示"0"
- 变化趋势为0：不显示趋势

**输入输出规则**:
- 输出：
  - total_novels | number | 总小说数
  - active_users | number | 活跃用户数
  - pending_chapters | number | 待审核章节数
  - pending_reports | number | 待处理举报数
  - trends | object | 各指标变化趋势

**业务规则**:
- 数值>=10000时显示为"x.xk"格式
- 数值>=1000000时显示为"x.xm"格式
- 趋势计算与上月同期对比

**权限控制**: 仅管理员可见  
**优先级**: P2

**验收标准**:
- [ ] AC1: 显示4个统计卡片，布局为4列网格
- [ ] AC2: 每个卡片显示正确的图标、数值、标签
- [ ] AC3: 数值格式化显示符合规则
- [ ] AC4: 变化趋势颜色正确（正数绿色，负数红色）
- [ ] AC5: 小于1024px时显示为2列

**来源**: [admin/dashboard.html L489-L523](../../html/pages/admin/dashboard.html#L489-L523)

### 2.4 待审核章节表格 (ADM-TBL-001)

**需求ID**: ADM-TBL-001  
**需求名称**: 待审核章节表格  
**功能描述**: 展示待审核章节列表，支持快速通过/拒绝操作  
**触发条件**: 页面加载完成或管理员主动刷新  
**前置条件**: 用户已登录且具有管理员权限  

**操作步骤**:
1. 查看待审核章节列表
2. 点击"通过"按钮审核通过章节
3. 点击"拒绝"按钮拒绝章节
4. 点击"查看全部"跳转到章节审核页面

**正常流程**:
1. 页面加载时获取待审核章节列表（默认显示前5条）
2. 表格显示：小说名称、章节标题、作者、提交时间、状态、操作
3. 点击"通过"按钮：弹出确认框，确认后章节状态变为"已通过"
4. 点击"拒绝"按钮：弹出确认框，确认后章节状态变为"已拒绝"
5. 操作成功后显示toast提示，表格数据刷新

**异常流程/边界情况**:
- 无待审核章节：显示"暂无待审核章节"空状态
- 网络错误：显示错误提示，提供重试按钮
- 操作冲突：章节已被其他管理员处理，提示"该章节已被处理"

**输入输出规则**:
- 输出：
  - novel_name | string | 小说名称
  - chapter_title | string | 章节标题
  - author | string | 作者名称
  - submit_time | datetime | 提交时间
  - status | enum | 状态（pending）

**业务规则**:
- 默认显示前5条数据
- 按提交时间倒序排列
- 操作后实时刷新列表

**权限控制**: 仅管理员可操作  
**优先级**: P2

**验收标准**:
- [ ] AC1: 表格正确显示待审核章节数据
- [ ] AC2: 通过/拒绝按钮可正常操作
- [ ] AC3: 操作后显示toast提示
- [ ] AC4: 点击"查看全部"跳转到章节审核页
- [ ] AC5: 无数据时显示空状态

**来源**: [admin/dashboard.html L526-L601
