## 1. 页面整体结构

### 1.1 页面元数据

| 属性 | 值 |
|------|-----|
| 页面标题 | {话题标题} - 社区论坛 - 小说阅读平台 |

## 2. 功能模块细粒度需求

### 2.1 话题内容区

#### 需求ID: CM-T-001

**需求名称**: 话题标题与元信息

**功能描述**: 显示话题标题和基本信息

**触发条件**: 页面加载完成

**前置条件**: 话题ID有效

**操作步骤**:
  1. 加载话题数据
  2. 渲染标题区

**正常流程**:
  1. 显示板块标签、精华标识
  2. 显示话题标题
  3. 显示作者信息、发布时间
  4. 显示浏览数、回复数

**异常流程/边界情况**:
  - 话题不存在: 404页面
  - 话题被删除: 显示"该话题已被删除"
  - 话题被屏蔽: 显示"该话题暂时无法查看"

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 话题ID
  - 输出: 话题数据

**优先级**: P1

**验收标准**:
  - [ ] AC1: 话题信息正确显示
  - [ ] AC2: 404/删除/屏蔽状态正确处理

**来源**: topic.html L1-L80

---

#### 需求ID: CM-T-002

**需求名称**: 话题内容展示

**功能描述**: 显示话题正文内容

**触发条件**: 话题数据加载完成

**前置条件**: 无

**操作步骤**:
  1. 渲染话题内容
  2. 处理富文本/Markdown

**正常流程**:
  1. 解析并渲染内容
  2. 支持Markdown格式
  3. 图片懒加载

**异常流程/边界情况**:
  - 图片加载失败: 显示占位图

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 话题内容
  - 输出: 渲染后的HTML

**业务规则**:
  - 支持Markdown语法
  - 图片最大宽度限制

**优先级**: P1

**验收标准**:
  - [ ] AC1: 内容正确渲染
  - [ ] AC2: Markdown解析正确

**来源**: topic.html L81-L140

---

#### 需求ID: CM-T-003

**需求名称**: 话题操作按钮

**功能描述**: 编辑、删除、举报话题

**触发条件**: 用户点击操作按钮

**前置条件**: 有对应权限

**操作步骤**:
  1. 显示操作按钮
  2. 用户点击执行操作

**正常流程**:
  - 编辑: 跳转编辑页面(仅作者)
  - 删除: 确认后删除(作者/管理员)
  - 举报: 弹出举报对话框

**异常流程/边界情况**:
  - 无权限: 按钮不显示

**权限控制**: 
  - 编辑: 仅作者
  - 删除: 作者、管理员
  - 举报: 登录用户

**输入输出规则**:
  - 输入: 操作类型
  - 输出: 操作结果

**优先级**: P1

**验收标准**:
  - [ ] AC1: 按钮按权限显示
  - [ ] AC2: 操作功能正常

**来源**: topic.html L141-L200

### 2.3 快速回复

#### 需求ID: CM-T-007

**需求名称**: 快速回复框

**功能描述**: 快速发表回复

**触发条件**: 用户在回复框输入

**前置条件**: 用户已登录

**操作步骤**:
  1. 用户输入内容
  2. 点击发表
  3. 提交回复

**正常流程**:
  1. 输入内容(1-2000字符)
  2. 点击"发表回复"
  3. 提交后清空输入框
  4. 新回复显示在列表末尾

**异常流程/边界情况**:
  - 内容为空: 提示"请输入内容"
  - 内容超长: 提示"内容不超过2000字符"
  - 未登录: 弹出登录框

**权限控制**: 登录用户

**输入输出规则**:
  - 输入: 内容 (string, 1-2000字符)
  - 输出: 回复结果

**业务规则**:
  - 敏感词过滤
  - 频率限制: 每分钟1条

**优先级**: P1

**验收标准**:
  - [ ] AC1: 回复功能正常
  - [ ] AC2: 验证规则正确
  - [ ] AC3: 未登录时引导登录

**来源**: topic.html L401-L480

**验收标准**:
