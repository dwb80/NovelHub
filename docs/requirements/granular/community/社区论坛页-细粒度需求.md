## 1. 页面整体结构

### 1.1 页面元数据

| 属性 | 值 |
|------|-----|
| 页面标题 | 社区论坛 - 小说阅读平台 |
| 页面路径 | /community |
| 登录要求 | 无需登录(浏览)，需登录(发帖/回复) |

### 1.3 响应式断点

| 断点 | 布局变化 |
|------|----------|
| ≥992px | 完整列表布局，右侧显示统计 |
| ≥768px | 简化列表布局 |
| <768px | 卡片式布局，隐藏部分信息 |

## 2. 功能模块细粒度需求

### 2.1 页面标题区

#### 需求ID: CM-F-001

**需求名称**: 页面标题与发布按钮

**功能描述**: 显示页面标题和发布话题入口

**触发条件**: 页面加载完成

**前置条件**: 无

**操作步骤**:
  1. 页面加载
  2. 渲染标题区

**正常流程**:
  1. 显示"社区论坛"标题
  2. 显示"发布话题"按钮
  3. 点击按钮进入发帖页面

**异常流程/边界情况**:
  - 未登录点击发布: 弹出登录对话框

**权限控制**: 发布话题需登录

**输入输出规则**:
  - 输入: 无
  - 输出: 页面标题UI

**业务规则**:
  - 发布按钮始终显示
  - 未登录点击时引导登录

**优先级**: P1

**验收标准**:
  - [ ] AC1: 标题正确显示
  - [ ] AC2: 发布按钮可点击
  - [ ] AC3: 未登录时引导登录

**来源**: forum.html L1-L50

---

### 2.2 板块导航

#### 需求ID: CM-F-002

**需求名称**: 板块筛选导航

**功能描述**: 按板块筛选话题

**触发条件**: 用户点击板块标签

**前置条件**: 话题数据已加载

**操作步骤**:
  1. 用户点击板块标签
  2. 话题列表按板块过滤

**正常流程**:
  1. 显示板块: 全部、书评交流、创作讨论、活动公告、求助问答
  2. 点击板块后高亮显示
  3. 列表过滤显示该板块话题
  4. URL参数更新: ?board=review

**异常流程/边界情况**:
  - 板块无话题: 显示"该板块暂无话题"

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 板块标识 (string)
  - 输出: 筛选后的话题列表

**业务规则**:
  - 默认选中"全部"
  - 板块由管理员配置

**优先级**: P1

**验收标准**:
  - [ ] AC1: 板块导航正确显示
  - [ ] AC2: 点击后正确筛选
  - [ ] AC3: URL参数正确更新

**来源**: forum.html L51-L120

### 2.3 筛选栏

#### 需求ID: CM-F-003

**需求名称**: 排序方式筛选

**功能描述**: 按不同维度排序话题

**触发条件**: 用户点击排序下拉框

**前置条件**: 话题数据已加载

**操作步骤**:
  1. 用户点击排序下拉框
  2. 选择排序方式
  3. 列表重新排序

**正常流程**:
  1. 下拉框选项: 最新回复、最新发布、最多回复、最多浏览
  2. 默认"最新回复"
  3. 选择后列表重新排序

**异常流程/边界情况**:
  - 无

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 排序方式 (string)
  - 输出: 排序后的话题列表

**业务规则**:
  - 最新回复: 按最后回复时间倒序
  - 最新发布: 按发布时间倒序
  - 最多回复: 按回复数倒序
  - 最多浏览: 按浏览数倒序

**优先级**: P1

**验收标准**:
  - [ ] AC1: 排序选项正确显示
  - [ ] AC2: 排序功能正常

**来源**: forum.html L121-L170

**业务规则**:
  - 精华由管理员或版主标记

**优先级**: P1

**验收标准**:

#### 需求ID: CM-F-005

**需求名称**: 话题搜索

**功能描述**: 搜索话题

**触发条件**: 用户在搜索框输入

**前置条件**: 话题数据已加载

**操作步骤**:
  1. 用户输入关键词
  2. 系统搜索话题
  3. 显示搜索结果

**正常流程**:
  1. 输入关键词，防抖300ms
  2. 搜索标题和内容
  3. 显示匹配话题

**异常流程/边界情况**:
  - 无结果: 显示"未找到相关话题"

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 关键词 (string, 1-100字符)
  - 输出: 搜索结果列表

**业务规则**:
  - 搜索范围: 话题标题、内容
  - 支持分页

**优先级**: P1

**验收标准**:
  - [ ] AC1: 搜索功能正常
  - [ ] AC2: 无结果时正确提示

**来源**: forum.html L211-L260

### 2.4 话题列表

#### 需求ID: CM-F-006

**需求名称**: 话题项展示

**功能描述**: 展示话题列表

**触发条件**: 话题数据加载完成

**前置条件**: 无

**操作步骤**:
  1. 加载话题数据
  2. 渲染话题列表

**正常流程**:
  1. 显示板块标签、精华标识
  2. 显示话题标题
  3. 显示作者信息、发布时间
  4. 显示回复数/浏览数
  5. 显示最后回复信息
  6. 点击标题进入话题详情

**异常流程/边界情况**:
  - 话题被删除: 显示"[已删除]"
  - 话题被屏蔽: 不显示

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 话题数据对象
    ```json
    {
      "topic_id": "string",
      "title": "string",
      "board": "string",
      "is_essential": "boolean",
      "author": {
        "id": "string",
        "name": "string",
        "avatar": "string"
      },
      "created_at": "timestamp",
      "reply_count": "number",
      "view_count": "number",
      "last_reply": {
        "author_name": "string",
        "time": "timestamp"
      }
    }
    ```
  - 输出: 话题列表DOM

**业务规则**:
  - 精华话题置顶显示
  - 标题过长截断显示

**优先级**: P1

**验收标准**:
  - [ ] AC1: 话题信息正确显示
  - [ ] AC2: 精华话题置顶
  - [ ] AC3: 点击进入详情

**来源**: forum.html L261-L350

### 2.5 分页

#### 需求ID: CM-F-007

**需求名称**: 分页导航

**功能描述**: 话题列表分页

**触发条件**: 话题数量超过每页数量

**前置条件**: 话题数据已加载

**操作步骤**:
  1. 计算总页数
  2. 渲染分页组件
  3. 用户切换页码

**正常流程**:
  1. 默认每页20条
  2. 显示分页组件
  3. 点击页码加载对应数据

**异常流程/边界情况**:
  - 只有一页: 不显示分页

**权限控制**: 公开访问

**输入输出规则**:
  - 输入: 页码
  - 输出: 对应页数据

**业务规则**:
  - 页码从1开始

**优先级**: P1

**验收标准**:
  - [ ] AC1: 分页组件正确显示
  - [ ] AC2: 分页功能正常

**来源**: forum.html L351-L400
