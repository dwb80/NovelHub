## 2. 页面加载器 (Page Loader)

### 需求ID: IDX-LOADER-001

**需求名称**: 页面加载动画

**功能描述**: 页面初始化时显示全屏加载动画，数据加载完成后淡出隐藏

**触发条件**: 页面DOM加载完成时自动触发

**前置条件**: 无

**操作步骤**:
1. 页面加载时显示加载器
2. 等待Mock数据加载完成
3. 执行渲染函数
4. 淡出隐藏加载器

**正常流程**:
1. 显示加载器（白色背景 + 旋转动画 + 文字"正在加载 NovelHub..."）
2. 检查window.MockData是否存在
3. 数据加载成功后执行渲染
4. 添加hidden类触发淡出动画
5. 500ms后从DOM移除

**异常流程/边界情况**:
- **数据加载失败**: 显示错误toast"加载失败，请刷新页面重试"
- **网络断开**: 显示网络状态提示
