## 2. 敏感词分级

### 2.1 敏感词等级定义

#### 需求ID: SENSITIVE-LEVEL-001

**需求名称**: 敏感词分级体系

**功能描述**: 定义敏感词的等级分类及对应处理策略

**等级定义**:

| 等级 | 等级码 | 说明 | 示例 | 处理策略 |
|------|--------|------|------|----------|
| P0-违禁 | prohibited | 违法违规内容 | 暴恐、毒品、色情 | 阻止提交 |
| P1-严重 | severe | 严重违规内容 | 人身攻击、歧视 | 阻止提交 |
| P2-一般 | normal | 一般敏感内容 | 粗俗语言、广告 | 替换/审核 |
| P3-轻微 | mild | 轻微敏感内容 | 敏感地名、争议词 | 替换 |

**等级判定标准**:

| 等级 | 判定标准 |
|------|----------|
| P0-违禁 | 涉及国家安全、违法犯罪、淫秽色情 |
| P1-严重 | 涉及人身攻击、种族/地域歧视、恶意诽谤 |
| P2-一般 | 涉及粗俗用语、商业广告、过度引流 |
| P3-轻微 | 涉及敏感地名、争议人物、政治相关 |

**优先级**: P1

**验收标准**:
- [ ] AC1: 敏感词分级准确
- [ ] AC2: 分级可配置调整
- [ ] AC3: 新词可快速定级

## 3. 敏感词替换规则

#### 需求ID: SENSITIVE-REPLACE-001

**需求名称**: 敏感词替换策略

**功能描述**: 定义不同等级敏感词的替换规则

**替换规则表**:

| 等级 | 应用场景 | 替换方式 | 替换结果示例 | 说明 |
|------|----------|----------|--------------|------|
| P0-违禁 | 全部 | 阻止提交 | - | 不允许出现 |
| P1-严重 | 全部 | 阻止提交 | - | 不允许出现 |
| P2-一般 | 评论 | 全词替换 | "这个词" → "***" | 替换为等长* |
| P2-一般 | 标题/用户名 | 阻止提交 | - | 不允许出现 |
| P3-轻微 | 全部 | 全词替换 | "这个词" → "***" | 替换为等长* |

**替换方式详解**:

| 替换方式 | 说明 | 示例 |
|----------|------|------|
| 全词替换 | 将整个敏感词替换为等长* | "敏感词" → "***" |
| 首字保留 | 保留首字，其余替换 | "敏感词" → "敏**" |
| 删除 | 直接删除敏感词 | "敏感词" → "" |
| 阻止提交 | 不允许内容提交 | 返回错误 |

**优先级**: P1

**验收标准**:
- [ ] AC1: 替换规则按等级执行

### 3.2 替换算法

#### 需求ID: SENSITIVE-ALGO-001

**需求名称**: 敏感词检测与替换算法

**功能描述**: 定义敏感词检测和替换的具体算法

**算法流程**:

```
输入: 待检测文本、敏感词库、用户等级、内容类型
输出: 检测结果、处理后文本

步骤:
1. 加载敏感词库（按等级、分类）
2. 构建AC自动机（Aho-Corasick）
3. 遍历文本进行多模式匹配
4. 对匹配到的敏感词:
   a. 查询敏感词等级和分类
   b. 根据等级和应用场景确定处理方式
   c. 执行替换或标记
5. 返回处理结果
```

**AC自动机匹配**:

```python
# 伪代码
class SensitiveWordFilter:
    def __init__(self):
        self.ac_automaton = build_ac_automaton(word_list)
    
    def filter(self, text, content_type='comment'):
        matches = self.ac_automaton.search(text)
        result = text
        
        for match in matches:
            word_info = self.get_word_info(match.word)
            action = self.determine_action(word_info, content_type)
            
            if action == 'block':
                return {'blocked': True, 'word': match.word}
            elif action == 'replace':
                replacement = '*' * len(match.word)
                result = result.replace(match.word, replacement)
        
        return {'blocked': False, 'text': result}
```

**优先级**: P1

**验收标准**:
- [ ] AC1: 检测准确率>95%
- [ ] AC2: 处理时间<10ms/千字
- [ ] AC3: 支持变体检测（拼音、谐音）

**来源**: AI推导补充，依据：敏感词过滤技术方案

### 3.3 变体检测

#### 需求ID: SENSITIVE-VARIANT-001

**需求名称**: 敏感词变体检测

**功能描述**: 检测敏感词的变体形式（拼音、谐音、拆字等）

**变体类型**:

| 变体类型 | 说明 | 示例 | 检测方式 |
|----------|------|------|----------|
| 拼音替换 | 用拼音代替汉字 | "敏感词" → "minganci" | 拼音匹配 |
| 谐音替换 | 用谐音字代替 | "敏感词" → "敏干词" | 谐音字典 |
| 拆字替换 | 用偏旁部首拆分 | "明" → "日月" | 拆字映射 |
| 特殊符号 | 插入特殊符号 | "敏感词" → "敏*感*词" | 去噪后匹配 |
| 繁简转换 | 繁体字形式 | "敏感词" → "敏感詞" | 繁简转换后匹配 |
| 大小写混合 | 拼音大小写混合 | "MINGANci" | 统一转小写 |

**变体处理规则**:

```
1. 去除干扰符号（*、#、空格等）
2. 繁简转换
3. 大小写统一
4. 尝试拼音匹配
5. 尝试谐音匹配
6. 尝试拆字匹配
7. 综合评分，超过阈值判定为敏感词
```

**优先级**: P2

**验收标准**:
- [ ] AC1: 常见变体可检测
- [ ] AC2: 误杀率<5%
- [ ] AC3: 检测性能满足要求

**来源**: AI推导补充，依据：敏感词变体检测技术

## 4. 处理流程

### 4.1 评论敏感词处理流程

#### 需求ID: SENSITIVE-FLOW-001

**需求名称**: 评论敏感词处理流程

**功能描述**: 定义用户评论提交时的敏感词处理流程

**处理流程**:

```
用户提交评论
    │
    ▼
前端预检（快速检测）
    │
    ├── 发现P0/P1级敏感词 ──► 前端提示"内容包含敏感词，请修改"
    │
    └── 通过预检
         │
         ▼
    提交到后端
         │
         ▼
    后端终检（完整检测）
         │
         ├─ 发现P0/P1级 ──► 拒绝提交，返回错误码
         │
         ├─ 发现P2级 ─────► 替换后发布，标记"内容已过滤"
         │
         ├─ 发现P3级 ─────► 替换后发布
         │
         └─ 无敏感词 ─────► 正常发布
```

**处理结果**:

| 检测结果 | 处理方式 | 用户提示 |
|----------|----------|----------|
| 含P0/P1级 | 拒绝提交 | "内容包含违规信息，请修改后重试" |
| 含P2级 | 替换后发布 | "内容已自动过滤敏感词" |
| 含P3级 | 替换后发布 | 无提示 |
| 无敏感词 | 正常发布 | 无 |

**优先级**: P1

**验收标准**:
- [ ] AC1: 流程各节点正常工作
- [ ] AC2: 错误提示清晰准确
- [ ] AC3: 处理日志完整记录

## 5. 敏感词库管理

### 5.1 敏感词库结构

#### 需求ID: SENSITIVE-DB-001

**需求名称**: 敏感词库数据结构

**功能描述**: 定义敏感词库的存储结构

**数据表结构**:

```sql
CREATE TABLE sensitive_words (
  id SERIAL PRIMARY KEY,
  word VARCHAR(100) NOT NULL,           -- 敏感词
  word_hash VARCHAR(64) NOT NULL,       -- 词哈希（用于快速查询）
  level VARCHAR(10) NOT NULL,           -- 等级：P0/P1/P2/P3
  category VARCHAR(10) NOT NULL,        -- 分类：POL/VIO/POR/...
  action VARCHAR(20) NOT NULL,          -- 处理方式：block/replace
  replacement VARCHAR(100),             -- 替换内容（null表示用*）
  variants JSONB,                       -- 变体形式：["变体1", "变体2"]
  enabled BOOLEAN DEFAULT true,         -- 是否启用
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  created_by VARCHAR(50),               -- 创建人
  UNIQUE(word)
);

CREATE INDEX idx_sensitive_words_level ON sensitive_words(level);
CREATE INDEX idx_sensitive_words_category ON sensitive_words(category);
CREATE INDEX idx_sensitive_words_enabled ON sensitive_words(enabled);
```

**优先级**: P1

**验收标准**:
- [ ] AC1: 表结构支持业务需求
- [ ] AC2: 索引优化查询性能
- [ ] AC3: 支持变体存储

```

    ▼

    │
```
