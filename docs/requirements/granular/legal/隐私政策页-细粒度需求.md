# 隐私政策页 - 细粒度需求

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面名称** | 隐私政策 |
| **页面路径** | /privacy |
| **优先级** | P2 |
| **页面目标** | 向用户说明平台如何收集、使用和保护用户数据 |

## 3. 组件详细说明

### 3.1 页面标题区

**位置**: 页面顶部
**样式**:
- 标题: 36px, font-weight: 700, 居中
- 更新日期: 14px, 颜色次要

**内容**:
- 主标题: "隐私政策"
- 最后更新日期

### 3.2 目录导航区

**位置**: 标题区下方
**样式**:
- 卡片式布局
- 章节列表
- 点击跳转对应章节

**章节列表**:
1. 信息收集范围
2. 信息使用方式
3. 信息保护措施
4. Cookie使用
5. 第三方服务
6. 用户权利
7. 联系我们

**交互**:
- 点击目录项平滑滚动到对应章节
- 滚动时高亮当前章节

### 3.3 政策内容区

**位置**: 目录区下方
**样式**:
- 章节标题: 24px, font-weight: 600
- 正文: 16px, 行高1.8
- 列表项使用标准列表样式

**内容章节**:

#### 1. 信息收集范围
- 账户信息（用户名、邮箱）
- 个人资料（头像、简介）
- 使用数据（阅读记录、收藏）
- 设备信息（IP地址、浏览器类型）

#### 2. 信息使用方式
- 提供和改进服务
- 个性化推荐
- 账户安全
- 法律合规

#### 3.
