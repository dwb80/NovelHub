## 4. 步骤详细说明

### 4.1 Step 1: 验证邮箱

**内容**:
- 步骤标题: "输入邮箱地址"
- 步骤描述: "请输入您注册时使用的邮箱地址，我们将发送验证码"

**表单字段**:

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 邮箱 | email | 是 | 邮箱格式，已注册邮箱 |

**按钮**:
- 主要: "发送验证码" / "下一步"
- 次要: "返回登录"

**交互**:
- 邮箱格式实时验证
- 点击发送后显示倒计时（60秒）
- 发送成功进入Step 2

**错误提示**:
- 邮箱格式错误: "请输入有效的邮箱地址"
- 邮箱未注册: "该邮箱未注册，请检查或前往注册"
- 发送失败: "验证码发送失败，请稍后重试"

### 4.2 Step 2: 验证验证码

**内容**:
- 步骤标题: "输入验证码"
- 步骤描述: "验证码已发送至 xxx@example.com"

**表单字段**:

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 验证码 | text | 是 | 6位数字 |

**附加功能**:
- 倒计时显示: "60秒后重新发送"
- 重新发送链接（倒计时结束后可用）
- 更换邮箱链接

**按钮**:
- 主要: "验证" / "下一步"
- 次要: "上一步"

**交互**:
- 验证码自动聚焦下一个输入框（分6个框输入时）
- 验证成功进入Step 3

**错误提示**:
- 验证码错误: "验证码错误，请重新输入"
- 验证码过期: "验证码已过期，请重新发送"

### 4.3 Step 3: 重置密码

**内容**:
- 步骤标题: "设置新密码"
- 步骤描述: "请设置您的新密码"

**表单字段**:

| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 新密码 | password | 是 | 8-20位，包含字母和数字 |
| 确认密码 | password | 是 | 与新密码一致 |

**附加功能**:
- 密码强度指示器
- 显示/隐藏密码按钮

**按钮**:
- 主要: "确认重置"
- 次要: "上一步"

**交互**:
- 密码强度实时检测
- 确认密码实时匹配验证

**错误提示**:
- 密码格式: "密码需8-20位，包含字母和数字"
- 密码不匹配: "两次输入的密码不一致"

### 4.4 成功状态

**内容**:
- 成功图标
- 标题: "密码重置成功"
- 描述: "您的密码已成功重置，请使用新密码登录"
- 按钮: "立即登录"

**交互**:
- 3秒后自动跳转到登录页
- 点击按钮立即跳转

## 5. 组件详细说明

### 5.1 步骤指示器

**样式**:
- 水平步骤条
- 当前步骤高亮
- 已完成步骤显示勾选标记

**步骤**:
1. 验证邮箱
2. 输入验证码
3. 重置密码

### 5.2 验证码输入

**方案A: 单个输入框**
- 6位验证码连续输入
- 自动验证（输入6位后自动提交）

**方案B: 分格输入**
- 6个独立输入框
- 自动聚焦下一个
- 支持粘贴完整验证码

### 5.3 密码强度指示器

**强度等级**:
- 弱: 红色
- 中: 黄色
- 强: 绿色

**判断标准**:
- 弱: 仅满足最低要求
- 中: 8位以上，包含大小写字母和数字
- 强: 12位以上，包含大小写字母、数字和特殊字符

## 6. 数据需求汇总

### 6.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/auth/forgot-password/send | POST | 发送验证码 |
| /api/auth/forgot-password/verify | POST | 验证验证码 |
| /api/auth/forgot-password/reset | POST | 重置密码 |

### 6.2 请求参数

```typescript
// Step 1: 发送验证码
interface SendCodeRequest {
  email: string;
}

// Step 2: 验证验证码
interface VerifyCodeRequest {
  email: string;
  code: string;
}

// Step 3: 重置密码
interface ResetPasswordRequest {
  email: string;
  code: string;
  newPassword: string;
}
```

### 6.3 响应结构

```typescript
interface ForgotPasswordResponse {
  success: boolean;
  message?: string;
  // 验证成功后返回token用于最后一步
  resetToken?: string;
}
```

## 7. 安全要求

- 验证码有效期: 5分钟
- 验证码错误次数限制: 5次
- 同一邮箱发送频率限制: 1分钟间隔
- 密码加密传输（HTTPS）
- 重置链接/验证码一次性使用

## 8. 性能要求

- 页面加载时间 < 1s
- 验证码发送响应 < 2s
- 验证响应 < 500ms

## 9. 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 网络错误 | 提示检查网络，提供重试 |
| 服务器错误 | 友好错误提示，记录日志 |
| 频繁请求 | 提示"操作过于频繁，请稍后再试" |
| 会话过期 | 提示重新开始流程 |

## 10. 注意事项

- 邮箱脱敏显示: xxx@example.com 显示为 xx*@example.com
- 支持返回上一步修改
- 刷新页面保留当前步骤（使用sessionStorage）
- 完成重置后清除相关缓存
