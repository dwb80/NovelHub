## 3. 组件详细说明（已完善）

### 3.1 页面标题区

**需求ID**: BK-HEADER-001

**功能描述**: 显示页面标题和书架统计信息

**位置**: 导航栏下方，容器内

**样式**:
- 主标题: 28px, font-weight: 700, color: var(--color-text-primary)
- 统计信息: 16px, color: var(--color-text-secondary)
- 间距: margin-bottom: 24px

**内容**:
- 主标题: "我的书架"
- 统计: "共收藏 {total} 本小说，{reading} 本正在阅读"

**数据来源**:
```typescript
interface BookshelfStats {
  total: number;      // 总收藏数
  reading: number;    // 正在阅读数
  completed: number;  // 已读完数
  hasUpdate: number;  // 有更新数
}
```

**加载状态**:
- 加载中: 显示骨架屏 "共收藏 -- 本小说"
- 加载完成: 显示实际数字

**优先级**: P1

**验收标准**:
- AC1: 统计数字正确显示
- AC2: 数字变化时动画过渡
- AC3: 加载状态显示骨架屏

---

### 3.2 Tab切换区

**需求ID**: BK-TAB-001

**功能描述**: 切换不同书架视图

**Tab项**:
| Tab | 标识 | 内容 |
|-----|------|------|
| 在读 | reading | 正在阅读的书籍 |
| 收藏 | favorites | 收藏的书籍 |
| 历史 | history | 阅读历史记录 |

**样式**:
- Tab高度: 44px
- 字体: 16px, font-weight: 500
- 激活状态: 下划线2px, 主色
- 过渡动画: 300ms ease

**交互**:
- 点击Tab切换内容区
- URL同步更新: ?tab=reading|favorites|history
- 刷新页面保持当前Tab

**内容切换动画**:
- 淡出当前内容: 150ms
- 淡入新内容: 150ms

**优先级**: P0

**验收标准**:
- AC1: Tab切换流畅
- AC2: URL参数同步更新
- AC3: 刷新后保持选中Tab

### 3.3 在读列表

**需求ID**: BK-READING-001

**功能描述**: 展示正在阅读的书籍列表

**列表项结构**:
```
┌─────────────────────────────────┐
```

## 4. 交互说明（新增章节）

### 4.1 页面加载流程

```
页面初始化
  ↓
显示骨架屏
  ↓
检查登录状态
  ├─ 未登录 → 重定向到登录页
  ↓ 已登录
获取书架数据
  ├─ 缓存命中 → 显示缓存数据
  ↓
请求最新数据
  ├─ 成功 → 更新显示
  ├─ 失败 → 显示缓存/错误提示
  ↓
检查书籍更新（异步）
  ↓
更新完成
```

### 4.2 书籍操作

**长按/右键菜单**:
| 操作 | 功能 | 确认 |
|------|------|------|
| 继续阅读 | 跳转到阅读器 | 否 |
| 查看详情 | 跳转到详情页 | 否 |
| 置顶 | 置顶到列表首位 | 否 |
| 标记已读 | 标记所有章节已读 | 是 |
| 移除 | 从书架移除 | 是 |

**移除确认弹窗**:
```
┌─────────────────────────────────┐
│ 移除书籍                        │
│                                 │
│ 确定要从书架移除《小说名》吗？   │
│ 移除后阅读进度将保留。          │
│                                 │
│      [取消]    [确认移除]       │
└─────────────────────────────────┘
```

**移除后Toast**:
- 消息: "《小说名》已从书架移除"
- 操作: [撤销] 按钮，5秒内有效

### 4.3 更新提示交互

**更新检测**:
- 进入页面时检测一次
- 页面可见时每5分钟检测一次
- 收到WebSocket推送时立即检测

**更新标记点击**:
- 点击带更新标记的书籍
- 弹窗提示: "有X章新内容，是否追更到最新章节？"
- 选项: [稍后] [立即追更]

**立即追更**:
- 跳转到最新未读章节
- 自动标记之前所有章节为已读
- 清除更新标记

## 5. 数据需求（已完善）

### 5.1 API接口

| 接口 | 方法 | 描述 | 缓存 |
|------|------|------|------|
| /api/bookshelf/reading | GET | 获取在读列表 | 5分钟 |
| /api/bookshelf/favorites | GET | 获取收藏列表 | 5分钟 |
| /api/bookshelf/history | GET | 获取历史记录 | 5分钟 |
| /api/bookshelf/:id | DELETE | 从书架移除 | 无 |
| /api/bookshelf/updates | GET | 检查书籍更新 | 1分钟 |
| /api/bookshelf/pin | POST | 置顶书籍 | 无 |

### 5.2 请求参数

```typescript
// 获取书架列表
interface GetBookshelfParams {
  type: 'reading' | 'favorites' | 'history';
  page?: number;        // 默认1
  pageSize?: number;    // 默认20
}

// 检查更新
interface CheckUpdatesParams {
  bookIds: string[];    // 要检查的书籍ID列表
}
```

### 5.3 响应结构

```typescript
// 书架项
interface BookshelfItem {
  id: string;
  novelId: string;
  title: string;
  cover: string;
  author: {
    id: string;
    name: string;
  };
  category: string;
  status: 'ongoing' | 'completed';
  
  // 阅读进度（在读类型）
  readingProgress?: {
    currentChapter: number;
    totalChapters: number;
    chapterTitle: string;
    percentage: number;
  };
  
  // 更新状态
  hasUpdate: boolean;
  newChaptersCount: number;
  
  // 时间信息
  lastReadAt?: string;    // ISO 8601
  bookmarkedAt?: string;  // ISO 8601
  updatedAt: string;      // ISO 8601
}

// 书架列表响应
interface BookshelfResponse {
  list: BookshelfItem[];
  pagination: {
    current: number;
    pageSize: number;
    total: number;
    totalPages: number;
  };
}

// 更新检查结果
interface UpdateCheckResult {
  bookId: string;
  hasUpdate: boolean;
  newChaptersCount: number;
}
```

## 6. 性能要求（新增）

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 首屏加载时间 | < 1s | FCP |
| 列表滚动帧率 | > 50fps | Chrome DevTools |
| 图片加载时间 | < 500ms | LCP |
| 操作响应时间 | < 100ms | 用户点击到反馈 |

**优化策略**:
1. 虚拟滚动: 列表超过50项时使用
2. 图片懒加载: 使用IntersectionObserver
3. 数据缓存: 本地缓存5分钟
4. 骨架屏: 加载期间显示骨架占位
