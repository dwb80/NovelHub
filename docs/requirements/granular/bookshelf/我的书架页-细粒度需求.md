# 我的书架页 - 细粒度需求

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面名称** | 我的书架 |
| **页面路径** | /bookshelf |
| **优先级** | P1 |
| **页面目标** | 管理用户收藏的小说，提供阅读入口和阅读进度管理 |
| **所属模块** | 用户中心 |
| **访问权限** | 登录用户 |

## 3. 组件详细说明

### 3.1 页面标题区

**位置**: 导航栏下方
**样式**:
- 标题: 28px, font-weight: 700
- 统计信息: 16px, 颜色次要

**内容**:
- 主标题: "我的书架"
- 统计: "共收藏 XX 本小说，XX 本正在阅读"

### 3.2 操作工具栏

**位置**: 标题区下方
**样式**:
- 横向布局，工具按钮组
- 管理模式下显示批量操作

**功能**:

| 功能 | 说明 |
|------|------|
| 管理模式 | 切换批量选择模式 |
| 筛选 | 按阅读状态筛选 |
| 排序 | 调整排序方式 |
| 搜索 | 搜索书架内小说 |

**筛选选项**:
- 全部
- 正在阅读
- 已读完
- 未开始
- 有更新

**排序选项**:
- 最近阅读
- 最近收藏
- 书名排序
- 更新时间

### 3.3 管理模式

**触发**: 点击"管理"按钮
**样式变化**:
- 每个小说卡片显示选择框
- 底部显示批量操作栏

**批量操作**:
- 全选/取消全选
- 批量移除
- 批量标记已读（可选）

### 3.4 小说卡片

**位置**: 网格区
**样式**:
- 封面图（3:4比例）
- 标题（最多2行）
- 阅读进度信息
- 操作按钮

**卡片内容**:

| 元素 | 说明 |
|------|------|
| 封面图 | 小说封面，点击跳转阅读 |
| 标题 | 小说标题，点击跳转详情 |
| 阅读进度 | "读到第X章" / "已读完" / "未开始" |
| 更新标记 | 有新章节时显示 |
| 管理选择框 | 管理模式下显示 |
| 移除按钮 | 从书架移除 |

**数据需求**:
```typescript
interface BookshelfItem {
  id: string;
  novelId: string;
  title: string;
  cover: string;
  author: {
    id: string;
    name: string;
  };
  status: 'ongoing' | 'completed';
  
  // 阅读进度
  readingProgress: {
    currentChapter: number;
    totalChapters: number;
    percentage: number;
    isCompleted: boolean;
    lastReadAt: Date;
  };
  
  // 更新状态
  hasUpdate: boolean;
  newChaptersCount: number;
  
  // 收藏信息
  bookmarkedAt: Date;
}

type BookshelfList = BookshelfItem[];
```

**交互**:
- 点击封面/标题: 继续阅读或查看详情
- 点击移除: 确认后从书架移除
- 管理模式下: 点击选择框选中

### 3.5 分页控制

**位置**: 小说网格下方
**样式**:
- 居中对齐
- 简洁分页器

**配置**:
- 每页显示: 20本
- 最多显示页码: 5个

### 3.6 空状态

**触发**: 书架为空时
**样式**:
- 居中显示
- 大图标 + 提示文字 + 操作按钮

**内容**:
- 书架图标
- "书架还是空的，去发现好书吧"
- "去书城看看"按钮

## 4. 交互说明

### 4.1 页面加载

| 触发条件 | 交互行为 |
|----------|----------|
| 页面初始化 | 加载书架列表 |
| 筛选变更 | 重新加载列表，重置分页 |
| 排序变更 | 重新排序列表 |
| 分页切换 | 加载对应页数据 |

### 4.2 阅读入口

| 操作 | 行为 |
|------|------|
| 点击封面/标题（有进度） | 跳转到阅读器，继续阅读 |
| 点击封面/标题（未开始） | 跳转到小说详情页 |
| 点击"继续阅读"按钮（可选） | 直接跳转到阅读器 |

### 4.3 移除确认

- 单本移除: 确认弹窗
- 批量移除: 确认弹窗，显示数量
- 移除后可撤销（可选，Toast提示）

### 4.4 更新提示

- 有新章节的小说显示"更新"标记
- 点击后标记为已读（可选）
- 支持"一键追更"（跳转到最新章节）

## 5. 数据需求汇总

### 5.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/bookshelf | GET | 获取书架列表 |
| /api/bookshelf/:id | DELETE | 从书架移除 |
| /api/bookshelf/batch | DELETE | 批量移除 |
| /api/bookshelf/updates | GET | 检查更新 |

### 5.2 请求参数

```typescript
interface GetBookshelfParams {
  filter?: 'all' | 'reading' | 'completed' | 'not_started' | 'has_update';
  sortBy?: 'last_read' | 'bookmarked_at' | 'title' | 'updated';
  keyword?: string;
  page?: number;
  pageSize?: number;
}
```

### 5.3 响应结构

```typescript
interface BookshelfResponse {
  list: BookshelfItem[];
  pagination: {
    current: number;
    pageSize: number;
    total: number;
    totalPages: number;
  };
  stats: {
    total: number;
    reading: number;
    completed: number;
    hasUpdate: number;
  };
}
```

## 6. 性能要求

- 首屏加载时间 < 1.5s
- 书架数据缓存
- 图片懒加载
- 更新检查异步执行

## 7. 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 加载失败 | 显示错误提示，提供重试 |
| 移除失败 | 恢复显示，提示错误 |
| 未登录访问 | 重定向到登录页 |

## 8. 本地存储

- 阅读进度本地缓存
- 书架列表本地缓存（可选）
- 离线时显示缓存数据
