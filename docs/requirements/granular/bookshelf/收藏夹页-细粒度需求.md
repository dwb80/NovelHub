### 3.3 小说收藏列表

#### 需求ID: FAV-NOVEL-001

**需求名称**: 小说收藏卡片

**功能描述**: 展示收藏的小说列表

**触发条件**: 页面加载完成

**前置条件**: 无

**数据获取**: window.MockData.BOOKSHELF_DATA

**卡片结构**:
| 元素 | 说明 |
|------|------|
| 封面 | 3:4比例小说封面 |
| 标题 | 小说名称 |
| 作者 | 作者名称 |
| 分类 | 小说分类标签 |
| 收藏时间 | "收藏于 2024-01-15" |
| 操作按钮 | 阅读/取消收藏 |

**操作按钮**:
| 按钮 | 功能 |
|------|------|
| 继续阅读 | 跳转到阅读页 |
| 取消收藏 | 从收藏夹移除 |

**取消收藏确认**: "确定要取消收藏吗？"

**样式**:
- 网格布局: 4列（桌面）、3列（平板）、2列（手机）
- 卡片背景: var(--color-bg-elevated)
- 悬停: translateY(-4px)

**优先级**: P0

**验收标准**:
- [ ] AC1: 收藏卡片正确显示
- [ ] AC2: 继续阅读按钮正常
- [ ] AC3: 取消收藏需确认
- [ ] AC4: 响应式布局正常
