## 2. 功能模块细粒度需求

### 2.1 页面头部

#### 需求ID: BS-HEADER-001

**需求名称**: 书架统计信息

**功能描述**: 显示书架小说总数

**触发条件**: 页面加载

**前置条件**: 用户已登录

**操作步骤**:
  1. 加载书架数据
  2. 统计小说数量
  3. 显示统计信息

**正常流程**:
  1. 显示"共 {count} 本小说"
  2. count为书架中的小说总数

**异常流程/边界情况**:
  - 书架为空: 显示"共 0 本小说"

**权限控制**: 登录用户

**输入输出规则**:
  - 输入: 用户ID
  - 输出: 小说数量

**优先级**: P0

**验收标准**:
  - [ ] AC1: 数量统计正确
  - [ ] AC2: 空书架显示正确

**来源**: bookshelf.html L1-L60

### 2.2 筛选栏

#### 需求ID: BS-FILTER-001

**需求名称**: 书架筛选

**功能描述**: 按条件筛选书架小说

**触发条件**: 用户点击筛选条件

**前置条件**: 用户已登录

**筛选选项**:
| 筛选条件 | 说明 |
|----------|------|
| 全部 | 显示所有书架小说 |
| 连载中 | 仅显示连载中的小说 |
| 已完结 | 仅显示已完结的小说 |
| 最近更新 | 最近7天有更新的小说 |
| 未读更新 | 有更新但未阅读的小说 |

**排序选项**:
| 排序方式 | 说明 |
|----------|------|
| 最近阅读 | 按最后阅读时间倒序 |
| 最近加入 | 按加入书架时间倒序 |
| 更新时间 | 按小说更新时间倒序 |
| 书名排序 | 按书名字母顺序 |

**正常流程**:
  1. 点击筛选条件
  2. 条件高亮显示
  3. 书架列表过滤
  4. 显示筛选结果

**异常流程/边界情况**:
  - 筛选结果为空: 显示"没有符合条件的小说"

**权限控制**: 登录用户

**输入输出规则**:
  - 输入: 筛选条件
  - 输出: 筛选后的列表

**优先级**: P0

**验收标准**:
  - [ ] AC1: 筛选条件正确
  - [ ] AC2: 筛选结果正确
  - [ ] AC3: 空结果提示正确

**来源**: bookshelf.html L101-L160

### 2.3 书架卡片

#### 需求ID: BS-CARD-001

**需求名称**: 书架小说卡片

**功能描述**: 展示书架中的小说信息和阅读进度

**触发条件**: 书架数据加载完成

**前置条件**: 用户已登录

**卡片结构**:
| 元素 | 说明 |
|------|------|
| 封面 | 小说封面图 |
| 连载标签 | 连载中/已完结标签 |
| 更新标记 | 有更新时显示"更新"角标 |
| 书名 | 小说名称 |
| 阅读进度 | "读到第X章 X%" |
| 继续阅读按钮 | 跳转至阅读页 |

**样式**:
- 封面: 宽度100%，宽高比2:3
- 连载标签: 右上角，绿色/蓝色
- 更新标记: 左上角，红色"更新"
- 书名: 单行，超出省略
- 进度: 灰色小字

**交互**:
- 点击封面/书名: 跳转小说详情
- 点击继续阅读: 跳转阅读页
- 长按/右键: 显示操作菜单（删除、置顶）

**正常流程**:
  1. 加载书架数据
  2. 渲染小说卡片
  3. 显示阅读进度
  4. 有新更新时显示标记

**异常流程/边界情况**:
  - 封面加载失败: 显示默认封面

**权限控制**: 登录用户

**输入输出规则**:
  - 输入: 书架数据
  - 输出: 卡片DOM

**业务规则**:
  - 有更新的小说排在前面
  - 最近阅读的小说排在前面
  - 最多显示200本，超出提示整理书架

**优先级**: P0

**验收标准**:
  - [ ] AC1: 卡片信息正确显示
  - [ ] AC2: 阅读进度正确
  - [ ] AC3: 更新标记正确显示
  - [ ] AC4: 点击跳转正确

**来源**: bookshelf.html L161-L280

**权限控制**: 登录用户

**输入输出规则**:
  - 输入: 小说ID
  - 输出: 页面跳转

**优先级**: P0

**验收标准**:
  - [ ] AC1: 跳转至正确章节
  - [ ] AC2: 阅读位置恢复正确
  - [ ] AC3: 无记录时跳转第一章

### 2.4 管理模式

#### 需求ID: BS-MANAGE-001

**需求名称**: 批量删除

**功能描述**: 批量删除书架小说

**触发条件**: 用户在管理模式下选择并删除

**前置条件**: 用户已登录，处于管理模式

**操作步骤**:
  1. 进入管理模式
  2. 选择要删除的小说（可多选）
  3. 点击"删除"按钮
  4. 确认删除
  5. 执行删除

**正常流程**:
  1. 显示复选框
  2. 选择小说（可全选）
  3. 点击删除弹出确认框
  4. 确认后从书架移除
  5. 显示删除成功提示

**异常流程/边界情况**:
  - 未选择任何小说: 删除按钮禁用
  - 删除失败: 提示"删除失败，请重试"

**权限控制**: 登录用户

**输入输出规则**:
  - 输入: 小说ID列表
  - 输出: 删除结果

**优先级**: P0

**验收标准**:
  - [ ] AC1: 复选框功能正常
  - [ ] AC2: 全选功能正常
  - [ ] AC3: 删除确认框正常
  - [ ] AC4: 删除后书架更新

**来源**: bookshelf.html L321-L400
