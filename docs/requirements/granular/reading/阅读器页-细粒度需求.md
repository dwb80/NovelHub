### 3.2 翻页方式

#### 需求ID: READER-PAGE-001

**需求名称**: 翻页/滚动方式

**功能描述**: 支持多种阅读翻页方式

**翻页模式**:
| 模式 | 说明 | 触发方式 |
|------|------|----------|
| 滚动模式 | 垂直滚动阅读 | 默认，鼠标滚轮/触摸滑动 |
| 翻页模式 | 左右翻页 | 点击屏幕左右侧/键盘左右键 |
| 自动阅读 | 自动滚动 | 开启后按设定速度自动滚动 |

**翻页区域**（翻页模式下）:
```
┌─────────────────────────────────┐
│         上一页区域 (30%)         │
│                                 │
├─────────────────────────────────┤
│                                 │
│         菜单区域 (40%)          │
│                                 │
├─────────────────────────────────┤
│         下一页区域 (30%)         │
└─────────────────────────────────┘
```

**优先级**: P1

## 7. 阅读进度

### 7.1 进度保存

#### 需求ID: READER-PROGRESS-001

**需求名称**: 阅读进度保存

**功能描述**: 自动保存和恢复阅读进度

**保存时机**:
| 事件 | 操作 |
|------|------|
| 每30秒 | 自动保存 |
| 切换章节 | 保存上一章进度 |
| 关闭页面 | 保存当前进度 |
| 滚动停止 | 防抖保存 |

**进度数据**:
```typescript
interface ReadingProgress {
  novelId: string;
  chapterId: string;
  chapterNumber: number;
  scrollPosition: number;
  percentage: number;
  lastReadAt: Date;
}
```

**恢复阅读**:
- 打开阅读器时恢复上次位置
- 显示"继续阅读"提示
- 支持"从头开始"选项

**优先级**: P0

## 9. 性能优化

| 优化点 | 策略 |
|--------|------|
| 内容加载 | 当前章节预加载前后各1章 |
| 图片懒加载 | 图片进入视口才加载 |
| 进度保存 | 防抖处理，减少写入 |
| 虚拟滚动 | 超长章节虚拟渲染 |
