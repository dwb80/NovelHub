## 12. 数据需求汇总

### 12.1 存储结构

```typescript
interface ReaderSettings {
  font: string;           // 字体
  fontSize: number;       // 字号 (12-32)
  fontWeight: number;     // 字重 (300-600)
  lineHeight: number;     // 行高 (1.5-2.2)
  paragraphSpacing: number; // 段间距 (0.5-1.5em)
  indent: number;         // 首行缩进 (0-2em)
  theme: string;          // 主题名称
  pageMode: string;       // 翻页模式
  pageAnimation: string;  // 翻页动画
  autoRead: boolean;      // 自动阅读开关
  autoReadSpeed: number;  // 自动阅读速度 (1-10)
  keepScreenOn: boolean;  // 屏幕常亮
  fullScreen: boolean;    // 全屏阅读
  showProgress: boolean;  // 显示进度
  showTime: boolean;      // 显示时间
  showBattery: boolean;   // 显示电量
}
```

### 12.2 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/user/reader-settings | GET | 获取阅读设置 |
| /api/user/reader-settings | PUT | 更新阅读设置 |
