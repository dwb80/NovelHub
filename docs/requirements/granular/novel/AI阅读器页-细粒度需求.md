# AI阅读器页细粒度需求文档

**最后更新**: 2026-04-13

---

## 1. 页面整体结构

### 1.1 页面元数据

| 属性 | 值 |
|------|-----|
| 页面标题 | 第{X}章：{章节名} - {小说名} - 小说阅读平台 |
| 页面路径 | /novel/{novel_id}/reader/{chapter_id} |
| 登录要求 | 无需登录(阅读)，需登录(记录进度) |
| 角色权限 | 公开访问 |

### 1.2 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│  阅读器头部 (固定顶部，滚动时隐藏/显示)                           │
│  [返回] 第{X}章：{章节名}                    [目录] [设置] [夜间] │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                         阅读内容区                               │
│                                                                 │
│                      第{X}章：{章节名}                           │
│                                                                 │
│                        章节正文...                               │
│                                                                 │
│                     (羊皮纸背景色)                               │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│  章节导航                                                       │
│  [← 上一章]              [返回目录]              [下一章 →]      │
├─────────────────────────────────────────────────────────────────┤
│  阅读器底部 (固定底部，滚动时隐藏/显示)                           │
│  [上一章] [目录] [进度 45%] [夜间] [设置] [下一章]               │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 响应式断点

| 断点 | 布局变化 |
|------|----------|
| ≥768px | 内容区最大宽度800px，居中显示 |
| <768px | 内容区全宽，减小边距 |
