## 4. 个人资料面板

### 4.1 头像与昵称

#### 需求ID: SETTINGS-PROFILE-001

**需求名称**: 头像上传

**功能描述**: 更换用户头像

**区域结构**:
| 元素 | 说明 |
|------|------|
| 当前头像 | 显示当前头像 |
| 上传按钮 | "更换头像"按钮 |

**交互**:
1. 点击上传按钮
2. 弹出文件选择框
3. 选择图片文件
4. 预览并裁剪
5. 确认上传

**约束**:
- 支持格式: jpg, png, gif
- 最大尺寸: 2MB
- 建议尺寸: 200x200px

**优先级**: P0

**功能描述**: 设置用户昵称

- 不能包含特殊字符
- 不能与其他用户重复

**优先级**: P0

## 5. 账户安全面板

### 5.1 密码修改

#### 需求ID: SETTINGS-ACCOUNT-001

**需求名称**: 修改密码

**功能描述**: 修改登录密码

**输入字段**:
| 字段 | 说明 | 规则 |
|------|------|------|
| 当前密码 | 验证身份 | 必填 |
| 新密码 | 新密码 | 8-20字符，包含字母和数字 |
| 确认密码 | 确认新密码 | 必须与新密码一致 |

**验证规则**:
- 当前密码必须正确
- 新密码不能与原密码相同
- 新密码必须包含字母和数字
- 两次输入必须一致

**优先级**: P0

## 11. 数据需求汇总

### 11.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/user/profile | GET | 获取用户资料 |
| /api/user/profile | PUT | 更新用户资料 |
| /api/user/avatar | POST | 上传头像 |
| /api/user/password | PUT | 修改密码 |
| /api/user/settings | GET | 获取用户设置 |
| /api/user/settings | PUT | 更新用户设置 |

### 11.2 请求参数

```typescript
interface UpdateProfileBody {
  nickname: string;
  bio?: string;
  gender?: 'male' | 'female' | '';
  birthday?: string;
  province?: string;
  city?: string;
}

interface UpdateSettingsBody {
  reading: {
    font: string;
    fontSize: number;
    theme: string;
    pageMode: string;
  };
  notifications: {
    system: boolean;
    update: boolean;
    comment: boolean;
    like: boolean;
    follow: boolean;
    message: boolean;
  };
  privacy: {
    historyVisibility: 'public' | 'private' | 'followers';
    bookshelfVisibility: 'public' | 'private' | 'followers';
    // ...
  };
}
```

## 12. 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 昵称重复 | 显示错误提示"该昵称已被使用" |
| 头像上传失败 | 显示错误提示，保留原头像 |
| 密码错误 | 显示错误提示"当前密码不正确" |
| 保存失败 | 显示错误提示，保留修改内容 |
