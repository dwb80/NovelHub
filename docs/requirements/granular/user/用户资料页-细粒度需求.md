## 3. 左侧个人信息边栏

### 3.1 个人资料卡片

#### 需求ID: PROF-CARD-001

**需求名称**: 个人资料卡片

**功能描述**: 展示用户头像、昵称、等级、简介和阅读统计

**触发条件**: 页面加载完成

**前置条件**: 用户已登录

**卡片结构**:
| 元素 | 说明 | 数据来源 |
|------|------|----------|
| 头像 | 100x100px圆形头像 | localStorage或默认头像 |
| 编辑按钮 | 悬浮在头像右下角 | 点击触发文件选择 |
| 昵称 | 用户显示名称 | localStorage.nickname |
| 等级 | 用户等级标识 | 固定显示"Lv.12 资深书虫" |
| 简介 | 个性签名 | localStorage.bio |
| 阅读统计 | 三列统计数据 | MockData |

**头像编辑**:
- 点击编辑按钮打开文件选择器
- 支持图片格式: image/*
- 文件大小限制: 2MB
- 超限时提示: "图片大小不能超过 2MB"
- 使用FileReader预览图片

**阅读统计数据**:
| 统计项 | 显示值 | 说明 |
|--------|--------|------|
| 阅读本 | 128 | 已读小说数量 |
| 阅读章 | 3.2k | 已读章节数量 |
| 阅读天 | 365 | 累计阅读天数 |

**编辑资料按钮**:
- 图标: 设置齿轮图标
- 文字: "编辑资料"
- 点击跳转: settings.html

**样式**:
- 卡片背景: var(--color-bg-elevated)
- 边框: 1px solid var(--color-border)
- 圆角: var(--radius-xl)
- 内边距: 1.5rem
- 头像边框: 3px solid var(--color-primary-light)

**优先级**: P0

**验收标准**:
- [ ] AC1: 头像正确显示
- [ ] AC2: 头像编辑功能正常
- [ ] AC3: 用户信息显示正确
- [ ] AC4: 编辑资料按钮可点击

**来源**: [profile.html L70-109](file:///d:/trae/xiaoshuo/html/pages/user/profile.html#L70-L109)
