## 3. 筛选栏

### 3.1 筛选条件组

#### 需求ID: CATEGORY-FILTER-001

**需求名称**: 分类筛选

**功能描述**: 按分类、状态、字数等条件筛选小说

**筛选组结构**:
| 筛选组 | 选项 |
|--------|------|
| 分类 | 全部、玄幻、都市、言情、科幻、历史、游戏、悬疑、武侠、军事、体育、轻小说 |
| 状态 | 全部、连载中、已完结 |
| 字数 | 全部、30万以下、30-50万、50-100万、100万以上 |
| 排序 | 热门、最新、评分、字数 |

**组件**: 横向筛选栏，每组包含标签选项

**样式规则**:
- 背景: var(--color-bg-elevated)
- 圆角: var(--radius-lg)
- 边框: 1px solid var(--color-border)
- 内边距: 1rem
- 筛选组间距: 1rem

**选项样式**:
- 默认: 灰色背景，圆角
- 选中: primary色背景，primary色边框
- 悬停: 背景色加深

**交互**:
- 点击选项切换选中状态
- 多选或单选根据筛选组确定
- 选择后立即更新小说列表

**优先级**: P0

## 7. 数据需求汇总

### 7.1 API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| /api/categories | GET | 获取所有分类 |
| /api/novels | GET | 获取小说列表（支持筛选和排序） |

### 7.2 请求参数

```typescript
interface GetNovelsParams {
  category?: string;      // 分类
  status?: string;        // 状态
  wordCount?: string;     // 字数范围
  sortBy?: string;        // 排序字段
  sortOrder?: 'asc' | 'desc';
  page?: number;
  pageSize?: number;
}

interface Category {
  id: string;
  name: string;
  icon: string;
  count: number;
  description: string;
}
```

## 8. 性能要求

- 分类网格首屏渲染 < 500ms
- 小说列表分页加载 < 1s
- 筛选切换响应 < 300ms

## 9. 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 分类加载失败 | 显示错误提示，提供重试 |
| 小说列表加载失败 | 显示错误提示，保留当前列表 |
