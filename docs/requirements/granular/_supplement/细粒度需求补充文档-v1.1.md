## 1. 文档概述

### 1.1 补充背景
基于需求文档与HTML原型的一致性检查，发现部分细粒度需求需要补充完善，以确保开发团队能够准确理解和实现所有功能。

### 1.2 补充原则
- **完整性**: 补充所有缺失的交互细节、边界情况、校验规则
- **可测试性**: 每个需求都有明确的验收标准
- **一致性**: 保持与现有需求文档的格式和术语一致
- **可追溯性**: 每个补充需求标注来源和依据

### 1.3 补充内容分类
| 类别 | 说明 | 优先级 |
|------|------|--------|
| 交互细节 | 用户操作的详细反馈和状态变化 | P0 |
| 边界情况 | 异常流程和极限情况处理 | P0 |
| 数据校验 | 输入数据的验证规则 | P0 |
| 性能指标 | 响应时间、加载时间等量化指标 | P1 |
| 安全要求 | 安全防护和数据保护 | P0 |
| 无障碍支持 | 辅助功能和键盘导航 | P1 |

## 2. 用户认证模块补充

### 2.1 登录页补充需求

#### 需求ID: LOGIN-FORM-001-SUP
**需求名称**: 表单字段实时校验

**功能描述**: 用户输入时实时校验字段格式，即时反馈错误信息

**触发条件**: 用户在表单字段输入或失去焦点时

**前置条件**: 表单字段已渲染完成

**校验规则**:
| 字段 | 校验规则 | 错误提示 | 校验时机 |
|------|----------|----------|----------|
| 邮箱 | 符合RFC 5322标准邮箱格式 | "请输入有效的邮箱地址" | 失焦时 |
| 密码 | 长度8-20位，包含至少1字母+1数字 | "密码需8-20位，包含字母和数字" | 输入时+失焦时 |
| 验证码 | 4-6位数字或字母 | "验证码格式错误" | 失焦时 |

**正常流程**:
1. 用户输入字段内容
2. 系统根据校验规则验证
3. 验证通过：显示绿色对勾图标
4. 验证失败：显示红色错误提示，边框变红

**异常流程/边界情况**:
- **输入为空**: 显示"此字段为必填项"
- **输入包含特殊字符**: 过滤或提示"包含非法字符"
- **输入超长**: 截断至最大长度，显示字数统计

**UI反馈**:
| 状态 | 边框颜色 | 图标 | 提示文字 |
|------|----------|------|----------|
| 默认 | #e5e7eb | 无 | 无 |
| 聚焦 | #6366f1 | 无 | 无 |
| 验证中 | #6366f1 | 加载动画 | "验证中..." |
| 验证通过 | #10b981 | 绿色对勾 | 无 |
| 验证失败 | #ef4444 | 红色感叹号 | 红色错误文字 |

**性能要求**:
- 校验响应时间 < 50ms
- 防抖处理：输入停止200ms后执行校验

**优先级**: P0

**验收标准**:
- AC1: 邮箱格式校验正确识别有效/无效邮箱
- AC2: 密码强度实时显示（弱/中/强）
- AC3: 错误提示在失焦后300ms内显示
- AC4: 验证通过状态在输入正确后立即显示

#### 需求ID: LOGIN-SECURITY-001-SUP
**需求名称**: 登录安全防护措施

**功能描述**: 实现多层次安全防护，防止暴力破解和异常登录

**触发条件**: 用户提交登录表单

**前置条件**: 表单验证通过

**安全防护规则**:
| 防护措施 | 规则 | 触发条件 |
|----------|------|----------|
| 登录频率限制 | 同一IP 1分钟内最多5次尝试 | 连续登录失败 |
| 账号锁定 | 连续5次失败锁定30分钟 | 同一账号 |
| 验证码要求 | 第3次失败起要求验证码 | 连续失败次数>=3 |
| 设备验证 | 新设备登录需邮箱验证 | 首次在新设备登录 |
| 异地登录提醒 | 检测登录IP地理位置变化 | IP归属地变化 |

**安全提示**:
- 登录失败时统一提示"账号或密码错误"，不区分具体错误
- 账号锁定时提示"账号已锁定，请30分钟后重试或联系客服"
- 新设备登录发送验证邮件，有效期15分钟

**日志记录**:
| 事件 | 记录内容 | 保留期限 |
|------|----------|----------|
| 登录成功 | 时间、IP、设备、UA | 90天 |
| 登录失败 | 时间、IP、账号、失败原因 | 90天 |
| 账号锁定 | 时间、账号、锁定原因 | 180天 |
| 异常登录 | 时间、账号、IP、风险类型 | 365天 |

**优先级**: P0

**验收标准**:
- AC1: 连续5次错误密码后账号正确锁定
- AC2: 锁定期间登录提示正确的锁定信息
- AC3: 新设备登录触发邮箱验证流程
- AC4: 所有安全事件正确记录日志

#### 需求ID: LOGIN-SESSION-001-SUP
**需求名称**: 登录会话管理

**功能描述**: 管理用户登录会话，支持多设备登录控制和会话过期处理

**触发条件**: 用户登录成功或主动操作

**会话规则**:
| 配置项 | 规则 | 说明 |
|--------|------|------|
| Token有效期 | 24小时 | 普通登录 |
| 记住我有效期 | 30天 | 勾选记住我 |
| 最大同时登录 | 5个设备 | 超出时踢出最早设备 |
| 空闲超时 | 30分钟无操作自动登出 | 仅前端 |
| 强制下线通知 | WebSocket推送 | 账号在其他地方登录 |

**会话管理功能**:
1. **查看活跃会话**: 用户可在设置中查看所有登录设备
2. **远程登出**: 可踢出其他设备的登录状态
3. **会话续期**: Token过期前自动刷新（过期前1小时）

**Token刷新机制**:
- Access Token: 有效期2小时
- Refresh Token: 有效期30天
- 刷新窗口: Access Token过期前1小时可刷新

**优先级**: P1

**验收标准**:
- AC1: Token在有效期内可正常访问
- AC2: Token过期后自动跳转登录页
- AC3: 多设备登录限制正确生效
- AC4: 远程登出后设备立即失效

### 2.2 注册页补充需求

#### 需求ID: REGISTER-VALIDATION-001-SUP
**需求名称**: 注册表单完整校验

**功能描述**: 对注册表单进行全面的数据校验，确保数据质量

**校验规则**:
| 字段 | 必填 | 最小长度 | 最大长度 | 格式要求 | 唯一性校验 |
|------|------|----------|----------|----------|------------|
| 邮箱 | 是 | - | 100 | 邮箱格式 | 实时校验 |
| 手机号 | 否 | 11 | 11 | 大陆手机号 | 实时校验 |
| 密码 | 是 | 8 | 20 | 字母+数字 | - |
| 确认密码 | 是 | 8 | 20 | 与密码一致 | - |
| 昵称 | 是 | 2 | 20 | 不含特殊字符 | 实时校验 |
| 验证码 | 是 | 4 | 6 | 数字/字母 | - |
| 用户协议 | 是 | - | - | 必须勾选 | - |

**昵称校验规则**:
- 允许：中文、英文、数字、下划线
- 不允许：连续3个相同字符、纯数字、敏感词
- 正则：`^[\u4e00-\u9fa5a-zA-Z0-9_]{2,20}$`

**密码强度规则**:
| 强度 | 规则 | 提示颜色 |
|------|------|----------|
| 弱 | 仅满足基本要求 | 红色 |
| 中 | 包含大小写字母+数字 | 黄色 |
| 强 | 包含大小写字母+数字+特殊字符 | 绿色 |

**优先级**: P0

**验收标准**:
- AC1: 所有必填字段未填写时阻止提交
- AC2: 邮箱/手机号重复时实时提示
- AC3: 密码强度指示器正确显示
- AC4: 昵称特殊字符过滤正确

```
开始注册
  ↓
填写注册信息
  ↓
前端校验通过？
  ├─ 否 → 显示错误提示 → 重新填写
  ↓ 是

  ↓

  ↓

  ↓

  ├─ 否 → 显示错误 → 修改信息
  ↓ 是

  ↓
发送欢迎邮件
  ↓
自动登录
  ↓
跳转引导页/首页

结束
```

| 错误次数 | 最多3次，超出需重新获取 |
| 格式 | 6位数字 |

**欢迎邮件内容**:
- 标题: "欢迎加入NovelHub - 开启您的阅读之旅"
- 内容: 包含平台介绍、新手指引链接、客服联系方式
- 发送时机: 注册成功后5分钟内

**优先级**: P0

**验收标准**:
- AC1: 完整注册流程可在3分钟内完成
- AC2: 验证码5分钟后失效
- AC3: 注册成功后自动登录
- AC4: 欢迎邮件正确发送
