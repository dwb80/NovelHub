# NovelHub 细粒度需求文档

## 概述

本文档对 NovelHub 平台的各项功能进行细粒度拆解，确保每个需求点都可被独立开发、测试和验收。

---

## 1. 用户管理模块

### 1.1 用户注册

#### USR-001: 邮箱注册
- **功能描述**: 用户通过邮箱地址注册账号
- **触发条件**: 用户点击"注册"按钮并选择邮箱注册方式
- **前置条件**: 邮箱地址未被注册
- **操作步骤**:
  1. 输入邮箱地址
  2. 设置密码（8-20位，包含字母和数字）
  3. 确认密码
  4. 输入验证码
  5. 同意用户协议
  6. 点击注册按钮
- **正常流程**: 验证通过 → 创建账号 → 发送验证邮件 → 跳转登录页
- **异常流程**:
  - 邮箱已存在: 提示"该邮箱已被注册"
  - 密码格式不符: 提示密码规则
  - 验证码错误: 提示重新输入
- **权限控制**: 无限制
- **输入输出规则**:
  - 输入: email(字符串,邮箱格式), password(字符串,8-20位), confirmPassword(字符串), captcha(字符串,4-6位)
  - 输出: userId(整数), token(字符串)
- **业务规则**: 密码需加密存储(MD5+Salt)
- **优先级**: P0
- **验收标准**:
  - [ ] AC1: 邮箱格式验证正确
  - [ ] AC2: 密码强度校验生效
  - [ ] AC3: 注册成功后发送验证邮件

#### USR-002: 手机号注册
- **功能描述**: 用户通过手机号注册账号
- **触发条件**: 用户选择手机号注册方式
- **前置条件**: 手机号未被注册
- **操作步骤**:
  1. 输入手机号
  2. 获取短信验证码
  3. 输入短信验证码
  4. 设置密码
  5. 同意用户协议
- **正常流程**: 验证通过 → 创建账号 → 自动登录 → 跳转首页
- **异常流程**:
  - 手机号已存在: 提示"该手机号已被注册"
  - 验证码过期: 提示"验证码已过期，请重新获取"
- **权限控制**: 无限制
- **优先级**: P1

#### USR-003: 第三方登录
- **功能描述**: 支持微信、QQ、微博快捷登录
- **触发条件**: 用户点击第三方登录图标
- **前置条件**: 已安装对应APP或已登录对应平台
- **操作步骤**:
  1. 点击第三方图标
  2. 授权确认
  3. 绑定手机号（首次登录）
- **正常流程**: 授权成功 → 获取用户信息 → 创建/绑定账号 → 登录成功
- **优先级**: P1

### 1.2 用户登录

#### USR-004: 账号密码登录
- **功能描述**: 使用账号密码登录系统
- **触发条件**: 用户访问登录页面
- **前置条件**: 账号已注册
- **操作步骤**:
  1. 输入账号（邮箱/手机号）
  2. 输入密码
  3. 可选：勾选"记住我"
  4. 点击登录
- **正常流程**: 验证成功 → 生成Token → 跳转首页
- **异常流程**:
  - 账号不存在: 提示"账号或密码错误"
  - 密码错误: 提示"账号或密码错误"（不区分）
  - 账号锁定: 提示"账号已被锁定，请联系客服"
- **业务规则**: 连续5次密码错误锁定账号30分钟
- **优先级**: P0

#### USR-005: 验证码登录
- **功能描述**: 使用手机号+短信验证码登录
- **触发条件**: 用户选择验证码登录
- **操作步骤**:
  1. 输入手机号
  2. 获取验证码
  3. 输入验证码
  4. 点击登录
- **优先级**: P1

### 1.3 个人中心

#### USR-006: 个人信息管理
- **功能描述**: 管理用户基本信息
- **字段**: 昵称、头像、性别、生日、个性签名
- **优先级**: P1

#### USR-007: 修改密码
- **功能描述**: 修改登录密码
- **操作步骤**:
  1. 输入原密码
  2. 输入新密码
  3. 确认新密码
  4. 提交
- **业务规则**: 新密码不能与旧密码相同
- **优先级**: P1

## 2. 小说阅读模块

### 2.1 小说详情

#### RD-001: 小说信息展示
- **功能描述**: 展示小说的详细信息
- **展示内容**:
  - 封面图（高清）
  - 标题（主标题+副标题）
  - 作者信息（头像、昵称、等级）
  - 分类标签
  - 简介（展开/收起）
  - 状态（连载/完结）
  - 字数统计
  - 更新时间
  - 评分（1-5星，支持小数）
  - 阅读数
  - 收藏数
- **优先级**: P0

#### RD-002: 章节列表
- **功能描述**: 展示小说所有章节
- **功能点**:
  - 正序/倒序切换
  - 章节搜索
  - 最新章节标识
  - VIP章节标识
  - 已读章节标识
  - 分页加载（每页50章）
- **优先级**: P0

#### RD-003: 相关推荐
- **功能描述**: 推荐相似小说
- **推荐维度**:
  - 同作者作品
  - 同分类作品
  - 读者还喜欢
- **展示数量**: 6本
- **优先级**: P2

#### RD-004: 评论互动
- **功能描述**: 展示和发表书评
- **功能点**:
  - 评论列表（分页，每页20条）
  - 评论排序（最新/最热）
  - 发表评论（字数限制10-500字）
  - 点赞评论
  - 回复评论
  - 举报评论
- **优先级**: P1

### 2.2 阅读器

#### RD-005: 阅读界面
- **功能描述**: 小说正文阅读界面
- **核心功能**:
  - 章节内容渲染
  - 翻页模式（滚动/左右翻页）
  - 预加载下一章
  - 阅读进度显示
  - 章节切换
- **优先级**: P0

#### RD-006: 字体设置
- **功能描述**: 自定义阅读字体
- **设置项**:
  - 字体大小（12px-24px，6档）
  - 行间距（紧凑/适中/宽松）
  - 字间距（默认/加宽）
- **优先级**: P1

#### RD-007: 主题设置
- **功能描述**: 切换阅读背景主题
- **主题选项**:
  - 日间模式（白底黑字）
  - 夜间模式（黑底灰字）
  - 护眼模式（米黄底）
  - 纸质模式（仿真纸纹）
- **优先级**: P1

#### RD-008: 目录导航
- **功能描述**: 快速跳转到指定章节
- **功能点**:
  - 侧滑目录面板
  - 当前章节高亮
  - 点击跳转
  - 书签快速定位
- **优先级**: P0

#### RD-009: 书签功能
- **功能描述**: 添加和管理书签
- **功能点**:
  - 添加书签（记录当前位置）
  - 书签列表
  - 跳转到书签位置
  - 删除书签
- **优先级**: P2

#### RD-010: 阅读进度
- **功能描述**: 保存和同步阅读进度
- **功能点**:
  - 自动保存阅读位置
  - 多设备同步
  - 继续阅读提示
- **优先级**: P0

## 4. 发现模块

### 4.1 分类浏览

#### DIS-001: 分类导航
- **功能描述**: 按分类浏览小说
- **分类维度**:
  - 男生频道（玄幻、都市、仙侠、科幻等）
  - 女生频道（言情、古言、现言、玄幻等）

- **筛选条件**:

  - 更新时间（3天内/7天内/30天内）
  - 评分（9分以上/8分以上）
- **优先级**: P0

#### DIS-002: 排行榜
- **功能描述**: 各类排行榜展示
- **榜单类型**:
  - 点击榜

  - 推荐榜
  - 新书榜
  - 完结榜
- **时间维度**: 日榜/周榜/月榜/总榜
- **优先级**: P1

### 4.2 搜索功能

- **必填信息**:
  - 作品名称（2-30字）

#### CRT-002: 作品列表
- **功能描述**: 管理已创建的作品
- **展示信息**:
  - 作品封面
  - 作品名称
  - 状态（连载/完结/暂停）
  - 字数统计
  - 阅读量
  - 操作按钮

#### CRT-003: 作品设置
- **功能描述**: 修改作品信息
- **可修改项**: 简介、标签、封面、状态

## 6. 非功能需求

### 6.1 性能需求

#### NF-001: 页面加载性能
- **指标**: 首屏加载时间 < 3秒
- **测量方式**: Lighthouse Performance Score >= 90
- **优先级**: P0

#### NF-002: 接口响应性能
- **指标**: API响应时间 < 500ms（P95）
- **测量方式**: 服务端监控
- **优先级**: P0

#### NF-003: 并发能力
- **指标**: 支持10000+并发用户
- **优先级**: P1

### 6.2 安全需求

#### NF-004: 数据加密
- **要求**: 用户密码使用BCrypt加密
- **要求**: 敏感接口使用HTTPS
- **优先级**: P0

#### NF-005: 访问控制
- **要求**: 接口鉴权（JWT Token）
- **要求**: 敏感操作二次验证
- **优先级**: P0

#### NF-006: 防护机制
- **要求**: 防SQL注入
- **要求**: 防XSS攻击
- **要求**: 防CSRF攻击
- **要求**: 接口限流（防刷）
- **优先级**: P0

### 6.3 可用性需求

#### NF-007: 系统可用性
- **指标**: 可用性 >= 99.9%
- **允许停机时间**: 每月 < 43分钟
- **优先级**: P1

#### NF-008: 数据备份
- **要求**: 数据库每日备份
- **要求**: 备份保留30天
- **优先级**: P1

### 6.4 兼容性需求

#### NF-009: 浏览器兼容
- **要求**: 支持Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **优先级**: P0

#### NF-010: 移动端适配
- **要求**: 支持iOS 12+, Android 8+
- **要求**: 响应式布局
- **优先级**: P0

### 6.5 体验需求

#### NF-011: 无障碍支持
- **要求**: 支持屏幕阅读器
- **要求**: 键盘可操作
- **要求**: 符合WCAG 2.1 AA标准
- **优先级**: P2
