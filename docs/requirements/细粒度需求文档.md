## 1. 用户管理模块

### 1.1 用户注册

#### USR-001: 邮箱注册
- **功能描述**: 用户通过邮箱地址注册账号
- **实现状态**: ⚠️ 部分实现
- **触发条件**: 用户点击"注册"按钮并选择邮箱注册方式
- **前置条件**: 邮箱地址未被注册
- **操作步骤**:
  1. 输入邮箱地址
  2. 设置密码（8-20位，包含字母和数字）
  3. 确认密码
  4. 输入验证码
  5. 同意用户协议
  6. 点击注册按钮
- **正常流程**: 验证通过 → 创建账号 → 发送验证邮件 → 跳转登录页
- **异常流程**:
  - 邮箱已存在: 提示"该邮箱已被注册"
  - 密码格式不符: 提示密码规则
  - 验证码错误: 提示重新输入
- **权限控制**: 无限制
- **输入输出规则**:
  - 输入: email(字符串,邮箱格式), password(字符串,8-20位), confirmPassword(字符串), captcha(字符串,4-6位)
  - 输出: userId(整数), token(字符串)
- **业务规则**: 密码需加密存储(MD5+Salt)
- **优先级**: P0
- **差异说明**: 密码强度校验规则需确认，邮件发送功能需验证
- **验收标准**:
  - [ ] AC1: 邮箱格式验证正确
  - [ ] AC2: 密码强度校验生效
  - [ ] AC3: 注册成功后发送验证邮件

#### USR-002: 手机号注册
- **功能描述**: 用户通过手机号注册账号
- **触发条件**: 用户选择手机号注册方式
- **前置条件**: 手机号未被注册
- **操作步骤**:
  1. 输入手机号
  2. 获取短信验证码
  3. 输入短信验证码
  4. 设置密码
  5. 同意用户协议
- **正常流程**: 验证通过 → 创建账号 → 自动登录 → 跳转首页
- **异常流程**:
  - 手机号已存在: 提示"该手机号已被注册"
  - 验证码过期: 提示"验证码已过期，请重新获取"
- **权限控制**: 无限制
- **优先级**: P1

#### USR-003: 第三方登录
- **功能描述**: 支持微信、QQ、微博快捷登录
- **触发条件**: 用户点击第三方登录图标
- **前置条件**: 已安装对应APP或已登录对应平台
- **操作步骤**:
  1. 点击第三方图标
  2. 授权确认
  3. 绑定手机号（首次登录）
- **正常流程**: 授权成功 → 获取用户信息 → 创建/绑定账号 → 登录成功
- **优先级**: P1

### 1.2 用户登录

#### USR-004: 账号密码登录
- **功能描述**: 使用账号密码登录系统
- **触发条件**: 用户访问登录页面
- **前置条件**: 账号已注册
- **操作步骤**:
  1. 输入账号（邮箱/手机号）
  2. 输入密码
  3. 可选：勾选"记住我"
  4. 点击登录
- **正常流程**: 验证成功 → 生成Token → 跳转首页
- **异常流程**:
  - 账号不存在: 提示"账号或密码错误"
  - 密码错误: 提示"账号或密码错误"（不区分）
  - 账号锁定: 提示"账号已被锁定，请联系客服"
- **业务规则**: 连续5次密码错误锁定账号30分钟
- **优先级**: P0

#### USR-005: 验证码登录
- **功能描述**: 使用手机号+短信验证码登录
- **触发条件**: 用户选择验证码登录
- **操作步骤**:
  1. 输入手机号
  2. 获取验证码
  3. 输入验证码
  4. 点击登录
- **优先级**: P1
