### 1.2 数据表结构

#### 用户表 (user)

| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| user_id | SERIAL | - | 否 | 自增 | 主键 |
| username | VARCHAR | 50 | 否 | - | 用户名 |
| email | VARCHAR | 100 | 是 | NULL | 邮箱 |
| phone | VARCHAR | 20 | 是 | NULL | 手机号 |
| password | VARCHAR | 255 | 否 | - | 加密密码 |
| avatar | VARCHAR | 255 | 是 | NULL | 头像URL |
| gender | SMALLINT | - | 是 | 0 | 性别:0未知,1男,2女 |
| birthday | DATE | - | 是 | NULL | 生日 |
| signature | VARCHAR | 200 | 是 | NULL | 个性签名 |
| status | SMALLINT | - | 否 | 1 | 状态:0禁用,1正常 |
| created_at | TIMESTAMP | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | - | 否 | CURRENT_TIMESTAMP | 更新时间 |

#### 小说表 (book)

| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| book_id | SERIAL | - | 否 | 自增 | 主键 |
| author_id | INTEGER | - | 否 | - | 作者ID |
| title | VARCHAR | 100 | 否 | - | 书名 |
| subtitle | VARCHAR | 100 | 是 | NULL | 副标题 |
| summary | TEXT | - | 是 | NULL | 简介 |
| cover | VARCHAR | 255 | 是 | NULL | 封面URL |
| category | VARCHAR | 50 | 否 | - | 分类 |
| tags | VARCHAR | 255 | 是 | NULL | 标签,逗号分隔 |
| status | SMALLINT | - | 否 | 0 | 状态:0连载,1完结,2暂停 |
| word_count | INTEGER | - | 否 | 0 | 总字数 |
| view_count | INTEGER | - | 否 | 0 | 阅读数 |
| collect_count | INTEGER | - | 否 | 0 | 收藏数 |
| rating | DECIMAL | 2,1 | 否 | 0.0 | 评分 |
| rating_count | INTEGER | - | 否 | 0 | 评分人数 |
| created_at | TIMESTAMP | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | - | 否 | CURRENT_TIMESTAMP | 更新时间 |

#### 章节表 (chapter)

| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| chapter_id | SERIAL | - | 否 | 自增 | 主键 |
| book_id | INTEGER | - | 否 | - | 小说ID |
| title | VARCHAR | 100 | 否 | - | 章节标题 |
| content | TEXT | - | 否 | - | 章节内容 |
| sequence | INTEGER | - | 否 | 0 | 章节序号 |
| word_count | INTEGER | - | 否 | 0 | 字数 |
| status | SMALLINT | - | 否 | 0 | 状态:0草稿,1已发布 |
| is_vip | SMALLINT | - | 否 | 0 | 是否VIP:0否,1是 |
| created_at | TIMESTAMP | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | - | 否 | CURRENT_TIMESTAMP | 更新时间 |

#### 书架表 (bookshelf)

| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| shelf_id | SERIAL | - | 否 | 自增 | 主键 |
| user_id | INTEGER | - | 否 | - | 用户ID |
| book_id | INTEGER | - | 否 | - | 小说ID |
| category_id | INTEGER | - | 是 | NULL | 分类ID |
| progress | DECIMAL | 5,2 | 否 | 0.00 | 阅读进度 |
| last_chapter_id | INTEGER | - | 是 | NULL | 最后阅读章节 |

## 2. 接口设计

### 2.1 RESTful API规范

#### 用户相关接口

```
POST   /api/auth/register          # 用户注册
POST   /api/auth/login             # 用户登录
POST   /api/auth/logout            # 用户登出
POST   /api/auth/refresh           # 刷新Token
GET    /api/user/profile           # 获取用户信息
PUT    /api/user/profile           # 更新用户信息
PUT    /api/user/password          # 修改密码
POST   /api/user/avatar            # 上传头像
```

#### 小说相关接口

```
GET    /api/books                  # 获取小说列表
GET    /api/books/{id}             # 获取小说详情
GET    /api/books/{id}/chapters    # 获取章节列表
GET    /api/books/{id}/chapters/{chapterId}  # 获取章节内容
GET    /api/books/{id}/comments    # 获取评论列表
POST   /api/books/{id}/comments    # 发表评论
POST   /api/books/{id}/collect     # 收藏/取消收藏
```

#### 书架相关接口

```
GET    /api/bookshelf              # 获取书架列表
POST   /api/bookshelf              # 添加书籍到书架
DELETE /api/bookshelf/{bookId}     # 从书架移除
PUT    /api/bookshelf/{bookId}/progress  # 更新阅读进度
GET    /api/bookshelf/categories   # 获取书架分类
POST   /api/bookshelf/categories   # 创建分类
```

#### 搜索相关接口

```
GET    /api/search                 # 搜索小说
GET    /api/search/suggestions     # 搜索建议
```

#### 创作相关接口

```
GET    /api/creation/works         # 获取作品列表
POST   /api/creation/works         # 创建新作品
PUT    /api/creation/works/{id}    # 更新作品信息
DELETE /api/creation/works/{id}    # 删除作品
GET    /api/creation/works/{id}/chapters  # 获取章节列表
POST   /api/creation/works/{id}/chapters  # 创建新章节
PUT    /api/creation/works/{id}/chapters/{chapterId}  # 更新章节
DELETE /api/creation/works/{id}/chapters/{chapterId}  # 删除章节
```

#### OpenClaw相关接口

```
POST   /api/openclaw/activate      # 激活OpenClaw
GET    /api/openclaw/status        # 获取OpenClaw状态
POST   /api/openclaw/generate      # 生成内容
```
