# NovelHub 输入验证测试文档

**版本**: v1.0  
**更新日期**: 2026-04-12

---

## 1. 测试目标

验证 NovelHub 系统对各类输入的验证和防护能力。

## 2. 验证规则

### 2.1 用户相关

| 字段 | 规则 | 测试用例 |
|------|------|----------|
| 用户名 | 3-20字符，字母数字下划线 | 2字符、21字符、特殊符号 |
| 邮箱 | 标准邮箱格式 | 无@、无域名、特殊字符 |
| 密码 | 8-128字符，需大小写+数字 | 7字符、无大写、无数字 |
| 手机号 | 11位数字 | 10位、12位、含字母 |

### 2.2 小说相关

| 字段 | 规则 | 测试用例 |
|------|------|----------|
| 标题 | 2-200字符 | 1字符、201字符 |
| 简介 | 0-2000字符 | 2001字符 |
| 标签 | 最多5个，每标签20字符 | 6个标签、21字符标签 |
| 封面 | jpg/png/webp，最大5MB | bmp格式、6MB文件 |

### 2.3 章节相关

| 字段 | 规则 | 测试用例 |
|------|------|----------|
| 标题 | 1-100字符 | 空、101字符 |
| 内容 | 100-50000字符 | 99字符、50001字符 |
| 价格 | 0-1000金币 | -1、1001 |

## 3. 验证测试

### TC-VAL-001: 用户名验证

| 输入 | 预期结果 |
|------|----------|
| "ab" | 失败，太短 |
| "abc" | 成功 |
| "this_is_max_length_20" | 成功 |
| "this_is_max_length_21" | 失败，太长 |
| "user@name" | 失败，含特殊字符 |

### TC-VAL-002: 邮箱验证

| 输入 | 预期结果 |
|------|----------|
| "test@example.com" | 成功 |
| "test@" | 失败，不完整 |
| "test.com" | 失败，无@ |
| "test@.com" | 失败，无域名前缀 |

### TC-VAL-003: 密码验证

| 输入 | 预期结果 |
|------|----------|
| "Test@123" | 成功 |
| "test@123" | 失败，无大写 |
| "Test@test" | 失败，无数字 |
| "Test123" | 失败，无特殊字符 |

## 4. 安全验证

### 4.1 XSS 防护

| 输入 | 预期结果 |
|------|----------|
| `<script>alert(1)</script>` | 转义输出 |
| `<img src=x onerror=alert(1)>` | 转义输出 |
| `javascript:alert(1)` | 过滤或转义 |

### 4.2 SQL 注入防护

| 输入 | 预期结果 |
|------|----------|
| `' OR '1'='1` | 安全处理 |
| `'; DROP TABLE users; --` | 安全处理 |
| `1 UNION SELECT * FROM users` | 安全处理 |
