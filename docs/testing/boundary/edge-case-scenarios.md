# NovelHub 边界场景测试文档

**版本**: v1.0  
**更新日期**: 2026-04-12

---

## 1. 测试目标

验证 NovelHub 系统在极端和异常情况下的行为。

## 2. 边界场景

### 2.1 数据量边界

| 场景 | 测试数据 | 预期结果 |
|------|----------|----------|
| 超长小说标题 | 200字符标题 | 正常显示/截断 |
| 超长章节内容 | 50000字章节 | 正常加载 |
| 大量章节 | 1000章小说 | 正常显示目录 |
| 大量评论 | 10000条评论 | 分页正常 |
| 大量标签 | 5个标签上限 | 拒绝更多标签 |

### 2.2 特殊字符

| 场景 | 测试数据 | 预期结果 |
|------|----------|----------|
| HTML标签 | `<b>标题</b>` | 转义显示 |
| SQL注入 | `'; DROP TABLE` | 安全处理 |
| 表情符号 |  | 正常显示 |
| 换行符 | 多行内容 | 正确换行 |
| 零宽字符 | 零宽空格 | 正确处理 |

### 2.3 并发边界

| 场景 | 测试方法 | 预期结果 |
|------|----------|----------|
| 同时点赞 | 100人同时点赞 | 计数正确 |
| 同时购买 | 10人同时购买 | 库存正确 |
| 同时评论 | 50人同时评论 | 全部成功 |

## 3. 异常场景

### 3.1 网络异常

| 场景 | 测试方法 | 预期结果 |
|------|----------|----------|
| 断网重连 | 断开网络后恢复 | 自动重试 |
| 超时 | 延迟响应 | 提示超时 |
| 弱网 | 限速网络 | 降级处理 |

### 3.2 系统异常

| 场景 | 测试方法 | 预期结果 |
|------|----------|----------|
| 服务宕机 | 停止服务 | 友好提示 |
| 数据库故障 | 断开数据库 | 缓存服务 |
| 缓存故障 | 停止Redis | 直连数据库 |

## 4. 测试用例

### TC-EDGE-001: 超长标题

**步骤**:
1. 创建200字符标题的小说
2. 查看列表显示
3. 查看详情显示

**预期**: 正常显示，超出部分截断

### TC-EDGE-002: 特殊字符评论

**步骤**:
1. 发表含HTML标签的评论
2. 查看评论显示

**预期**: HTML标签被转义，不执行
