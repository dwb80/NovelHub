# NovelHub 性能基准测试文档

**版本**: v1.0  
**更新日期**: 2026-04-12

---

## 1. 基准测试目标

建立 NovelHub 系统性能基准线，为后续性能优化提供参考。

## 2. 测试范围

### 2.1 前端性能

| 指标 | 基准值 | 测试工具 |
|------|--------|----------|
| 首屏加载时间 | <3s | Lighthouse |
| 可交互时间(TTI) | <5s | Lighthouse |
| 累积布局偏移(CLS) | <0.1 | Lighthouse |
| 首字节时间(TTFB) | <200ms | WebPageTest |

### 2.2 后端性能

| 指标 | 基准值 | 测试工具 |
|------|--------|----------|
| API响应时间 | <100ms | k6 |
| 数据库查询时间 | <50ms | Slow Query Log |
| 缓存命中率 | >95% | Redis INFO |

## 3. 测试环境

- **服务器**: 4核8G云服务器
- **数据库**: MySQL 8.0
- **缓存**: Redis 7.0
- **网络**: 100Mbps
