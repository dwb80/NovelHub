# NovelHub 缓存一致性测试文档

**版本**: v1.0  
**更新日期**: 2026-04-12

---

## 1. 测试目标

验证 NovelHub 系统缓存与数据库的一致性。

## 2. 测试场景

### 2.1 缓存更新

| 场景 | 测试方法 | 预期结果 |
|------|----------|----------|
| 小说信息更新 | 更新小说标题 | 缓存同步更新 |
| 章节发布 | 发布新章节 | 章节列表缓存更新 |
| 用户资料修改 | 修改用户名 | 用户缓存更新 |

### 2.2 缓存失效

| 场景 | 测试方法 | 预期结果 |
|------|----------|----------|
| 小说删除 | 删除小说 | 相关缓存清除 |
| 用户注销 | 用户注销 | 会话缓存清除 |
| 数据过期 | 等待过期时间 | 缓存自动失效 |

## 3. 一致性检查

```sql
-- 检查小说数据一致性
SELECT n.id, n.title, c.title as cached_title
FROM novels n
LEFT JOIN cache c ON c.key = CONCAT('novel:', n.id)
WHERE n.updated_at > c.updated_at;
```

## 4. 测试用例

### TC-CACHE-001: 小说更新缓存同步

**步骤**:
1. 查询小说A，写入缓存
2. 更新小说A标题
3. 再次查询小说A

**预期**: 返回更新后的标题

### TC-CACHE-002: 缓存过期

**步骤**:
1. 设置缓存过期时间为5秒
2. 写入缓存数据
3. 等待5秒后查询

**预期**: 缓存已失效，从数据库读取
