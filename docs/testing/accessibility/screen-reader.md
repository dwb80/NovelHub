# NovelHub 屏幕阅读器测试文档

**版本**: v1.0  
**更新日期**: 2026-04-12

---

## 1. 测试目标

确保 NovelHub 对屏幕阅读器用户友好，符合 WCAG 2.1 AA 标准。

## 2. 测试环境

- **屏幕阅读器**: NVDA, JAWS, VoiceOver
- **浏览器**: Chrome, Firefox, Safari
- **操作系统**: Windows, macOS, iOS

## 3. 测试项目

### 3.1 页面结构

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 标题层级 | 正确使用 h1-h6 | 待检查 |
| 地标元素 | 使用 nav, main, aside 等 | 待检查 |
| 跳过链接 | 提供跳到主内容链接 | 待检查 |

### 3.2 表单可访问性

| 检查项 | 要求 | 状态 |
|--------|------|------|
| 标签关联 | label 与 input 正确关联 | 待检查 |
| 错误提示 | 清晰描述错误信息 | 待检查 |
| 必填标识 | 明确标识必填字段 | 待检查 |

### 3.3 键盘导航

| 检查项 | 要求 | 状态 |
|--------|------|------|
| Tab顺序 | 符合逻辑顺序 | 待检查 |
| 焦点可见 | 焦点样式清晰可见 | 待检查 |
| 快捷键 | 提供键盘快捷键 | 待检查 |

## 4. 测试用例

### TC-A11Y-001: 首页导航

**步骤**:
1. 打开首页
2. 使用 Tab 键导航
3. 验证焦点顺序

**预期**: 可以顺利导航到所有功能

### TC-A11Y-002: 阅读器体验

**步骤**:
1. 打开小说阅读器
2. 使用屏幕阅读器阅读内容
3. 验证章节切换

**预期**: 内容可被正确朗读
