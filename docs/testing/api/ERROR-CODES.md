## 1. 错误代码结构

### 1.1 代码格式

错误代码采用 4 位数字格式：`XYZZ`

| 位置 | 含义 | 说明 |
|------|------|------|
| **X** | 错误级别 | 1-系统, 2-业务, 3-第三方, 4-客户端 |
| **Y** | 模块分类 | 0-通用, 1-用户, 2-小说, 3-书架, 4-评论, 5-支付 |
| **ZZ** | 具体错误 | 01-99 具体错误码 |

### 1.2 错误级别

| 级别 | 代码范围 | 说明 |
|------|----------|------|
| **系统错误** | 1000-1999 | 服务器内部错误 |
| **业务错误** | 2000-2999 | 业务逻辑错误 |
| **第三方错误** | 3000-3999 | 外部服务错误 |
| **客户端错误** | 4000-4999 | 请求参数错误 |

## 6. 错误处理示例

### 6.1 后端返回示例

```json
{
  "code": 2103,
  "message": "邮箱已注册",
  "errors": [
    {
      "field": "email",
      "message": "该邮箱已被注册",
      "code": "EMAIL_EXISTS",
      "value": "test@example.com"
    }
  ],
  "meta": {
    "timestamp": "2026-04-12T10:30:00Z",
    "requestId": "req_123456789",
    "path": "/api/users/register",
    "method": "POST"
  }
}
```

### 6.2 前端处理示例

```typescript
// 错误处理工具
class ErrorHandler {
  static handle(error: ApiError): void {
    switch (error.code) {
      case 2103: // 邮箱已注册
        message.error('该邮箱已被注册，请直接登录');
        break;
      case 2105: // 密码错误
        message.error('密码错误，请重试');
        break;
      case 4102: // Token过期
        authService.refreshToken();
        break;
      case 4200: // 请求过于频繁
        message.warning('操作过于频繁，请稍后再试');
        break;
      default:
        message.error(error.message || '操作失败，请重试');
    }
  }
}

// 请求拦截器
apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.data?.code) {
      ErrorHandler.handle(error.response.data);
    }
    return Promise.reject(error);
  }
);
```

## 7. 错误日志规范

### 7.1 日志格式

```json
{
  "timestamp": "2026-04-12T10:30:00.123Z",
  "level": "ERROR",
  "requestId": "req_123456789",
  "userId": "usr_001",
  "errorCode": 2103,
  "errorMessage": "邮箱已注册",
  "path": "/api/users/register",
  "method": "POST",
  "params": {
    "email": "test@example.com"
  },
  "stack": "...",
  "service": "user-service",
  "ip": "192.168.1.1"
}
```

### 7.2 日志级别

| 级别 | 使用场景 |
|------|----------|
| **DEBUG** | 调试信息，开发环境 |
| **INFO** | 正常业务日志 |
| **WARN** | 警告，可恢复错误 |
| **ERROR** | 错误，需要关注 |
| **FATAL** | 致命错误，系统异常 |
