# NovelHub 渗透测试文档

**版本**: v1.0  
**更新日期**: 2026-04-12

---

## 1. 测试目标

发现 NovelHub 系统的安全漏洞，确保系统能够抵御常见攻击。

## 2. 测试范围

- 用户认证系统
- API 接口安全
- 数据库安全
- 文件上传功能
- 敏感信息保护

## 3. 测试项目

### 3.1 SQL 注入

| 测试点 | 测试方法 | 预期结果 |
|--------|----------|----------|
| 登录接口 | `' OR '1'='1` | 登录失败 |
| 搜索接口 | `'; DROP TABLE users; --` | 正常搜索 |
| 用户查询 | `1 AND 1=1` | 正常返回 |

### 3.2 XSS 攻击

| 测试点 | 测试方法 | 预期结果 |
|--------|----------|----------|
| 评论功能 | `<script>alert('xss')</script>` | 内容被转义 |
| 用户名 | `<img src=x onerror=alert(1)>` | 内容被转义 |
| 小说标题 | `javascript:alert(1)` | 内容被转义 |

### 3.3 CSRF 防护

| 测试点 | 测试方法 | 预期结果 |
|--------|----------|----------|
| 转账操作 | 伪造请求 | 请求被拒绝 |
| 修改密码 | 伪造请求 | 请求被拒绝 |
