## 发现的问题

### 高优先级问题

#### 问题1: 新书速递空状态缺失
**位置**: index.html - renderNewBooks  
**问题**: 当NOVELS中没有isNew=true的数据时，列表为空，无提示  
**建议**: 添加空状态处理

```javascript
// 建议修复
function renderNewBooks() {
    const container = document.getElementById('newBooksList');
    const novels = NOVELS.filter(n => n.isNew).slice(0, 10);
    
    if (novels.length === 0) {
        container.innerHTML = '<div class="empty-state">暂无新书</div>';
        return;
    }
    
    // ... 原有渲染逻辑
}
```

---

#### 问题2: 收藏列表使用错误数据源
**位置**: my-bookshelf.html - renderFavoritesList  
**问题**: 使用n.isHot作为收藏标记，应为实际用户收藏数据  
**建议**: 接入真实收藏API或使用BOOKSHELF_DATA

---

### 中优先级问题

#### 问题3: 智能补全硬编码
**位置**: search.html - fetchSuggestions  
**问题**: 使用硬编码的mockSuggestions  
**建议**: 接入后端搜索建议API

---

#### 问题4: 阅读进度精度问题
**位置**: reading.html  
**问题**: 进度计算使用整数百分比，可能不够精确  
**建议**: 保留一位小数或使用千分比

---

### 低优先级问题

#### 问题5: 数据缓存策略缺失
**位置**: 全局  
**问题**: 每次页面加载都重新请求/生成数据  
**建议**: 添加localStorage缓存和过期机制
