## 🔧 技术实现

### 1. 主题切换
```javascript
themeToggle.addEventListener('click', () => {
    isDark = !isDark;
    if (isDark) {
        document.body.style.filter = 'invert(1) hue-rotate(180deg)';
        sunIcon.style.display = 'none';
        moonIcon.style.display = 'block';
    } else {
        document.body.style.filter = '';
        sunIcon.style.display = 'block';
        moonIcon.style.display = 'none';
    }
});
```

### 2. 移动端菜单
```javascript
mobileMenuToggle.addEventListener('click', () => {
    mobileNavMenu.style.display = 'block';
    setTimeout(() => mobileNavMenu.classList.add('active'), 10);
});

mobileNavClose.addEventListener('click', () => {
    mobileNavMenu.classList.remove('active');
    setTimeout(() => mobileNavMenu.style.display = 'none', 300);
});
```

### 3. 路径卡片切换
```javascript
document.querySelectorAll('.path-card').forEach(card => {
    card.addEventListener('click', function() {
        document.querySelectorAll('.path-card').forEach(c => c.classList.remove('active'));
        this.classList.add('active');
        showToast(`已切换到${pathNames[this.dataset.path]}路径`, 'success');
    });
});
```

### 4. Toast 提示系统
- 成功/错误/信息三种类型
- 渐入渐出动画
- 3 秒自动消失
- 右上角显示
