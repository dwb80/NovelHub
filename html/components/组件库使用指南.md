## 1. 组件库概述

NovelHub 组件库是一套基于 Web Components 和原生 JavaScript 的可复用 UI 组件集合，旨在提供一致的用户体验和高效的开发效率。

### 1.1 设计原则
- **一致性**: 遵循统一的设计规范
- **可访问性**: 支持键盘导航和屏幕阅读器
- **响应式**: 适配多种设备尺寸
- **轻量级**: 零依赖，原生实现

### 1.2 目录结构
```
html/components/
├── index.html                    # 组件库入口
├── base/                         # 基础组件
│   ├── toast.html               # Toast 提示
│   ├── loading.html             # Loading 加载
│   └── modal.html               # Modal 弹窗
├── search/                       # 搜索组件
│   └── search-suggest.html      # 搜索建议
├── reader/                       # 阅读器组件
│   ├── reader-settings.html     # 阅读设置
│   ├── chapter-toc.html         # 章节目录
│   └── bookmark.html            # 书签
└── bookshelf/                    # 书架组件
    ├── book-card.html           # 书籍卡片
    └── batch-select.html        # 批量选择
```

## 2. 基础组件

### 2.1 Toast 提示

#### 功能特性
- 四种类型：success、error、warning、info
- 自动关闭（默认 3 秒）
- 支持手动关闭
- 移动端适配

#### 使用方法

**引入组件**
```html
<div class="toast-container" id="toastContainer"></div>
<script src="../../components/base/toast.html"></script>
```

**调用方式**
```javascript
// 基础调用
Toast.show({
    type: 'success',
    message: '操作成功',
    title: '提示',
    duration: 3000,
    closable: true
});

// 快捷方法
Toast.success('操作成功');
Toast.error('操作失败');
Toast.warning('警告信息');
Toast.info('提示信息');
```

#### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| type | string | 'info' | 提示类型：success/error/warning/info |
| message | string | '' | 提示内容 |
| title | string | '' | 标题（可选） |
| duration | number | 3000 | 显示时长（毫秒），0 表示不自动关闭 |
| closable | boolean | true | 是否显示关闭按钮 |

---

### 2.2 Loading 加载

#### 功能特性
- 三种类型：旋转加载器、骨架屏、页面遮罩
- 支持自定义加载文案
- 按钮加载状态

#### 使用方法

**引入组件**
```html
<div class="loading-spinner" id="loadingSpinner"></div>
<div class="skeleton-container" id="skeletonContainer"></div>
<div class="page-loading" id="pageLoading"></div>
<script src="../../components/base/loading.html"></script>
```

**调用方式**
```javascript
// 显示/隐藏旋转加载器
Loading.showSpinner(container, '加载中...');
Loading.hideSpinner();

// 显示/隐藏骨架屏
Loading.showSkeleton(container, 'card', 6);
Loading.hideSkeleton(container);

// 页面加载遮罩
Loading.showPageLoading('正在加载...');
Loading.hidePageLoading();

// 按钮加载状态
Loading.setButtonLoading(button, true);
Loading.setButtonLoading(button, false);
```

#### 骨架屏类型
- `card`: 卡片骨架（小说卡片）
- `list`: 列表骨架（书籍列表）
- `paragraph`: 段落骨架（文章内容）

---

### 2.3 Modal 弹窗

#### 功能特性
- 四种类型：default、confirm、alert、input
- ESC 键关闭
- 点击遮罩关闭
- 回调函数支持

#### 使用方法

**引入组件**
```html
<div class="modal-overlay" id="modalOverlay"></div>
<div class="modal" id="modal">
    <div class="modal-header">
        <h3 class="modal-title" id="modalTitle">提示</h3>
        <button class="modal-close" id="modalClose">×</button>
    </div>
    <div class="modal-body" id="modalBody">
        <p class="modal-message" id="modalMessage"></p>
    </div>
    <div class="modal-footer" id="modalFooter">
        <button class="btn btn-secondary" id="modalCancel">取消</button>
        <button class="btn btn-primary" id="modalConfirm">确认</button>
    </div>
</div>
<script src="../../components/base/modal.html"></script>
```

**调用方式**
```javascript
// 基础调用
Modal.show({
    title: '确认删除',
    message: '确定要删除这个项目吗？',
    confirmText: '删除',
    cancelText: '取消',
    showCancel: true,
    type: 'confirm',
    onConfirm: () => {
        console.log('确认');
    },
    onCancel: () => {
        console.log('取消');
    }
});

// 快捷方法
Modal.confirm('确定要执行此操作吗？', () => {
    // 确认回调
});

Modal.alert('这是一条警告信息', '警告');

Modal.delete('确定要删除吗？', () => {
    // 删除确认回调
});
```

## 3. 搜索组件

### 3.1 SearchSuggest 搜索建议

#### 功能特性
- 搜索历史管理（本地存储）
- 智能补全
- 热门搜索
- 键盘导航（↑↓ 选择，Enter 确认，Esc 关闭）
- 输入防抖（300ms）

#### 使用方法

**HTML 结构**
```html
<div class="search-box-wrapper">
    <div class="search-box">
        <input type="text" id="searchInput" placeholder="搜索...">
        <button type="button" class="search-btn" id="searchBtn">搜索</button>
    </div>
    
    <!-- 搜索建议下拉 -->
    <div class="search-suggest-dropdown" id="searchSuggest">
        <div class="suggest-section" id="historySection">
            <div class="suggest-header">
                <span class="suggest-title">搜索历史</span>
                <button class="suggest-clear" id="clearHistory">清空</button>
            </div>
            <ul class="suggest-list" id="historyList"></ul>
        </div>
        
        <div class="suggest-section" id="suggestSection" style="display: none;">
            <div class="suggest-header">
                <span class="suggest-title">智能补全</span>
            </div>
            <ul class="suggest-list" id="suggestList"></ul>
        </div>
        
        <div class="suggest-section" id="hotSection">
            <div class="suggest-header">
                <span class="suggest-title">热门搜索</span>
            </div>
            <ul class="suggest-list" id="hotList"></ul>
        </div>
    </div>
</div>
```

**JavaScript 调用**
```javascript
const SearchSuggest = {
    input: document.getElementById('searchInput'),
    suggest: document.getElementById('searchSuggest'),
    currentIndex: -1,
    maxHistory: 20,
    
    init: function() {
        this.bindEvents();
        this.initHotSearch();
    },
    
    // ... 完整实现见 search-suggest.html
};

// 初始化
document.addEventListener('DOMContentLoaded', function() {
    SearchSuggest.init();
});
```

#### 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| maxHistory | number | 20 | 最大历史记录数 |
| debounceDelay | number | 300 | 防抖延迟（毫秒） |
| suggestCount | number | 5 | 智能补全数量 |
| hotCount | number | 8 | 热门搜索数量 |

## 6. 最佳实践

### 6.1 组件引入顺序
```html
<!-- 1. 样式 -->
<link rel="stylesheet" href="../../assets/css/base.css">
<link rel="stylesheet" href="../../assets/css/components.css">

<!-- 2. Toast 组件 -->
<div class="toast-container" id="toastContainer"></div>

<!-- 3. Modal 组件 -->
<div class="modal-overlay" id="modalOverlay"></div>
<div class="modal" id="modal">...</div>

<!-- 4. Loading 组件 -->
<div class="page-loading" id="pageLoading"></div>

<!-- 5. 组件脚本 -->
<script src="../../components/base/toast.html"></script>
<script src="../../components/base/modal.html"></script>
<script src="../../components/base/loading.html"></script>
```

### 6.2 错误处理
```javascript
// API 请求示例
async function fetchData() {
    try {
        Loading.showPageLoading();
        const data = await api.getData();
        // 处理数据
    } catch (error) {
        Toast.error('加载失败，请重试');
    } finally {
        Loading.hidePageLoading();
    }
}
```

### 6.3 移动端适配
- Toast 组件在移动端显示在底部
- Modal 组件在移动端全宽显示
- SearchSuggest 下拉在移动端从底部弹出
